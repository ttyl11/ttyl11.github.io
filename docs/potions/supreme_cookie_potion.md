# 🍪 至尊曲奇

## 基本信息

- **分类**: 元素变身 / 资源重置
- **稀有度**: 普通
- **使用时机**: 战斗内
- **目标**: 自身

## 描述

永久变[次元系](/powers/dimensional_power.md)；所有牌回满PP，并把消耗堆/抽牌堆/弃牌堆的牌全部洗入弃牌堆（手牌不动）。

## 详细机制

- **永久变次元系**：属性永久设定为次元系（跨战斗持续）。
- **满 PP**：所有 PP 卡牌 PP 回满。
- **全场重洗**：把抽牌堆、弃牌堆、**消耗堆**的牌全部洗入**弃牌堆**（手牌保持不动），相当于把三堆合并成一大沓弃牌堆。

## 小贴士

- **资源大洗牌 + 免 PP**：回满 PP + 三堆合一(连**消耗堆**都拉回来!)让几乎所有牌都重新变可用——等于把"耗掉的资源"一股脑回收,此战后续回合牌源极度充裕。
- **"消耗也被捞回"是隐藏亮点**：通常消耗牌是永久离场的,至尊曲奇打破这一规则把它们洗回弃牌堆,让"该用过已经用掉的牌"重新可抽,节奏直接重置。
- **手牌不动的用意**：当前手牌不洗,避免打断你正在布局的组合;只回收未使用的牌。若你想"两手抓",一波已经安排好的出牌顺序不会被打乱。
- **次元系 + 资源推进**：变次元系则长期走"次元"路线;这瓶短期真正值钱的是满PP和三堆回收,适合在一轮资源跑空后使用来续命续航。
- **与[PP药水](pp_potion.md)对比**：PP药水只回PP,至尊曲奇回PP+全面回收,附带变次元,但它是普通稀有度——资源重置能力的性价比在普通档位非常突出。
