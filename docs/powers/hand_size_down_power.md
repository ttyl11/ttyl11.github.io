# 梦缚

> **归属**：玩家可施加（施加给自身）
> **施加来源**：玩家卡牌[如梦令](/cards/character/ru_meng_ling.md)（打出时本场手牌上限 -2）

## 基本信息

- **类型**：减益（Debuff）
- **叠加方式**：按层数叠加（层数 = 本场降低的手牌上限）
- **可见**：否（隐身，不显示图标）

## 描述

本场战斗内，<span style="color:#d4a017;font-weight:600">手牌上限</span><span style="color:#d44;font-weight:600">-层数</span>。

## 详细机制

- **降低量 = 层数**：每次施加多少层，本场手牌上限就 -多少；多次施加会累加。
- **只影响持有者**：只降低被施加玩家的手牌上限。
- **本场战斗有效**：战斗结束时能力移除，上限自动还原。
