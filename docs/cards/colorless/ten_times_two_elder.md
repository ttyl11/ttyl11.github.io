# 十倍二长老？

<img src="/images/cards/ten_times_two_elder.png" alt="十倍二长老？" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 无色牌
- **能量消耗**: 0
- **类型**: 能力
- **稀有度**: 普通
- **目标**: 自身
- **可升级**: 是（1 级）

## 描述

每回合开始时，从<span style="color:#3aa675;font-weight:600">3</span>张角色卡中选择一张加入<span style="color:#d4a017;font-weight:600">手牌</span>。升级后打出时再从<span style="color:#3aa675;font-weight:600">3</span>张中选择一张加入。

## 升级后

每回合开始时，从<span style="color:#3aa675;font-weight:600">3</span>张<span style="color:#d4a017;font-weight:600">升级</span>其他角色卡中选择一张加入[<span style="color:#d4a017;font-weight:600">手牌</span>](/mechanics/hand.md)。打出时再从<span style="color:#3aa675;font-weight:600">3</span>张中选择一张加入。

## 小贴士

- **🔑 0 费持续供牌**：0 费能力，打出后整场战斗每回合开始（**先于抽牌**）弹出三选一，选中卡直接入手；长战斗能白嫖十几张外池卡，是跨池构筑的补给线。
- **候选池 = 五个原版角色池**：铁血战士、静默猎手、缺陷、亡灵法师、统治者五池合并，随机抽 <span style="color:#3aa675;font-weight:600">3</span> 张**互不重复**的候选；不含 mod 角色（索伦森/皮皮）与无色牌。
- **是三选一，不是随机塞**：候选生成后由玩家自选 1 张（必须选，不能跳过），主动权在自己手里。
- **升级有两处收益**：① 每回合的 3 张候选全部为升级形态；② 打出升级副本时立即额外三选一一次（候选同样升级）。升级当回合即可多拿一张。
- **多张不叠加**：能力为单例，重复打出不会让每回合多选一次；但打出**升级副本**会立刻再触发一次即时三选一，并把后续候选永久切成升级版（已升级状态不会被打回普通）。
- **先入手、再抽牌**：三选一发生在回合开始抽牌之前，拿到的牌已在手牌里，抽牌数与手牌上限结算都会把它算进去。
- **衍生牌**：候选与入手的牌都是战斗内衍生牌，战斗结束消失，不进牌组；打出时按卡面原费用结算。
- **性价比**：0 费、能力牌打出即离场（同一副本每场一次）；升级副本打出后等于每回合白拿一张升级外池卡，是极少数 0 费长线收益牌。
