# 集中

> **归属**：玩家与怪物均可持有（原版能力）
> **施加来源**：原版与 mod 的充能球相关卡牌/遗物/能力

<img src="/images/powers/focus_power.png" alt="集中" style="max-width:120px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 增益（Buff）
- **叠加方式**: 计数（按层数叠加）
- **可见**: 是
- **允许负值**: 是

## 描述

提升充能球的效力。

## 详细机制

- **效果**：每层集中为每个充能球的**被动数值**与**激发数值**各 +1。
- **影响范围**：所有充能球（原版与 mod 充能球都吃）。
- **不影响**：非充能球伤害、能力牌效果等其他数值。
