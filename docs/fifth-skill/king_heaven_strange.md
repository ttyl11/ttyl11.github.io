## 小贴士

- **格挡转双重输出是核心**：这张牌把"格挡"这个防御属性变成双重攻击——①自身+敌方全场格挡总和的攻击伤害 ②自身格挡 <span style="color:#3aa675;font-weight:600">300</span>%（升级 <span style="color:#3aa675;font-weight:600">500</span>%）的固定伤害。防御姿态反而是最佳输出时机，"防御即进攻"做到极致。
- **敌人格挡反成你的输出**：攻击伤害 = 自身格挡 + **所有敌方格挡**的总和（多人模式队友格挡**不计入**）。敌人叠格挡通常让你头疼，但这张牌让敌人格挡变成你的伤害来源——敌人格挡越高，这张牌打出的攻击伤害也越高，面对高格挡敌人收益翻倍。
- **攻击伤害是普通攻击，吃增伤也被格挡**：这一段伤害按普通攻击结算——自身[力量](/powers/strength_power.md)、敌方[易伤](/powers/vulnerable_power.md)、增伤类效果都会放大它；同理也会被敌人各自的格挡抵扣。结算时逐个敌人独立计算格挡减免。
- **格挡减费，30 格挡 = 0 费**：自身每满 <span style="color:#3aa675;font-weight:600">5</span> 点[格挡](/mechanics/block.md)耗能 <span style="color:#3aa675;font-weight:600">-1</span>（按整数除法，<span style="color:#3aa675;font-weight:600">29</span> 格挡也是减 <span style="color:#3aa675;font-weight:600">5</span> 费）。<span style="color:#3aa675;font-weight:600">25</span> 格挡即降至 <span style="color:#3aa675;font-weight:600">1</span> 费、<span style="color:#3aa675;font-weight:600">30</span> 格挡直接 <span style="color:#3aa675;font-weight:600">0</span> 费打出——配合防御流派叠格挡后，这张牌从 <span style="color:#3aa675;font-weight:600">6</span> 费降到免费。
- **固定伤害只取自身格挡，不含敌人**：固定伤害 = 自身格挡 × <span style="color:#3aa675;font-weight:600">300</span>%（升级 <span style="color:#3aa675;font-weight:600">500</span>%），只算自身格挡不算敌人。所以自身 <span style="color:#3aa675;font-weight:600">30</span> 格挡时，每个敌人吃 <span style="color:#3aa675;font-weight:600">90</span> 固定伤害（升级 <span style="color:#3aa675;font-weight:600">150</span>），下回合开始结算不可格挡、不吃力量。
- **迁鸣主动补格挡**：带[迁鸣](/mechanics/qianming.md)——变化牌堆时（打出/弃置/抽牌/消耗等常规牌堆变动）获得 <span style="color:#3aa675;font-weight:600">10</span> 点格挡，每次触发叠 <span style="color:#3aa675;font-weight:600">10</span>。不靠回合结束保留蓄格挡，而是靠攻防过程中反复换牌堆自动累积格挡，格挡越多，伤害+减费+固定伤害三重同步放大。
- **核心矛盾：格挡是防御资源也是输出资源**：格挡既能挡伤害又能转伤害，两个用途争抢同一资源。打出这张牌**不消耗自身格挡**，但格挡会留在身上继续抵伤——最佳时机是回合末格挡还没被打掉时爆发，同一段格挡先转成伤害、剩下的部分还能继续挡敌人反击。
- **升级固定伤害 +200%**：升级固定伤害百分比 <span style="color:#3aa675;font-weight:600">300</span>%→<span style="color:#3aa675;font-weight:600">500</span>%，即自身格挡 <span style="color:#3aa675;font-weight:600">30</span> 时固定伤害从 <span style="color:#3aa675;font-weight:600">90</span>→<span style="color:#3aa675;font-weight:600">150</span>。攻击伤害不变，升级只强化固定伤害这一项。
- **性价比**：<span style="color:#3aa675;font-weight:600">6</span> 费换全场格挡伤害 + 固定伤害双效合一，格挡减费机制让实际费用可能远低于 <span style="color:#3aa675;font-weight:600">6</span>，配合格挡流派是"防御即进攻"的核心定价。
