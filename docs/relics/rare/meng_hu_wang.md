# 猛虎王

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 稀有

### 数值参数

| 参数 | 数值 |
|---|---|
| 能量触发阈值 | 当前能量 > 5 |
| 每次给牌 | 1 张随机 X 费牌 |
| 进化阈值 | 累计打出 20 张 X 费牌 |
| 触发频率 | 每回合至多 1 次 |

## 描述

①每回合首次[gold]能量[/gold]大于[blue]5[/blue]时，向[gold]手牌[/gold]加入[blue]1[/blue]张随机[gold]X费牌[/gold]。②累计打出[blue]20[/blue]张[gold]X费牌[/gold]后，变化为[gold]万兽之尊·猛虎王[/gold]。

## 详细机制

- **X 费牌定义（拉通全卡池）**：X 费牌 = 耗能为 X、打出时消耗当前所有能量的牌（`EnergyCost.CostsX`）。范围不限于当前角色——**涵盖原版所有角色 + seer 全部角色 + 其它 mod 已注册的 X 费牌**，任何一方都算数、都可能被抽到。
- **①能量>5 触发**：判断的是**当前能量**（玩家本回合可用能量数值），首次超过 5（即 ≥6）时触发一次，向手牌随机加入一张 X 费牌。每回合至多触发 1 次（回合开始和打出牌后各检查一次）。X 费牌能吃下超标的能量，把"能量溢出"变成即时战力。
- **②20 张 X 费牌进化**：计数口径 = **我方累计打出的 X 费牌张数**（跨战斗累计）。达到 20 张后自动替换为[万兽之尊·猛虎王](/relics/epic/wan_shou_zhi_zun_meng_hu_wang.md)（`RelicCmd.Replace`），进化只换遗物本身，进度换算为万兽之尊的长期收益。**遗物图标角标实时显示累计 X 费牌打出数**。
- **随机 X 费牌加入手牌**：从全卡池随机 pick 一张 X 费牌（排除状态/诅咒/任务牌），创建实例加入手牌，立即可用。

## 小贴士

- **能量能叠到 6+ 的构筑优先考虑**：本遗物吃"高能量"环境——能量上限高的角色/遗物（如能量药水、加能量上限的能力）最容易触发①，把多余能量转化为 X 费牌再打出去，形成"能量-卡牌"循环。
- **想速进化就多拿 X 费牌**：X 费牌打出既算进化进度，又因消耗所有能量而触发高 X 值效果。手牌里 X 费牌越多，进化越快；进化后（万兽之尊）还会继续放大 X 费牌收益。
- **拿到手首回合就能开始刷**：①在回合开始检查能量，能量>5 立即给一张 X 费牌，配合高能量起手可以"第一回合就白拿一张 X 费牌再打出"。
