# 弹控（DanKong）

**弹控**是 Seer Mod 的自定义卡牌关键词，持有者免疫[异常状态](/mechanics/abnormal-status.md)并反弹给来源。

## 基本信息

| 项目 | 说明 |
| --- | --- |
| 类型 | Mod 卡牌关键词（免疫+反弹型） |
| 效果 | 免疫并反弹异常状态 |
| 适用 | 卡面缩写术语，配合具体回合数出现 |

## 规则说明

- **免疫**：持有者不会获得异常状态
- **反弹**：本该施加给持有者的异常状态会反转施加给来源方（敌人对持有者施加异常 → 该异常落到敌人自己身上）
- 对比：[免控](/mechanics/mian_kong.md)是纯免疫；弹控在免疫基础上带回反制，适合用来惩罚喜欢上状态的敌人
