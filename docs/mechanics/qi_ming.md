# 齐鸣（QiMing）

**齐鸣**是 Seer Mod 的自定义卡牌关键词，同名牌每打出一次，此牌费用 -1。

## 基本信息

| 项目 | 说明 |
| --- | --- |
| 类型 | Mod 卡牌关键词（费用减免型） |
| 效果 | 同名牌每打出一次，费用 -1 |
| 适用 | 卡面缩写术语，最低 0 费 |

## 规则说明

- **计数来源**：本场战斗中打出过多少张与此牌同名的牌
- 每多打出一张同名牌，此牌费用 -1（最低降至 0 费）
- 例：打出第 1 张三费的同名牌后，下一张同名牌 2 费，再下一张 1 费……以此类推
- 适合多张同名卡在手的构筑，形成"越打越便宜"的连环节奏
