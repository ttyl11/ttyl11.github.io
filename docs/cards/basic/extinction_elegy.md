## 升级后

PP: 5/5 [吸强](/mechanics/xi_qiang.md)。对所有敌人造成<span style="color:#3aa675;font-weight:600">11</span>点伤害。

## 详细机制

- **吸强**：对每个敌人，若其[全属性](/mechanics/all_attributes.md)提升（力量/防御/命中/速度四项的正值层数）> 0，则将该项从敌人移除，并以等量施加给自身。一个敌人 4 项全有 = 把它的全部属性升级搬到自己身上。
- **只取正值**：敌人的负值层数（属性降低）不受影响；自身只获得敌人原有的正值强度，不获取下降值。
- **群体输出**：清除属性后对所有敌人同时造成伤害，面伤自带补刀能力。

## 小贴士

- **属性搬家的核弹**：面对爱叠属性的敌人（尤其是回合开始放 buff 的精英/Boss），这张牌一边清零敌方强化、一边把自己喂满——敌人若有 5 层力量、3 层防御，打完你就变成 +5 力量 +3 防御的全场输出手。本质是"敌方越强，我越强"的反打牌。
- **升级优先级很高**：伤害 <span style="color:#3aa675;font-weight:600">7 → 11</span>，纯 +4 面板；属性搬运部分不随升级变化，但前期能更快给小怪收尾。
- **先清后打的顺序**：先搬运属性再结算伤害——搬运来的力量在当回合就能为这张牌自己的 11 点伤害提供加成，团战里配合高力量敌人可打出巨额伤害。
- **性价比**：<span style="color:#3aa675;font-weight:600">1</span> 费 = 群体清属性 + 自强化 + 面伤三位一体，对手越强收益越高。
