# 工程师苏克

## 基本信息

* **分类**: 非塔罗遗物

* **稀有度**: 商店

## 描述

拾起时，在休息处获得「核心跃迁」选项：选择一个已拥有的遗物，将其稀有度提升一阶。

* **升级路径**：普通 → 罕见 → 稀有 → Seer 史诗 → Seer 传说。

* **升级范围**：普通升**全部**罕见池、罕见升**全部**稀有池（原版 + seer + 其它 mod）；稀有升 Seer 史诗池、Seer 史诗升 Seer 传说池；目标池会排除初始/商店/事件遗物。

* **不可升级**：初始、商店、事件遗物不可作为升级源；没有自定义稀有度的先古遗物不可选；传说遗物已是终点。没有可升级遗物时选项仍会显示，但选择后不会发生替换。

## 小贴士

* **遗物品质跃升**：每次休息只能把一件遗物升**一阶**（普通→罕见→稀有→史诗→传说），多次休息才能连续跃升；是稳定提升遗物质量的手段。

* **升级池**：从**高一阶**的池子随机抽取，并排除初始/商店/事件类遗物；原版没有史诗/传说，所以“稀有以上”两阶只会升成 Seer 遗物。

* **史诗→传说**：Seer 系列的史诗遗物可通过此遗物升级为传说遗物，是获取传说遗物的主要途径之一。

* **搭配策略**：适合搭配遗物数量多、升级需求高的构筑（如堆遗物的"遗物流"）。前期拿到可尽早规划遗物品质路线。

* **注意遗物上限**：升级后遗物替换为新遗物，若总遗物数过高会触发遗物上限惩罚，建议控制升级节奏。

* **性价比**：商店稀有度合理——每次休息就能自由升级一件遗物，长期收益远超一次性宝箱。
