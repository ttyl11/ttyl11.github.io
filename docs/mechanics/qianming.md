# 迁鸣（QianMing）

**迁鸣**是赛尔（Seer）职业独有的稀有关键词，控制带有此关键词的牌在牌堆发生变化时的触发行为。

## 规则说明

| 项目       | 说明                                                                         |
| ---------- | ---------------------------------------------------------------------------- |
| 适用范围   | 仅赛尔角色牌                                                                     |
| 触发时机   | **此牌自身**在牌堆之间移动时（抽到手牌、弃牌、洗回抽牌堆、进入消耗堆等）                       |
| 不触发     | 进入打出堆（被手动打出的瞬间）不触发；离开打出堆归位时正常触发                                  |
| 效果       | 由该卡牌自定义效果；无自定义效果的卡牌此关键词仅作为标记，不产生额外效果                        |
| 关键词类型 | **触发型关键词**，具体效果写在卡牌描述里，关键词本身只提供触发时机                             |
| 与溯引关系 | 溯引只在"此牌被抽到手牌"时触发；迁鸣覆盖此牌在牌堆之间的各种移动                                |

**典型流程：**

1. **此牌移动**：这张迁鸣牌被抽到手牌、弃掉、洗回抽牌堆、进入消耗堆等。
2. **触发检测**：系统检测到这张牌发生了牌堆变化，立即触发其效果。
3. **效果结算**：由卡牌自定义逻辑执行（如扣金币、添加附魔、抽牌等）。
4. **打出例外**：这张牌被手动打出、进入打出堆的瞬间不触发；打出后离开打出堆归位时才算一次变化。

关键细节：

- 迁鸣是**触发型关键词**，关键词本身不写效果，效果写在卡牌描述里
- 触发条件是**这张牌自己换牌堆**，不是"任意牌换牌堆"；其它牌移动不会触发它
- 与**溯引**的区别：溯引只在被抽到手牌时触发；迁鸣覆盖这张牌在牌堆之间的各种移动
- 与**残鸣**的区别：残鸣只在这张牌被消耗时触发

## 与类似机制的区别

| 机制               | 区别                                                                   |
| ------------------ | ---------------------------------------------------------------------- |
| **溯引（SuYin）**  | 溯引仅在"被抽到手牌时"触发一次；迁鸣响应所有牌堆变更，触发条件更广              |
| **回响（Echo）**    | 回响只在己方回合开始时检查抽牌堆，把其中的回响牌复制到弃牌堆；迁鸣不限定时机和位置    |
| **真神（TrueGod）** | 真神牌只能被自动打出；迁鸣不限制牌的打出方式，只是提供额外触发效果                  |
| **残鸣（CanMing）** | 残鸣仅在被[消耗](/mechanics/exhaust.md)时触发；迁鸣的触发条件更为宽泛           |
