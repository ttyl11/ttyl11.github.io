# 殊死

> **归属**：玩家可施加（中性倒计时）
> **施加来源**：
> - [殊死一搏](/cards/character/desperate_last_stand.md)（卡牌——首次打出施加 16 层，之后每次打出把剩余回合减半）

## 基本信息

- **类型**: 中性（None）
- **叠加方式**: 计数（Counter）
- **可见**: 是

### 数值参数

| 参数 | 数值 |
|---|---|
| 剩余回合 | 16 |

## 描述

<span style="color:#3aa675;font-weight:600">16</span>回合后死亡。

## 详细机制

- **层数 = 剩余回合**，图标上直接显示当前层数。
- **递减时机**：自身回合结束时 -1；层数降到 0 时**自身立即死亡**（直接击杀，不造成伤害，可被[复活](/mechanics/revive.md)类效果救回）。
- **类型为中性**（既非增益也非减益），因此**不会被净化 / 清增益 / 清减益类效果移除**——只能靠打出[殊死一搏](/cards/character/desperate_last_stand.md)来加速倒计时。
- **加速方式**：每次打出殊死一搏，剩余回合**减半并向上取整**：16 → 8 → 4 → 2 → 1 → 1（剩 1 层时不再下降）。
- **卡面同步**：殊死一搏的卡面倒计时数值会实时跟随本能力层数（无论该牌在手中、抽牌堆还是弃牌堆）。

## 小贴士

- **这是纯粹的倒计时，不带任何增益**：它只是把"你还有几回合"可视化在能力栏上。
- **归零必死，没有豁免**：无论是否继续打牌，倒计时走完都会死亡。想活下来只能靠[复活](/mechanics/revive.md)或免疫死亡类效果对冲。
- **加速 = 自尽**：反复打出殊死一搏会让倒计时指数级缩短（16→8→4→2→1），所以打出次数就是"剩余寿命"的直接开关。
- **无法被净化**：不要指望用清减益手段解除它——设计上就是不可逆的代价。
