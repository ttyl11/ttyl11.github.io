# 残鸣（CanMing）

**残鸣**是赛尔（Seer）职业独有的稀有关键词，控制带有此关键词的牌在被[消耗](/mechanics/exhaust.md)时的行为。

## 规则说明

| 项目       | 说明                                                                             |
| ---------- | -------------------------------------------------------------------------------- |
| 适用范围   | 仅赛尔角色牌                                                                         |
| 触发时机   | 此牌被[消耗](/mechanics/exhaust.md)时                                            |
| 效果       | 从[消耗牌堆](/mechanics/exhaust_pile.md)中选择 1 张牌加入手牌；若无消耗牌则效果跳过        |
| 关键词类型 | **触发型关键词**，不在描述文字中显示，但会出现在关键词标注中                                                   |
| 资源循环   | 残鸣将消耗牌堆中的牌回收至手牌，形成"消耗→回收"的资源循环，提升单张牌的使用效率                    |

**典型流程：**

1. **打出卡牌**：带有残鸣的牌被打出并结算效果。
2. **进入消耗堆**：由于带有消耗关键词，该牌从手牌进入消耗堆。
3. **触发残鸣**：系统检测到残鸣关键词，立即从[消耗牌堆](/mechanics/exhaust_pile.md)随机选择 1 张牌加入手牌。
4. **继续游戏**：被选中的牌回到手牌，等待下次打出。

关键细节：

- 残鸣的触发时机在**消耗瞬间**，牌已进入消耗堆后才触发选择
- 若消耗牌堆为空，残鸣效果跳过（不产生任何效果）
- 被选中的牌随机从消耗牌堆中抽取，玩家无法指定具体哪张牌
- 与[蚀返](/mechanics/shifan.md)的区别：蚀返是生成复制品到抽牌堆，残鸣是从消耗牌堆回收已有牌

## 带残鸣的卡牌

- [神权忤逆](/cards/character/shen_quan_wu_ni.md)：被消耗时从消耗牌堆选择 1 张加入手牌

## 与类似机制的区别

| 机制               | 区别                                                                   |
| ------------------ | ---------------------------------------------------------------------- |
| **蚀返（ShiFan）** | 蚀返向[抽牌堆](/mechanics/draw_pile.md)生成本牌复制品；残鸣从消耗牌堆选已有牌入手       |
| **回响（Echo）**    | 回响每回合开始时从牌堆生成复制品到手牌；残鸣仅在被消耗时触发，触发条件更严格              |
| **消耗（Exhaust）** | 消耗是离场机制；残鸣是在消耗时触发回收效果，让牌以另一种形式回到手牌                    |
| **预见（Scry）**    | 预见操控牌堆顶；残鸣操控的是消耗牌堆，两者操作的牌堆区域不同                       |
