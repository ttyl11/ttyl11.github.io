# 源·宵

<img src="/images/relics/seer_yuan_xiao.png" alt="源·宵" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物

- **稀有度**: 罕见

## 描述

你每打出一张牌后，若[能量](/mechanics/energy)为 <span style="color:#3aa675;font-weight:600">0</span> 且手牌大于 <span style="color:#3aa675;font-weight:600">7</span> 张，获得 <span style="color:#3aa675;font-weight:600">1</span> 点能量。

- **触发时机**：每张牌结算完毕后判定一次。

- **条件**：当前能量恰好为 <span style="color:#3aa675;font-weight:600">0</span>，且手里还有超过 <span style="color:#3aa675;font-weight:600">7</span> 张牌。

- **奖励**：满足条件即白得 <span style="color:#3aa675;font-weight:600">1</span> 点能量。

## 风味文字

<span style="color:#d44;font-weight:600">宵尽天明，源远流长。</span>

## 小贴士

- **"掏空钱包还能赊一口"的引擎**：只要你这手牌打空能量后手里还攥着一把牌（>7 张），就再送 <span style="color:#3aa675;font-weight:600">1</span> 点能量。多打一张 = 多一个判断机会，越能连招的牌组越容易连踩触发。

- **手牌多 + 能量空 = 它的甜区**：抽牌猛、能铺手的流派天然适配——一轮里经常"能量打光但手里还是 7 张以上"，于是每打一张多回一口，甚至能把一回合的能量链续到别人不敢想。

- **注意它只在你"空能量"时才给**：能量还有富余时不触发，别指望它当常规产费。它是"断粮后的急救费"，不是"起步的加油费"。

- **别为它硬控手牌**：把牌攥在手里不打出会牺牲节奏。正确姿势是正常打，遇到"打空了但手牌还厚"的自然场景白嫖，而不是刻意憋牌。

- **性价比**：罕见定级合理，常态是锦上添花，但在抽牌流的能量链里能滚出惊人的额外行动，值得为它配多抽。
