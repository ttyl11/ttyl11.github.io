# 游戏流程改造

Seer Mod 对杀戮尖塔2 的游戏流程进行了全面改造，包括五幕流程、子地图系统、遭遇战比例调整、起始遗物注入、Neow 选项扩展、强制解锁 Neow 纪元六大方面。

::: tip Mod 扩展了什么
- 新增第四幕「星海尽头」与第五幕「终焉之门」：一局自动从三幕变五幕（见[第四幕与第五幕](./act-four-five)）
- 新增子地图系统：独立的长图战斗小关卡 + 活动小游戏（见[子地图与活动](./submap-activity)）
- 遭遇战比例调整：Mod 怪物与原版怪物的遭遇比例自动平衡
- 起始遗物注入：所有角色开局获得群星的礼赠
- Neow 选项扩展：为每个古代存在追加 Mod 遗物选项
- 强制解锁 Neow 纪元：无需完成前置进度即可访问 Neow
:::

## 五幕流程

- **幕数**：原版三幕扩展为五幕，第四幕「星海尽头」、第五幕「终焉之门」均为默认幕并进入随机幕列表，一局自动走完五幕。
- **遭遇**：第四、五幕的普通 / 精英池由前三层赛尔遭遇混编（不混原版），并按出身幕做生命、减伤、增伤缩放。
- **Boss**：第四幕 5 位、第五幕 4 位，均为本幕专属 Boss 池。
- **事件与先古**：事件沿用原版第三幕 7 个 + 13 个不限幕赛尔事件；先古各 1 位（圣光灵神 / 重生之翼）。

完整规则、缩放数值与策略见 **[第四幕与第五幕](./act-four-five)**。

## 子地图系统

### 概述

子地图是 Mod 独有的独立小关卡，**打完 Boss 后在奖励界面选「前往」进入**（见[子地图与活动](./submap-activity)），完成后返回下一幕原地图。地图规模随活动不同：单列 1~100 个战斗节点，或 3~6 列、70~150 行的分支长图；边推图边玩活动小游戏，玩法与奖励详见 **[子地图与活动](./submap-activity)**。

### 进入与返回

- **进入**：通过同步 Action 进入子地图，保存原地图状态（地图、已访问坐标、楼层、当前坐标）
- **入口随机**：每次进入随机抽中「界王神灵」「圣光的恩泽」「幽暗之证」「贪婪洞窟」「黑暗之心」「永恒幻瞳」「极天之翼」「王者之证」「地神试炼」「真命龙王」「激活节点」「探寻本心」之一（各 1/12），结果两端一致
- **开场先古**：进入后先触发一位先古之民（不回血、不给遗物，只固定给刻印）
- **嵌套支持**：子地图可以嵌套（继承旧 session 的原地图状态）
- **返回**：访问终点（最后一行战斗节点）后自动返回（通关但未领奖时会暂缓），也可在活动面板发起「退出关卡」全队表决；均恢复原地图状态
- **不死保障**：子地图内玩家生命归零不会死亡，会恢复到本场战斗开始时的生命值；单人局或全队同时归零时退出子地图，多人局只要有队友存活就继续战斗。极天之翼、地神试炼改为扣机会 / 回合上限并留在原地
- **存档恢复**：支持从存档恢复子地图状态（终点已访问→恢复原版地图；未访问→重建 session 继续）

::: tip 子地图的战略意义
子地图是一段**无奖励、无死亡**的连续战斗，真正的产出是通关活动后拿到的一件史诗 / 传说遗物。只有界王神灵、圣光的恩泽、幽暗之证用战斗积攒「行动次数」，其余 9 个活动各有自己的推进资源（体力、种子、龙珠、词条等）。
:::

## 遭遇战比例调整

### 比例自动平衡

Mod 的怪物和事件与原版混合时，通过补丁自动调整比例：

- **按房间类型分组**：怪物房、精英房、Boss 房分别处理
- **目标比例**：Mod 条目数量 = 原版条目数量 × 比例 / (1 - 比例)
- **多余移除**：超出目标的 Mod 条目按条目 ID 排序移除（确定性，确保多人同步）
- **不足保留**：不足目标数量时保留全部 Mod 条目

### 事件均匀交错

- 重建事件列表，使用 Bresenham 算法均匀交错原版和 Mod 事件
- 确保两类事件在地图上均匀分布，避免聚集

### 存档修复

- 若存档中 Boss 房间为 null，用占位遇敌修复
- 让原版方法重新随机生成 Boss

## 起始遗物注入

### 群星的礼赠作为起始遗物

- **补丁目标**：游戏数据库初始化
- **注入方式**：遍历所有角色模型（含 Mod 角色），为每个角色注册群星的礼赠为起始遗物
- **效果**：所有角色开局自动获得群星的礼赠

::: tip 群星的礼赠的普适性
群星的礼赠是所有角色的通用起始遗物，提供[遗物宝库](./relic-right-click)右键功能。这意味着无论选择哪个角色，都能通过右键群星的礼赠获取 30 选 1 的遗物。
:::

## Neow 选项扩展

### 选项池扩展

Mod 为 Neow（以及其它古代存在）的选项池追加了 27+ 个 Mod 遗物选项：

| 古代存在 | 追加选项数 |
| --- | --- |
| Neow | 27（15 普通 + 12 先古塔罗） |
| Darv | 5 |
| Vakuu | 9 |
| Pael | 5 |
| Tanx | 5 |
| Tezcatara | 5 |
| Orobas | 10 |
| Nonupeipe | 6 |

### 选项抽取接管

- **补丁目标**：Neow 初始选项生成
- **接管方式**：Postfix 完全替换原版抽取结果
- **抽取流程**：
  1. 过滤已锁定选项
  2. 过滤不允许的遗物
  3. Fisher-Yates 洗牌（消耗古代事件的 RNG）
  4. 取前 4 个作为初始选项
  5. 对尘封之书选项进行先古牌初始化确保非空

### 尘封之书特殊处理

- 尘封之书选项需要确保先古牌不为空
- 调用先古牌初始化方法进行多级回退查找
- 详见 [卡牌池扩展](./card-pool-extension)

## 强制解锁 Neow 纪元

### 概述

原版需要完成前置进度才能解锁 Neow 纪元。Mod 通过补丁强制解锁，让玩家无需前置进度即可访问 Neow。

### 实现

- **补丁目标**：存档管理器的解锁状态生成
- **补丁类型**：Prefix
- **逻辑**：检查是否已有 Neow 纪元但未显示，若是则强制解锁显示

## 整体流程

综合以上改造，Seer Mod 的游戏流程为：

1. **游戏开始**：强制解锁 Neow 纪元，所有角色获得群星的礼赠为起始遗物
2. **Neow 事件**：选项池包含 27+ 个 Mod 遗物选项，4 选 1
3. **地图探索**：遭遇战比例自动平衡，Mod 与原版怪物/事件均匀分布
4. **子地图**：打完会推进到下一幕的 Boss 时，奖励界面 Proceed 会问「是否前往打怪」，选前往即随机进入一个活动，通关后带走一件史诗 / 传说遗物（见[子地图与活动](./submap-activity)）
5. **商店**：精英战后用赛尔豆买卡/服务/遗物；在休息处右键星辰之录，用泰坦之灵抽永久属性
