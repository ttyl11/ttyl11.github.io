# 古代巨型机器人

<img src="/images/relics/ancient_giant_robot.png" alt="古代巨型机器人" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物

- **稀有度**: 史诗（自定义稀有度）

### 数值参数

| 参数             | 数值         |
| -------------- | ---------- |
| 四态触发后获得最大生命    | 25% 当前最大生命 |
| 战斗结束每满 PP 牌增益  | +1 最大生命    |
| 战斗结束每不满 PP 牌减益 | -1 最大生命    |

## 描述

①打出不同类别的牌获得对应充能球/栏位：攻击牌→闪电充能球，技能牌→冰霜充能球，能力牌→玻璃充能球，其他牌→充能球栏位。②当①的四种奖励各获得过至少一次时，①本场战斗失效，随后获得 <span style="color:#3aa675;font-weight:600">25</span>%最大生命。③战斗结束时结算：每有一张满 PP 的牌最大生命 <span style="color:#d4a017;font-weight:600">+1</span>，每有一张不满 PP 的牌最大生命 <span style="color:#d4a017;font-weight:600">-1</span>。

## 详细机制

- **①的牌类判定**：按牌类型分四类——攻击牌产[闪电](/orbs/lightning_orb.md)、技能牌产[冰霜](/orbs/frost_orb.md)、能力牌产[玻璃](/orbs/glass_orb.md)，其余（先古牌、无色牌、诅咒牌、状态牌等）产[充能球栏位](/mechanics/channeling.md)。打出顺序不限，四种各出一次即完成。

- **①的充能球结算**：闪电和冰霜为原版对应充能球（每次回合开始自动激发产生伤害），玻璃为原版效果（激发时恢复格挡）。栏位 +1 为永久增加，不影响任何已有充能球。

- **②的触发与切换**：四种类型各打出过至少 1 张的瞬间，①立即失效（后续出牌不再产充能球），同时立即结算约等于当前最大生命四分之一的最大生命增益。失效后闪一下图标。

- **③的战斗结束结算**：在战斗结束时触发，只处理**牌组中的牌**（排除战斗中临时衍生的非牌组牌）且拥有 PP 概念的牌。满 PP 每张 +1 最大生命，不满 PP 每张 -1 最大生命。战斗结束时有任意变化则闪图标。

- **③与②的叠加**：②获得的最大生命是永久增益（进入下一场战斗保留），③的战斗结束结算同样作用于当前最大生命并在战斗结束后持久保留——两条路径都能提升最大生命，互不冲突。

- **③的牌必须是 PP 牌**：普通牌（无 PP 系统）不参与结算；满 PP 和不满 PP 的判断基于战斗结束时该牌的实际 PP 值，不是初始值。

## 小贴士

- **①是一条 4 步解锁链，②是终点**：前中期靠打出各类牌积累充能球和栏位，一旦四种各出过一次，①立即停止，换取 25% 最大生命的即时效应——相当于用后续出牌的引擎收益换了一波即时坦度。拿到这 25% 之前，出牌策略要优先覆盖四种类型。

- **①的核心是"出一张攻击牌就够了"**：闪电、冰霜、玻璃各一张、栏位各一次，四条全打出来就能触发②。最经济的打法是每类出一张低费牌完成解锁，然后把剩余手牌当普通牌打出（不再产充能球但也不亏，因为②已经触发）。

- **③是一把双刃剑**：满 PP 牌越多，③收益越大；但牌组里有任何一张不满 PP 的 PP 牌，战斗结束时就会掉最大生命。如果你牌组里的 PP 牌没有用完，或者打完了但没满（比如打到了 2/3），③反而在扣血——需要合理控制 PP 消耗节奏，或者牌组 PP 牌本身打满后再用③收尾。

- **②和③是同一枚遗物的两条成长路径**：②走"快速解锁换坦度"路线，适合速通流；③走"留到战斗结束看 PP 状态结算"路线，适合牌组里 PP 牌占比高且倾向打满的构筑。两条路径可以叠加：先靠①打完四种充能球触发②，再在后续战斗中用③进一步叠最大生命。

- **最大生命增益在战斗外保留**：②获得的 25% 最大生命和③结算后的增减都是跨战斗持久的，可以在多场战斗中累积——每场战斗都能通过③微调，通过②批量暴涨。

- **性价比**：史诗合理——①在前中期提供稳定的充能球产出（闪电/冰霜/玻璃三球都有独立战术价值），②是一次性坦度跃升，③提供战斗结束时的 PP 状态博弈。四条联动但分阶段生效，不是无脑强，需要规划出牌顺序。
