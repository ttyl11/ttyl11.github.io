# 秒杀（MiaoSha）

**秒杀**是 Seer Mod 的自定义卡牌关键词，有概率直接击杀目标（对 Boss 无效）。

## 基本信息

| 项目 | 说明 |
| --- | --- |
| 类型 | Mod 卡牌关键词（即死型） |
| 效果 | 有概率直接击杀目标（对 Boss 无效） |
| 适用 | 卡面缩写术语，常配合具体概率出现 |

## 规则说明

- **即死判定**：攻击时按给定概率判定命中即杀——无论目标剩余多少生命，直接击杀
- **对 Boss 无效**：Boss 敌人免疫秒杀；只对普通怪/精英生效
- 概率式关键词，赌中收益极大（一张牌解决高血量精英），未命中则按普通结算
- 例：[绝命火焰](/cards/character/fatal_flame.md)的"X% 概率秒杀（对 Boss 无效）"
