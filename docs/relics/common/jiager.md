## 基本信息

* **分类**: 非塔罗遗物

* **稀有度**: 普通

### 数值参数

| 参数   | 数值                   |
| ---- | -------------------- |
| 易伤层数 | {VulnerableAmount} 层 |
| 力量加成 | {StrengthAmount} 点   |

## 描述

战斗开始时，为自身施加{VulnerableAmount}层[易伤](/powers/vulnerable_power.md)，并获得{StrengthAmount}点[力量](/powers/strength_power.md)。

<span style="color:#d44;font-weight:600">加格尔。</span>

## 小贴士

* **代价与收益并存**：以易伤（受到伤害 ×1.5）换取力量（攻击伤害+每层）的即时增益，需在战斗前权衡风险。

* **战斗内生效**：易伤和力量都在战斗开始时施加，当场比赛内持续存在，无法中途关闭。

* **易伤的持续影响**：{VulnerableAmount} 层易伤使受到的攻击伤害 ×1.5，高难度战斗中面对高伤害敌人时风险显著。

* **力量的进攻收益**：力量每层增加 1 点攻击伤害，配合高频攻击牌组可快速回本。

* **普通稀有度定位**：高风险高回报遗物，适合能承受额外伤害、以力量为核心输出的牌组；不擅长防守的跑局慎拿。
