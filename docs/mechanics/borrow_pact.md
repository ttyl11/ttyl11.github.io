# 彼岸契约

**彼岸契约**是 Seer Mod 的自定义卡牌关键词，效果是数场战斗后此牌自动从你的牌组中移除。

## 基本信息

| 项目 | 说明 |
| --- | --- |
| 类型 | Mod 卡牌关键词（效果型） |
| 效果 | 在数场战斗后从你的[牌组](/mechanics/card-pool-extension.md)中移除 |
| 触发时机 | 战斗结算后 |

## 规则说明

- 携带此关键词的牌会自动倒计时，数场战斗后从牌组中消失，无需玩家操作
- 相当于带期限的借用牌：过期即离场，适合暂时借用强力牌、临时代偿等待定构筑的场面
- 与[化墟](/mechanics/ruination.md)（打出一张随机状态牌进弃牌堆）、[寂灭](/mechanics/nirvana.md)（战斗结束从牌组移除）的区别：彼岸契约是**按战斗场数**自动移除，不过问是否打过

## 与类似关键词的区别

| 关键词 | 区别 |
| --- | --- |
| [寂灭](/mechanics/nirvana.md) | 打出后本场战斗结束从牌组移除；彼岸契约按场数自动移除 |
| [化墟](/mechanics/ruination.md) | 打出时向弃牌堆加随机状态牌；彼岸契约是场数到期移除 |
