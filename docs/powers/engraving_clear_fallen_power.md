# 堕落净化

> **归属**：玩家可施加
> **施加来源**：刻印「恐怖深渊刻印」赐予（此后每场战斗开始时获得）

## 基本信息

- **类型**：中性（None）
- **叠加方式**：不叠加
- **可见**：是

## 描述

每回合开始时，移除自身全部[red]堕落[/red]。

## 详细机制

- **触发时点**：你的回合开始时。
- **移除方式**：直接移除整个「堕落」能力（不是减少层数）；没有堕落时无事发生。
