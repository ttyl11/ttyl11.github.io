# 🟢 绿火

## 基本信息

- **分类**: 增益
- **稀有度**: 普通
- **使用时机**: 战斗内
- **目标**: 自身

### 数值参数

| 参数 | 数值 |
|---|---|
| 全属性加成 | +1 / 回合 |
| 立即加成 | +1 |

## 描述

获得全属性+<span style="color:#3aa675;font-weight:600">1</span>。每回合开始时，再次获得全属性+<span style="color:#3aa675;font-weight:600">1</span>。

## 详细机制

- **立即生效**：喝下的瞬间就给[力量](/powers/strength_power.md)、[命中](/powers/accuracy_power.md)、[防御](/powers/defense_power.md)、[速度](/powers/speed_power.md)四项属性各 +1。
- **每回合叠加**：[绿火](/powers/green_fire_power.md)能力让**每个回合开始**再为四项属性各 +1，滚雪球。
- **四条腿走路**：力量=伤害、命中=伤害命中率、防御=减伤、速度=先手与回避，四项同时成长，攻防速一手抓。
- **持续整场**：速度和绿火能力本身不消退（防御/力量等属性能力通常也持续整场），回合越多累积越高。

## 小贴士

- **滚雪球之王**：这是四瓶火焰里"上限最高"的一瓶。第 1 回合四维 +1，往后每回合再 +1——第 3 回合就是四维 +3、第 5 回合四维 +5。把单回合收益拆开看，前期平平，中期开始质变。
- **打的就是持久战**：回合数越多，绿火累计的纯收益越恐怖。开场就喝，享受最大累积；适合搭配长线控制/磨血卡组，撑过前几回合后接管游戏。
- **全能但不突出**：&quot;四维各 +1/回合&quot;任何单项都不算爆炸，但胜在全面——既加输出又加防御又加速。对于缺哪补哪、没有明确路线的卡组来说是最稳妥的选择。
- **与单维增益对比**：若你的卡组极度偏攻击（一堆力量卡），[紫火](purple_fire_potion.md)的 50% 伤害放大可能更直接；但绿火在"既要又要"的均衡卡组里性价比远超任何单一属性。
- **首次喝的时点**：能力牌/阈值类构筑（如命中触发某个增伤阈值）尤其赚，早喝一回合就多叠一层。
