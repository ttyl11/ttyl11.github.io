# 异常反噬

> **归属**：玩家可施加
> **施加来源**：刻印「锦·嫣红」赐予（仅当前这场战斗）

## 基本信息

- **类型**：中性（None）
- **叠加方式**：不叠加
- **可见**：是

## 描述

每回合开始时，对每个敌人造成其[red]异常状态[/red]层数×[blue]5[/blue]点的[gold]固定伤害[/gold]。

## 详细机制

- **触发时点**：你的回合开始时。
- **统计口径**：把该敌人身上全部[red]异常状态[/red]的层数求和（27 种异常，不分类别），再 ×5；没有异常层数时不施加。
- **结算方式**：施加等量的[gold]固定伤害[/gold]能力，在该敌人自己的回合开始时结算，不是当场扣血。
- **目标**：所有存活敌人，逐个独立计算。
