## 小贴士

- **Boss战核弹，伤害翻倍是核心**：在 Boss 房间（按房间类型判定）基础伤害 ×<span style="color:#3aa675;font-weight:600">2</span>——<span style="color:#3aa675;font-weight:600">35</span> 伤变 <span style="color:#3aa675;font-weight:600">70</span>，升级 <span style="color:#3aa675;font-weight:600">50</span> 伤变 <span style="color:#3aa675;font-weight:600">100</span>。这张牌就是为 Boss 战准备的终结卡，普通战斗和精英战不享受翻倍，尽量留给 Boss。
- **按普通攻击伤害结算**：<span style="color:#3aa675;font-weight:600">35</span>/<span style="color:#3aa675;font-weight:600">50</span> 点（Boss 翻倍后 <span style="color:#3aa675;font-weight:600">70</span>/<span style="color:#3aa675;font-weight:600">100</span>）是普通攻击伤害，会吃[力量](/powers/strength_power.md)、目标[易伤](/powers/vulnerable_power.md)与暴击加成，也会被格挡。
- **双异常压制——麻痹 + 害怕叠出 63% 减攻**：同时施加[麻痹](/powers/ma_power.md) + [害怕](/powers/fear_power.md)各 <span style="color:#3aa675;font-weight:600">2</span> 回合。麻痹令其攻击伤害 -10%，害怕再令攻击伤害 -30%——两者相乘，Boss 的攻击输出直接打到 **63%**（0.9 × 0.7）。这两个减伤都只作用于**攻击伤害**，不削减灼烧、固定伤害这类非攻击伤害。
- **麻痹的易伤基本吃不到**：麻痹在该敌人的回合开始时给它挂 <span style="color:#3aa675;font-weight:600">1</span> 层[易伤](/powers/vulnerable_power.md)，但这层易伤会在**该敌方回合结束时**立刻减 <span style="color:#3aa675;font-weight:600">1</span> 层消失——轮到你出牌攻击时它已经不在了。所以不要把它当成"2 回合叠 2 层"的增伤窗口；它只覆盖敌方回合内发生的攻击结算。
- **减伤与增伤的消耗条件不同**：自身获得[减伤](/powers/next_damage_reduction_power.md)（<span style="color:#3aa675;font-weight:600">50</span> 层，下次受到的攻击伤害减半）与[增伤](/powers/next_damage_boost_power.md)（<span style="color:#3aa675;font-weight:600">100</span> 层，下次攻击伤害翻倍）。减伤只要发生一次伤害结算就会消失——哪怕这次攻击被完全格挡、实际掉血为 <span style="color:#3aa675;font-weight:600">0</span>，也包括灼烧、固定伤害这类非攻击伤害；增伤则在你的**下一次攻击命令结算完后**移除，同样不管那次攻击有没有打出伤害。两者都不作用于非攻击伤害。
- **同名牌减费，越打越便宜**：打出后获得减费能力，同名牌每次打出费用 <span style="color:#3aa675;font-weight:600">-1</span>（最低 <span style="color:#3aa675;font-weight:600">0</span>）。首次 <span style="color:#3aa675;font-weight:600">4</span> 费，第二次 <span style="color:#3aa675;font-weight:600">3</span> 费，第三次 <span style="color:#3aa675;font-weight:600">2</span> 费……第五次开始 <span style="color:#3aa675;font-weight:600">0</span> 费。多张同名卡在长战斗中反复打出后实际成本极低。
- **升级 +15 伤，Boss 战相当于 +30**：升级 <span style="color:#3aa675;font-weight:600">35</span>→<span style="color:#3aa675;font-weight:600">50</span>，Boss 战翻倍后相当于 +<span style="color:#3aa675;font-weight:600">30</span> 伤（<span style="color:#3aa675;font-weight:600">70</span>→<span style="color:#3aa675;font-weight:600">100</span>）。其它效果不变，升级只强化伤害。
- **爆发回合的"全套服务"**：伤害 + 双异常 + 减伤 + 增伤 + 减费五效合一，但增伤减伤只下次生效、双异常只 2 回合——打出后要立即跟进输出牌利用增伤窗口，别浪费那 100% 增伤。
- **性价比**：<span style="color:#3aa675;font-weight:600">4</span> 费换 <span style="color:#3aa675;font-weight:600">35</span> 伤（Boss <span style="color:#3aa675;font-weight:600">70</span>）+ 攻防双向异常 + 减伤增伤 + 减费。普通战斗性价比一般，**Boss 战价值爆炸**——是值得为 Boss 战专门留着的终端卡。
