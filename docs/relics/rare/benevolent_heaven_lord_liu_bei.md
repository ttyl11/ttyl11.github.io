# 仁天之君·刘备

<img src="/images/relics/benevolent_heaven_lord_liu_bei.png" alt="仁天之君·刘备" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 稀有

## 描述

回合开始时，自身每处于一种<span style="color:#d44;font-weight:600">[异常状态](/mechanics/abnormal-status.md)</span>，则随机对敌人施加[攻击无效](/mechanics/intent)或[封属](/mechanics/intent)（随机一个）。

- **触发条件**：仅在我方回合开始时触发，统计自身当前处于的异常状态种类数（不累计层数，仅按种类计数）。
- **目标范围**：每个异常状态对应一次随机施加，随机选一个敌人施加攻击无效或封属，可能多次命中同一敌人（每个敌人最多各 1 个，同类不叠加）。
- **封印效果**：施加的封印只让对应类型意图的效果失效——攻击无效只废攻击意图，封属只废非攻击意图；单个封印不会阻止另一类型的意图执行。

## 小贴士

- **封印是"按类型"而非"整回合"**：每次施加攻击无效或封属只废对应类型的意图——攻击无效只废攻击、封属只废非攻击。敌人排"攻击 + 增益 + 召唤"且只被施加攻击无效时，攻击失效但增益/召唤照常；只有被同时施加两种封印（攻击无效 + 封属）才整回合空过。想封死一个复合行动，需要集齐两个封印。
- **按种类计数，不按层数**：统计的是异常状态**种类数**——凝滞 3 层 + 失明 2 层只算 2 种。只需要种类多样，不需要叠层数，1 层就顶 1 个名额。
- **每种异常状态换一次随机施加**：N 种异常状态 = N 次独立随机选敌人并施加攻击无效或封属。**选择可能重复命中同一敌人**——重复点同一个敌人时，若它已集齐两种封印则浪费（同类不叠加），否则补上它缺少的类型。敌人数量越接近异常状态种类数，点名越不浪费。
- **单体 Boss 时 2 种就够**：Boss 一回合只有一个行动，攻击无效 + 封属各 1 个就能把 Boss 整回合封死，额外的异常状态种类在单体战斗中是冗余——它们的价值在多敌人场景兑现。
- **异常状态是"燃料"，越多越好**：通常挨异常状态是坏事，在这件遗物手里是控制弹药。主动让自己进入多种不同异常状态（自施加类效果、敌方施加的异常都可以吃），把负面转化为每回合的群体封印。
- **触发时序在我方回合开始**：封印发生在你回合开始的那一刻——封掉的是敌人**即将执行**的本轮行动中对应类型的意图，正好护住你这一整个回合的输出环境。
