# 护盾反弹



<img src="/images/powers/reflect_block_power.png" alt="护盾反弹" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 增益（Buff）
- **叠加方式**: 叠加
- **可见**: 是

## 描述

本回合内，将自身<span style="color:#d4a017;font-weight:600">护盾</span>格挡的伤害反弹给攻击者。

## 详细机制

- **只反弹「被格挡」的部分**：按本次伤害总量减去实际掉血，得到被格挡的数值，原样反弹给攻击者。
- **反弹可被格挡**：反弹是普通无加成伤害，不是固定伤害——对方有格挡就能吃掉。
- **只反外部攻击**：来源必须是其他生物；自伤、无来源 DoT 不触发。
- **有效窗口**：从施加后一直持续到**敌方回合结束**才移除，正好覆盖敌人的进攻回合。
- **层数不影响数值**：层数只作为存在标记，反弹量始终是实际被格挡的伤害。
