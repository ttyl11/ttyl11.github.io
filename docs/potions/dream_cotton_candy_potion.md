# 🍬 梦境边陲棉花糖

## 基本信息

- **分类**: 元素变身 / 随机变化
- **稀有度**: 普通
- **使用时机**: 战斗内
- **目标**: 自身

## 描述

永久变[超能系](/powers/psychic_power.md)；手牌中至多<span style="color:#3aa675;font-weight:600">3</span>张牌随机变化为另一张随机牌（变换临时，仅当次生效）。

## 详细机制

- **永久变超能系**：属性永久设定为超能系（跨战斗持续）。
- **随机变牌**：从手牌中选至多 3 张牌，随机变化为**另一张随机牌**。
- **变换是临时的**：变化的牌只在当前生效，不写入卡组（属性和元素变化是永久的，但**牌变换是临时**的）。

## 小贴士

- **两种"永久"别搞混**：元素变超能是**永久**的（写进遗物标记、每场重施加），而手牌变牌只是**当次战斗的临时赌局**——别期待变出来的牌能留着用。
- **用废牌赌一票**：专门挑手牌里没用的卡（状态牌、废牌、走不动的臭牌）去变化，等于把垃圾牌临时"重新抽"一次，稳赚不亏。
- **超能系的收益**：转超能是永久长期收益，变化只是附赠的即时娱乐。评估时以"我要不要转超能系"为主，变化当作锦上添花。
- **普通稀有度的风险**：变化随机无定向，欧了变神卡、非了可能还变废。若手牌全是宝贝，别去动它们；反之全是臭牌时这瓶近乎白嫖一次重roll。
