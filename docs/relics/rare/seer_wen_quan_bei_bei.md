# 温泉贝贝

<img src="/images/relics/seer_wen_quan_bei_bei.png" alt="温泉贝贝" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物

- **稀有度**: 稀有

## 描述

当你的生命值将要降为 <span style="color:#3aa675;font-weight:600">0</span> 或以下时，以**无穷之血**复活；若你的回合结束前取得**胜利**，则以 <span style="color:#3aa675;font-weight:600">1</span> 点生命存活，否则**死亡**。

- **触发**：受到致死伤害（生命值即将降到 <span style="color:#3aa675;font-weight:600">0</span> 或以下）时触发，每场战斗最多触发一次。
- **复活**：生命值瞬间恢复为无穷（数值巨大），此期间你完全**无敌**，不受伤害。
- **窗口**：从复苏那一刻起，一直无敌到你的回合结束，相当于白送一整轮时间。
- **结果**：你的回合结束前胜利 → 落到 <span style="color:#3aa675;font-weight:600">1</span> 点生命存活；否则到下个敌人回合开始即真死。无论死亡前有多少生命，最终都只留 <span style="color:#3aa675;font-weight:600">1</span> 点。

## 风味文字

<span style="color:#d44;font-weight:600">向死而生，温而复苏。</span>

## 小贴士

- **这是"最后一回合"的斩杀保险，不是永久无敌**：触发后你只剩这轮冲锋陷阵的时间，窗口一过没赢就真死。所以它是给"就差最后一击"的对局兜底的遗物，核心用法是把这一整轮用在终结上，而不是撤退续命。

- **核心矛盾：坦度与时间的极限对赌**：复活后你完全无敌、怎么挨打都不掉血，但代价是必须在这一轮内解决战斗——你叠的防御、回血、护甲在窗口结束后统统救不了命，唯一解法是这轮内赢。

- **赢了也不是白赢，血线被锁死成 1 点**：即便这轮斩杀成功，你也只剩 <span style="color:#3aa675;font-weight:600">1</span> 点生命进入后续（不回到死亡前血量）。稀有度定位正在于此：给你一次近乎必赢的翻盘，却要你用命换——参考同类复活类遗物（如[朱雀](/relics/rare/vermilion_bird)是复活回半血再战），温泉贝贝把收益和代价都压到了最极端。

- **使用时机**：在首领战、精英战或高威胁遭遇里，卡在"下一击就能终结/下一击就团灭"的临界点时，它往往是分胜负的那最后一张底牌；但若你的卡组撑不了一轮内爆发的斩杀，这件遗物就只是个"晚死一回合"的安慰。

- **性价比**：稀有，等价于"额外一整回合 + 无限坦度 + 保底再一条命"，专为打一轮内斩杀的决战型思路准备。
