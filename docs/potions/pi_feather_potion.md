# 🪶 皮神的羽毛

## 基本信息

- **分类**: 增益（生存）
- **稀有度**: 稀有
- **使用时机**: 战斗内
- **目标**: 自身

### 数值参数

| 参数 | 数值 |
|---|---|
| 神羽片数 | 3 |
| 触发阈值 | 生命低于 <span style="color:#3aa675;font-weight:600">60%</span> |
| 回复比例 | 回复至 <span style="color:#3aa675;font-weight:600">97%</span> 最大生命 |

## 描述

获得 <span style="color:#3aa675;font-weight:600">3</span> 片[神羽](/powers/divine_feather_power.md)。

## 详细机制

- **作用于自身**：无需选择目标，为自身施加[神羽](/powers/divine_feather_power.md)能力 3 层。
- **神羽机制**：神羽按层数记（1 片 = 1 层计数器）。每个己方回合结束时，若生命低于 <span style="color:#3aa675;font-weight:600">60%</span>，消耗 <span style="color:#3aa675;font-weight:600">1</span> 片把生命回复到 <span style="color:#3aa675;font-weight:600">97%</span> 最大生命——即"低血自动救一次"。
- **上限在层数**：一次性灌注 3 层 = 至多 3 次触发机会，用完即空。
- **悬浮提示**：附带神羽能力提示，可确认剩余片数。

## 小贴士

- **本质是 3 次"低血自动回血保险"，不给增伤**：它不提供任何输出或属性，价值全在容错——相当于把"可能会被一脚打到濒死"的风险，用 3 次自动回血软垫。对吃爆发、怕集火的牌组价值极高。
- **使用时机：预测血线而不是现在血线**：血量健康时用不会立刻体现价值，真正的收益在"下一回合可能被连续打穿"的预判。打精英/Boss 前一回合、或身带易伤时灌入，等于提前上保险。
- **与拥有层数上限的技能是两回事**：它不叠加属性、不随回合增长，属于一次性消耗型保护；一旦触发完 3 片就归零，别期望它长期站场。
- **搭配思路**：配合高回复/高格挡的站场流，能大幅提升"赖着不死"的韧性；配合生命比例阈值高的词条，触发频次与回血幅度越高、单瓶价值越大。
- **性价比**：作为稀有药水，它把全部收益押在生存端——输出牌组会嫌它占栏，而偏防御/控制的牌组则把它当关键保命符。
