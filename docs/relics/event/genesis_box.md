# 创世魔盒

<img src="/images/relics/genesis_box.png" alt="创世魔盒" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 事件遗物
- **稀有度**: 事件
- **获取途径**: [「莱达宇宙：缺失的愚者塔罗」](/events/missing_fool_tarot.md) 事件，选择「小心翼翼，伸手触碰魔盒」

## 描述

每次击败精英后，随机获得1件<span style="color:#d4a017;font-weight:600">塔罗遗物</span>。

- **精英战是塔罗稳定来源**：从 21 件塔罗遗物（魔术师到世界，不含愚者）中随机抽取 1 件。优先从未拥有的池子里抽；全部集齐后才会重复。一局游戏通常打 4~5 场精英战，能稳定拿到若干件塔罗，但 21 件全集齐的概率很低，所以不必担心大量重复的情况。
- **不含愚者，呼应事件主题**：塔罗池是魔术师到世界共 21 件，永远不含[愚者](/relics/common/tarot_fool.md)——正对应获取事件「**缺失的**愚者塔罗」的标题：魔盒里装的是大阿卡纳的后 21 张，愚者这张牌本身是缺失的。想要愚者得去别的事件找。
- **只精英战斗触发**：普通战斗、Boss 战不触发，只有击败精英后才送。拿到它之后主动多走精英房间，每场精英战 = 常规奖励 + 一件塔罗，收益翻倍。
- **塔罗遗物强度参差不齐**：不同塔罗遗物的效果差异较大，比如[恋人](/relics/common/tarot_lovers.md)、[战车](/relics/common/tarot_chariot.md)往往较强，但也有偏弱或需要特定配合的塔罗。不要期望每场都拿到神卡。
- **重复获得的实际影响**：塔罗遗物注册在公共池（SharedRelicPool），每次获得都是独立实例，各自有独立的 SavedProperty 状态。部分塔罗（如[战车](/relics/common/tarot_chariot.md)、[恶魔](/relics/common/tarot_devil.md)、[月亮](/relics/common/tarot_moon.md)）属于独立计数型，重复后每份都会独立触发，收益叠加；另一部分（如[女祭司](/relics/common/tarot_high_priestess.md)、[死神](/relics/common/tarot_death.md)）属于条件判定型，多次触发判定的是同一批敌人，会有部分效果重叠。绝大多数情况下不会出现大量重复，因此不必刻意规避重复塔罗。
- **事件三选一需按局况取舍**：「**小心翼翼，伸手触碰魔盒**」是最常见的选择；「**远远观望**」直接 +18 最大生命，缺血局价值很高；「**当场砸碎**」可删废牌，但每删一张损失 15% 当前生命，最多 5 张且可随时取消，适合牌组里有严重废牌又承受得起代价的局。三个选项没有绝对的优劣，取决于你的具体处境。
