- **分类**: 衍生牌
- **能量消耗**: 0

- **关键词**: 无
- **可升级**: 否

## 描述

命运抉择：随机永久移除 1 件非初始遗物。

## 详细机制

- **不是普通可打出卡牌**：只在[王牌术师](/monsters/elite/ace_magician_monster.md)的技能「命运抉择」选择界面中出现。
- **选中即结算**：由王牌术师直接随机永久移除你 1 件**非初始遗物**；初始遗物不受影响。
- **正常不会获得**：属于衍生卡池，不会出现在奖励、商店或随机生成中。

## 小贴士

- **两害相权取其轻**：与「死亡」相比，掉一件遗物通常是更好的结果；但如果遗物是整套构筑的核心，损失也可能大于死亡之外的一切。
- **初始遗物是安全区**：只移除非初始遗物，角色的初始遗物、开局固定遗物不会被选中。
- **随机不可控**：移除哪件完全随机，无法挑选；遗物越多，关键遗物被点中的概率越低。
