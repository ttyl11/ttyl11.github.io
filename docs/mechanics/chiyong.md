# 迟涌（ChiYong）

**迟涌**是赛尔（Seer）职业独有的稀有关键词，控制带有此关键词的牌在洗入牌堆时的位置。

## 规则说明

| 项目       | 说明                                                                         |
| ---------- | ---------------------------------------------------------------------------- |
| 适用范围   | 仅赛尔角色牌                                                                     |
| 触发时机   | 每次牌堆洗牌（含每场战斗开始时的初始洗牌，以及弃牌堆洗回抽牌堆）                            |
| 效果       | 带有迟涌的牌不随机洗入，而是直接放入[抽牌堆](/mechanics/draw_pile.md)底部            |
| 开局同样生效 | 每场战斗开始时的初始洗牌也会触发——迟涌牌开局就被放到抽牌堆底，通常要抽完整轮牌才轮到它       |

**典型流程：**

1. **战斗开始**：初始洗牌时迟涌牌就被放到[抽牌堆](/mechanics/draw_pile.md)底部——开局通常抽不到它。
2. **首次使用**：牌被打出后进入弃牌堆。
3. **后续洗牌**：下次弃牌堆洗回抽牌堆时，迟涌牌不会随机分配位置，而是直接放在抽牌堆最底部。之后需抽完整个牌堆才会再次拿到这张牌。
4. **下一场战斗**：重新洗牌开局，初始洗牌会再次把它放到抽牌堆底——**每场战斗独立计算，互不影响**。

关键细节：

- 迟涌在所有洗牌环节生效（开局初始洗牌与后续弃牌堆洗回都算），只影响"牌进入抽牌堆时的位置"，不影响抽牌堆顶的抽牌行为
- 与[凝驻](/mechanics/ningzhu.md)互为镜像：凝驻让牌留在弃牌堆不参与洗牌，迟涌让牌进入抽牌堆但放在底部
- 不存在任何跨战斗的计数器或持久化状态；每场战斗结束后所有数据清空，下场战斗从零开始

## 实战影响

- 迟涌牌在单场战斗中使用后，下次获得前需要抽完整轮牌堆，适合设计为"高伤害、低频率"的核心输出牌。
- 配合[预见（Scry）](/mechanics/scry.md)等操控牌堆顶的能力可以提前预读迟涌牌的位置。
- 迟涌牌本质上是"延迟再出现"的控制手段，而非"永久消失"或"冷却时间"。

## 与类似机制的区别

| 机制                | 区别                                                                     |
| ------------------- | ------------------------------------------------------------------------ |
| **凝驻（NingZhu）**  | 凝驻让牌留在弃牌堆不参与洗牌；迟涌让牌进入抽牌堆但固定放在底部                           |
| **消耗（Exhaust）**  | 消耗后牌移出本局所有区域，彻底离开本次旅程；迟涌仅改变洗入位置，牌仍在牌组中                |
| **虚无（Ethereal）** | 虚无的牌回合结束时留在手牌则消耗；迟涌与手牌管理无关                                |
| **回响（Echo）**     | 回响每回合从牌堆生成复制品到手牌；迟涌控制的是洗入位置，无复制机制                        |

## 带迟涌的卡牌

- [几曾识干戈](/cards/character/ji_ceng_shi_gan_ge.md)：造成伤害随战斗递增，迟涌防止它在早期低伤害时被过早抽到
- [龙缘之息](/cards/character/dragon_breath.md)：抽到名称带「龙」的牌自动打出的常驻能力，迟涌限制其出现频率
- [冲锋](/cards/curse/charge.md)：自伤与"本场已造成伤害"成反比，迟涌让它晚点出现、给你时间先把伤害刷够
- [拖50](/cards/curse/drag_burden.md)：惩罚随回合数递增，迟涌让它后期才被抽到，反而加重伤害
