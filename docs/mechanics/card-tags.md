# 角色卡牌标签

角色卡牌标签是 Seer Mod 通过 RitsuLib 注册的自定义 CardTag 系统，为 5 种原版角色分别定义专属标签，实现"仅对某角色生效"的卡牌过滤机制。

::: tip Mod 扩展了什么
- 原版有 CardTag 系统但种类有限，Mod 注册了 5 个角色专属 CardTag
- 通过标签过滤，实现卡牌"仅对某角色生效"的效果
- 标签 ID 使用 XxHash32 确定性生成，多端天然一致无需网络同步
:::

---

## 5 种角色标签

Mod 为杀戮尖塔2 的 5 种原版角色分别注册了专属 CardTag：

| 标签名 | 对应角色 |
| --- | --- |
| Ironclad | 铁甲战士 |
| Silent | 静默猎手 |
| Defect | 缺陷机器人 |
| Regent | 摄政者 |
| Necrobinder | 死灵术士 |

::: warning 角色名称说明
杀戮尖塔2 的角色在代码中命名为 Ironclad/Silent/Defect/Regent/Necrobinder，对应原版的铁甲战士/静默猎手/缺陷机器人/摄政者/死灵术士。Mod 沿用这套命名体系。
:::

## 标签注册机制

### 确定性 ID 生成

- 标签的数值 ID 通过确定性哈希算法生成
- 同一个限定 ID 在所有端上生成相同的数值
- 无需网络同步，多端天然一致

### 注册方式

通过 RitsuLib 的卡牌标签注册系统注册，使用特性声明。

---

## 卡牌打标签

卡牌通过声明标签属性来附加角色归属标签：

- 一张卡牌可以拥有多个角色标签（但通常只属于一个角色）
- 标签在卡牌类定义时静态绑定，运行时不可变
- 通过检查卡牌标签集合中是否包含特定角色标签来判断

### 已使用角色标签的卡牌示例

| 角色标签 | 卡牌示例 |
| --- | --- |
| Ironclad | 战·圣灵天威、千劫战意 |
| Silent | 恶咒追魂、蛟龙出水、森罗万象、圣地擎山碎、缄默律令、昊海垂天 |
| Defect | 疯狂编码、圣灵雷霆斩、纯净能量 |
| Regent | 予天繁星、圣耀明瞳斩 |
| Necrobinder | 夜·冥昭瞢闇、百鬼夜行、亡灵律动、亡灵风暴 |

## 标签的实际用途

### 按角色查标签

`SeerCardTags.ForCharacterId` 可以把角色 ID 映射成对应标签：

- 玩家角色为铁甲战士 → 返回 Ironclad 标签
- 玩家角色为静默猎手 → 返回 Silent 标签
- 以此类推

### 没有效果限定

目前这些角色标签只用于**标记卡牌出处**，代码里没有任何"检查标签后限制打出/生效"的逻辑：

- 带 Ironclad 标签的牌，静默猎手拿到也能正常打出
- 标签不会改变卡牌进入哪个卡池，也不影响奖励生成
- 所谓"专属卡"只是设计上的归属，不是硬性限制

## 其它标签

### 龙标签

Mod 注册了一个 `Dragon` 卡牌标签（`SeerTags.Dragon`），但目前**没有卡牌实际挂载它**，也没有代码按它做判定。

[龙威](./dragon-majesty)识别龙牌的方式是**检查卡牌类名是否包含 `Dragon`**，与这个标签无关；类名不含 `Dragon` 的牌不会被算作龙牌。

### 原版标签

Mod 也使用原版的 CardTag 系统：
- 打击牌标签（Strike）
- 防御牌标签（Defend）
- 部分遗物和卡牌效果通过原版标签过滤

## 战略意义

### 角色出处标记

角色标签记录这张牌"本来是给谁设计的"，方便图鉴分类与后续扩展；它不影响实际使用。

### 跨角色卡牌

不带任何角色标签的卡牌属于通用卡池；带角色标签的牌也没有使用限制。

### 龙牌体系

龙牌不是靠标签判定，而是靠卡牌类名里的 `Dragon`。龙牌数量影响[龙威](./dragon-majesty)的开局属性加成。
