# 归源（XuPP）

**归源**是 Seer Mod 的自定义卡牌关键词，触发后所有卡牌 PP 回满。

## 基本信息

| 项目 | 说明 |
| --- | --- |
| 类型 | Mod 卡牌关键词（资源回复型） |
| 效果 | 所有卡牌 PP 回满 |
| 适用 | 卡面缩写术语 |

## 规则说明

- **归源 = 把 PP 补满**：关键词文本写的是"所有卡牌 PP 回满"，但**实际回复范围由每张卡的描述决定**：
  - 永恒：回复战斗中所有 PP 牌
  - 多元时间线：只回复从消耗堆选出的那张牌
  - 烬灭之拥 / 寂·妖胧天鸣：回复消耗堆中被放回手牌的牌
  - 耀武遗辉：回复除自身外的所有 PP 牌
- 一次性资源拉满，适合连续打出高 PP 消耗牌的关键回合
- 与 [PP药水](/potions/pp_potion.md)效果相近，但作为卡面词条由各卡牌自行结算
