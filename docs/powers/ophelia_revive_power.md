# 奥菲利娅复活

**复活型** · 不可见能力 · 无图标

## 效果

整局游戏首次死亡时，恢复自身 25 点生命与所有 PP。

这场战斗结束后，向牌组中加入 1 张「[终末·赫星黎明](/cards/character/final_star_dawn_skill.md)」。
