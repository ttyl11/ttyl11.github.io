# 🐚 海螺

## 基本信息

- **分类**: 净化
- **稀有度**: 罕见
- **使用时机**: 战斗内
- **目标**: 自身

## 描述

[消耗](/mechanics/exhaust.md)[手牌](/mechanics/hand.md)、[抽牌堆](/mechanics/draw_pile.md)和[弃牌堆](/mechanics/discard_pile.md)中所有[状态牌](/mechanics/abnormal-status.md)和[诅咒牌](/mechanics/curse-system.md)。

## 详细机制

- **清除范围**：从手牌、抽牌堆、弃牌堆三处收集所有**状态牌**（`Status`）与**诅咒牌**（`Curse`）。
- **批量消耗**：将这些牌全部移入消耗堆，不再参与后续抽/弃/打出。
- **不作用于能力牌/普通牌**：只清状态与诅咒，其他牌不受影响。

## 小贴士

- **净化牌堆**：一局内被塞进一堆状态/诅咒时，用它可以一次性清空，解放手牌与抽牌质量。
- **化解"脏牌"危机**：面对会往你牌堆塞病的敌人、或因事件拿到诅咒时极其好用。
- **性价比**：罕见稀有度，纯粹的"牌堆净化器"，针对性强。
