# 风定绝尘

> **归属**：怪物专属（玩家无法施加）
> **施加来源**：怪物自带——[圣谕之风·岚](/monsters/elite/holy_edict_wind_lan_monster.md)（技能「谕·风定绝尘」）

## 基本信息

- **类型**: 中性（None，不参与增益/减益分类）
- **叠加方式**: 叠加（Counter，层数 = 剩余回合）
- **可见**: 是

### 数值参数

| 参数 | 数值 |
|---|---|
| 持续回合 | 3（由技能施加 3 层） |

## 描述

持续期间，敌人无法打出能力牌，且自身的属性提升无法被移除。

## 详细机制

- **封锁能力牌**：敌方（玩家方）打出**能力牌**时直接无效，不消耗能量、不进入结算；攻击牌、技能牌不受影响。
- **属性提升锁定**：自身受到力量/防御/命中/速度的**负向**数值变化时，该变化被归零——降属性削不掉岚已有的提升；但直接移除能力的清强（如「移除增益」类效果）会绕过此钩子，仍然有效。
- **不是免控**：只拦上述四维的负向变化，异常状态照常可以施加；异常免疫由同招式的「弹控」「免弱」负责。
- **持续窗口**：在**敌方（玩家）回合结束**时 -1 层，3 层即覆盖 3 个玩家回合；不是在岚自己的回合结束递减。

## 小贴士

- **能力牌先别打**：持续期间打出的能力牌会直接浪费，优先用攻击/技能牌过度，等层数掉完再铺能力。
- **降属性手段失效**：想削岚的全属性，在这 3 回合内不会生效，别把关键减属性牌浪费在这里。
