## 小贴士

- **自伤换输出的设计**：这张牌的核心是"用自身烧伤的层数当伤害源"——给自身挂 <span style="color:#3aa675;font-weight:600">5</span> 层烧伤（升级 7 层）。**已有烧伤时是在原层数上追加**，不是设为 5：身上本有 3 层，打出后就是 8 层。此后每打一张牌就对随机敌人造成等于该次出牌时烧伤层数的伤害。烧伤每回合 -1，所以是个**递减输出窗口**。
- **这张牌自身不触发**：能力是在它结算之后才挂上的，所以打出八月的流火这一张本身不会造成追加伤害；从下一张牌开始才计入。
- **烧伤的真实效果**：烧伤在持有者**回合开始时**自伤 <span style="color:#3aa675;font-weight:600">3</span> 点（不可格挡、不受力量加成的非攻击伤害），随后层数 -1；同时使持有者造成的攻击伤害每段 -1（固定值减伤，不是百分比）。注意：自伤和减攻都是固定值，**与烧伤层数无关**——5 层烧伤和 1 层烧伤都是每回合掉 3 血、每段攻击 -1。
- **八月的流火能力的伤害特性**：能力触发时对随机敌人造成的是非攻击伤害——**可被格挡**，格挡够高时可以完全挡下；但**不吃力量/易伤**。注意这与烧伤自伤是两回事：烧伤每回合的 3 点自伤打的是你自己，不可格挡。
- **结算时机的小细节**：能力记录的是**出牌瞬间**的烧伤层数，结算伤害时按这个层数算。这意味着如果出牌过程中烧伤层数发生变化（如某张牌会清除自身烧伤），伤害按**出牌瞬间**的层数算，不是结算瞬间。
- **目标随机**：每次出牌都从可命中敌人中随机选一个，多敌人遭遇战中无法指定目标，但长时间看会均匀分布。**多人模式下两端结果一致**。
- **烧伤层数是伤害源，多多益善**：能力伤害等于**出牌瞬间**的烧伤层数——若其它效果给自己叠加烧伤，此卡的触发伤害随之水涨船高，而自伤仍是固定 3 点/回合、攻伤 -1 固定值，都不随层数增长。叠烧伤对这个体系是纯赚。
- **升级的价值（递减数列要算总账）**：烧伤回合 5→7。烧伤每回合 -1，所以伤害是递减的——按每回合打 3 张牌估算：5 层总输出 = 3×(5+4+3+2+1) = **45** 点；7 层 = 3×(7+6+5+4+3+2+1) = **84** 点，提升约 **+87%**，远超表面上的"+2 回合"。升级优先级极高。
- **风险提示**：自身烧伤会持续掉血，低血量时慎用。注意烧伤的攻击减伤效果会影响你的攻击牌输出。
- **性价比**：PP 1 = 单场只能打一次；1 费换一张常驻能力，烧伤联动出牌的额外伤害回本快。
