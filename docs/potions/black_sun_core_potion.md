# 🖤 黑日之核

## 基本信息

- **分类**: 生存 / 交换
- **稀有度**: 稀有
- **使用时机**: 任意
- **目标**: 自身 / 对商人

### 数值参数

| 参数 | 数值 |
|---|---|
| 复活生命 | 最大生命的 44% |

## 描述

持有时：死亡时以最大生命值的 <span style="color:#3aa675;font-weight:600">44%</span> 复活，随后移除本药水。

也可以投掷给[商人](/mechanics/currency.md)换取 <span style="color:#3aa675;font-weight:600">1</span> 件随机[史诗遗物](/relics/epic/)。

## 详细机制

- **被动复活**：持有本药水期间（战斗中持续保持复活能力），若死亡则以最大生命值 44% 复活，随后本药水被移除。
- **双模式**：战斗中打开是护身符；战斗外对真商人使用则兑换随机史诗遗物并消耗药水。
- **对商人换取**：仅在真商人（`MerchantRoom`）处可用，随机获取 1 件 Seer Mod 的史诗稀有度遗物（不含重复持有的）。
- **一次下层**：复活或兑换只会发生一次，触发后药水消失。

## 小贴士

- **保命底牌**：44% 生命复活的兜底，适合高难 Boss 或关键时刻防翻车，触发即代表救了一次。
- **商人是另一出路**：不想留保命符时可直接变现为史诗遗物，取决于当前装备强度。
- **稀有且一次性**：复活或兑换二选一消耗，用前想清楚当前更缺"容错"还是"成长"。
