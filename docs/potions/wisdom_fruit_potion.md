# 🍎 智慧果实

## 基本信息

- **分类**: 元素变身
- **稀有度**: 普通
- **使用时机**: 战斗内
- **目标**: 自身

### 数值参数

| 参数 | 数值 |
|---|---|
| 随机 0 费牌 | 4 张 |

## 描述

永久变[自然系](/powers/nature_power.md)，手牌加入<span style="color:#3aa675;font-weight:600">4</span>张随机 0 费牌。

## 详细机制

- **永久变自然系**：把自身属性永久设定为自然系，**跨战斗持续**（后续每场战斗开始自动重施加）。
- **0 费牌**：从**你自己角色卡池**里筛出能量消耗为 0 的牌，随机抽 4 张加入手牌。
- **当回合可用**：4 张 0 费牌直接进手牌，许多可立即免费打出。

## 小贴士

- **白嫖输出 + 白嫖属性**：永久转成自然系 + 手上凭空多 4 张 0 费牌。0 费牌 = 免费的行动、免费的资源，这场战斗立刻白拿一轮爆发/过牌。
- **普通稀有度的超高性价比**：变系本身已是成长，再附赠 4 张 0 费——对依赖 0 费联动/过牌的卡组，这是超低价的一次性冲刺。
- **注意牌池随机性**：0 费牌来自你角色池，质量参差。卡得越好的卡组，随机到的 0 费牌价值越高。
- **变系的永久性**：一旦转自然系，后续战斗都按自然系结算元素克制。若你原本依赖别的元素（如火系增伤），**慎重——变系是永久决定，不是临时切换**。
- **与[无相](attribute_change_potion.md)对照**：智慧果实是"变成固定自然系 + 白送4牌"，无相是"自由挑选元素";前者拿到即赚牌，后者胜在可控。

## 相关机制
