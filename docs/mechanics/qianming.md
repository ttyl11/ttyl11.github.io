# 迁鸣（QianMing）

**迁鸣**是赛尔（Seer）职业独有的稀有关键词，控制带有此关键词的牌在牌堆发生变化时的触发行为。

## 规则说明

| 项目       | 说明                                                                         |
| ---------- | ---------------------------------------------------------------------------- |
| 适用范围   | 仅赛尔角色牌                                                                     |
| 触发时机   | 牌堆发生任何变化时（包括抽牌、洗牌、弃牌、获得新牌等）                                  |
| 效果       | 由该卡牌自定义效果；无自定义效果的卡牌此关键词仅作为标记，不产生额外效果                        |
| 关键词类型 | **触发型关键词**，不在描述文字中显示，但会出现在关键词标注中                               |
| 与溯引关系 | 迁鸣响应更广泛的牌堆变更；溯引仅在"被抽到手牌"时触发一次，两者触发条件和范围不同                  |

**典型流程：**

1. **牌堆变化**：任何导致牌堆状态改变的動作发生时（抽牌、洗牌、弃牌、获得牌等）。
2. **触发检测**：系统检测到带有迁鸣关键词的牌存在于牌组中，立即触发其效果。
3. **效果结算**：由卡牌自定义逻辑执行（如添加附魔、生成充能球、抽牌等）。
4. **继续游戏**：触发完成后游戏继续，不受是否在手牌中影响。

关键细节：

- 迁鸣是**纯被动触发型关键词**，描述文本中不显示，只在关键词列表中可见
- 触发条件不限于抽牌——弃牌、洗牌、获得新牌等所有牌堆变更都会触发
- 与**溯引**的区别：溯引仅响应"被抽到手牌"这一动作且只触发一次；迁鸣响应更广泛的牌堆状态变更
- 迁鸣牌不需要在手牌中，只要存在于牌组即可触发

## 带迁鸣的卡牌

- [告命诗途](/cards/character/gao_ming_shi_tu.md)：牌堆变化时，从手牌选一张未附魔的牌添加随机五音附魔

## 与类似机制的区别

| 机制               | 区别                                                                   |
| ------------------ | ---------------------------------------------------------------------- |
| **溯引（SuYin）**  | 溯引仅在"被抽到手牌时"触发一次；迁鸣响应所有牌堆变更，触发条件更广              |
| **回响（Echo）**    | 回响每回合开始时从抽牌堆生成复制品到手牌；迁鸣是被动触发，不限定时机和位置          |
| **真神（TrueGod）** | 真神牌只能被自动打出；迁鸣不限制牌的打出方式，只是提供额外触发效果                  |
| **残鸣（CanMing）** | 残鸣仅在被[消耗](/mechanics/exhaust.md)时触发；迁鸣的触发条件更为宽泛           |
