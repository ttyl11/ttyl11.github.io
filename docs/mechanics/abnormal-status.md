# 异常状态

Seer Mod 引入了 **27 种独有异常状态**，模拟赛尔号原版的异常机制。这些异常状态与原版尖塔的虚弱/易伤/缩小等 Debuff **完全独立**——它们有独立的施加途径、衰减规则和免疫机制。

::: tip 核心硬规则：没有明说的免控都只是免疫异常状态
原版的虚弱/易伤/缩小等是通用 Debuff；Seer Mod 的异常状态是独立体系。在 Mod 中，**除特别注明（如明确标注“含能力下降”或“免疫所有异常状态与属性下降”）外，所有没有明说的「免控」均统一且仅代表「免疫异常状态」**，不免疫原版通用 Debuff，亦不免疫属性下降（由「免弱」防护）。
:::

---

## 异常状态分类清单

在全量 **27 种** 异常状态中，**狂暴、星赐、凝滞、超频 4 种已被硬性排除在随机池外**。
- **权威全量名单（27 种）**：包含以下全部 27 种状态，作为规则本体参与免控/弹控、偷天换日转移、流派统计（如峰回路转 7 种异常）与刻印触发；
- **随机施加池（23 种）**：仅包含下方可随机池中的 23 种负面异常，绝不会随出下方排除组中的 4 种状态。

---

### 一、 排除在随机池外的异常状态（硬性排除，共 4 种）

> [!IMPORTANT]
> 这 4 种在底层规则上**完全属于权威异常状态本体**（可被免控/弹控拦截、可被偷天换日转移或驱散、计入异常流派计数与刻印触发）。
> 但它们**被硬性排除在随机施加池外**（`SeerAbnormalStatus.ExcludedFromRandom`），任何卡牌、遗物或怪物技能中的「随机异常状态」均**绝对无法抽到它们**：

| 异常 | 核心效果 | 衰减 | 为什么排除在随机池外 |
| --- | --- | --- | --- |
| **狂暴** | 造成的攻击伤害提升 **25%**（增益型异常） | 回合末 -1 | **防止给敌人送爆发**：若随机给敌人上 +25% 增伤，会导致敌方爆发反噬玩家暴毙 |
| **星赐** | 造成伤害提升 **10%**，打出攻击牌时回复 **1** 点 PP（增益型异常） | 回合末 -1 | **防止给敌人送资源**：属于强力正向资源增益，绝不可随机施加给敌人 |
| **凝滞** | 免疫其它异常；怪物持有[封属](/mechanics/intent)（非攻击意图失效），玩家持有无法额外抽牌 | 回合末 -1 | **防止给敌人送金身**：自带免控保护且封属机制特殊，不可泛滥随出 |
| **超频** | 回合开始获得 1 层[先制](/powers/first_strike_power.md)；移除时获得 **2** 层瘫痪 | 触发后 -1 | **防止打乱出招轴**：随机给敌人会赋予先制加速爆发，破坏出牌节奏预期 |

### 二、 随机施加池中的异常状态（共 23 种）

所有「随机施加 X 种异常状态」的卡牌、遗物、怪物技能与药水，均统一且仅从以下 **23 种** 负面异常中抽取：

#### 1. 减伤类（降低攻击伤害，共 8 种）

| 异常 | 核心效果 | 衰减 |
| --- | --- | --- |
| **睡眠** | 攻击伤害降低 **50%**；受到未被格挡的伤害时立即移除（缪斯施加的睡眠改为只 -1 层） | 回合末 -1 |
| **害怕** | 攻击伤害降低 **30%** | 回合末 -1 |
| **沸涌** | 受到的攻击伤害**至少为 5**；受到暴击时暴击倍率提升至 **×2**（先反算暴击前伤害，取最大值后再 ×2） | 回合末 -1 |
| **失明** | 攻击时 **50%** 概率自伤（原伤害的 **20%**），**50%** 概率伤害减半（**×50%**） | 回合末 -1 |
| **衰弱** | 每层使**受到的**攻击伤害增加 **25%**（增伤方向，与原版易伤类似但独立） | 回合末 -1 |
| **瘫痪** | 攻击伤害降低 **10%**；回合开始时若上回合未造成伤害，获得虚弱/易伤/缩小各 1 层 | 回合末 -1 |
| **麻痹** | 攻击伤害降低 **10%**；回合开始时获得 1 层易伤 | 回合末 -1 |
| **感染** | 攻击伤害降低 **20%**；回合末获得 **2** 层中毒 | 回合末 -1 |

#### 2. 转化类（一种异常转化为另一种，共 4 种）

| 异常 | 核心效果 | 衰减 |
| --- | --- | --- |
| **冰封** | 攻击伤害降低 **20%**；回合结束时移除并转化为 **2** 层冻伤 | 回合末移除并转化 |
| **神游** | 攻击伤害降低 **20%**；回合末获得 **2** 层睡眠 | 回合末 -1 |
| **焚烬** | 攻击伤害降低 **20%**；回合末获得 **2** 层烧伤 | 回合末 -1 |
| **易燃** | 造成攻击伤害降低 **20%**；受到攻击时获得 **2** 层烧伤 | 回合末 -1 |

#### 3. 持续伤害类（回合开始/结束扣血，共 6 种）

| 异常 | 核心效果 | 衰减 |
| --- | --- | --- |
| **烧伤** | 回合开始受 **3** 点不可格挡伤害，攻击伤害降低 **1** 点 | 回合开始结算后 -1 |
| **冻伤** | 回合开始受 **5** 点不可格挡伤害 | 回合开始结算后 -1 |
| **中毒** | 回合开始受 **层数** 点伤害，结算后层数减半 | 回合开始结算后减半 |
| **流血** | 回合结束受 **层数÷2** 的伤害（向下取整）；受到攻击时 +1 层 | 回合末结算伤害后 -1 |
| **寄生** | 回合开始受 **2** 点伤害，所有对手回复 **2** 点生命 | 回合开始结算后 -1 |
| **混乱** | 回合开始受 **5** 点不可格挡伤害，[命中](/powers/accuracy_power.md) **-1**（负命中每层让受击目标闪避率 +5%） | 回合开始结算后 -1 |

#### 4. 特殊机制类（共 5 种）

| 异常 | 核心效果 | 衰减 |
| --- | --- | --- |
| **沉默** | **持有者造成的**单次攻击伤害若超过 **30**，该次伤害整体降为 0；非玩家持有者回合末受到 1 点伤害 | 回合末 -1 |
| **束缚** | 存在时自身无法获取先制 | 回合末 -1 |
| **石化** | 攻击伤害降低 **70%**；本应造成的伤害 **70%** 转化为自身格挡 | 回合末 -1 |
| **诅咒** | 攻击伤害降低 **10%**。玩家持有：回合开始获得一张诅咒牌；怪物持有：回合结束按权重受到随机伤害（<span style="color:#3aa675;font-weight:600">50%</span>→3、<span style="color:#3aa675;font-weight:600">40%</span>→5、<span style="color:#3aa675;font-weight:600">9%</span>→8、<span style="color:#3aa675;font-weight:600">1%</span>→50） | 回合末 -1 |
| **臣服** | 攻击伤害降低 **70%**；移除时玩家获得 **2** 张随从牌、怪物获得 **3** 层力量 | 回合末 -1 |

## 衰减规则汇总

异常状态的衰减时机并不统一：

| 衰减时机 | 涉及异常 |
| --- | --- |
| 回合开始结算后 -1 | 烧伤、冻伤、寄生、混乱 |
| 回合开始结算后减半 | 中毒（层数减半，向下取整） |
| 回合末 -1 | 睡眠、害怕、沸涌、失明、衰弱、瘫痪、麻痹、感染、沉默、束缚、石化、诅咒、臣服、神游、焚烬、易燃、凝滞、狂暴、星赐 |
| 回合末结算伤害后 -1 | 流血（先受层数÷2 伤害，存活则 -1） |
| 回合开始触发后 -1 | 超频（N 层 = N 个回合开始各触发一次先制，减到 0 移除时给 2 层瘫痪） |
| 一次性移除 | 冰封（回合末移除并转化为 2 层冻伤）、睡眠（受未格挡伤害时立即移除；缪斯施加的睡眠改为只 -1 层） |

## 异常免疫

以下能力可免疫 Seer 异常状态。注意各能力的**免疫范围和消耗方式差别很大**：

| 能力 | 免疫范围 | 机制 |
| --- | --- | --- |
| [异常免疫](/powers/debuff_immune_power.md) | Seer 异常状态 | 免疫 N 回合（N=层数）；对方回合结束时 -1，不按次数消耗 |
| [异常免疫·反弹](/powers/debuff_immune_reflect_power.md) | Seer 异常状态 | 同上，且免疫时把该异常反弹给所有敌人 |
| [永久免控](/powers/permanent_debuff_immune_power.md) | Seer 异常状态 + 属性下降 | 明确标注的双重免疫，永久生效，无层数 |
| [免疫](/powers/immunity_power.md) | Seer 异常状态 | 预留能力，当前无获取途径 |
| [次数免疫](/powers/void_plating_power.md) | Seer 异常状态 | 免疫下 N 次异常，每次成功免疫后 -1 层 |
| [支援庇护](/powers/support_immune_count_power.md) | Seer 异常状态 | 受到异常时免疫该次异常并消耗 1 层 |
| [未来奇点](/powers/future_singularity_power.md) | Seer 异常状态 + 所有原版 Debuff | 免疫时消耗 1 层；另有按层数解锁的附带效果 |
| [凝滞](/powers/stasis_power.md) | 其它 Seer 异常状态 | 自身就是一种异常状态；自己回合结束时 -1 |
| [神话](/powers/myth_power.md) | 所有 Seer 异常状态 | 永久生效，无层数（部分怪物自带） |
| [圣谕形态](/powers/divine_form_power.md) | 固定伤害 + Seer 异常状态 | 另有圣诰/邪诲附加效果 |
| [龙胆](/powers/dragon_whisker_power.md) | Seer 异常状态 | 每层：使用牌时对随机敌人造成 1 点固定伤害；受到异常时消耗 1 层抵消 |
| [白色龙鳞](/powers/white_dragon_scale_power.md) | 攻击伤害 / 固定伤害 / 异常 / 属性下降 | 每层免疫一次（各类附带反制效果）；对方回合结束时 -1 |
| [黄色龙鳞](/powers/yellow_dragon_scale_power.md) | Seer 异常状态 | 触发免疫时消除对手基础属性提升，然后自身消失 |
| [罗生门](/powers/rashomon_power.md) | Seer 异常状态 | 5 层；玩家打出 PP 牌时 PP 消耗 **+2**；玩家回合结束时 -1 |
| [传说结界](/powers/legendary_barrier_power.md) | 属性下降（力量/防御/命中/速度/先制） | 详见下方说明 |

::: warning 部分遗物也提供异常免疫
「蓓丽安特」「皮神」（Boss 战）等遗物同样会拦截异常状态的施加，详见各遗物页面。
:::

### 传说结界的特殊行为

传说结界（史莱姆国王招式"传说结界"、暴君史莱姆招式"绝望结界"施加，两者是同一种能力）的实际效果：

- **免疫全部异常状态**：27 种异常状态都**无法施加**到持有者身上（施加量直接归零，不分正负层数）
- **免疫能力下降**：力量、防御、命中、速度、先制无法被降低（负向修改归零）。**只拦负向修改**：直接施加[虚弱](/powers/weak_power.md)/[易伤](/powers/vulnerable_power.md)（正向层数）不会被拦下。
- 结界整场永久生效（无层数衰减、不被清增益/清减益移除），与按敌方回合递减的[异常免疫](/powers/debuff_immune_power.md)不同

## 施加途径

### 卡牌/怪物招式

- 直接施加异常状态的招式（如比比鼠电火花→烧伤）
- **异变**关键词：打出时对自己施加随机 1 种异常，持续 2 回合
- **炼狱**关键词：伤害翻倍，打出时对自己施加随机 1 种异常，持续 5 回合
- 部分怪物招式附加异常（墨杜萨石化系列、奇幻之粉的多异常等）

### 状态宝石附魔

状态宝石附魔共 22 种，覆盖各类异常状态——给卡牌附魔后，打出时对目标施加对应异常 N 回合。详见 [附魔机制](./enchantment)。

### 充能球

- 森林充能球：被动施加中毒，激发施加感染
- 海洋充能球：被动施加冻伤，激发施加冰封
- 火山充能球：被动施加烧伤，激发施加焚烬
