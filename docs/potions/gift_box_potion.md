# 🎁 星愿礼盒

## 基本信息

- **分类**: 博彩 / 经济
- **稀有度**: 罕见
- **使用时机**: 任意
- **目标**: 自身

### 数值参数

| 参数 | 数值 |
|---|---|
| 获得遗物概率 | 10% |
| 获得金币 | 99（约定 90% 概率） |

## 描述

<span style="color:#3aa675;font-weight:600">10%</span>概率获得一个随机遗物，否则获得<span style="color:#3aa675;font-weight:600">99</span>金币。

## 详细机制

- **随机判定**：两端同步掷判定，10% 时从遗物池拿一个随机遗物；否则 +99 金币。
- **任意时机**：战斗内外皆可开箱。
- **遗物来源**：从当前可获得的遗物池中随机抽取。

## 小贴士

- **90% 都是金币保底**：大概率只是 99 金币，相当于一个"小额经济药水"。把它当**期待值**算：0.1×遗物价值 + 0.9×99金币，多数时候收益平平。
- **彩票心理**：10% 的遗物是真正的惊喜——一个强力遗物可能抵几十倍金币价值。可以理解为"用一瓶罕见药水买彩票"。
- **任意时机的便利**：战斗外也能开，意味着缺钱进货时顺手开一局也不占用战斗节奏；但要注意它没有"成长性"，遗物价值随你卡组变化弹性大。
- **稀缺性对照**：罕见稀有度+大概率低回报，让它在"需要稳定战力"的成型卡组里优先级不高；但对扩遗物池/赌成型很有吸引力。
- **别再赌一句**：若你想要的是某类特定遗物，10% 的随机并不定向——除非只是想要"多点遗物数"，否则保留金币药/战利品可能更稳。
