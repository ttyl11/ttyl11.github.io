# 龙威

> **归属**：怪物专属（玩家无法施加）
> **施加来源**：怪物自带——[哈莫雷特](/monsters/elite/hamlet_monster.md)

## 基本信息

- **类型**: 无类型（不参与增益/减益分类，不可被驱散/净化）
- **叠加方式**: 单例（不可叠加）
- **可见**: 是

## 描述

①战斗开始时，自身获得等同于敌人初始牌组中「龙」牌数量的全属性提升。<br/>②你打出的牌与上一张类型不同时，重放一次；类型相同时不重放。

## 详细机制

- **开局加成**：战斗开始时统计所有玩家初始牌组中**类名含 Dragon** 的牌，总张数同时加到自身的力量、防御、命中、速度四项上；没有龙牌就不加。
- **重放**：与上一张类型不同 → 本次出牌结算两次（playCount +1）；类型相同 → playCount 归 0，牌照常耗能、进弃牌堆/消耗堆，但 OnPlay 与附魔、词缀效果一次都不结算。
- **第一张安全**：战斗中的第一张牌没有"上一张"，正常结算。
- **类型按卡牌类别**：攻击 / 技能 / 能力 / 状态；升级、费用不影响。
- **自动打出也算**：自动打出的牌同样参与类型比较与重放/无效判定。
