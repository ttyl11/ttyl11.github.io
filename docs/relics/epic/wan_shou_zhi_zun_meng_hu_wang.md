## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 史诗

### 数值参数

| 参数 | 数值 |
|---|---|
| ①计数器 | 每打出一张牌 +5（角标显示，即当前概率%，封顶 100） |
| ②抽到 X 费牌能量 | +1 |
| ③收集范围 | 每个角色各 1 张（原版 5 角色 + seer 角色池） |

## 描述

①每打出一张牌，[gold]X费牌[/gold]概率+[blue]5%[/blue]；打出[gold]X费牌[/gold]时按当前概率[gold]自动重打[/gold]一次。②抽到[gold]X费牌[/gold]时，获得[blue]1[/blue]点[gold]能量[/gold]。③拾起时，每个角色各获得[blue]1[/blue]张其[gold]X费牌[/gold]。

## 详细机制

- **①计数器随出牌累计，打出 X 费牌时按概率重打**：每打出一张牌，计数器 +5（角标显示，数值即当前重打概率%），封顶 100。打出 X 费牌那一刻（与从哪个牌堆打出无关），按当前计数器概率判定，命中即自动重打该牌一次。**重打继承这张牌第一次打出时的 X 值（打出前能量），不会因能量已被消耗而打空**。自动重打不计数、不递归；计数器每场战斗重置。
- **②抽到 X 费牌 +1 能量**：任何来源抽到 X 费牌（回合初始抽牌、过牌、遗物/能力补牌等）都触发，获得 1 能量——缓解 X 费牌"吃光能量"的副作用，鼓励多抽多打。
- **③拾起时每个角色各 1 张 X 费牌**：获得本遗物时，为**每个角色各随机 1 张其 X 费牌**加入牌组（范围：原版 5 角色卡池 + seer 角色池 SeerCardPool，每个角色最多 1 张，不重复）。升级进化获得本遗物时同样触发；**若在战斗中进化（猛虎王打出第 20 张 X 费牌时），收集会延迟到本场战斗结束统一执行**，避免战斗中途牌库突变。

## 小贴士

- **想提升重打概率就先多打牌**：打出 5 张牌计数器到 25，此时打 X 费牌有 25% 概率再打一次（20 张封顶 100%）。低成本牌先铺场堆概率，再打 X 费牌收益最大。
- **先攒能量再打 X 费牌**：X 费牌第一次打出消耗当前所有能量，重打继承打出前的 X 值——能量越高，首打与重打的收益都越大。②的 +1 能量与能量积累遗物/药水配合，能让 X 费牌打出"满状态"效果。
- **留意牌组构成**：③按角色各给 1 张，数量可控（少量），角色池里没有 X 费牌的角色不给。
- **计数器每场重置，单场经营**：重打概率是当场的资源，跨场不保留——想打满 100% 概率爆发，就在单场战斗里优先铺场堆牌数，把高爆发 X 费牌留到计数器高时再打。
- **进化时机影响③**：若在战斗中进化获得本遗物，③的收集会延迟到本场战斗结束才执行，中途牌库不变——不用怕战斗中突然被塞牌打乱抓牌节奏。
