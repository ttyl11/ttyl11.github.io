# 生命灵珠

> **归属**：玩家可施加
> **施加来源**：
> - [生命灵珠](/potions/life_gem_potion.md)（药水——使用后获得）

## 基本信息

- **类型**: 中性（None）
- **叠加方式**: 计数（Counter）
- **可见**: 是

### 数值参数

| 参数 | 数值 |
|---|---|
| 生命阈值 | 50% |
| 低于阈值：承伤倍率 | 80%（减伤 20%） |
| 高于阈值：造成倍率 | 140%（增伤 40%） |

## 描述

本场战斗中，自身生命值低于<span style="color:#5a9e2e;font-weight:600">50%</span>时受到的伤害降低<span style="color:#3aa675;font-weight:600">20%</span>；高于<span style="color:#5a9e2e;font-weight:600">50%</span>时造成的伤害提高<span style="color:#3aa675;font-weight:600">40%</span>。

## 详细机制

- **动态判定**：每次伤害结算时按**结算瞬间**的生命比例判定。
  - 自身生命 **< 50%**：作为受伤方时，承伤 ×0.8。
  - 自身生命 **> 50%**：作为伤害来源时，造成伤害 ×1.4。
  - 生命**正好 50%**：两个效果都不触发。
- **未按伤害类型过滤**：代码没有限定「攻击伤害」，因此**固定伤害等其他伤害也吃这个乘区**——这与「固定伤害通常不受增减伤影响」的口径不同。
- **乘算区间**：与其它百分比增减伤相乘。
- **仅本场战斗**：战斗结束随能力移除。

## 小贴士

- **两个效果互斥**：高血只能拿增伤，低血只能拿减伤。
- **血量在 50% 附近反复横跳时收益最大**：输出时保持高血吃 1.4 倍，被集火掉到 50% 以下立刻转成抗伤。
- **低血时输出会掉**：低血状态没有增伤，要打爆发前先回血。
- **固定伤害也受影响**：因为代码不过滤伤害类型，低血减伤会把固定伤害也压到 0.8 倍；反之高血时你打出的固定伤害也会 ×1.4。
