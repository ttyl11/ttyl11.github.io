# 小熊

> **归属**：怪物专属（玩家无法正常获得）
> **施加来源**：怪物自带——[安妮](/monsters/normal/annie_monster.md)

<img src="/images/powers/bear_power.png" alt="小熊" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 无类型（不参与增益/减益分类，不可被驱散/净化）
- **叠加方式**: 计数器（按层数叠加）
- **可见**: 是

## 描述

受到卡牌伤害时累积怒气，每满<span style="color:#3aa675;font-weight:600">10</span>层立即结束敌人回合。

## 详细机制

- **只认卡牌伤害**：只有带卡牌来源的伤害才叠层；DoT、固定伤害等非卡牌伤害不叠。
- **完全格挡不叠**：必须实际造成未格挡伤害才 +1 层；被格挡到 0 的那次不计数。
- **每满 10 层立即结束所有敌方玩家的回合**：多人模式下逐个强制结束（不可撤销）；召唤物归并到主人，不会对同一玩家重复结束。
