## 小贴士

- **8 费但攻击牌减费——手牌满攻击牌时几乎免费**：[手牌](/mechanics/hand.md)中每有一张攻击牌（不含自身），耗能 <span style="color:#3aa675;font-weight:600">-1</span>（最低 <span style="color:#3aa675;font-weight:600">0</span>）。手牌攒 <span style="color:#3aa675;font-weight:600">5</span> 张攻击牌时只需 <span style="color:#3aa675;font-weight:600">3</span> 费，攒 <span style="color:#3aa675;font-weight:600">8</span> 张时 <span style="color:#3aa675;font-weight:600">0</span> 费——实际费用取决于手牌攻击牌数量。
- **3 回合核弹窗口——攻击伤害 +150%/250%**：打出后 <span style="color:#3aa675;font-weight:600">3</span> 回合内（含打出当回合）你造成的**受力量加成的攻击伤害** +<span style="color:#3aa675;font-weight:600">150</span>%（升级 +<span style="color:#3aa675;font-weight:600">250</span>%）。注意增伤只作用于攻击牌那类伤害——[固定伤害](/powers/fixed_damage_power.md)等非攻击类型不吃增伤。配合先制白嫖，<span style="color:#3aa675;font-weight:600">3</span> 回合内可以倾泻大量攻击牌，每张都吃增伤。
- **每打出一张自己的牌——随机敌人 1 点伤害 + 自身回 1 血**：持续期间每打出一张自己的牌（任何类型都算，**这张牌自身也算**），对一名随机可攻击敌人造成 <span style="color:#3aa675;font-weight:600">1</span> 点可被[格挡](/mechanics/block.md)的伤害，并回复等量生命。这不是[饮血](/mechanics/vampiric.md)，而是这张牌自带的固定 1 点伤害/治疗：不吃力量、暴击、增伤、防御与闪避，可被格挡吸收。体力低于 <span style="color:#3aa675;font-weight:600">50</span>% 时翻倍为 <span style="color:#3aa675;font-weight:600">2</span> 点。持续 <span style="color:#3aa675;font-weight:600">3</span> 回合（含打出当回合，自己回合结束递减）。
- **99 先制——之后 3 个回合几乎免费打牌**：打出后的 <span style="color:#3aa675;font-weight:600">3</span> 个回合**开始时**各获得 <span style="color:#3aa675;font-weight:600">99</span> 层[先制](/powers/first_strike_power.md)（打出当回合**不**触发）。先制的效果是"打出的下一张牌费用 -<span style="color:#3aa675;font-weight:600">99</span>（最低 <span style="color:#3aa675;font-weight:600">0</span>）、打一张后消失"——所以每个触发回合的第一张牌免费。连续三个回合白嫖一张任意牌。
- **全属性 +1 + 接下来 3 回合的力量/速度成长**：打出时自身力量、防御、命中、速度各 +<span style="color:#3aa675;font-weight:600">1</span>；之后**接下来 3 个回合开始时**各再获得力量 +<span style="color:#3aa675;font-weight:600">1</span>、速度 +<span style="color:#3aa675;font-weight:600">1</span>（共 +<span style="color:#3aa675;font-weight:600">3</span>/+<span style="color:#3aa675;font-weight:600">3</span>，不含打出当回合）。力量放大攻击伤害，速度提升抽牌（玩家正速度每层多抽 1 张，随后弃掉约半数）。
- **升级增伤 150%→250%——核弹变超核弹**：升级后攻击伤害加成从 <span style="color:#3aa675;font-weight:600">150</span>% 提升至 <span style="color:#3aa675;font-weight:600">250</span>%，<span style="color:#3aa675;font-weight:600">3</span> 回合内攻击伤害 ×<span style="color:#3aa675;font-weight:600">3.5</span>。对一张 <span style="color:#3aa675;font-weight:600">8</span> 费核弹牌来说，升级收益巨大。
- **性价比**：<span style="color:#3aa675;font-weight:600">8</span> 费换 <span style="color:#3aa675;font-weight:600">3</span> 回合核弹窗口（攻击 +<span style="color:#3aa675;font-weight:600">150</span>%/<span style="color:#3aa675;font-weight:600">250</span>%、<span style="color:#3aa675;font-weight:600">99</span> 先制、每打牌伤害 + 回血、全属性 +<span style="color:#3aa675;font-weight:600">1</span>），手牌攻击牌减费让实际费用远低于 <span style="color:#3aa675;font-weight:600">8</span>。
