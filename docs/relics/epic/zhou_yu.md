# 周瑜

<img src="/images/relics/zhou_yu.png" alt="周瑜" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 史诗

### 数值参数

| 参数 | 数值 |
|---|---|
| 业火涤尘间隔 | 3 回合（第3、6、9…回合触发） |
| 抽牌堆每牌最大生命损失 | 5 |
| 弃牌堆每牌固定伤害 | 5 |
| 回合结束恢复PP数量 | 3 张 |
| 每张PP牌恢复量 | 1 |
| 洗牌时抽牌数 | 2 张 |
| 附魔最低费牌 | 1 张/回合 |

## 描述

①每隔 <span style="color:#3aa675;font-weight:600">3</span> 回合（第 <span style="color:#3aa675;font-weight:600">3</span> 回合起），开启<span style="color:#d4a017;font-weight:600">业火涤尘</span>：消耗抽牌堆和弃牌堆中所有非附魔牌，抽牌堆每消耗1张所有敌人损失 <span style="color:#3aa675;font-weight:600">5</span> 点最大生命；弃牌堆每消耗1张所有敌人受到 <span style="color:#d4a017;font-weight:600">5</span> 点固定伤害。<br/>②回合开始时，手牌中最低费的可打出牌随机一张获得<span style="color:#d4a017;font-weight:600">[永耀](/mechanics/eternal_radiance.md)</span>。<br/>③回合结束时，随机 3 张消耗牌堆中的 PP 牌各恢复 <span style="color:#3aa675;font-weight:600">1</span> 点 PP。<br/>④牌堆洗牌时，抽 <span style="color:#3aa675;font-weight:600">2</span> 张牌。

## 详细机制

- **业火涤尘触发时机**：玩家自己的回合开始时触发（不计敌方回合）。第 3、6、9…回合各触发一次，之后每 3 回合一轮回。战斗结束后计数器归零，下场战斗重新从第 3 回合开始计算。
- **业火涤尘的结算顺序**：先统一收集抽牌堆和弃牌堆中所有**非附魔**牌（快照，避免边收集边修改集合），然后一次性将所有牌消耗掉，最后才结算伤害。顺序是**先扣最大生命，再扣当前生命**——这意味着如果敌人最大生命被扣到 0 以上但已无足够当前生命，伤害仍会正常结算。PP 牌在消耗时同步清空 PP。
- **①为何只烧非附魔牌**：业火涤尘只针对没有附魔的牌——一旦牌带附魔（如永耀、技能加成等），就不会被消耗。这样附魔过的关键牌（如低费核心攻击牌）可以安全保留到下一轮业火涤尘。
- **②最低费牌附魔永耀**：每回合开始时，从手牌中筛选出「可打出、未附魔、可被附魔」的牌，取其中费用最低的一张随机附加永耀。若手牌中所有牌都不可被打出或无法附魔（如负面状态牌、进阶之灾等负费牌），则不触发。永耀牌耗能降为 0 并获得保留，但每回合只能打出 1 张（由[永耀](/mechanics/eternal_radiance.md)追踪机制保证）。
- **③PP 恢复范围**：只对消耗牌堆中的 PP 卡生效，且只恢复 Pp 未满的牌。如果消耗牌堆中没有符合条件的 PP 卡，则跳过此效果。每次最多恢复 3 张（恢复量 = 1 PP/张）。
- **④洗牌抽牌时机**：在每次玩家牌堆完成洗牌后立即触发（包括初始洗牌和战斗中的常规洗牌），不受其他抽牌效果干扰。每场战斗可能触发多次。
- **①③与 PP 牌的联动**：业火涤尘消耗 PP 牌时会将 PP 清零，之后通过③恢复——这意味着 PP 牌在业火涤尘后可以重新进入循环使用。配合④的持续补牌，PP 资源可以不断滚动。

## 小贴士

- **业火涤尘是核心引擎**：这张遗物的价值主要来源于每 3 回合一次的业火涤尘——清库抽牌堆和弃牌堆，对全场造成大量伤害和最大生命削弱。牌组越大（总牌数越多），单次业火涤尘的收益越高。慢速牌组（大费高伤牌占比高）反而更适合这张遗物，因为每轮战斗可以攒更多牌供业火涤尘消耗。
- **②的永耀附魔是免费弹药**：被永耀附魔的牌耗能 0 且有保留，意味着可以当回合留着下回合用，或者当回合打出也不占能量槽。每回合稳定产出一张免费牌，是持续的续航保障。
- **③是业火涤尘的补给链**：业火涤尘会清空所有 PP 牌的 PP，③在回合结束时回收部分 PP，让这些 PP 牌可以重新使用。如果牌组中有大量 PP 牌，③的回旋价值极高——本质上是用 PP 资源换取每 3 回合一次的爆发。
- **④是额外的过牌引擎**：洗牌抽 2 张是持续滚动的过牌，尤其适合配合大量弃牌（如奇巧、业火涤尘）触发洗牌的牌组。业火涤尘清掉一堆牌后立刻洗牌，④就触发了一次补牌。
- **注意业火涤尘的不可控性**：业火涤尘一次性烧光抽牌堆和弃牌堆所有非附魔牌——如果牌组里有很多高价值 PP 牌或附魔牌以外的关键牌，会被一并烧掉。搭配③的 PP 恢复可以弥补 PP 牌损失，但其他一次性效果牌需要提前做好规划。
- **性价比**：史诗合理——3 条辅助效果（永耀附魔/PP 恢复/洗牌抽牌）+ 1 条每 3 回合爆发的核心机制，整体引擎属性强，适合 PP 牌组和慢速控制流。
