# 斯嘟尔

<img src="/images/relics/seer_siduer.png" alt="斯嘟尔" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物

- **稀有度**: 商店

### 数值参数

| 参数 | 数值 |
|---|---|
| 每个蜡制遗物融化的战斗数 | 5 |

## 描述

每次经过<span style="color:#d4a017;font-weight:600">宝箱房间</span>时获得一个随机<span style="color:#3aa675;font-weight:600">稀有</span> seer<span style="color:#d4a017;font-weight:600">蜡制遗物</span>，各自在<span style="color:#3aa675;font-weight:600">5</span>场战斗后融化。

- **经过宝箱房即奖励**：每当你进入一个宝箱房间，自动获得一个 **随机稀有稀有度的 seer 遗物**，并以"蜡制遗物"的形式交到你手上。
- **稀有池**：只从稀有稀有度的 seer 遗物（`SEER_RELIC_SEER_` 前缀）中随机抽取；已持有且不可堆叠者会被避开，不会重复给到无效遗物。
- **独立融化倒计时**：每个蜡制遗物**各自**在 <span style="color:#3aa675;font-weight:600">5</span> 场战斗（指你参与的战斗）后**单独融化**——不是统一计时，也不是"一次性全融"。

### 蜡制遗物

**蜡制遗物**（源自原版"玩具盒 ToyBox"引入的概念）是一种"会随时间消失"的特殊遗物：它正常生效，但倒计时归零后会**融化（Melt）**并离场。斯嘟尔发放的每个蜡制遗物都带着自己的独立计时，融化互不影响。

- **实时列表**：遗物描述末尾会**动态列出**当前每个蜡制遗物的名字 + 剩余融化场数，形如：

> 蜡制遗物：
>
> - 蜡制·某某遗物（剩 5 场融化）
>
> - 蜡制·另一遗物（剩 3 场融化）

- **计数器**：斯嘟尔的遗物计数器会显示你**当前持有的蜡制遗物数量**，随获得/融化自动增减。

## 机制说明

- **触发时机**：`AfterRoomEntered` 中判定 `room is TreasureRoom`——只要进入宝箱房间就发放，不要求你打开宝箱或选择奖励。
- **独立倒计时的实现**：每个蜡制遗物以"遗物 Entry"为键，单独记录剩余场数；每场战斗结束各自 `-1`，谁的计数到 0 就只融化谁。这与原版玩具盒"统一倒计时、每 N 场熔最左侧"不同，多个蜡制遗物可以错峰融化。
- **来源隔离**：倒计时只跟踪斯嘟尔自己发放的蜡制遗物；其它来源（如玩具盒）的蜡制遗物不影响本计时，也不会被误融化。
- **读档/刷新**：进入任何房间时都会刷新描述里的蜡制列表，保证实时准确，不会因存档加载而显示错乱。

## 小贴士

- **这是"每过一个宝箱房就借一件稀有装"**：每进一个宝箱房白拿一件随机稀有 seer 遗物，等于阶段性给自己的构筑临时补强。蜡制遗物在用完 5 场前能完整发挥效果，相当于一段"限时稀有遗物"体验。

- **它是"多个上限叠加"的玩法**：因为每个蜡制遗物独立计时，多过几个宝箱房就能同时挂着好几件稀有遗物一起生效，数值叠起来相当可观。前提是尽快在它们融化前用完。

- **要算准"有效期"**：每个蜡制遗物都是 <span style="color:#3aa675;font-weight:600">5</span> 场战斗的"租约"。拿到后优先在其有效期内让它发挥最大价值（配合对应构筑），别把它当永久遗物规划成大后期策略。

- **稀有池会"挑没用的给"**：已持有且不可堆叠的稀有遗物会被排除，所以重复拿时更容易得到新面孔；但随机性仍在——可能给到完全契合构筑的，也可能给到当前用处不大的。

- **性价比**：商店。以"限时"为代价换来每次宝箱房的稳定稀有收益，配合多宝箱房路线收益可观，适合愿意围绕"限时稀有装"滚动构筑的玩法。
