# 万里春啼

> **归属**：玩家可施加
> **施加来源**：玩家获得——[万里春·北鸟](/relics/epic/wan_li_chun_bei_niao.md)（遗物，回合开始时全场异常总层数 > 5 时赋予）

## 基本信息

- **类型**: 增益（Buff）
- **叠加方式**: 单例（一次性，不叠加）
- **可见**: 是

### 数值参数

| 参数 | 数值 |
|---|---|
| 解除对象 | 所有生物（敌人 + 自身）的异常 |
| 解除计数 | 每种异常计 1（各生物分别计） |
| 全属性下降 | 每解除 1 种，所有敌人全属性 -1 |
| 转嫁异常 | 等量（解除种类数）种随机异常，各 2 回合 |
| 清空记录 | 北鸟的"记录异常"被清空 |

## 描述

回合结束时，解除所有生物[异常](/mechanics/abnormal-status.md)（每解除<span style="color:#3aa675;font-weight:600">1</span>种，所有敌人[全属性](/mechanics/all_attributes.md)-<span style="color:#3aa675;font-weight:600">1</span>）；下回合开始敌人受到等量随机[异常](/mechanics/abnormal-status.md)<span style="color:#3aa675;font-weight:600">2</span>回合，清空[记录](/mechanics/abnormal-status.md)。

## 详细机制

### 回合结束（自身侧）

1. **解除所有生物异常**：敌我双方各生物身上每个异常状态（按种类去重）逐一移除，每移除 1 种，**所有敌人生存单位全属性 -1**（力量/防御/速度/命中各 -1，与该异常数量无关，按"种类"计）；
2. **记录解除种类数 N**：N = 本次总共解除的种类数总和（所有生物累加，每种每个生物各计一次）；
3. **清空北鸟记录**：把[万里春·北鸟](/relics/epic/wan_li_chun_bei_niao.md)的"记录异常"重置——本场重新进入无记录状态。

### 下回合开始（敌方侧）

- 给**所有存活敌人**施加 N 种**随机[异常](/mechanics/abnormal-status.md)**，各持续 2 回合（N 与回合结束时解除的种类数一致；随机选取在多人模式下两端一致）。
- 结算后自身移除（一次性）。若解除种类数为 0，直接移除不转嫁。

## 小贴士

- **全场的异常 X 光**：回合结束把敌我双方的异常一次清空，同时把"异常压力"转嫁给敌人——越是你被异常缠身、越是敌方异常层数高，本能力的转嫁量越大。
- **全属性 -1 是隐藏打断**：每解除 1 种（各生物分别计），所有敌人四维各 -1，敌人越多、异常越杂，负面效果越重。
- **清记录 = 重启循环**：转嫁后北鸟回到无记录状态，下一回合再吃到首个异常会重新记录并转 3 回合混乱——适合反复利用③的减伤与转嫁节奏。
