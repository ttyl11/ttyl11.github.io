# 🟢 绿色恶魔水晶

## 基本信息

- **分类**: 防御与增益
- **稀有度**: 罕见
- **使用时机**: 战斗内
- **目标**: 自身

### 数值参数

| 参数 | 数值 |
|---|---|
| 每回合防御 | 2 |
| 额外抽牌 | 1 |
| 使用代价（最大生命） | 1 |

## 描述

持有时，每回合开始时，获得 <span style="color:#3aa675;font-weight:600">2</span> 点[防御](/mechanics/all_attributes.md)，并额外抽 <span style="color:#3aa675;font-weight:600">1</span> 张牌。

使用：失去 <span style="color:#d44;font-weight:600">1</span> 点[最大生命值](/mechanics/all_attributes.md)，随机变成[红色](/potions/red_demon_crystal_potion.md)或[紫色](/potions/purple_demon_crystal_potion.md)恶魔水晶。

## 详细机制

- **被动增益**：持有期间每个己方回合开始时自动获得 2 防御 + 额外抽 1 张牌，无需主动使用。
- **主动使用**：点击使用后扣除 1 点最大生命值，随机转变成红色或紫色恶魔水晶（用同步 RNG 判定）。
- **三色框架**：红/绿/紫共享"被动增益 + 扣最大生命变身"框架，颜色决定被动效果。
- **防御与过牌**：防御提高自身减伤强度，额外抽牌改善每回合手牌数量。

## 小贴士

- **攻守兼备的过牌**：每回合 +2 防御兼 +1 过牌，是三色里最"坦"也最"润滑"的被动。
- **提升牌组流畅度**：额外抽牌让关键牌更早上手，配合防御能在站场中从容展开。
- **变身权衡**：主动使用扣最大生命，喜欢绿水晶的防御+过牌被动就尽量不主动变身。
- **性价比**：罕见稀有度，长期持有的防御与过牌收益综合很高。
