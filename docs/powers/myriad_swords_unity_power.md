## 基本信息

- **类型**: 增益（Buff）
- **叠加方式**: 单例（不可叠加）
- **可见**: 是

## 描述

在你的回合开始时，自动从你的消耗牌堆打出一张[gold]君王之剑[/gold]。

## 详细机制

- **每回合白打一张**：自己回合开始时，从消耗牌堆里找第一张君王之剑；没有或当前不可打出时就不触发。
- **每回合只打 1 张**：无论消耗堆里堆了多少张，一次回合开始只自动打出第一张。
- **目标自动选**：需要单体目标时随机挑一个可命中的敌人；自身/全体目标牌按原目标结算。
- **能力不生剑**：它只负责「从消耗堆打」，君王之剑得靠宝剑等效果先送进消耗堆。
- **整场常驻**：能力不减少、不消失，只要消耗堆里还有君王之剑，每回合都会继续打。

## 小贴士

- **先造剑再开能力**：卡牌本身给 3 张 0 费宝剑；宝剑打出时会把手中所有君王之剑送进消耗堆，之后能力才有货可打。
- **消耗堆是弹药库**：多囤几张君王之剑，等于每回合多一次免费输出，长期战收益很高。
- **别把君王之剑留在手里**：留在手牌里不会被能力选中，必须先进消耗堆。
