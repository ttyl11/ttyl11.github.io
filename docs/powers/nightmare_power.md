# 梦魇

> **归属**：仅敌人持有（玩家无法自行获得此能力）
> **施加来源**：玩家施加给敌方——[圣武天尊·关羽](/relics/ancient/guan_yu.md)（遗物）

<img src="/images/powers/nightmare_power.png" alt="梦魇" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

* **类型**: 减益（Debuff）

* **叠加方式**: 计数器（Counter，层数累加）

* **可见**: 是

* **血条预测**: 否

### 数值参数

| 参数   | 说明                  |
| ---- | ------------------- |
| 斩杀条件 | 层数 > 圣武天尊·关羽持有者最大生命 |

## 描述

敌人回合开始时，若此状态层数大于**圣武天尊·关羽**持有者的**最大生命**，敌人死亡。

## 详细机制

* **斩杀判定时机**：

  * 仅在**梦魇持有者的回合开始时**触发一次判定

  * 若关羽持有者在此回合中因受伤而降低最大生命，可能导致斩杀门槛随之降低

  * 判定为**严格大于**，层数等于最大生命时不触发

* **斩杀方式**：

  * 直接调用击杀指令，无视格挡、护甲、免疫等任何保护效果

  * 属于即死效果，无法通过任何手段规避或减少伤害（因为本质是瞬杀，无伤害数值）

* **施加途径**：

  * 攻击命中关羽持有者时：施加 <span style="color:#3aa675;font-weight:600">1</span> 层

  * 关羽持有者未格挡的受伤时：施加 <span style="color:#3aa675;font-weight:600">2</span> 层

## 小贴士

* **斩杀门槛看关羽最大生命，不是当前生命**。即使关羽满血，只要最大生命较低，梦魇也容易达标。

* **被动受伤触发最强**：关羽吃一次未格挡伤害就跳 2 层，比主动攻击快一倍。

* **层数只增不减**：梦魇没有自然衰减，唯一清除方式是敌人死亡。一旦达标，下回合即死。

* **适用于关血少、梦魇高的对局**：关羽最大生命越低，斩杀门槛越低，梦魇威胁越大。
