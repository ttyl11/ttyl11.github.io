# ✨ 圣佑

## 基本信息

- **分类**: 净化
- **稀有度**: 普通
- **使用时机**: 战斗内
- **目标**: 自身

## 描述

移除自身所有负面效果。

## 详细机制

- **移除范围**：移除身上**所有类别为 Debuff（负面）的能力**——包括原版的虚弱/易伤/中毒，以及 mod 的异常状态、固定伤害、束缚、怕、诅咒等一切标记为负面的能力。
- **保留范围**：不变装为正面的能力（增益/元素/四维 buff）一律保留。
- **即时生效**：喝下立刻结算移除，无延迟。
- **净化级别**：属于"清场级"净化，比单点驱散彻底得多。

## 小贴士

- **全家桶一键解**：中毒、虚弱、易伤、束缚、怕、诅咒……无论敌人给你上多少种负面，一口圣佑全清。是面对"叠负面型敌人"的通用解药。
- **别浪费保底用途**：普通稀有度易获取，建议忍着等对面给你上贵重 debuff 再喝，前期一个普通虚弱就用掉有点奢侈。
- **与[乾坤](reverse_potion.md)的分工**：乾坤只转四维负值（且转成**正收益**），圣佑是清所有负面——前者"化敌为益"，后者"归零"。若你的负面以四维为主，乾坤更赚；若中毒/束缚一堆，圣佑更干净。
- **对自伤构筑友好**：mod 有大量"给自己叠负面换输出"的卡，圣佑在不打断构筑节奏的前提下随时给你一次"刹车"。
- **局限**：只能解"负面类别"，若某个机制被设计成特殊类型而非 Debuff，则不在移除之列；个别遗物负面可能需要特定手段。
