# 常之罚

## 基本信息

- **归属**：玩家能力
- **类型**：增益
- **叠加**：单例（不叠加；实际效果按是否存在判定）
- **施加来源**：[艾夏拉](/relics/rare/constancy.md)（自身回合开始时获得 1 层）
- **可见**: 是

## 描述

①本回合打出的第一张牌为<span style="color:#d4a017;font-weight:600">攻击牌</span>时，攻击伤害+<span style="color:#3aa675;font-weight:600">20</span>%；否则敌人回合内首次受到的攻击伤害-<span style="color:#3aa675;font-weight:600">20</span>%。<br/>敌人回合结束时移除。

## 详细机制

- 只记录拥有者**本回合打出的第一张牌**，之后打出的牌不再改变判定。
- **攻击分支**：第一张是攻击牌时，拥有者本回合全部攻击伤害 ×1.2。
- **非攻击分支**：第一张不是攻击牌时，改为在随后的敌人回合中，拥有者**第一次**受到的攻击伤害 ×0.8；同一敌人回合只减伤一次，后续攻击按原伤害结算。
- 移除时机在**敌人回合结束**，所以非攻击分支能完整覆盖其后的敌方回合；如果在自己回合结束移除，减伤分支永远来不及生效。
- 层数本身不叠加百分比，重复获得只刷新存在状态。
