# 十倍二长老

> **归属**：玩家可施加
> **施加来源**：玩家获得——[十倍二长老？](/cards/colorless/ten_times_two_elder.md)（卡牌）

## 基本信息

- **类型**: 增益（Buff）
- **叠加方式**: 单例（不可叠加；重复打出只刷新同一实例）
- **可见**: 是

## 描述

在你的回合开始时，从 3 张随机其他角色卡中三选一，将选中卡加入[手牌](/mechanics/hand.md)。若施加来源是升级牌，之后的候选全部为升级形态。

> 悬浮提示写"随机将一张其他角色的牌加入手牌中"，实际为玩家三选一。

## 详细机制

- **触发时机**：`BeforeSideTurnStart`，在持有者所属阵营的回合开始时，**先于当回合抽牌**。
- **候选池**：铁血战士、静默猎手、缺陷、亡灵法师、统治者五个原版角色卡池的全部解锁卡合并，不放回抽 3 张（互不重复）。
- **选择方式**：三选一，必须选 1 张，不能跳过；选中卡加入手牌底部。
- **升级状态**：施加时记录来源牌是否升级；是则后续每回合候选均为升级形态，且该状态只增不减。
- **单例**：再次施加不会增加每回合的选择次数；但升级副本施加时会立即触发一次额外三选一。
- **衍生**：候选与加入的牌均为战斗内衍生牌，战斗结束消失。
