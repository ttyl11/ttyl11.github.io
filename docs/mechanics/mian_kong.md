# 免控（MianKong）

**免控**是 Seer Mod 的核心卡牌关键词，持有者**仅免疫[异常状态](/mechanics/abnormal-status.md)**。

::: tip 核心硬规则：没有明说的免控都只是免疫异常状态
在 Seer Mod 中，除个别卡牌/能力特别注明（如明确标注「含能力下降」或「免疫所有异常状态与属性下降」）外，**所有没有明说的「免控」均统一且仅代表「免疫异常状态」**：
- **不免疫原版通用减益**：原版的虚弱、易伤、脆弱、缩小等普通 Debuff 不在防护范围内，会被正常施加；
- **不免疫属性下降**：力量、防御、命中、速度的降低属于属性下降范畴，由「免弱」防护，免控对其无效；
- **不阻断友方增益**：免控仅防御敌方负面状态，自己或队友施加的正面增益（包括属于异常体系的狂暴、星赐等正面状态）不会被自身的免控拦截。
:::

## 规则说明

- **免疫异常状态**：持有此关键词的角色不会受到异常状态施加（烧伤/中毒/石化/睡眠等全部 27 种异常状态均被免疫拦截）
- 描写面常见写法为"免控 X"（X 为回合数），效果对应本场战斗免疫异常状态 X 回合（或按描述中的具体层数计，在对方回合结束时减少 1 层）
- 与「免疫异常」的关系：免控是关键词简称，底层机制完全对应[异常免疫](/powers/debuff_immune_power.md)能力
