# 紫幽

<img src="/images/relics/seer_zi_you.png" alt="紫幽" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物

- **稀有度**: 罕见

### 数值参数

| 参数     | 数值        |
| ------ | --------- |
| 初始提升   | 全属性 +5    |
| 每回合衰减  | 全属性 -1    |
| 每层属性堕落 | 1         |
| 归零回合   | 第 5 回合    |

## 描述

[战斗开始](/mechanics/game-flow)时，自身[全属性](/mechanics/all_attributes) + <span style="color:#3aa675;font-weight:600">5</span>。每[回合开始](/mechanics/game-flow)时，自身[全属性](/mechanics/all_attributes) - <span style="color:#3aa675;font-weight:600">1</span>，每有1层属性提升，[堕落](/powers/fallen_power.md) <span style="color:#3aa675;font-weight:600">1</span>。

- **全属性**：力量、防御、命中、速度四项一起变化。
- **衰减不可逆**：每回合四项各 -1，第 5 回合起由增益转为负层（按各属性负效果结算）。
- **每回合堕落**：自身回合开始时，统计你身上四项属性（力量/防御/命中/速度）的**正值层数之和**——每有 1 层就获得 1 层[堕落](/powers/fallen_power.md)。只算正层，负层不计入；且统计发生在"全属性 -1"之前，用的是当回合开始时的属性。

## 小贴士

- **巅峰就在进战那一刻，第一回合已经开始跌**：战斗开始瞬间全属性 +5 是峰值，随后每个回合开始 -1——首回合实际只吃到 +4。但前几回合一上来就力量撑攻击、防御减受伤、速度多抽牌，压制力依然极强，是罕见遗物里少见的"开局就硬好几个身位"的类型。

- **核心矛盾：它逼你在热度没过之前结束战斗**：每回合四项都 -1，拖到第 5 回合 +5 归零后开始反向削弱。它明摆着是"速战速决"型遗物，跟拖字诀卡组相性很差——打得越久，这件遗物就从帮手变成累赘。

- **负层数按各属性负效果结算，不是简单白板**：归零之后力量减攻击、防御反过来增加受到的攻击伤害、命中每负层让攻击更容易被闪避、速度变成少抽并须弃牌——拖到后期会四项同时拖你后腿，所以别把它当永久增益养。

- **四项 +5 里真正立刻生效没那么满**：命中正层提供暴击率（每层 +10%），速度是每层 +1 抽、须弃掉半数，真正即时的硬提升是力量加攻击和防御减受伤。但即便只看这两项，前几回合也够猛。

- **堕落是附带的负面，别当真收益**：[堕落](/powers/fallen_power.md)本质是**负面层数**——叠满 100 会被[魔君接管](/powers/demon_takeover_power.md)强控乱打牌（当回合失控）。紫幽的堕落随属性递减逐回合走完：首回合 20 层 → 16 → 12 → 8 → 4，共累计 **60 层**——到不了 100 层触发接管，但会让任何其它堕落来源更容易被推上失控线。把它当"需要控量的代价"而不是收益来对待。

- **性价比**：罕见，第一回合白送全属性 +5，前几回合接近"增伤 + 减伤 + 抽牌"全包；只要不拖到第 5 回合后就是纯赚，适合爆发快、回合短的卡组。堕落作为副作用自动衰减，总量可控，不构成主要负担。
