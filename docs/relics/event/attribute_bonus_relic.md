# 属性加成

<img src="/images/relics/attribute_bonus_relic.png" alt="属性加成" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 事件
- **获取途径**: 「万能属性添加机」事件（免费试用=2个、小额付费=3个、全额梭哈=6个）

### 数值参数

| 参数 | 数值 |
|---|---|
| 事件设定值 | 1/2/5（由事件选项决定） |
| 每场实际属性总数 | 2/3/6 |
| 战后金币 | 20/30/60 |

## 描述

在每场战斗开始时，获得<span style="color:#3aa675;font-weight:600">0</span>个随机属性加成。

- **属性总数通常为设定值+1**：本遗物会先看自身是否已有元素——若还没有，就额外补上群星的礼赠那 1 个，总属性数 = 事件设定值+1（免费试用 2 个、小额付费 3 个、全额梭哈 6 个）；若已有其它来源的元素，则只施加事件设定值个。战后金币始终按事件设定值+1 结算（20/30/60，即每个属性 10 金币）。
- **属性种类**：从 26 种元素属性（草/水/火/飞行/电/机械/地面/普通/冰/超能/战斗/光/暗影/神秘/龙/圣灵/次元/远古/邪灵/自然/王/混沌/神灵/轮回/虫/虚空）中随机施加。

## 小贴士

- **每场战斗获得随机元素属性**：战斗开始时从 26 种元素属性中随机抽取若干个施加，总数 = 事件设定值+1（免费试用 2 个、小额付费 3 个、全额梭哈 6 个）。元素属性决定[克制倍率](/mechanics/element-affinity.md)——克制敌方元素 ×1.5、被敌方克 ×0.75、无关系 ×1.0，只作用于攻击伤害。
- **多属性按官方合并公式，不是连乘**：系数 = (各属性系数之和) ÷ n × (1 + 克制系数个数 − 1)。例如 7 个属性里 3 个克制、3 个微弱、1 个中性： (1.5×3 + 0.75×3 + 1) ÷ 7 × (1 + 2) ≈ **3.32 倍**；5 个克制 + 2 个中性： (1.5×5 + 1×2) ÷ 7 × (1 + 4) ≈ **6.79 倍**。属性越多上限越高，但每个属性都会拉低平均值，并不是“1.5 的 n 次方”。
- **重复抽到同一元素没有额外收益**：元素能力是单实例，重复抽到同一元素只会重复施加同一个能力，不会形成第二个属性位——等于浪费一次抽取。真正决定倍率的是**不同属性**的数量与克制/微弱分布。
- **属性打的是双向牌**：你的元素既决定你打敌人的倍率，也决定有元素的敌人打你的倍率——抽到被敌人克的属性，敌方攻击对你 ×1.5、你的攻击对敌 ×0.75，双重劣势。面对无元素的敌人（部分怪物没有属性分配）时属性完全无效，只剩金币收益。
- **战后额外金币是稳定底线**：每场战斗结束后额外获得等量×10 的金币（20/30/60）。长期跑线可以累积一笔可观金币——全程梭哈选项（60 金币/场）跑 30 场战斗就是 1800 金币。属性随缘、金币保底，这是本遗物的真实定价：金币收入是确定性收益，元素是彩票。
- **获取途径决定强度**：事件中选择"免费试用"设定 1，"小额付费"设定 2，"全额梭哈"设定 5。投入越多收益越高，梭哈选项的每场金币是免费试用的 3 倍，属性乘区上限也更高（同时方差更大）。
- **属性数量固定不升级**：事件选择后属性数量就固定了，没有后续升级途径。选择时需要权衡当前金币储备和长期收益——短跑线（快打 Boss）免费试用够用，长跑线梭哈的累计金币更划算。
