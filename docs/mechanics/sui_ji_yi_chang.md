# 随机异常（SuiJiYiChang）

**随机异常**是 Seer Mod 的自定义卡牌关键词，施加 X 种随机[异常状态](/mechanics/abnormal-status.md)，持续 Y 回合。

## 基本信息

| 项目 | 说明 |
| --- | --- |
| 类型 | Mod 卡牌关键词（异常施加型） |
| 效果 | 施加 X 种随机异常状态，持续 Y 回合 |
| 适用 | 卡面缩写术语，X/Y 由具体卡牌数值决定 |

## 规则说明

- **随机抽取**：从 25 种[异常状态](/mechanics/abnormal-status.md)中随机取 X 种，施加给目标，各持续 Y 回合
- 目标为敌人时：每个敌人同时吃下这 X 种异常（抽取结果对全体一致）
- 可抽到[石化](/powers/petrify_power.md)等强控，也可能抽到较弱的异常，收益看运气
- 例：[魔·黑天暗罚](/fifth-skill/magic_black_sky_punishment.md)的"随机异常 2，2"（2 种、2 回合）
