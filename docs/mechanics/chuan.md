# 川

**川**是 Seer Mod 的自定义卡牌关键词，打出后触发[预见](/mechanics/scry.md) 5，然后抽 3 张牌。

## 基本信息

| 项目 | 说明 |
| --- | --- |
| 类型 | Mod 卡牌关键词（触发型） |
| 效果 | 打出后[预见](/mechanics/scry.md) 5，然后抽 3 张牌 |
| 触发时机 | 卡牌打出后 |

## 规则说明

- **预见 5**：查看牌堆顶 5 张牌，可丢弃其中任意数量，再按剩余牌序放回（详见[预见](/mechanics/scry.md)）
- **抽 3 张**：处理完预见后，从牌堆顶抽 3 张牌入手牌
- 预见的牌与抽的牌来自同一牌堆，先看后抽，可直接把想要的牌留在堆顶立刻抽到
