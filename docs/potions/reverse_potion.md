# 🔄 乾坤

## 基本信息

- **分类**: 属性操控
- **稀有度**: 普通
- **使用时机**: 战斗内
- **目标**: 自身 & 全体敌人

## 描述

自身所有负属性转为正数，敌人所有正属性转为负数。

## 详细机制

- **自身翻身**：自己四项属性（[力量](/powers/strength_power.md)/[命中](/powers/accuracy_power.md)/[防御](/powers/defense_power.md)/[速度](/powers/speed_power.md)）中**为负数**的，直接反转成正数（-X → +X）。
- **敌人坠渊**：所有敌人四项属性中**为正数**的，直接反转成负数（+X → -X），把敌人的 buff 全部变成 debuff。
- **只作用于四维**：与[双极](twin_potion.md)一致，聚焦力量/命中/防御/速度四项，不含元素属性。
- **条件触发**：仅当该项存在对应的正/负值才反转，无负值部位对自身是空转，无比正属性部位对敌人是空转。

## 小贴士

- **化敌之强为己之强**：敌人的"力量 +5、防御 +5"喝下去瞬间全变 -5，一记乾坤把敌人的优势偷走并反过来变成自己的优势，是克制"叠属性型 Boss"的神器。
- **自救神药**：自己被上了命中 -10、防御 -3 等 debuff 时喝一口，负面全部转正，等于**同时完成了净化 + 强化**，一箭双雕，比单纯驱散更赚。
- **与[双极](twin_potion.md)的攻守分工**：双极要"先有正负"才翻倍，乾坤是"直接把正负颠倒"。这里如果敌人清一色全 debuff、自己清一色全 buff，乾坤会两边都空转——这时双极反而更优；反之场面越极端（敌强我负）乾坤收益越爆炸。
- **战略反制**：遇到专门给自己叠 buff 的敌人（如愈战愈强的 Boss），乾坤是少数能"拆掉对面成长"的途径，务必留到关键时刻。
- **净化的补充**：乾坤只反转四维负值，异常状态（中毒、束缚等）并不在此列，仍需要[圣佑](holy_blessing_potion.md)这类净化药水来处理。
