# 🩸 血契

## 基本信息

- **分类**: 召唤 / 自伤
- **稀有度**: 罕见
- **使用时机**: 战斗内
- **目标**: 自身

### 数值参数

| 参数 | 数值 |
|---|---|
| 失去生命 | 当前生命 10% |
| 召唤量 | 失去量 × 2（奥斯提） |

## 描述

失去当前生命值的<span style="color:#3aa675;font-weight:600">10%</span>，每回合开始召唤双倍奥斯提。

## 详细机制

- **代价**：立即失去当前生命的 10%（攻击类自伤，可被减免/免疫）。
- **代价转化**：以"未被减免的失去量 × 2"作为[奥斯提](/mechanics/summon.md)的召唤强度。
- **每回合召唤**：之后**每个回合开始**召唤奥斯提，召唤规模与该强度挂钩。
- **奥斯提**：是 mod 的召唤单位，为其承伤/提供收益的前排生物。

## 小贴士

- **拿血换前线**：用 10% 当前生命换一个**持续每回合成长的奥斯提**，等于用自己的血线抵押给召唤物做盾。血够多时这是"先进攻后再用奥斯提续命"的双保险。
- **血越多越划算**：失去量按当前生命 10% 算，血越多失去越多、召唤的奥斯提也越强——但注意反过来：残血时失去少、召唤弱。所以**尽量在半血以上喝**。
- **护盾/免伤放大**：代价是攻击类自伤，可被[格挡](/mechanics/block.md)/免疫挡掉一部分，**挡掉的那部分不转为召唤**，但本体掉血更少——这是一把双刃剑，需权衡"少流血"与"拿去喂召唤"。
- **持续承伤单位**：奥斯提每回合自动召唤，等于给了你一个持续的"前排肉盾"，特别适合部署在需要扛住敌人的体系里，让本体专注输出。
- **反制**：若敌人有清召唤/斩杀召唤的手段，血契的投入可能被瞬间拆掉，要注意战场节奏。
