# 🌑 大暗黑天秘药

## 基本信息

- **分类**: 卡牌生成 / 爆发
- **稀有度**: 稀有
- **使用时机**: 战斗内
- **目标**: 自身

## 描述

将一张[魔·黑天暗罚](/fifth-skill/magic_black_sky_punishment.md)加入你的手牌，本回合费用为0。

## 详细机制

- **生成卡牌**：往手牌加入一张[魔·黑天暗罚](/fifth-skill/magic_black_sky_punishment.md)。
- **本回合 0 费**：该卡标记为"本回合免费"，当前回合直接打出不需要付能量费。
- **一次性爆发**：药水本身不影响后续回合，那张免费卡打完即止。

## 小贴士

- **定向大爆发**：直接送一张指定的强力卡且**本回合免单**，等于白嫖一次 4 费级的大招。适合在需要瞬间斩杀或清场的节点直接一波。
- **节奏药**：稀有度说明它不常见，但它的强在于"指定卡 + 免费"——不是随机，而是你明确知道会给什么，可以围绕这张卡的机制提前布局（如配合它的附带效果体系）。
- **别囤着**：免费只在当前回合，属性浪费。柔和时机刚需时马上喝，别让它躺在药水栏里过期。
