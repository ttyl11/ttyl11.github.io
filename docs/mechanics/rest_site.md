# 休息处选项

休息处（火堆）默认提供 2 个选项（休息、锻造），多人模式额外有互助；其余选项由遗物或卡牌追加。休息处也是右键使用[星辰之录](/relics/event/star_tracker_relic.md)进入泰坦之灵商店的场所。

## 基础选项

- **休息**：回复自身最大生命 <span style="color:#3aa675;font-weight:600">30</span>%。回复量受遗物/能力修正（`Hook.ModifyRestSiteHealAmount`）。
- **锻造**：从**牌组**中选择 <span style="color:#3aa675;font-weight:600">1</span> 张可升级的卡牌进行升级。这里的牌池是整副牌组，不是手牌或弃牌堆；牌组中没有可升级卡牌时该选项灰显。
- **互助**（多人专属）：选择另一名玩家，回复其最大生命 <span style="color:#3aa675;font-weight:600">30</span>%。不能选择自己。

## 原版遗物/卡牌追加选项

| 选项 | 来源 | 效果 |
|---|---|---|
| 举重 | Girya（稀有遗物） | 累计举重次数 +1，最多 3 次；之后每进入战斗房间，按累计次数获得等量力量。达到 3 次后选项消失。 |
| 点燃 | PumpkinCandle（先古遗物） | 点燃层数 +5；每场战斗结束 -1，层数大于 0 时最大能量 +1。 |
| 孵化 | ByrdonisEgg（任务牌） | 获得 Byrdpip 遗物。 |
| 挖掘 | Shovel（遗物） | 从遗物袋前端抽取 1 件随机遗物。 |
| 烹饪 | MeatCleaver（先古遗物） | 从牌组移除 2 张牌，最大生命 +9；可移除的牌少于 2 张时不可选。 |
| 复制 | PaelsGrowth（先古遗物） | 复制牌组中**所有**带克隆附魔的卡牌并加入牌组。不是只复制 1 张，也不涉及手牌或弃牌堆。 |

## mod 追加选项

### 跑步（巧克利）

- **触发**：持有[巧克利](/relics/rare/chocoli.md)，且任意一份巧克利累积的跑步机会大于 0。每打完 3 场战斗（普通/精英/Boss 房间，子地图等非战斗房间不计）获得 1 次机会，遗物计数器显示当前机会数。
- **结算**：一次性清零**所有**份数的跑步机会。每消耗 1 次机会：锻炼次数 +1（统一记在第一份巧克利上），并复制 1 份巧克利遗物。
- **战斗开始加成**：每份巧克利各自向自身施加 <span style="color:#3aa675;font-weight:600">2</span> 层灾厄；锻炼次数大于 0 时，再获得敏捷 +锻炼次数、速度 +2×锻炼次数、手牌上限 +锻炼次数。
- **要点**：属性加成按**总锻炼次数**计算，不随遗物份数翻倍；但灾厄由每份遗物**分别**施加，份数越多每场战斗开始时的灾厄层数越高。

### 赛尔号，启动！（罗杰船长）

- **触发**：持有[罗杰船长](/relics/shop/captain_roger.md)，且牌组中的赛尔号尚未启动。罗杰船长获得时会把赛尔号加入牌组。
- **效果**：赛尔号进入启动状态，移除“不可打出”，本场战斗可以打出一次。
- **重置**：无论本场是否打出，战斗结束后都会自动取消启动并重新加上“不可打出”，下次需要再次在休息处启动。
- **战斗奖励**：在打出赛尔号的战斗中，战斗结束额外获得 <span style="color:#3aa675;font-weight:600">2</span> 个随机普通遗物（赛尔号升级后为 <span style="color:#3aa675;font-weight:600">3</span> 个），从遗物袋前端抽取。

### 核心跃迁（工程师苏克）

- **触发**：持有[工程师苏克](/relics/shop/engineer_su_ke.md)即出现该选项，无其他条件。
- **结算**：从已拥有的遗物中选择 1 件，将其替换为高一阶的随机遗物。目标池会排除初始、商店、事件遗物。
- **可选范围**：普通、罕见、稀有、Seer 史诗遗物。不可选：初始/商店/事件遗物、没有自定义稀有度的先古遗物、传说遗物。
- **升级链条**：普通 → 罕见（原版罕见池）；罕见 → 稀有（原版稀有池）；稀有 → **Seer 史诗池**；Seer 史诗 → **Seer 传说池**。
- **要点**：原版没有史诗/传说稀有度，因此“稀有以上”两阶只能升成 seer 遗物；传说已是终点。没有可升级遗物时选项仍会显示，但选择后不会发生任何替换。
