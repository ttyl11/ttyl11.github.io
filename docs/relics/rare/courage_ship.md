# 勇气号

<img src="/images/relics/seer_courage_ship.png" alt="勇气号" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 稀有
- **获取途径**: 战斗奖励、事件奖励等随机池

## 描述

每次<span style="color:#d4a017;font-weight:600">洗牌</span>时，获得<span style="color:#a070d0;font-weight:600">勇气之魂</span>：自身下个回合结束时，再额外开启一回合。

## 风味文字

<span style="color:#d44;font-weight:600">勇气可嘉。</span>

## 关联能力

- [勇气之魂](/powers/courage_soul_power.md)：每获得一层，下个回合结束时再额外开启一回合。

## 小贴士

- **洗牌触发**：每次弃牌堆的牌被洗入抽牌堆时都会触发（包括被动洗牌和主动效果），不受能量或手牌限制，可以稳定叠加。
- **额外回合的价值极高**：每获得一层勇气之魂，等于在下回合后额外赠送一个完整回合，可以打出更多牌、积累更多伤害。多份勇气号遗物（或与其他获得勇气之魂的来源配合）会让额外回合指数级增长。
- **节奏规划**：额外回合会打乱原有的回合节奏，适合需要爆发输出或大量补牌的构筑——在额外回合里一次性倾泻手牌，收益远超正常回合。
- **与云玩家的互补**：[迪莫豪斯](/relics/shop/dimo_house.md) 移除了赛尔牌后若获得勇气号，可用额外回合快速打出换回来的原版稀有卡，实现高速爆发。
