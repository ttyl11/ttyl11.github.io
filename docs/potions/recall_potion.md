# ⏳ 时溯药水

## 基本信息

- **分类**: 恢复 / 资源
- **稀有度**: 稀有
- **使用时机**: 战斗内
- **目标**: 自身

### 数值参数

| 参数 | 数值 |
|---|---|
| 回血量 | 最大生命值（回满） |
| 暴食诅咒 | 1 张（战斗结束加入牌组） |

## 描述

恢复所有生命值和PP值。本场战斗结束时，将<span style="color:#3aa675;font-weight:600">1</span>张[暴食](/cards/curse/gluttony.md)诅咒牌加入你的牌组。

## 详细机制

- **瞬间回满**：把生命值恢复到**最大生命值**。
- **满 PP**：让所有 PP 卡牌的 PP 值回满。
- **延迟代价**：施加一层能力，**战斗结束时**往卡组里塞 1 张[暴食](/cards/curse/gluttony.md)诅咒牌（代价不立即支付）。

## 小贴士

- **最强"整车回血"之一**：罕见地"回满血量 + 回满 PP"同时发生，等于一瓶把血线和输出资源都拉回巅峰。在血量濒危又急着打 Boss 的节点，是救命级的稀有药水。
- **代价能"拖延"**：暴食诅咒在**战斗结束**才进卡组，也就是说你在当前战斗爽完之后才承担代价。若本场结束直接进入商店/删除卡牌，代价几乎被抵消——这是它的隐藏优势。
- **性价比账**：一瓶 = 满血 + 满 PP，代价是 1 张诅咒。与[PP药水](pp_potion.md)（只回 PP）+ 大奶药水的组合相比，它用一张诅咒换来一次性的全面重置，中后期救人局面下远超拼凑。
- **慎在"快赢了"时用**：若战斗只剩一记补刀，喝它纯属吃掉一张诅咒的负收益。留到"真的快倒/必须扛住接下来几回合"的关键节点。
- **诅咒处理手段**：手上有删除卡/净化诅咒的途径时，时溯的代价近乎归零，优先考虑保留它应对高压 Boss。
