# 蚀返（ShiFan）

**蚀返**是赛尔（Seer）职业独有的稀有关键词，控制带有此关键词的牌在被[消耗](/mechanics/exhaust.md)时的行为。

## 规则说明

| 项目       | 说明                                                                             |
| ---------- | -------------------------------------------------------------------------------- |
| 适用范围   | 仅赛尔角色牌                                                                         |
| 触发时机   | 此牌被[消耗](/mechanics/exhaust.md)时                                            |
| 效果       | 向[抽牌堆](/mechanics/draw_pile.md)生成一张本牌的复制品；复制品同样带有蚀返关键词         |
| 关键词类型 | **触发型关键词**，不在描述文字中显示，但会出现在关键词标注中                                                   |
| 连锁潜力   | 复制品若再次被消耗，会再次触发蚀返，形成持续生成复制品的连锁反应                                                   |

**典型流程：**

1. **打出卡牌**：带有蚀返的牌被打出并结算效果。
2. **进入消耗堆**：由于带有消耗关键词，该牌从手牌进入消耗堆。
3. **触发蚀返**：系统检测到蚀返关键词，立即向[抽牌堆](/mechanics/draw_pile.md)生成一张本牌的复制品。
4. **复制品处理**：新生成的复制品同样带有蚀返和消耗关键词，若再次被打出并消耗，会再次触发蚀返。

关键细节：

- 蚀返的触发时机在**消耗瞬间**，早于战斗结束；复制品直接进入抽牌堆而非等待战斗结束
- 复制品与原牌完全相同，包括所有关键词和 PP 值
- 连锁触发：复制品若再次被消耗，会再次生成一张复制品，理论上可无限连锁（受牌堆容量限制）
- 与[残鸣](/mechanics/canming.md)的区别：残鸣是从消耗牌堆选牌入手，蚀返是向抽牌堆生成复制品

## 带蚀返的卡牌

- [神权忤逆](/cards/character/shen_quan_wu_ni.md)：被消耗时向抽牌堆生成一张本牌复制品

## 与类似机制的区别

| 机制               | 区别                                                                   |
| ------------------ | ---------------------------------------------------------------------- |
| **残鸣（CanMing）** | 残鸣从[消耗牌堆](/mechanics/exhaust_pile.md)选 1 张牌加入手牌；蚀返向抽牌堆生成复制品 |
| **回响（Echo）**    | 回响每回合开始时从牌堆生成复制品到手牌；蚀返仅在被消耗时触发，触发条件更严格              |
| **真神（TrueGod）** | 真神牌存放在独立牌堆中；蚀返的复制品直接进入主抽牌堆                         |
| **消耗（Exhaust）** | 消耗是离场机制；蚀返是在消耗触发额外效果，让牌以复制品形式回归牌组                    |
