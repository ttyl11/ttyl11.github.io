# 薇

> mod 卡牌关键词（SEER_KEYWORD_VIGIL）

由[薇尔诗](/relics/legendary/vier_poem.md)赋予部分卡牌的关键词。

## 机制

当一张**非"薇"**的相邻卡牌被打出时，带有"薇"关键词的卡牌会**自动打出**。

- **触发条件**：打出的牌与"薇"牌在手牌中**左右相邻**（紧挨着）。基于打出前的手牌快照判定位置。
- **自动打出**：触发后，"薇"牌自动以默认目标打出，不消耗能量；但仍会走正常的 PP 扣除（PP 大于 0 时每次 -1）。
- **每次只触发一个**：若两侧都有"薇"牌，只自动打出其中一个（优先左侧）。
- **不可打出的牌不触发**：若"薇"牌带有"不可打出"关键词，不会自动触发；PP 不足不算此列。
- **PP 归 0 仍会触发**：薇只检查薇牌是否带"不可打出"关键词，不检查 PP，因此 0 PP 的薇牌仍会被自动打出。持有[无为觉者](/relics/legendary/inaction_awakener.md)时，0 PP 的牌会先跳过自身效果，再由遗物改写 PP。

## 小贴士

- **手牌位置很重要**：薇牌必须紧挨着打出的牌才会触发，要合理安排手牌顺序，把薇牌放在打算先打出的牌旁边。
- **零费自动打出**：薇牌自动打出不消耗能量，是免费的额外行动，但仍会扣 PP；PP 归 0 后仍可触发，配合过牌可形成连锁反应。
