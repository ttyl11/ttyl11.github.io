# 🔴 红色恶魔水晶

## 基本信息

- **分类**: 属性与增益
- **稀有度**: 罕见
- **使用时机**: 战斗内
- **目标**: 自身

### 数值参数

| 参数 | 数值 |
|---|---|
| 每回合力量 | 2 |
| 每回合速度 | 2 |
| 使用代价（最大生命） | 1 |

## 描述

持有时，每回合开始时，获得 <span style="color:#3aa675;font-weight:600">2</span> 点[力量](/mechanics/all_attributes.md)和 <span style="color:#3aa675;font-weight:600">2</span> 点[速度](/mechanics/all_attributes.md)。

使用：失去 <span style="color:#d44;font-weight:600">1</span> 点[最大生命值](/mechanics/all_attributes.md)，随机变成[绿色](/potions/green_demon_crystal_potion.md)或[紫色](/potions/purple_demon_crystal_potion.md)恶魔水晶。

## 详细机制

- **被动增益**：持有本药水期间（只要在药水栏），每个己方回合开始时自动获得 2 力量 + 2 速度，无需主动使用。
- **主动使用**：点击使用后扣除 1 点最大生命值，随机转变为绿色或紫色恶魔水晶（用同步 RNG 判定）。
- **水晶可变**：三色恶魔水晶（红/绿/紫）共享"被动增益 + 扣最大生命变身"框架，颜色只决定被动效果不同，变身即切换成另一瓶的被动。
- **同一时间持有一瓶**：变身是"变形"而非额外获得，变身后旧效果消失、新水晶的被动生效。

## 小贴士

- **白嫖力量速度**：占用一个药水栏即可每回合稳定 +2 力量 +2 速度，回合越多收益越大，适合站场持伤型牌组。
- **最大生命是代价**：每次主动使用掉 1 点最大生命，多次变身会导致生命上限递减；若追求永久属性且不介意上限，可多次变身轮换。
- **变身连锁**：红→绿→红→紫等随机轮转，可反复利用不同水晶的被动。
- **性价比**：罕见稀有度，被动增益在前中期很可观的"永动机"类药水，慎用主动变身以免损失上限。
