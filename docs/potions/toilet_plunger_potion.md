# 🪠 清通棒

## 基本信息

- **分类**: 交互
- **稀有度**: 罕见
- **使用时机**: 战斗外
- **目标**: 自身

## 描述

选择一个**遗物**进行移除，[初始遗物](/relics/starter/)除外。

## 详细机制

- **选择移除**：弹出遗物选择网格，从当前持有的非初始遗物中选择一个移除。
- **初始遗物不可移除**：初始/起始稀有度遗物不能作为目标。
- **可取消**：允许取消选择而不消耗效果。
- **战斗外**：只能在战斗外使用。

## 小贴士

- **遗物取舍**：拿到不想要/负面的遗物时可移除，优化遗物组合。
- **针对性清理**：某些遗物带来副作用（如易伤、特殊召唤），清掉能改善构建。
- **性价比**：罕见稀有度提供一次遗物整形机会，属于"治理构建"道具。
