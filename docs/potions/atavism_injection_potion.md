# 💉 返祖针剂

## 基本信息

- **分类**: 元素变身 / 恢复
- **稀有度**: 稀有
- **使用时机**: 战斗内
- **目标**: 自身

## 描述

永久变[普通系](/powers/normal_power.md)并恢复生命至满。

## 详细机制

- **永久变普通系**：把自身属性永久设定为普通系（跨战斗持续）。
- **回满生命**：恢复生命到**最大生命值**。
- **无副作用**：单一效果集中，不改动其他状态。

## 小贴士

- **"回满 + 定系"的组合拳**：稀有药水最实在的用法——把命补满的同时，把元素定成中性的普通系。普通系在克制表里相对平衡，适合不想被元素绑定、追求稳健的构筑。
- **血满就是最终底牌**：回满生命=把你从死亡线直接拉回满状态，对残血残条的高压时刻是救命级的。稀有度值这个价。
- **普通系的取舍**：没有元素硬优势，等于放弃"用克制打加成"。但换来的是**彻底摆脱元素体系管理**（不会被弱点属性压制），对不买元素流、只靠硬实力打牌的玩家反而更省心。
- **与[智慧果实](wisdom_fruit_potion.md)等"带附赠"变系的差别**：返祖把全部价值押在"回满血+中性系"，不像智慧果实送 4 张牌；它的亮点是治疗，攻击面靠你自己。

## 相关机制
