# 二律背反

> **归属**：玩家可施加
> **施加来源**：玩家获得——[二律背反](/cards/character/antinomy.md)（卡牌）

<img src="/images/powers/antinomy_power.png" alt="二律背反" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 增益（Buff）
- **叠加方式**: 单例（不可叠加）
- **可见**: 是

## 描述

下一次对手的攻击若不是<span style="color:#d4a017;font-weight:600">暴击</span>，则免疫该次攻击。

## 详细机制

- **免疫条件**：
  - 目标必须是自身
  - 掉血来源必须是敌方生物
  - 伤害来源**没有暴击**（无暴击能力，或本次攻击未暴击）
  - 满足以上条件时，掉血完全无效化；判定发生在格挡之后，代码不要求来源必须是攻击牌
- **暴击穿透**：暴击伤害不受二律背反影响，照常生效。
- **被攻击后消失**：当本方受到对方攻击且拥有者是被命中目标之一时，移除自身。即无论是否暴击、哪怕被普通格挡全挡下，被攻击一次后该能力即消失；非攻击伤害被免疫则不会消耗这层效果。
- **视觉效果**：能力生效时会闪烁提示。
- **无层数设计**：无层数，效果只看"有无"。
