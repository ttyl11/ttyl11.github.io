# 十倍二长老？

<img src="/images/cards/ten_times_two_elder.png" alt="十倍二长老？" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 无色牌
- **能量消耗**: 0
- **类型**: 能力
- **稀有度**: 普通
- **目标**: 自身
- **可升级**: 是（1 级）

## 描述

每回合开始时，从<span style="color:#3aa675;font-weight:600">3</span>张其他角色卡中选择一张加入[<span style="color:#d4a017;font-weight:600">手牌</span>](/mechanics/hand.md)。

## 升级后

每回合开始时，从<span style="color:#3aa675;font-weight:600">3</span>张<span style="color:#d4a017;font-weight:600">升级</span>其他角色卡中选择一张加入[<span style="color:#d4a017;font-weight:600">手牌</span>](/mechanics/hand.md)。打出时再从<span style="color:#3aa675;font-weight:600">3</span>张中选择一张加入。

## 小贴士

- **触发机制**：打出时对自身施加能力。该能力每回合开始时，从<span style="color:#3aa675;font-weight:600">3</span>张随机其他角色卡中**三选一**，把选中那张加入[<span style="color:#d4a017;font-weight:600">手牌</span>](/mechanics/hand.md)——从随机塞一张升级为自主挑选，主动权回到玩家手里。
- **角色卡池**：从铁血战士（Ironclad）、静默（Silent）、缺陷（Defect）、亡灵法师（Necrobinder）、统治者（Regent）五个角色卡池中随机抽取 <span style="color:#3aa675;font-weight:600">3</span> 张未锁定卡供选择。
- **升级效果**：升级后，每回合的三选一候选和入职的卡都会**自动升级**；且打出时额外再从 <span style="color:#3aa675;font-weight:600">3</span> 张中三选一加入一张。
