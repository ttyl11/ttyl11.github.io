# ⚙️ 齿轮核心

## 基本信息

- **分类**: 资源
- **稀有度**: 普通
- **使用时机**: 战斗外
- **目标**: 自身

## 描述

获得 <span style="color:#3aa675;font-weight:600">1</span> 个额外的[药水](/potions/index.md)栏位。

## 详细机制

- **永久提升**：使用后永久增加 1 个药水栏位（写入玩家本体，跨战斗保留）。
- **战斗外使用**：只能在战斗外用，用于扩充常驻药水容量。
- **栏位差异**：药水数量显示与上限随之提高，可携带更多药水进入后续战斗。

## 小贴士

- **多一瓶就是多一张牌**：额外药水栏位长期等于每次多带一瓶药水，战略价值随对局推进递增。
- **优先找自动增益类药水**：扩充的栏位建议放被动/长效药水（如恶魔水晶、积木塔），最大化"白嫖"收益。
- **性价比**：普通稀有度却永久加栏位，是很值得优先占栏使用的药水。
