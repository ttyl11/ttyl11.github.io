## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 罕见
- **进化链**: [小特](/relics/common/xiao_te.md) → [莱茵] → [莱茵哈特](/relics/rare/lai_yin_ha_te.md)

### 数值参数

| 参数 | 数值 |
|---|---|
| ①固伤来源 | 回合结束时的自身当前格挡 |
| ①目标 | 所有可命中敌人 |
| ②进化阈值 | 累计施加 200 固定伤害 |
| 计数口径 | 全来源施加固定伤害（跨战斗累积） |

## 描述

①回合结束，对所有敌人施加等于自身[gold]格挡[/gold]的[gold]固定伤害[/gold]。②累计施加[blue]200[/blue][gold]固定伤害[/gold]，升级为[gold]莱茵哈特[/gold]。

## 详细机制

- **①回合结束按格挡施加固定伤害**：每个我方回合结束时，取**自身当前格挡数值**，对所有可命中敌人各施加等量[固定伤害](/powers/fixed_damage_power.md)。格挡归 0 时不触发。固定伤害走能力结算（`PowerCmd.Apply<SeerFixedDamagePower>`），下回合开始真正扣血，吃[免疫固定伤害](/powers/immune_fixed_damage_power.md)等机制。
- **①与"格挡数值"实时挂钩**：结算用的格挡是回合结束那一刻的当前值（不是历史最大值）——只要回合结束时还站得住格挡，就全量打出。格挡越高，①惩罚越疼。
- **②累计固伤口径**：**由你施加的固定伤害全来源计数**（`TryModifyPowerAmountReceived` 监听，过滤 giver 为自身或自家宠物）——包括①自己回合结束打的固伤、卡牌固伤、其它遗物固伤，全部叠加进进化数值，跨战斗累积，角标实时显示。达到 200 进化为[莱茵哈特](/relics/rare/lai_yin_ha_te.md)。
- **②进化判定时机**：进化判定放在**异步安全点**（回合开始 / 战斗结束）执行——因为固伤计数发生在同步的 `TryModifyPowerAmountReceived` 里不能 await，进化替换要等回到异步钩子再触发，同一时刻不会重复进化。
- **施加强度说明**：①对每个敌人施加的层数 = 当前格挡，没有上限；敌人有[免疫固定伤害](/powers/immune_fixed_damage_power.md)时该敌人不扣血但不会反噬。

## 小贴士

- **堆格挡 = 全员吃饭**：①把当前格挡原样转成对每个敌人的固定伤害，敌方越多，"格挡→伤害"的转化总量越大。配合高格挡防御流，一次回合结束就能把 30+ 格挡变成全场 30 点固伤。
- **固定伤害无视格挡**：固定伤害不可格挡，打在有格挡的敌人身上也直接扣血——①适合破"堆格挡怪"。
- **进化靠持续输出固伤**：②只要你在持续施加固伤（卡牌、召唤物、①本身）就在推进，200 点比小特的 300 格挡更容易攒。优先出手牌里带固定伤害的牌，或让①的高格挡回合多触发几次。
- **别让格挡被清空再结束回合**：回合结束时格挡为 0 则①不触发——输出前先保住格挡，避免被清格挡/掉格挡机制把①掐死。
