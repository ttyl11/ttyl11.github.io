# 🏛️ 立柱

## 基本信息

- **分类**: 防御
- **稀有度**: 普通
- **使用时机**: 战斗内
- **目标**: 自身

## 描述

获得 <span style="color:#3aa675;font-weight:600">1</span> 层[人工制品](/powers/artifact_power.md)。

## 详细机制

- **作用于自身**：为自身施加 1 层[人工制品](/powers/artifact_power.md)能力。
- **人工制品**：免疫下一次被强加的负面效果（debuff 防护），使用后被消耗。

## 小贴士

- **关键防护**：用来挡一次致命的 debuff（如针对你的净除/强虚弱等）。
- **时机**：面对喜欢第一个回合就叠异常的敌人、或即将被施加强效果前使用最有效。
- **性价比**：普通稀有度单层防护，属针对性道具。
