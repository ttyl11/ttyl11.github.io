## 小贴士

- **全属性 +2 是全场双向增益**：力量、防御、命中、速度各 +<span style="color:#3aa675;font-weight:600">2</span> 施加给所有存活生物（含队友与所有敌人）。力量 +2 → 攻击伤害 +2；防御 +2 → 受到的受力量加成攻击伤害 -2；命中 +2 → 暴击率 +<span style="color:#3aa675;font-weight:600">20</span>%（并隐藏地让受击目标闪避 -<span style="color:#3aa675;font-weight:600">10</span>%）；速度 +2 → 玩家回合开始多抽 <span style="color:#3aa675;font-weight:600">2</span> 张再弃 <span style="color:#3aa675;font-weight:600">1</span> 张，怪物回合开始获得最大生命 <span style="color:#3aa675;font-weight:600">10</span>% 的[格挡](/mechanics/block.md)。敌人的收益会实打实作用在你身上，尽量在敌方爆发前打出。
- **格挡也送给敌人**：所有存活生物获得 <span style="color:#3aa675;font-weight:600">15</span> 点（升级后 <span style="color:#3aa675;font-weight:600">30</span> 点）[格挡](/mechanics/block.md)。你的格挡吸收敌方攻击，敌人的格挡也吸收你的攻击。适合在敌人即将爆发高伤害时打出，用格挡吸收；不适合在你准备当回合斩杀时打出，因为敌人也获得了格挡。
- **多抽牌只给自己，实际覆盖接下来 2 个回合**：能力按 <span style="color:#3aa675;font-weight:600">3</span> 层施加，但打出当回合结束就先减 <span style="color:#3aa675;font-weight:600">1</span> 层——之后只有接下来 <span style="color:#3aa675;font-weight:600">2</span> 个回合开始时各多抽 <span style="color:#3aa675;font-weight:600">2</span> 张（共 <span style="color:#3aa675;font-weight:600">4</span> 张），第 <span style="color:#3aa675;font-weight:600">3</span> 个回合开始前已归零。这是这张牌的核心隐性收益。
- **速度不是相互抵消**：玩家 +<span style="color:#3aa675;font-weight:600">2</span> [速度](/powers/speed_power.md) = 回合开始多抽 <span style="color:#3aa675;font-weight:600">2</span> 张、随后强制弃 <span style="color:#3aa675;font-weight:600">1</span> 张；敌人 +<span style="color:#3aa675;font-weight:600">2</span> 速度 = 每个敌人各自在自身回合开始获得最大生命 <span style="color:#3aa675;font-weight:600">10</span>% 的格挡。多敌人时合计格挡更多，斩杀前要算进去。
- **升级只翻倍格挡**：升级后[格挡](/mechanics/block.md) <span style="color:#3aa675;font-weight:600">15</span> → <span style="color:#3aa675;font-weight:600">30</span>，翻倍。其他参数（全属性 +<span style="color:#3aa675;font-weight:600">2</span>、多抽牌层数）均不变。升级适合需要硬抗高频攻击的场景，纯输出流派升级价值有限。
- **性价比**：<span style="color:#3aa675;font-weight:600">1</span> 费打出 = 全场 +<span style="color:#3aa675;font-weight:600">2</span> 全属性（双向）+ <span style="color:#3aa675;font-weight:600">15</span>/<span style="color:#3aa675;font-weight:600">30</span> 格挡（同样给敌人）+ 自身接下来 2 个回合共多抽 <span style="color:#3aa675;font-weight:600">4</span> 张。抽牌优势在自己这边，但属性与格挡双方对等。罕见稀有度合理。
