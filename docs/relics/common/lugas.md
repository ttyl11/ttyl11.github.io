## 描述

## 小贴士

* **战斗开始时即时加入**：抽牌堆在战斗开局前就填入巨石，不影响初始手牌数量，但会稀释后续抽牌质量。

* **巨石的战术价值**：巨石是原版 STS2 的 1 费 Token **攻击牌**，造成 16（升级后 20）点伤害。免费获得 3 张等同于 48（升级后 60）点总伤害，开局防守压力小的场合可用于补充输出。

* **稀释风险**：每场战斗固定加入多张巨石，长期持有会压缩牌组中有效卡牌的占比，需权衡防御收益与牌组效率。

* **普通稀有度定位**：提供稳定伤害手段，适合前期缺乏输出手段的牌组，但中后期可能被更高效的攻击卡取代。
