# 勇气之魂

## 基本信息

- **归属**：玩家能力
- **类型**：增益
- **叠加**：计数型
- **施加来源**：[勇气号](/relics/rare/courage_ship.md)（洗牌时获得 1 层，额外回合中洗牌不触发）；部分刻印
- **可见**: 是

## 描述

自身回合结束时，额外获得 <span style="color:#3aa675;font-weight:600">1</span> 个回合。

## 详细机制

- 每层提供 **1 个额外回合**；额外回合结束后层数 −1。
- 只有能力的拥有者能获得额外回合，多人模式下不会把队友一起拉进额外回合。
- 勇气号的触发条件是「拥有者洗牌」，洗牌一次给 1 层；在额外回合中洗牌不再给层，避免无限连锁。
