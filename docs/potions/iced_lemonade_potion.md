# 🍋 冰镇柠檬汁

## 基本信息

- **分类**: 净化 / 资源
- **稀有度**: 罕见
- **使用时机**: 战斗内
- **目标**: 自身

### 数值参数

| 参数 | 数值 |
|---|---|
| 每解除 1 个负面 | +1 能量 |

## 描述

解除自身所有负面效果，每解除<span style="color:#3aa675;font-weight:600">1</span>个负面，获得<span style="color:#3aa675;font-weight:600">1</span>点能量。

## 详细机制

- **解除负面**：移除自己身上所有被判定为负面的能力。
- **能量置换**：每解除一个负面，获得 1 点能量（解除 N 个 = +N 能量）。
- **一次大净化 + 白拿能量**：负面越多，解除后回的能量越多。

## 小贴士

- **"把敌人的debuff折现成能量"**：表面是净化,实际是——你的负面越多,喝一口越赚。被上了一堆负面(虚弱+易伤+中毒+束缚)时喝,既全清又白捡一大笔能量,等于"敌人帮你充能"。
- **罕见稀有度的高峰价值**：在"负面debuff堆满身的战局"中,这瓶的数值豪华(可能+5~+6能量还清场)。但若身上没负面,它就是一瓶空转的"白净身",所以**等debuff攒起来再喝**。
- **与[圣佑](holy_blessing_potion.md)对照**：圣佑纯净化无收益;柠檬汁净化+每项1能量,几乎全面覆盖并超越——代价是罕见稀有度、不会在普通档位刷到。
- **适合"我叠负面我骄傲"的构筑**：mod 有"故意给自己上 debuff 换输出"的卡,这类构筑拿柠檬汁能把负面反向变现,收益拉满。
- **别为了能量故意等太久**：负面堆着也持续扣你状态,别为多赚 1 点能量硬扛到濒危——在"还能吃收益"的安全节点喝最好。
