# 附魔

附魔是附加到卡牌上的特殊修饰，使卡牌在打出时触发额外效果。一张卡牌只能拥有一个附魔。Seer Mod 在原版附魔系统基础上，新增了**状态宝石**和**特殊附魔**两大类。

::: tip Mod 扩展了什么
- **状态宝石**（22 种）：打出时对目标施加对应异常状态 3 回合
- **特殊附魔**（10 种）：注能、冷却时间、星皇之怒、永耀、孤雷风暴、五音系列（仐囙乂册卩）
:::

---

## 状态宝石

状态宝石是一类统一规则的附魔——**打出时对目标施加对应异常状态 N 回合**。N 的数值随附魔等级提升。

| 束缚宝石 | 束缚 |

::: warning 自身施加的宝石
**狂暴宝石**和**超频宝石**是对**自身**施加状态，而非目标——狂暴是增益（不属于异常状态），超频是异常状态。
:::

### 状态宝石的统一规则

- **持续回合数**：统一为 3 回合（N = 3）
- **施加时机**：打出时
- **目标**：单体牌对选中的目标施加；群体牌与无目标牌对所有可命中敌人施加；狂暴/超频固定对自身施加
- **可附魔类型**：攻击牌、技能牌、能力牌
- **可被异常免疫**：目标有异常免疫时施加无效（狂暴宝石的狂暴是增益，不受异常免疫影响）

## 特殊附魔

特殊附魔有各自独立的规则，不遵循状态宝石的统一模式。

### 注能

- **效果**：被附魔的牌起手置于抽牌堆底，第 1 回合自动打出
- **定位**：让关键起手牌每战自动触发，不占起手手牌

### 冷却时间

- **效果**：这张牌获得「重放」+1，并获得「消耗」
- **定位**：让一次性卡牌多打一次，但之后进入消耗

### 星皇之怒

- **效果**：第一次打出此牌后，此牌获得「重放」+1；首次打出本身不享受重放
- **定位**：让卡牌首打后自动重放一次，形成爆发

### 永耀

- **效果**：被附魔的牌获得「保留」，耗能降为 0，但所有「永耀」牌每回合只能打出一张
- **定位**：永耀牌可以留在手里，但每回合只能用一张——适合作为"保底输出"

### 五音系列

五音系列是 5 个单字命名的附魔，打出后触发各自效果：

| 附魔 | 效果 |
| --- | --- |
| **仐** | 打出后，自身先制 +1 |
| **囙** | 打出后，手牌、抽牌堆、弃牌堆中所有 PP 牌各恢复 1 点 PP（不超过上限） |
| **乂** | 打出后，解除自身所有异常状态 |
| **册** | 打出后，对目标造成其当前生命 10% 的非攻击伤害（可被格挡），自身恢复实际造成的伤害量 |
| **卩** | 打出后，若以此牌击败对手，自身最大生命 -20，造成的攻击伤害永久 +10%，受到的伤害永久 -10%（可叠加） |

::: tip 五音细节
囙 不作用于正在打出的这张牌——它此时已离开手牌；册 的伤害向下取整，被格挡时只按实际掉血回复；卩 判定这张牌指定的目标，无目标/群体牌会随机选定一名敌人，若该敌人被此牌击杀同样会触发。
:::

::: tip 卩的成长性
卩是唯一有"永久成长"效果的附魔——击败对手后永久增伤减伤。适合作为 Boss 击杀流的核心。
:::

### 孤雷风暴

- **效果**：打出时，依次从抽牌堆、弃牌堆、消耗牌堆各选择至多 2 张牌销毁，每销毁 1 张，自身全属性（力量/防御/命中/速度）+1
- **定位**：用牌堆资源换面板，适合需要清堆或堆属性的卡组；选择是逐堆进行的，可以少选或不选

**五音与孤雷风暴的限制**：六种特殊附魔（五音 + 孤雷风暴）都只能附在攻击牌、技能牌、能力牌上。

---

## 附魔的施加途径

- **神谕充能球**：激发时随机为一张手牌施加随机附魔
- **部分卡牌/遗物**：直接施加特定附魔
- **事件/商店**：部分事件/商店提供附魔服务

## 附魔与卡牌类型的兼容性

部分卡牌类型对附魔有特殊限制：

- **诅咒/状态牌**：部分附魔可能无法施加（需检查兼容性）
- **衍生牌**：通常可以附魔
- **任务牌**：视具体附魔而定
