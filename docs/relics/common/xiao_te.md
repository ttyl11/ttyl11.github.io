# 小特

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 普通
- **进化链**: [小特] → [莱茵](/relics/uncommon/lai_yin.md) → [莱茵哈特](/relics/rare/lai_yin_ha_te.md)

### 数值参数

| 参数 | 数值 |
|---|---|
| ①每级能力提升格挡 | +1 |
| ②进化阈值 | 累计获得 300 格挡 |
| 计数口径 | 全来源获得格挡（跨战斗累积） |

## 描述

①回合开始，自身每有[blue]1[/blue]级[gold]能力提升[/gold]，获[blue]1[/blue][gold]格挡[/gold]。②累计获[blue]300[/blue][gold]格挡[/gold]，升级为[gold]莱茵[/gold]。

## 详细机制

- **①能力提升层数定义**：指自身四维（力量/防御/命中/速度）**正层数之和**——只取正数叠加，负值（能力下降）不计入。比如力量+2、防御+3、命中+1、速度+0 时，能力提升 = 6 级，回合开始获得 6 格挡。
- **①触发时机**：每个我方回合开始时判断一次（`AfterSideTurnStart`），层数 >0 才触发，为 0 或负不获得。
- **②累计格挡口径**：**全来源获得的格挡都计数**（`AfterBlockGained` hook）——不只算小特①自身给的，还包括卡牌格挡、其它遗物/能力补给的格挡。跨战斗累积，计数写进遗物角标（`ShowCounter`），达到 300 那一刻立即进化为[莱茵](/relics/uncommon/lai_yin.md)。
- **②进化后计数清空**：进化成莱茵后，小特累计的 300 不再保留，莱茵重新从 0 开始统计自己的进化进度（各阶段计数器独立零）。

## 小贴士

- **想速进化就别省格挡牌**：②统计的是"获得格挡总量"，**获得不等于保留**——被打破、回合切换清空的格挡也算数。只要拿到格挡就推进进化，防御牌、能力牌、遗物格挡都能刷，进化速度唯一取决于你制造格挡的频率。
- **①的收益与能力提升绑定**：四维正层越厚每回合白拿格挡越多。配合开局全属性+、防御/命中叠加的构筑，能力提升轻松堆到 10+ 层，回合开局直接白嫖 10 格挡。
- **这是最弱的进化链第1环**：小特本身只提供"能力提升→格挡"的白嫖 + 累积进化，输出几乎为零。指望他单挑不现实，定位纯粹是进化链载体——尽快刷满 300 格挡升级，把成长潜力让给莱茵、莱茵哈特。
- **单场极限刷法**：回合内反复获得/转化格挡（如格挡转固伤再回格挡、重放带格挡牌）可以在同一回合内把累计数快速推高，不等回合开始结算。
