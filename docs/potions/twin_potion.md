# ♊ 双极

## 基本信息

- **分类**: 属性操控
- **稀有度**: 普通
- **使用时机**: 战斗内
- **目标**: 自身 & 全体敌人

### 数值参数

| 参数 | 说明 |
|---|---|
| 自身正值属性 | 翻倍 |
| 敌人负值属性 | 翻倍 |

## 描述

自身所有正值属性翻倍，敌人所有负值属性翻倍。

## 详细机制

- **自身增益翻倍**：把自己身上的[力量](/powers/strength_power.md)、[命中](/powers/accuracy_power.md)、[防御](/powers/defense_power.md)、[速度](/powers/speed_power.md)四项属性中**为正数**的翻倍（+X → +2X）。
- **敌人减益翻倍**：把所有敌人身上四项属性中**为负数**的也翻倍（-X → -2X），即敌人的负面状态被进一步放大。
- **只作用于四维**：不含元素属性、不含其他类型能力，纯粹聚焦于力量/命中/防御/速度四项。
- **条件触发**：只有当前该项**存在正/负值**才翻倍，没有叠过增益/减益的部位等于无效动作。

## 小贴士

- **"锦上添花"而非"无中生有"**：双极不吃"空手增益"——你得先叠出 buff（自身力量 +X、敌人命中 -X 等）它才有东西可翻。所以**先铺 BUFF 再喝**，收益最大。
- **一笔三赚**：把自己的 buff 翻倍 + 把敌人的 debuff 翻倍，一次喝药双端获利。敌人被打残的命中、防御漏洞会被进一步放大，配合[失明药水](blind_potion.md)这类先手削属性效果绝佳。
- **时机的艺术**：喝得越晚（buff/debuff 叠得越高）翻的绝对值越大，但也越可能战斗已接近尾声。最佳窗口是"增益拉满但战斗还有好几回合"的中期。
- **与[乾坤](reverse_potion.md)对照**：乾坤是把正负颠倒，双极是把正负都放大。前者适合"化敌为友"，后者适合"趁胜追击扩大优势"。
- **对纯 buff 敌人乏力**：若敌人全程不放减益（全正属性），双极的"敌人半"就空转了，仅吃"自身半"——但也别浪费，作为自我强化药水依然可用。
