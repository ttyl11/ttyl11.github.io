# 🔥 炽焰之心

## 基本信息

- **分类**: 增益（高方差）
- **稀有度**: 罕见
- **使用时机**: 战斗内
- **目标**: 自身

### 数值参数

| 参数 | 数值 |
|---|---|
| 火种层数 | 50 |

## 描述

获得 <span style="color:#3aa675;font-weight:600">50</span> 层[火种](/powers/spark_power.md)。

## 详细机制

- **作用于自身**：无需选择目标，为自身施加[火种](/powers/spark_power.md)能力 50 层。
- **火种的真实机制**：回合结束时，**10% 概率将全部火种转化为火苗**，转化时获得等量增伤与减伤；若未转化，则全部火种消散。**它不是"随回合累积"，也不是稳定增伤。**
- **50 层 = 单决的巨额赌注**：每次回合末判定一次——10% 变成 **+50 增伤 / +50 减伤**，90% 则 50 层灰飞烟灭。
- **悬浮提示**：附带火种能力提示，可确认当前层数。

## 小贴士

- **这是全游戏最"赌"的药水之一**：50 层火种不保证任何收益，只看每回合末那一下 10% 判定。成了就是一次性 +50/+50 的顶级攻守叠加，败了整瓶白用。**把它当彩票，别当稳定强化。**
- **怎么算期望**：若每回合都能判定且失败不清（实际失败即清，见下），单回合期望 ≈ 50 × 10% = +5 增/减伤——但现实是"不成即空"，所以客观看待：你是在用一整瓶换 10% 的巨额提升 + 90% 的归零。
- **成功后的火苗是永久增/减伤**：一旦转化成火苗，等量增伤减伤是持续有效的（画面转火苗后的姿态），所以赌赢一回合等于永久质变，之后的每回合都吃双刃优势。想赌就建立在"输了不伤月经"的前提上。
- **何时值得一赌**：胜券在握、这瓶药属于"白嫖机会"时，赌赢收益巨大、赌输了也无损失——是最好的时机。反之，生死攸关、急需确定输出/防御时，不要依赖它，它可能让你下回合直接裸奔。
- **不要与"稳定火种随回合增长"混为一谈**：许多玩家误以为火种会累积递增，实际是单次判定、不成即空。5 层和 50 层同样只有 10% 概率，区别只是赌注大小——所以这瓶药的层级价值，全看你敢不敢押 50。
