# 解弱（JieRuo）

**解弱**是 Seer Mod 的自定义卡牌关键词，打出后解除自身的[全属性](/mechanics/all_attributes.md)下降。

## 基本信息

| 项目 | 说明 |
| --- | --- |
| 类型 | Mod 卡牌关键词（清除型） |
| 效果 | 解除自身全属性下降 |
| 适用 | 卡面缩写术语 |

## 规则说明

- **解除对象**：自身的[力量/命中/防御/速度](/mechanics/all_attributes.md)负值（下降）
- 解除后该属性回到无状态（视为 0），不产生额外正值
- 对比：[反弱](/mechanics/fan_ruo.md)把下降转为提升；解弱只把下降清空、止损不赚属性
