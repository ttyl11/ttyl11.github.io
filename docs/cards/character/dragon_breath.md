## 描述

PP: 1/1 抽到带「<span style="color:#d4a017;font-weight:600">龙</span>」的牌：自动打出。

## 升级后

PP: 1/1 抽到带「<span style="color:#d4a017;font-weight:600">龙</span>」的牌：自动打出。

## 详细机制

- 打出后获得[龙缘之息](/powers/dragon_breath_power.md)能力。
- **触发条件**：自身抽到一张**名称含"龙"**的牌时，自动打出该牌。判定按本地化名称：中文名含「龙」，英文名含 Dragon / Draconic，与龙魂等龙牌体系口径一致。
- **不可打出的牌不自动打出**（带[不能被打出](/mechanics/unplayable.md)关键词的牌会被跳过）。
- **目标选择**：需要指定目标的牌，会从当前可命中敌人中**随机**选一个；群体 / 无目标 / 自身的牌按原样结算；场上没有可命中敌人时，单体牌会被跳过或空过，不产生效果。
- **自动打出照常消耗 PP**：每张被自动打出的 PP 牌扣 1 点 PP，不会自动补充；但即使 PP 已经是 0，自动打出**仍会执行该牌效果**（PP 停在 0），所以 PP 耗尽不会让龙牌“哑火”，只是没有 PP 留给后面的关键牌。
- **X 费牌按 X=0 结算**：自动打出不会投入能量，X 费牌会以 0 能量结算（不花能量，但 X 也为 0）。
- **多张只叠层数**：再打一张龙缘之息只把能力层数加到 2，抽到龙牌仍只自动打出一次——层数只影响图标数字，不增加触发次数。
- **[迟涌](/mechanics/chiyong.md)**：洗牌时此牌不随机分配位置，而是直接放入[抽牌堆](/mechanics/draw_pile.md)**底部**（每场战斗独立计算）。

## 小贴士

- **龙体系的引擎**：牌组里"龙"字牌越多，抽牌即自动出牌，等于白嫖一次**能量**（不耗能量，但照常扣 1 PP）。配合大量龙牌构筑时，抽牌环节本身就变成输出环节。
- **要注意 PP 会被吃掉**：自动打出依然消耗 PP，可能把你留给关键牌的 PP 用掉；但 PP 归零不会阻止自动打出，0 PP 的牌仍会执行效果。
- **随机目标有风险**：自动打出的单体牌目标是随机的，可能打偏；群体牌不受影响。
- **迟涌让它开局靠后**：战斗开始洗牌时此牌被放在抽牌堆底部，通常要抽完一轮才拿到；它作为能力牌打出后不会回到牌堆，迟涌只影响第一次抽到它的时间。
- **升级只降费**（2→1），能力本身不变。降费后更容易与龙牌同回合组合，优先级中等。
