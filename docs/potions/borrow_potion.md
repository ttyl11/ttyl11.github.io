# 🤝 借势

## 基本信息

- **分类**: 卡牌生成
- **稀有度**: 罕见
- **使用时机**: 战斗内
- **目标**: 自身

### 数值参数

| 参数 | 数值 |
|---|---|
| 选择次数 | 3 次 |
| 每次可选 | 3 选 1（单角色池） |
| 牌池 | 5 个角色牌池 |

## 描述

从5个角色牌池中，每次选择<span style="color:#3aa675;font-weight:600">3</span>张中选1张，共选择<span style="color:#3aa675;font-weight:600">3</span>张牌加入你的手牌。

## 详细机制

- **牌池来源**：一次性从** 5 个角色牌池**（铁甲战士 / 静默猎手 / 故障机器人 / 亡灵契约师 / 储君）抽取候选。
- **三选一**：每次从 3 张随机牌中选 1 张加入**手牌**，共进行 3 次。
- **免费到手**：选中的牌直接进手牌，是本回合/本场可用的额外资源。

## 小贴士

- **"白嫖"他职神卡的过滤器**：借势让你摸到的不是纯随机牌，而是**每个角色池的精选 3 选 1**——相当于 3 次"他职化"的选牌，能定向捞到缺的解场/爆发/核心牌（如铁甲的格挡、契约师的亡灵体系）。
- **期望值极高**：3 次从 5 池 × 3 候选里挑，等于"弱化版的万金油选牌"。罕见稀有度里，能把卡组临时补上一波强牌，是刷牌型卡组的最爱。
- **补体系的万金油**：无论缺输出还是缺防御，借势总能从某个角色池给你捞一张对口牌，是"缺啥补啥"的低门槛解决方式。
- **别忘它是"临时牌"**：这些牌只是进手牌用于当前战斗，不永久加入卡组。所以应**立即在当前回合/战斗用掉**，而不是留在手里期望下一场还在。
- **三连抽节奏**：3 次选择可以逐步积累手牌量，配合过牌构筑每轮都能补满资源，适合"资源多到用不完"的节奏型打法。
