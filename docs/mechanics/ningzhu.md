# 凝驻（NingZhu）

**凝驻** 是赛尔（Seer）职业独有的稀有关键词，标识一张牌具有"驻留于弃牌堆"的独特性质。拥有凝驻的牌在每场战斗结束后，**不会**被洗回抽牌堆，而是永久留在弃牌堆中。

## 规则说明

| 项目 | 说明 |
|------|------|
| 适用范围 | 仅赛尔角色牌 |
| 触发时机 | 战斗结束时（AfterCombatEnd） |
| 效果 | 该牌从本轮战斗的弃牌堆移除，不再参与后续抽牌堆洗牌 |
| 叠层方式 | 每张凝驻牌拥有独立的战斗次数计数器，格式为 `凝驻N场战斗` |

**典型流程：**

1. 战斗开始时，凝驻牌正常加入抽牌堆，可被正常抽取和使用。
2. 牌使用后进入弃牌堆。
3. 战斗结束触发凝驻判定：该牌不再洗回抽牌堆，而是直接移出本轮弃牌堆。
4. 下次战斗开始时，该牌**不会**出现在抽牌堆中。

## 与类似机制的区别

| 机制 | 区别 |
|------|------|
| **消耗（Exhaust）** | 消耗后牌移出本局所有区域，不可回收；凝驻仅在战斗结束后移出弃牌堆，下一局会重新出现 |
| **毁灭（Destruction）** | 毁灭牌在使用时即被销毁，不再存在于任何区域；凝驻牌正常使用，战斗结束后才离场 |
| **保留（Retain）** | 保留允许牌在使用后留在手上；凝驻控制的是战斗结束后的去向 |

## 数值说明

凝驻通常以 `凝驻N场战斗` 的形式标注在卡牌描述末尾，N 为正整数，表示该牌将在 N 场战斗中保持驻留状态（即不在那 N 场战斗中回到抽牌堆）。计数逐场递减，归零后该牌恢复正常。

- `凝驻1场战斗`：当前战斗结束后台牌不出现在下一场的抽牌堆中；下一场结束后重新进入抽牌堆。
- `凝驻4场战斗`：连续 4 场战斗中均不在抽牌堆里，第 5 场恢复。
