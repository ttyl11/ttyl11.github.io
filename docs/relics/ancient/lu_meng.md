## 基本信息

* **分类**: 非塔罗遗物

* **稀有度**: 先古（史诗品质）

* **来源**: 通用遗物池

* **计数显示**: 图标上显示本场战斗累计的手牌上限加成值（每次洗牌+3）

## 效果

① 回合结束时，若本回合没有打出攻击牌，本回合所有[手牌](/mechanics/hand.md)[保留](/mechanics/retain.md)。

② 回合开始时，从牌堆顶的 x 张牌中选出要获得的牌，x 等于当前[手牌数](/mechanics/hand.md)，每种类型的牌最多可各获得 1 张，每获得 1 张获得 1 点能量。未选中的牌置入[弃牌堆](/mechanics/discard_pile.md)。

③ 每次[洗牌](/mechanics/draw_pile.md)时，手牌上限+3，本场战斗有效。

## 小贴士

* **① 保留是单回合保留，仅限不打攻击牌的回合**：本效果在回合结束前触发，只有当本回合**从未打出过攻击牌**时生效。一旦打出攻击牌，条件立即失效。保留让手牌进入下回合，不会进入弃牌堆——这是典型的"攒牌不丢"机制。

* **② 预见 x = 当前手牌数，未选中的牌进弃牌堆**：查看的牌数等于当前手牌数，从其中选出要获得的牌。每张选中的牌加入手牌并获得 1 点能量，所以预见本质是"以能量换取牌"。每种类型最多选 1 张，防止同类型重复获取。手牌为空时预见 0 张，不触发选牌界面。**没选中的牌会全部置入弃牌堆**——被"翻看"过的牌不会留在抽牌堆顶反复出现，而是沉入弃牌堆，等抽牌堆抽空回洗后才会再见。这既是"看牌过滤"的收益，也是"选走好牌后剩下的牌不再挡抽牌"的隐性价值。

* **③ 洗牌加手牌上限，每洗+3**：每次触发洗牌（抽牌堆空后弃牌堆回洗），手牌上限在本场战斗内 +3，累积不重置。多次洗牌可以叠很高——是典型的大后期构筑核心。手牌上限提升不影响当前手牌，只影响后续回合可以持有的最大数量。

* **①与②的配合**：打出能力牌/技能牌保留手牌，下回合手牌更多 → 预见更多牌 → 获得更高能量 → 打出更多牌。这条链路上，攻击牌的缺席是保留的前提，但攻击牌也是破局的终结手段——需要根据战况权衡"保留攒手牌"还是"攻击破局"。

* **② 弃牌堆下沉 = 主动刷洗牌，喂大③的手牌上限**：未选中的牌置入弃牌堆，意味着抽牌堆被翻过的牌下放到底，抽牌堆会更快见底 → 更早触发[洗牌](/mechanics/draw_pile.md)，而每次洗牌都叠一次③的「手牌上限+3」。所以②不只是"看牌过滤"，更是一条主动推洗牌节奏、加速叠手牌上限的引擎——预见次数越多，洗牌越频繁，③的加成滚得越快。代价是翻看即弃，选走后剩下的牌短期内回不到抽牌堆，出牌节奏需要自己掂量。

* **③ 手牌上限需要洗牌激活**：如果一场战斗很少洗牌（抽牌堆始终够用的话），手牌上限加成就无法累积。配合"大量低费牌 + 高洗牌频率"的构筑可以快速拉开手牌上限差距。

* **图标计数含义**：遗物图标上显示的数字 = 本场战斗已累积的手牌上限加成总值（每次洗牌 +3），方便随时查看当前加成总量。
