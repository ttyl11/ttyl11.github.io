# 兹拉特

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 普通

## 描述

局外<span style="color:#d44;font-weight:600">右键</span>此遗物，再加入一个此遗物。拾起时，获得卡牌<span style="color:#d4a017;font-weight:600">跪地求饶</span>、<span style="color:#d4a017;font-weight:600">乌合之势</span>、<span style="color:#d4a017;font-weight:600">找茬</span>。战斗开始时，<span style="color:#d44;font-weight:600">[堕落](/powers/fallen_power.md)</span> <span style="color:#3aa675;font-weight:600">51</span>。

- **右键复制**：仅局外（非战斗）可用，右键加入一个自身副本，可反复无限叠加。
- **拾起给卡**：每次获得（包括复制得到的副本）都会发放上述 3 张卡牌。
- **战斗开始给[堕落](/powers/fallen_power.md)51**：每场战斗开始时，自身立即获得 51 层[堕落](/powers/fallen_power.md)。堕落是**负面层数**——51 层够不上 100 触发魔君接管，等于每场开局就背着半个百位的失控压力；想走堕落流（或是给[无常幽鬼](ghost_impermanence.md)这类"堕落到100"的触发垫层数）是方便，不玩堕落流的坚守其它体系时则要多留神层数别被其它来源推破百。
- **判定**：战斗内不能右键使用（非战斗状态才生效）。

## 风味文字

<span style="color:#d44;font-weight:600">兹拉特。</span>

## 小贴士

- **无限自我复制**：右键可无限复制自己，配合拾起给卡，能在局外快速丰满牌组。
- **三张新卡**：跪地求饶、乌合之势、找茬均进入牌组，注意组合搭配。
- **开场51层堕落**：每场固定送 51 层[堕落](/powers/fallen_power.md)。堕落是**负面层数**——51 层离 100 层失控线一步之遥，再叠 49 层就会被[魔君接管](/powers/demon_takeover_power.md)（当回合失控自动打牌）。对[无常幽鬼](ghost_impermanence.md)这类"堕落达到100触发"的遗物/卡是方便的垫层数，对其它构筑则更像开局就背着的半个失控炸弹，别把它当纯福利。
- **多人同步**：右键复制经多人游戏动作同步，主客两端行为一致。
