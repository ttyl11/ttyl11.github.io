# 🫘 庆典多味豆

## 基本信息

- **分类**: 元素变身
- **稀有度**: 稀有
- **使用时机**: 战斗内
- **目标**: 自身

## 描述

之后的每场战斗开始时，可以选择两个属性成为（每次三选一，共选 2 个属性）。

## 详细机制

- **持久标记**：使用后写入永久元素遗物的"庆典"状态，**跨战斗持续生效**。
- **每场触发**：之后每一场战斗开始时，弹出两次「三选一」，各选出一个属性成为你的元素属性。
- **双属性**：每次战斗你都能持有两个自选元素属性。
- **先清已有元素**：触发时先移除旧元素，再装备新选的属性（保持纯净）。

## 小贴士

- **全场"自定义克制作战"**：以后每场开局都能按当前敌人**现场挑两个最克制它的元素**，是所有变身药水里最"灵活、可控"的一支。杂兵就挑克制、Boss 就挑针对它的弱点。
- **稀有度换取"每场都赚"**：虽然售价稀有，但它不是一次性——一整局的每一场战斗都白送两次选属性的权力，长期收益远超单发变身药。
- **选择策略**：别总选同一属性——把第 1、2 个槽位分别拿来对抗该房间主要敌人的两种属性，双克叠加最能拉满威力。
- **注意与永久元素的互斥**：若你也用过「永久变 X 系」的其它变身药，庆典会与之产生选择槽位/互斥关系（触发时清已有元素），别让两套机制打架，明确走哪条路线。
- **成型卡组的神器**：当卡组已经成型、只差元素打点，庆典能最大化输出克制。适合在一个"元素体系"上押宝的长期规划。
