# 赴火

> **归属**：玩家可施加
> **施加来源**：玩家获得——[赴火](/cards/character/embrace_flame)（卡牌）

<img src="/images/powers/embrace_flame_power.png" alt="赴火" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 增益（Buff）
- **叠加方式**: 实例化（每次施加独立实例，各自计数）
- **可见**: 是
- **来源**: mod

### 数值参数

| 参数 | 数值 | 升级后 |
|---|---|---|
| 阈值 | X | X+1 |
| 回合数 | 1 → 0 | 1 → 0 |

## 描述

下个回合内，你耗能不大于<span style="color:#3aa675;font-weight:600">0</span>的牌会额外打出<span style="color:#3aa675;font-weight:600">1</span>次。

## 详细机制

- **回合数（图标数字）**：打出当回合显示 `1`（1 回合后生效），下一次**自身回合开始**时变为 `0`（本回合生效），并在该回合结束时移除——下一回合已不存在。
- **施加时机**：打出[赴火](/cards/character/embrace_flame)（耗能 X）时对自身施加一个能力实例，并把阈值写入该实例（基础 = 打出的 X，升级后 = X+1），当回合不生效。
- **0 能量时**：X=0 不造成伤害；未升级时阈值为 0，不会施加能力；升级后阈值为 1，仍会挂上能力。
- **生效时机**：回合数变为 `0` 的那一回合（激活时闪现提示），你打出的**耗能不大于阈值**的牌**结算次数 +1**（打一张、效果执行两遍，与原版"爆发"同款机制）。
- **移除时机**：生效回合结束时移除该实例，只生效一个回合。
- **互不取代、互不合并**：每打出一次「赴火」各生成一个**独立实例**，自带自己的回合数与阈值（原版"炸弹"同款多实例倒数）。因此在能力**已生效**的那一回合再打出「赴火」，旧实例照常生效、不会被覆盖，新实例从 `1` 开始自己的倒数；同一回合打出多张也各自倒数、各自生效。
- **费用判定口径**：按"本次打出会消耗的费用"判断——普通牌取**含费用修正后的当前费用**，X 费牌按本次投入的能量数。
- **重新打出会再消耗 PP**：被重新打出的 PP 牌**每个结算各扣一次 PP**（基础 1 点，打一张、结算两次 = 扣 2 点）；PP 扣到 0 为止，第二次结算**仍会执行效果**。持有「不动明王」遗物时，若 PP 已为 0，则跳过这次扣除，效果照常执行。
