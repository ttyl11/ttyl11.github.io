# ⭐ 星之能

## 基本信息

- **分类**: 控制 / 战术
- **稀有度**: 普通
- **使用时机**: 战斗内
- **目标**: 全体敌人

## 描述

所有敌人本回合封属且攻击无效，但将它们回满生命。

## 详细机制

- **全体封属**：给所有敌人施加**封属**状态（本回合无法使用属性类增益）。
- **全体封攻**：给所有敌人施加**攻击无效**状态（本回合所有攻击牌无效）。
- **回满血量**：作为代价，把所有敌人生命恢复到最大值。
- **当回合控制**：两类控制只在当前回合内生效。

## 小贴士

- **"买一回合安全"要价很高**：用敌人的满血换它们一回合不能攻击、不能叠属性。这是**非标靶式的拖延控场**——适合你正被敌方属性增长/连击压制、急需一个喘息回合囤牌/回血/叠盾的危局。
- **别对满血敌人乱用**：如果敌人本来血就满，封属/封攻是"白拿";但敌血不满时,这瓶等于把已造成的伤害全部归还,再用控制权换回来——**伤害不回收**的部分才划算。算好血量盈亏再喝。
- **当回合控制的局限**：只控一回合,下回合敌人恢复原状、血还回满。它是"争取时间"而非"造成优势",适合反杀前的铺垫,不适合日常消耗。
- **与"一回合清场"连招**：先用星之能抢回一回合,下回合用爆发药(如[湮灭](collapse_potion.md))或大招一口气带走——把"控制回合"转化成"斩杀回合"是最优解。
- **普通稀有度为何强**：一个能让你"白赚一整回合出手权"的控场,配合爆发卡往往直接改变战局,稀有度虽低价值却高。
