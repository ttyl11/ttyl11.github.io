# 周瑜

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 史诗（自定义稀有度）

### 数值参数

| 参数          | 数值                 |
| ----------- | ------------------ |
| 业火涤尘触发间隔    | 每 3 回合（第 3、6、9…回合） |
| 抽牌堆每牌最大生命损失 | 5                  |
| 弃牌堆每牌伤害     | 5                  |
| 回合结束恢复PP数量  | 最多 3 张             |
| 每张PP牌恢复量    | 1                  |

## 描述

①每隔 <span style="color:#3aa675;font-weight:600">3</span> 回合（第 <span style="color:#3aa675;font-weight:600">3</span> 回合起），开启<span style="color:#d4a017;font-weight:600">业火涤尘</span>：一次性消耗抽牌堆和弃牌堆中所有非附魔牌，抽牌堆每消耗 1 张所有敌人损失 <span style="color:#3aa675;font-weight:600">5</span> 点最大生命；弃牌堆每消耗 1 张所有敌人受到 <span style="color:#d4a017;font-weight:600">5</span> 点不可格挡的非攻击伤害。②回合开始时，手牌中最低费的可打出且未被附魔的牌，随机一张获得<span style="color:#d4a017;font-weight:600">[永耀](/mechanics/eternal_radiance.md)</span>（耗能降为 0，获得[保留](/mechanics/retain.md)，每回合只能打 1 张）。③回合结束时，随机 3 张消耗牌堆中的 PP 牌各恢复 <span style="color:#3aa675;font-weight:600">1</span> 点 PP。④牌堆洗牌时，抽 <span style="color:#3aa675;font-weight:600">2</span> 张牌。

## 工作机制

- **业火涤尘触发时机**：在玩家自己的回合开始时触发，第 3、6、9、12…回合各触发一次，之后每 3 回合一轮回。每场战斗独立计算，互不影响。
- **业火涤尘的结算结构**：先对抽牌堆和弃牌堆做快照，收集所有非附魔牌后**统一执行消耗**，最后统一结算伤害。伤害总量 = 抽牌堆非附魔牌数 × 5 的最大生命损失 + 弃牌堆非附魔牌数 × 5 的伤害，不会因中途敌人死亡而中断后续结算。PP 牌被消耗时同时清空其 PP。
- **②永耀附魔的筛选逻辑**：从手牌中找出"未附魔、可被永耀附魔、当前可打出"的牌，再从中取能量费用最低的一张随机附加永耀；费用按当前已生效的修正后费用计算。若手牌全是不可打出的牌或没有可附魔的牌，则跳过。
- **③PP 恢复范围**：只检查消耗牌堆中的 PP 牌，且只选 PP 未满的牌。每次最多恢复 3 张，每张恢复 1 点 PP（不超过上限）。随机选择保证多人模式两端一致。
- **④洗牌抽牌时机**：牌堆洗牌完成后立即触发，每场战斗可能多次触发——业火涤尘烧完一堆牌后必然触发一次，后续常规弃牌→洗牌也会触发。不消耗行动次数。
- **PP 牌循环链路**：业火涤尘把 PP 牌清空 PP 并消耗 → 这些 PP 牌进入消耗堆 → 回合结束时③随机恢复其中最多 3 张各 1 PP → 恢复后的 PP 牌随抽牌流程重新进入战斗 → 再次被业火涤尘消耗。这是完整的 PP 资源循环。

## 小贴士

- **业火涤尘是真正的引擎，不是点缀**：这件遗物的核心在①。抽牌堆 N 张非附魔牌 + 弃牌堆 M 张非附魔牌 = 所有敌人损失 5N 最大生命 + 受到 5M 伤害。牌组越大、业火涤尘前积累的牌越多，单次爆发越强。一个 60 张牌组、业火涤尘前攒了 20 张抽牌堆牌 + 15 张弃牌堆牌，等价于所有敌人 -100 最大生命 + 受到 75 伤害，这是一次足以终结多数 Boss 的爆发。慢速牌组（高费大伤害牌占比高）反而是最佳载体——每轮积累更久、爆发更高。
- **②永耀附魔是稳定免费输出**：每回合稳定产出一张耗能 0 且保留的牌，等于每回合白嫖一次出牌机会。关键是永耀牌每回合只能打 1 张，所以②的价值在"保证你每回合至少有一张免费牌可用"而非"无限连打"。配合保留，这张免费牌可以跨回合留到业火涤尘回合使用。
- **③①构成 PP 循环**：业火涤尘烧掉的所有 PP 牌，PP 归零后进入消耗堆；回合结束时③把其中最多 3 张各回 1 PP，让它们重新获得使用次数。PP 牌可以反复进出消耗堆——相当于用业火涤尘的爆发代价换取 PP 牌的持续循环。PP 牌多的牌组受益最大。
- **④洗牌的收益是隐形的滚雪球**：业火涤尘烧光大量牌后必然触发洗牌，④立刻抽 2 张——每 3 回合额外获得 2 张牌，且不需要任何代价。配合③的 PP 恢复，形成快速再生。
- **永耀附魔的「最低费」是双刃剑**：遗物总是附魔手牌里最便宜的那张可打出牌。如果手牌里有大量 0 费牌，②会附魔其中随机一张——这些牌本身就不耗能，附魔永耀后价值不大；真正的收益来自附魔一张 1 费牌，让它变成免费打出。因此手牌里应尽量保持有 1~2 费的核心攻击牌。
- **业火涤尘的副作用要预判**：业火涤尘一次性烧掉所有非附魔牌，包括你自己的核心攻击牌和技能牌。如果你打算在业火涤尘当回合出牌，务必在业火涤尘触发前用完核心牌（业火涤尘在回合开始、先于你出牌）。或提前给核心牌附魔（附魔的牌不会被烧）。
- **③只恢复消耗堆，不直接补抽牌堆 PP**：业火涤尘烧掉的 PP 牌进入消耗堆，③在回合结束时把它们从消耗堆里"捞"回有效状态（恢复 PP），但捞回来的 PP 牌要等下次洗牌才能重新进抽牌堆。所以③是"准备下轮弹药"，不是"当下补充"。
- **性价比**：史诗合理——①是每张牌组规模 ×5 量级的爆发，②是每回合免费的稳定资源，③是 PP 牌的循环保障，④是隐形的持续过牌。四条效果互相咬合，牌组越大收益越高。
