# 周瑜

<img src="/images/relics/zhou_yu.png" alt="周瑜" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 史诗（自定义稀有度）

### 数值参数

| 参数 | 数值 |
|---|---|
| 业火涤尘触发间隔 | 每 3 回合（第 3、6、9…回合） |
| 抽牌堆每牌最大生命损失 | 5 |
| 弃牌堆每牌固定伤害 | 5 |
| 回合结束恢复PP数量 | 最多 3 张 |

## 描述

①每隔 <span style="color:#3aa675;font-weight:600">3</span> 回合（第 <span style="color:#3aa675;font-weight:600">3</span> 回合起），开启<span style="color:#d4a017;font-weight:600">业火涤尘</span>：一次性消耗抽牌堆和弃牌堆中所有非附魔牌，抽牌堆每消耗1张所有敌人损失 <span style="color:#3aa675;font-weight:600">5</span> 点最大生命；弃牌堆每消耗1张所有敌人受到 <span style="color:#d4a017;font-weight:600">5</span> 点固定伤害。<br/>②回合开始时，手牌中最低费的可打出且未被附魔的牌，随机一张获得<span style="color:#d4a017;font-weight:600">[永耀](/mechanics/eternal_radiance.md)</span>（耗能降为 0，获得[保留](/mechanics/retain.md)，每回合只能打1张）。<br/>③回合结束时，随机 3 张消耗牌堆中的 PP 牌各恢复 <span style="color:#3aa675;font-weight:600">1</span> 点 PP。<br/>④牌堆洗牌时，抽 <span style="color:#3aa675;font-weight:600">2</span> 张牌。

## 详细机制

- **业火涤尘触发时机**：在玩家自己的回合开始时触发（即 `AfterSideTurnStart`，只响应己方回合）。第 3、6、9、12…回合各触发一次，之后每 3 回合一轮回。战斗结束后 `TurnCount` 重置，每场战斗独立计算，互不影响。
- **业火涤尘的结算结构**：代码先对抽牌堆和弃牌堆做两次快照（`Where(c => c.Enchantment == null).ToList()`），收集所有非附魔牌后再统一执行消耗，最后统一结算伤害。这意味着伤害总量 = 抽牌堆非附魔牌数 × 5 的最大生命损失 + 弃牌堆非附魔牌数 × 5 的固定伤害，不会因为中途敌人死亡而中断后续结算。PP 牌在被消耗时同步调用 `ForceSetPp(0)` 清空 PP。
- **②永耀附魔的筛选逻辑**：从手牌中找出「未附魔、`CanEnchant` 返回 true、`CanPlay(out_, out_)` 返回 true」的牌，再从中取能量费用最低的一张随机附加永耀。注意：费用比较用的是 `GetWithModifiers(CostModifiers.Local)`，即当前已生效的能量修正后的费用。若手牌全为不可被打出的牌（如负费攻击牌被敌人封系后无法打出）或无可附魔的牌，则跳过。
- **③PP 恢复范围**：只检查消耗牌堆（ExhaustPile）中的 `SeerPpCardModel` 类型卡牌，且只选择 Pp < MaxPp 的牌（满 PP 的不恢复）。每次最多恢复 3 张（受 `RestorePpCount` 限制），每张恢复 1 点 PP（不超过 MaxPp）。使用 `CombatCardSelection` 随机源保证多人模式同步。
- **④洗牌抽牌时机**：`AfterShuffle` 钩子在玩家牌堆完成洗牌后立即触发，每场战斗中可能多次触发——业火涤尘烧完一堆牌后必然触发一次，后续常规弃牌→洗牌也会触发。不消耗行动次数。
- **PP 牌循环链路**：业火涤尘把 PP 牌的 PP 清零并消耗 → 这些 PP 牌进入消耗堆 → 回合结束时③随机恢复其中最多 3 张各 1 PP → 恢复后的 PP 牌随着抽牌流程重新进入战斗 → 再次被业火涤尘消耗。这是一个完整的 PP 资源循环。

## 小贴士

- **业火涤尘是真正的引擎，不是点缀**：这件遗物的核心在①。抽牌堆有 N 张非附魔牌 + 弃牌堆有 M 张非附魔牌 = 所有敌人损失 (5N) 最大生命 + 受到 (5M) 固定伤害。牌组越大、业火涤尘前积累的牌越多，单次爆发越强。一个 60 张牌组、业火涤尘前攒了 20 张抽牌堆牌 + 15 张弃牌堆牌，等价于所有敌人 -100 最大生命 + 受到 75 固定伤害，这是一次足以终结多数 Boss 的爆发。慢速牌组（高费大伤害牌占比高）反而是这件遗物的最佳载体——因为每轮积累更久、爆发更高。
- **②永耀附魔是稳定免费输出**：每回合稳定产出一张耗能 0 且保留的牌，等于每回合白嫖一次出牌机会（这张牌不占能量槽，且可以留到以后再用）。关键是永耀牌每回合只能打 1 张，所以②的附魔价值在「保证你每回合至少有一张免费牌可用」而非「让你无限连打」。配合保留关键词，这张免费牌可以跨回合保留到下回合或业火涤尘回合使用。
- **③①构成 PP 循环**：业火涤尘烧掉的所有 PP 牌，PP 归零后进入消耗堆；回合结束时③把其中最多 3 张各回 1 PP，让它们重新获得使用次数。这意味着 PP 牌可以反复进进出出消耗堆——相当于用业火涤尘的爆发代价换取了 PP 牌的无限续杯（每张 PP 牌在每一轮业火涤尘里可以被回收再用）。PP 牌多的牌组受益最大。
- **④洗牌的收益是隐形的滚雪球**：业火涤尘烧光大量牌后必然触发洗牌，④立刻抽 2 张。如果业火涤尘烧了 30 张牌，之后洗牌再抽 2 张——这意味着你每 3 回合额外获得 2 张牌，且不需要任何代价。配合③的 PP 恢复，新抽的 PP 牌也可能在当回合就被③回 PP，形成快速再生。
- **永耀附魔的「最低费」是双刃剑**：遗物总是附魔手牌里最便宜的那张可打出牌。如果你的手牌里有大量 0 费牌，②会附魔其中随机一张——这些牌本身就不耗能，附魔永耀后变成「0 费+保留」，价值不大；真正的收益来自附魔一张 1 费牌，让它变成免费打出。因此手牌里应该尽量保持有 1~2 费的核心攻击牌，而不是全塞 0 费过牌。
- **业火涤尘的副作用要预判**：业火涤尘一次性烧掉所有非附魔牌，包括你自己的核心攻击牌和技能牌——这些牌一旦被打出过进入弃牌堆也会被烧。如果你打算在业火涤尘当回合出牌，务必在业火涤尘触发前用完核心牌（业火涤尘在回合开始、先于你出牌）。或者提前给核心牌附魔（永耀附魔的牌有附魔保护，不会被烧）。
- **③只恢复消耗堆，不直接补抽牌堆 PP**：业火涤尘烧掉的 PP 牌进入消耗堆，③在回合结束时把它们从消耗堆里「捞」回有效状态（恢复 PP），但捞回来的 PP 牌要等下次洗牌才能重新进抽牌堆，再抽到手。所以③是「准备下轮弹药」，不是「当下补充」。
- **性价比**：史诗合理——①是每张牌组规模 ×5 量级的爆发，②是每回合免费的稳定资源，③是 PP 牌的永续循环保障，④是隐形的持续过牌。四条效果互相咬合，牌组越大收益越高，不是纯数值堆砌的遗物。
