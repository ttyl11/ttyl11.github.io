# 遗物监禁

> **归属**：怪物施加给玩家
> **施加来源**：怪物自带——[莫塔里安](/monsters/boss/motalian_monster.md)技能 3（随机封印玩家遗物）
> **类型**：减益（Debuff）
> **叠加方式**：不叠加
> **可见**：是

<img src="/images/powers/relic_seal_power.png" alt="遗物监禁" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 描述

被监禁的遗物在本场战斗中无法生效，本场战斗结束后才可用。

## 详细机制

- **让遗物暂时失效**：被点名的遗物在本场战斗内不参与任何钩子结算，等同于不存在。
- **可多件累积**：多次施放会追加封印不同遗物，互不覆盖。
- **战后自动解封**：战斗结束时把所有被封印的遗物恢复正常。
- **不影响已获得的效果**：只封本场战斗的触发，不改遗物本身与局外属性。
