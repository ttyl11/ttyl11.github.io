# 🎁 大礼包药水

## 基本信息

- **分类**: 资源与召唤
- **稀有度**: 稀有
- **使用时机**: 任意时机（战斗内/外均可）
- **目标**: 自身

### 数值参数

| 参数 | 数值 |
|---|---|
| 金币数量 | 99 |
| 遗物概率 | 10% |
| 金币概率 | 90% |

## 描述

<span style="color:#3aa675;font-weight:600">10</span>%概率获得一个随机遗物，否则获得<span style="color:#3aa675;font-weight:600">99</span>[金币](/mechanics/money_pouch.md)。

## 详细机制

- **随机判定**：10% 概率获得遗物，90% 概率获得 99 金币。多人模式两端结果一致。
- **遗物分支（10%）**：从遗物队列前端抽取下一个遗物并获得。
- **金币分支（90%）**：获得 99 金币。
- **局外可用**：可在非战斗房间使用，是跑图获取资源的稀有药水。
## 小贴士

- **10% 赌遗物**：10% 概率白嫖遗物是稀有药水中的最高期望收益，90% 也有 99 金币保底。
- **局外使用更稳**：战斗外使用避免占用战斗节奏，99 金币可商店消费，遗物则直接入库。
- **金币的复利价值**：99 金币在商店可购买多张卡牌或升级，即使没抽到遗物，金币本身的长期收益也很可观。
- **稀有定位决定使用策略**：稀有药水出现概率低，建议优先在战斗外使用以节省战斗回合；战斗中使用则期待那 10% 的遗物惊喜。
- **遗物队列公平性**：遗物从队列前端抽取，意味着前面已获得过的遗物不会重复出现，10% 概率获得的遗物必然是当前队列中的下一个。
