# 暴击强化

> **归属**：玩家可施加
> **施加来源**：刻印「锦·绯红」赐予（仅当前这场战斗）

## 基本信息

- **类型**：中性（None）
- **叠加方式**：不叠加
- **可见**：是

## 描述

本场战斗中，你的暴击伤害额外提高[blue]50%[/blue]。

## 详细机制

- **只认自身伤害**：只有造成者为自身时才生效。
- **倍率**：×1.5，与暴击本身的 1.5 倍相乘，暴击时合计 ×2.25。
- **不检查伤害类型**：判定只问「当前是否暴击」；处于「锁定II」时判定恒为暴击，此时自身造成的所有伤害都 ×1.5。
