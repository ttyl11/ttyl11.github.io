# 金汤

> **归属**：玩家可施加
> **施加来源**：刻印「光栅炮刻印」赐予（此后每场战斗开始时获得）

## 基本信息

- **类型**：中性（None）
- **叠加方式**：不叠加
- **可见**：是

## 描述

你的回合结束时，[gold]格挡[/gold]不会清空；若你本回合打出了攻击牌，则改为正常清空。

## 详细机制

- **记录时点**：你的回合结束时，记录当时的剩余格挡，以及本回合是否打出过攻击牌。
- **补回时点**：下个你的回合开始时，游戏会清空格挡，本能力随即把记录值补回——效果等同于格挡跨回合保留。
- **攻击则失效**：上一个你的回合打出过攻击牌，则不补回。
- **补回方式**：按正常「获得格挡」结算，受敏捷等格挡修正影响，也会触发获得格挡相关效果。
- 记录值为 0 时无事发生。
