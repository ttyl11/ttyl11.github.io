# 圣铸复活

## 基本信息

- **归属**：玩家能力（隐藏图标）
- **类型**：增益
- **叠加**：单层
- **施加来源**：[至序圣华](/relics/legendary/order_holy_hua.md)（未复活时每场战斗开始获得）
- **可见**: 否

## 描述

①首次死亡时，回复至最大生命值的 <span style="color:#3aa675;font-weight:600">20%</span>。
②复活后立即移除此能力与**圣铸**计数。

## 详细机制

- **回复口径**：把生命补到最大生命的 20%，不是「回复 20% 最大生命」；当前生命已高于 20% 时不会触发。
- **复活过程无敌**：复活期间免疫伤害、免疫能力施加、不可被攻击，并阻止战斗提前结束。
- 复活成功后能力与圣铸计数一起移除，本场战斗不能再靠它复活；遗物会记录已复活状态——这条记录会保留到整局结束，之后遗物的行为随之改变。
- 只保护「死亡」这一次，不免疫之后的伤害。
