# 🦋 翩跹之蝶

## 基本信息

- **分类**: 地图 / 跳过
- **稀有度**: 罕见
- **使用时机**: 战斗内
- **目标**: 自身

## 描述

跳过一次**普通战斗**，且**不获得任何奖励**。

## 详细机制

- **使用范围**：仅在普通战斗中使用有效；对 Boss 战斗、精英战斗不可用（使用按钮在那些场景禁用）。
- **效果**：战斗中使用后，所有敌人立即逃离，战斗正常结束，但**不结算任何奖励**（无卡牌/遗物/金币奖励）。
- **使用条件**：必须正处于普通战斗房，且房间类型既非 Boss 也非精英。
- **奖励抑制**：本次战斗的奖励会被判定为空，因此跳过不拿任何东西。

## 小贴士

- **避免无价值战斗**：Boss 和精英都能打但普通战斗奖励不值得付出代价时，可用它跳过。
- **跳过等于放弃收益**：没有奖励，适合想省命/省药水、或不想冒风险时"安全跳过"普通战。
- **性价比**：罕见稀有度，提供一次"无损脱离普通战"的机会，战略上是止损工具。
