# 永久属性系统

永久属性是 Seer Mod 独有的**跨战斗持久化属性**系统。通过泰坦之灵商店的金蛋抽奖获得的属性加成，会**在后续每一场战斗开始时自动生效**——不同于原版能力（单次战斗内 Buff），永久属性是贯穿整局的"基础面板"。

::: tip 类比
可以理解为角色养成：抽奖获得的属性像 RPG 中的等级提升，永久强化角色面板，不随战斗结束而消失。
:::

---

## 获取途径

永久属性来自**泰坦之灵商店**的金蛋抽奖（用「星辰之录」在休息处右键进入），详见[赛尔豆与泰坦之灵](./currency)。

- 每次抽 1 泰坦之灵
- 抽奖结果按星级分配，星级越高越强
- 另有[刻印](/mechanics/)可以写入少量永久属性（闪避、吸血、开战固伤等），不属于金蛋奖池

## 星级概率与保底

| 星级 | 基础概率 | 保底 |
| --- | --- | --- |
| 1 星 | 86% | — |
| 2 星 | 10% | 10 抽未出 2 星及以上必出 2 星 |
| 3 星 | 3% | 20 抽未出 3 星及以上必出 3 星 |
| 4 星 | 0.95% | 40 抽未出 4 星及以上必出 4 星 |
| 5 星 | 0.04% | 80 抽未出 5 星及以上时 90% 给 5 星 |
| 6 星 | 0.01% | 80 抽保底的另外 10%；另有大小保底 |

**大小保底**：抽到 5 星后激活大保底，下一次概率抽中 5 星时强制升为 6 星；80 抽保底遇到大保底直接给 6 星；抽到 6 星后清除大保底。

## 属性的实际效果

所有属性在**每场战斗开始**时由 `SeerPermanentBonusPatch` 重新施加，因此战斗内仍可能被清除类效果移除，下一场战斗会再次获得。

| 属性 | 效果 |
| --- | --- |
| 力量 | 每层 +1 攻击伤害 |
| 防御 | 每层使受到的攻击伤害 -1 |
| 敏捷 | 每层 +1 格挡 |
| 命中 | 正层每层 +10% 暴击率，并使受击目标闪避 -5%；负层每层使对手对你的闪避 +5% |
| 速度 | 玩家正层：每层回合开始多抽 1 张，随后强制弃掉约半数；怪物正层：回合开始获得最大生命 5% 的格挡；负层镜像给对方 |
| 荆棘 | 受击时反伤（原版荆棘） |
| 永久增伤 | 攻击伤害 ×(1 + N%)，乘区独立 |
| 永久减伤 | 受到的攻击伤害 ×(1 - N%) |
| 再生 | 回合结束时回复 N 点生命，然后层数 -1 |
| 活力 | 下一次攻击 +N 伤害，打出后消耗 |
| 先制 | 每层使下一张牌耗能 -1，打出任意牌后清空 |
| 辉星 | 战斗开始时获得 N 点辉星（一次性） |
| 召唤 / 锻造 | 战斗开始时召唤 N / 铸造 N（一次性） |
| 集中 | 原版集中，增强充能球 |
| 覆甲 | 回合结束时获得 N 点格挡，下一回合开始时 -1 层 |
| 仪式 | 原版仪式，回合结束获得力量 |
| 狂暴 | 每层攻击伤害 +25%，自身回合结束时 -1 层 |
| 复制 / 熵 / 人工制品 / 缓冲 / 无实体 | 均按原版同名能力生效 |
| 充能球栏位 | 战斗开始时永久增加 N 个充能球栏位 |
| 随机充能球 | 战斗开始时随机生成 N 个充能球（闪电/冰霜/黑暗/等离子/玻璃） |
| 龙胆 | 每层使打出牌时对随机敌人造成 1 点固定伤害，受到异常时消耗 1 层抵消 |
| 神耀能量 | 每层使受到的伤害 -12%，最高 6 层 |
| 魔王咒怨 | 每层攻击伤害 +5%、受伤 -5%、攻击有 3% 概率秒杀；10 层时免疫异常状态 |

### 5 星附带效果

| 效果 | 说明 |
| --- | --- |
| 改善 | 战斗结束后随机升级牌组中 N 张可升级牌 |
| 禁忌魔典 | 战斗结束后获得 N 个删牌奖励 |
| 神羽 | 每回合结束时若生命低于 60%，消耗 1 片回复至 97%；消耗会写回永久计数 |
| 永昌玺 | 最高 6 层，攻击伤害 +8%/层，并逐层解锁固伤、回血、免疫、击晕等效果，详见[永昌玺](/powers/eternal_seal_power.md) |

这四种效果与普通永久属性一样按存档计数，每场战斗开始时重新施加对应能力；其中改善与禁忌魔典的收益在战斗结束时结算。

## 生效与存档

- **每场战斗开始时**：按存档数值重新施加力量、防御等能力
- **跨战斗持久**：数据由 `SeerCurrencyData` 按玩家 NetId 保存在跑局存档中，退出重进不丢失
- **多人独立**：每名玩家各有一份永久属性，互不影响
- **随机充能球**使用跑局同步 RNG，两端结果一致
