# 创世兵魂

<img src="/images/relics/seer_chuang_shi_bing_hun.png" alt="创世兵魂" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物

- **稀有度**: 商店

### 数值参数

| 参数   | 数值        |
| ---- | --------- |
| 额外能量 | 5 点       |
| 触发房间 | 精英 / Boss |

## 描述

精英或 Boss 战斗开始时，第一回合把牌抽满，并获得 <span style="color:#3aa675;font-weight:600">5</span> 点能量。

- **触发时机**：只在**精英**和 **Boss** 战斗生效，普通/小怪战斗无收益。
- **抽满手牌**：把牌补齐到[手牌上限](/mechanics/hand)，不会越抽越多。
- **能量性质**：额外白送，不扣上限、不计代价，第一回合起手即用。

## 风味文字

<span style="color:#d44;font-weight:600">兵魂不灭，创世永存。</span>

## 小贴士

- **专打精英和决战的开场爆发**：普通战斗完全不触发，它的价值全压在精英 / Boss 那两口的开门资源上——属于"路线上有精英/Boss 就血赚，纯小怪流就白板"的定向遗物。

- **首回合抽满 + 5 能量，等于第一回合多打半套牌**：起手手牌齐、能量又比平时多 5 点，回合一的爆发上限被拉得很高，很适合拆一次性高费大牌或一波流 Combo。

- **抽满的收益随手牌上限水涨船高**：抽到上限为止，所以本身的[手牌上限](/mechanics/hand)越高，这一把抽满拉到的手牌越多——配合手牌上限类遗物越到后期越赚。

- **不怎么被拖字诀拖累**：因为是"第一回合"即时结算，后续回合没有任何副作用，打完第一把就是一件白得的商店遗物，不用像持续 buff 那样担心掉线。

- **性价比**：商店遗物换"精英 / Boss 首回合抽满 + 5 能量"的开门爆发，对决战极其划算，但普通战斗零收益，值不值取决于你路线上的精英 / Boss 密度。
