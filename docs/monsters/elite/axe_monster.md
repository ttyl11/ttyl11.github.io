# 阿克希亚

> **类型**：精英怪物
> **初始生命**：<span style="color:#3aa675;font-weight:600">190-194</span>
> **遭遇战**：第二层精英战斗
> **特性**：寒冰护体（不高于 10% 血回满，无限次）+ 极度冰点（首次回满后秒杀级反击）+ 冰系三招循环

## 被动能力（开局自带）

| 名称 | 类型 | 效果 |
|------|------|------|
| **[寒冰护体](/powers/ice_armor_power.md)** | 被动型，不可消除（不显示层数） | 受到伤害后，若自身生命值不高于最大生命值的 10%，回复所有生命值。可无限次触发。**首次**触发时，当回合立即把当前行动改为「极度冰点」（仅一次） |

::: tip 寒冰护体机制
- 触发时机：受到伤害后检查，若当前生命值 ≤ 最大生命值 × 10% 即回满
- 193 血（平均）的 10% = 19.3，即**血量 ≤ 19 时触发**回满
- 回血量 = 最大生命值 - 当前生命值（直接回满）
- **回血可无限次触发**：每次不高于 10% 都回满，不是一次性能力
- **极度冰点仅一次**：首次触发寒冰护体时，当回合立即把当前行动改成极度冰点；之后再次触发寒冰护体只回满，不再出现极度冰点
- 能力类型为不可消除（不被消除类效果清除）
:::

## 行动逻辑

阿克希亚按「冰封 → 玄冰箭 → 冰天雪地」三招循环出招。寒冰护体**首次**触发时，会把**当回合**尚未执行的行动立刻改成「极度冰点」（仅一次）；极度冰点不推进循环，下一回合仍按原顺序出招。

```mermaid
flowchart TD
    start([战斗开始]) --> q0{本回合首次触发寒冰护体？}
    q0 -->|否| seal["冰封"]
    q0 -->|是（仅一次）| extreme1["极度冰点"]
    extreme1 -->|不推进循环，下一回合仍打冰封| seal
    seal -->|下一回合| q1{本回合首次触发寒冰护体？}
    q1 -->|否| arrow["玄冰箭"]
    q1 -->|是（仅一次）| extreme2["极度冰点"]
    extreme2 -->|不推进循环，下一回合仍打玄冰箭| arrow
    arrow -->|下一回合| q2{本回合首次触发寒冰护体？}
    q2 -->|否| storm["冰天雪地"]
    q2 -->|是（仅一次）| extreme3["极度冰点"]
    extreme3 -->|不推进循环，下一回合仍打冰天雪地| storm
    storm -->|循环| q0
```

> **说明**：极度冰点在寒冰护体首次触发时**当回合立即**替换当前行动（伤害 = 所有玩家中最大的最大生命值）；它不打乱循环计数，下一回合继续打原本该打的招。之后寒冰护体再触发只回血，不会再出极度冰点。

## 招式表

| 招式名 | 意图 | 类型 | 效果 |
|--------|------|------|------|
| **冰封** | 冰封 | Debuff | 所有敌人获得冰封 <span style="color:#3aa675;font-weight:600">3</span> 层 + 速度 <span style="color:#3aa675;font-weight:600">-2</span>；自身攻击 <span style="color:#3aa675;font-weight:600">+2</span> |
| **玄冰箭** | 攻击 <span style="color:#3aa675;font-weight:600">6</span>×<span style="color:#3aa675;font-weight:600">4</span> | 多段攻击 | 对单体目标造成 <span style="color:#3aa675;font-weight:600">6</span> 点伤害 <span style="color:#3aa675;font-weight:600">4</span> 次（共 <span style="color:#3aa675;font-weight:600">24</span> 点）；所有敌人先制 <span style="color:#3aa675;font-weight:600">-1</span>（你下张牌耗能 -1） |
| **冰天雪地** | 攻击 <span style="color:#3aa675;font-weight:600">20</span> | 全体攻击 + 自身增益 | 对所有敌方目标造成 <span style="color:#3aa675;font-weight:600">20</span> 点伤害；自身获得 <span style="color:#3aa675;font-weight:600">20%</span> 永久闪避 |
| **极度冰点** | 极度冰点 | 特殊反击 | 对所有敌方目标造成等于「所有玩家中最大的最大生命值」的伤害（可格挡，受力量影响）。仅寒冰护体首次触发时使用一次 |

::: tip 异常状态效果
- **冰封**：攻击伤害降低 <span style="color:#3aa675;font-weight:600">20%</span>，回合结束时移除并转化为 <span style="color:#3aa675;font-weight:600">2</span> 层冻伤
- **冻伤**：回合开始时受到 <span style="color:#3aa675;font-weight:600">5</span> 点伤害并减少 1 层（每层持续 1 回合）；现在只由冰封转化产生
- **闪避**：每次受到的攻击有 <span style="color:#3aa675;font-weight:600">20%</span> 概率完全闪避
- **先制 -1**：负数先制会让下一张打出的牌耗能 <span style="color:#3aa675;font-weight:600">-1</span>（变便宜），打出后移除所有先制
- **速度 -2**：负速度不再直接减少抽牌，而是镜像给敌方——每只敌人视为 +2 层，各自回合开始获得最大生命 <span style="color:#3aa675;font-weight:600">10%</span> 的格挡
- **攻击 +2**（自身力量）：每层 +1 攻击伤害
:::

::: warning 极度冰点伤害计算
- 伤害值 = 所有玩家中**最大的最大生命值**（不是当前生命值）
- 单人模式：伤害 = 你的最大生命值（满血时通常为75点）
- 多人模式：伤害 = 队伍中最大生命值最高的那个玩家的最大生命值，所有玩家受到相同伤害
- 伤害类型为攻击伤害（可格挡、受力量/易伤影响），不是固定伤害
- 例：最大生命值 75 时，极度冰点造成 75 点伤害，需要 75 点格挡才能完全防住
:::

## 策略提示

1. **核心战术：控血**：阿克希亚不会主动回血，寒冰护体只在血量 ≤ 19 时被动触发回满。所以**平时正常打即可，只要不把血量打到 ≤ 19 就永远不会回血**。把血量压到 20-30 左右停手，等爆发牌到位再一击从 20+ 血直接打到 0，寒冰护体根本没机会触发。如果爆发足够，也可以从一开始就猛打直接秒杀，同样绕过寒冰护体。只有"无脑多段攻击不小心把血打到 ≤ 19"才会触发回满，属于操作失误。

2. **极度冰点只有一次，扛过就安全了**：极度冰点只在寒冰护体**首次**触发时出现——触发当回合它就会把原本的行动立刻改成极度冰点，而不是拖到下一回合。之后再触发寒冰护体也不会再用极度冰点。所以即使操作失误触发了回满，只要扛过这一次极度冰点（造成等于所有玩家中最大生命值的伤害，需准备等量格挡），之后阿克希亚就只剩三招循环，威胁大减。控血失误不是世界末日。

3. **三招循环可预判**：冰封 → 玄冰箭 → 冰天雪地，按固定顺序循环。冰封回合是控制回合（不造直接伤害但全队减速+减攻+冰封），玄冰箭是单体输出回合，冰天雪地是全体输出+自身闪避回合。提前预判下一招可以合理分配格挡资源，也能选在低威胁回合（如冰封回合）攒爆发牌。

4. **冰封回合的连环控制极强**：冰封施加全队冰封 3 层（减攻 20%+转化冻伤）+ 速度 -2（我方负速度镜像给敌方：每只敌人回合开始获得最大生命 <span style="color:#3aa675;font-weight:600">10%</span> 的格挡），同时自身攻击 +2。紧接着的玄冰箭 6×4=24 点伤害 + 先制 -1（你下张牌耗能 -1，算是一点补偿），真正压制输出的是冰封的 -20% 攻击伤害——不解冰封就一直在打折。携带解冰封/解减速手段尤为重要。

5. **冻伤的持续伤害不可忽视**：冰封回合结束时转化 2 层冻伤（每回合 5 点，持续 2 回合共 10 点）。冰天雪地不再施加冻伤，改为自身获得 20% 永久闪避。多回合积累下来冻伤仍然可观，一轮完整循环后身上通常叠 2 层冻伤（每回合 10 点）。这也是控血战术要"打得干脆"的原因——拖太久冻伤会压垮自己。

6. **玄冰箭是单体攻击，冰天雪地是全体攻击**：玄冰箭 6×4=24 点伤害打同一目标，附带的先制 -1 是全队施加；冰天雪地 20 点伤害打全体，并让自身获得 20% 永久闪避。多人模式下玄冰箭需要被点名的玩家重点防御，冰天雪地则需要全队防御。

7. **多人模式极度冰点取最高最大生命值**：多人模式下极度冰点伤害 = 队伍中最大生命值最高的玩家的最大生命值，所有玩家受到相同伤害。队伍中不要有过高血量的角色可降低极度冰点伤害。建议高血量玩家优先叠格挡，或用嘲讽类能力保护。

8. **斩杀线参考**：193 血（平均）的 10% = 19.3，血量 ≤ 19 触发回满。控血时把血量压到 20-30 区间最安全，爆发牌准备好后一击带走。
