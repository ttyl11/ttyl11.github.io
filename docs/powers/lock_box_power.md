# 锁匣

> **归属**：玩家可施加
> **施加来源**：玩家获得——[锁匣](/cards/status/lock_box.md)（卡牌）

## 基本信息

- **类型**：减益（Debuff）
- **叠加方式**：计数
- **可见**：否（隐藏能力）

## 描述

[gold]手牌[/gold]中有「锁匣」时，你无法打出[gold]攻击牌[/gold]。

## 详细机制

- **只看手牌**：锁匣不在手牌时解除封锁；锁匣本身仍可正常打出。
- **只封攻击牌**：技能牌、能力牌、状态牌不受影响。
- **自动打出不受限**：自动打出的牌不受本能力封锁。
- **升级联动**：每打出一张能力牌，手牌中的锁匣升级 1 次。
