# 尘封

> **类型**：卡牌关键词 / 跨战斗封锁状态

## 描述

被尘封的牌**无法打出**，需要再经历数场战斗后才能解除；同一名称的所有副本会一起被封锁。

## 详细机制

- **按牌名封锁**：尘封记录的是卡牌条目，不是某一张具体副本。只要一种牌被尘封，牌组里所有同名卡都同时无法打出。
- **不会叠加**：重复尘封同一种牌时，取剩余场数较大的那个，不会把两个数字相加。
- **跨战斗倒计时**：每场战斗开始时剩余场数 −1，减到 0 时解除尘封，之后可以正常打出。
- **卡面提示**：被尘封的牌会显示「（N 场战斗后可打出）」的悬浮提示，方便判断还剩多久。
- **与「封印」不同**：莫塔里安施加的「封印」只在**当前战斗**内封锁，战斗结束即解除；尘封是跨战斗的长期封锁。

## 常见来源

- [狂沙领主·萨特](/monsters/elite/mad_sand_lord_sate_monster.md)的「黯天之尘」：每次触发随机尘封你 1 张牌，持续 5 场战斗。
