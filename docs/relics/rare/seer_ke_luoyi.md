## 基本信息

- **分类**: 非塔罗遗物

- **稀有度**: 稀有

## 描述

**商店删牌**不限次数，且不再花费金币，改为损失 <span style="color:#3aa675;font-weight:600">10</span> 点**最大生命**。

- **删牌服务改革**：原版商店的删牌服务每店只能使用一次、且删牌费用随次数递增；拥有克洛伊后，删牌**不限次数**，且完全**不再花金币**。
- **新的代价**：每删除一张牌，永久损失 <span style="color:#3aa675;font-weight:600">10</span> 点**最大生命**——这是无法恢复的血线损失。
- **界面提示**：商店删牌槽的价格图标会从金币换成红爱心、数字标红，明确告知你是在**扣生命**而非扣金币。

## 小贴士

- **这是"用血换牌组纯净"的高强度投资**：删牌是这个游戏最贵的成长投入之一——每店限一次、金币费用还逐次递增。克洛伊把"限次 + 金币"两重限制全部移除，代价改成干脆的 <span style="color:#3aa675;font-weight:600">10</span> 点最大生命，等于让你放开手脚把牌组精修到极致。

- **核心交易：牌组纯净度 vs 永久血线**：每删一张就永久 -<span style="color:#3aa675;font-weight:600">10</span> 最大生命，删多了会把自己删成脆皮。越到后期越珍贵的是"一张少拖累一回合"的牌组，而越到后期 <span style="color:#3aa675;font-weight:600">10</span> 点血也越接近白板的损失——这两股拉力让克洛伊成了一个需要精打细算的收益机器。

- **不要把删牌当纯免费福利**：每店章至少删掉真卡手的牌（诅咒、高费低效牌）才回本；为删一张平庸牌掏 <span style="color:#3aa675;font-weight:600">10</span> 点最大生命往往不值。想清楚：这张牌"每回合拖累你到什么程度"比"我现在想不想精简"更重要。

- **最佳配合时机**：当你的核心打法已经成型，靠更快摸到关键牌来滚雪球（如依赖某几张核心的输出/防御牌）时，克洛伊的价值直线上升——牌组越干净，越接近全抽核心。

- **性价比**：稀有，纯成长型遗物，上限极高（把牌组削到只剩核心），但血线代价不可逆，只适合愿意用血换输出的构筑。
