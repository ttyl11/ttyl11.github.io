# 财小爷

## 基本信息

* **分类**: 非塔罗遗物

* **稀有度**: 商店

### 数值参数

| 参数     | 数值           |
| ------ | ------------ |
| 额外泰坦之灵 | +1（每次掉落或获得时） |

## 描述

你的[泰坦之灵](/mechanics/currency.md)每次掉落时+1。

## 风味文字

<span style="color:#d44;font-weight:600">财小爷。</span>

## 小贴士

* **仅影响泰坦之灵数量**：每次泰坦之灵掉落（从怪物处击杀掉落或从奖励中获取），额外再多获得 1 个泰坦之灵。不改变泰坦之灵的掉落概率，只改变掉落后的数量。

* **商店稀有度定位**：作为商店遗物，稳定增益泰坦之灵获取量，适合依赖泰坦之灵体系构建的牌组。

* **叠加性**：持有多个财小爷时，每个都会独立触发，即每掉落一个泰坦之灵，实际获得 1+N 个（N 为持有的财小爷数量）。
