# 工程师苏克

## 基本信息

* **分类**: 非塔罗遗物

* **稀有度**: 商店

## 描述

拾起后，在休息处会额外出现「核心跃迁」选项。选择后从已持有的可升级遗物中，选一件替换为稀有度更高的随机遗物。

* **升级路径**：普通 → 罕见 → 稀有 → 史诗 → 传说。

* **升级范围**：沿「普通 → 罕见 → 稀有 → 史诗 → 传说」全链可升；每阶从同稀有度池随机抽取替代品。

* **不可升级**：已达传说的遗物不可选；初始/商店/事件/先古类遗物也可进入池子参与升级。

## 小贴士

* **遗物品质跃升**：可将普通遗物直接升级至罕见/稀有，是快速提升遗物质量的核心手段。尤其在后期，稀有遗物对构筑的帮助极大。

* **升级池**：从所有当前稀有度的遗物中随机抽取，含初始/商店/事件类遗物，无额外过滤。

* **史诗→传说**：Seer 系列的史诗遗物可通过此遗物升级为传说遗物，是获取传说遗物的主要途径之一。

* **搭配策略**：适合搭配遗物数量多、升级需求高的构筑（如堆遗物的"遗物流"）。前期拿到可尽早规划遗物品质路线。

* **注意遗物上限**：升级后遗物替换为新遗物，若总遗物数过高会触发遗物上限惩罚，建议控制升级节奏。

* **性价比**：商店稀有度合理——每次休息就能自由升级一件遗物，长期收益远超一次性宝箱。
