# 魔君接管

> **归属**：玩家专属（混沌魔君·索伦森）
> **施加来源**：玩家自身——[堕落](/powers/fallen_power.md)每累积满 100 层倍数时
> **界面显示**：本能力**不在战斗界面显示**（内部触发机制，无图标）

## 基本信息

- **类型**: 无类型（不参与增益/减益分类）
- **叠加方式**: 单例（不可叠加）
- **可见**: 否（隐藏能力）

## 描述

被<span style="color:#9b59b6;font-weight:600">魔君接管</span>：自动打出手中所有可打出的牌，优先耗能更高的牌，持续到你下个回合开始。

## 详细机制

- **施加即接管**：堕落每满 <span style="color:#3aa675;font-weight:600">100</span> 层，立即触发接管——自动从手中依次打出所有**可打出**的牌。
- **终止条件**：手中没有可打出的牌、战斗结束、或玩家本回合已主动结束回合时停止。
- **自动移除**：持续到自身下回合开始自动移除（我方下回合开始时结束接管）。
- **与混沌化身的联动**：堕落满 100 触发接管的同时获得[混沌化身](/mechanics/chaos-incarnation.md)——能量不足也能继续打出，接管过程可能把能量打空后继续用最大生命抵扣着打。
