# 雷蒙教官

## 基本信息

* **分类**: 非塔罗遗物

* **稀有度**: 商店

## 描述

在火堆升级卡牌时，为每张升级卡牌新增一个随机的赛尔附魔。

* **触发时机**：每次在火堆完成卡牌升级后触发，每张被升级的卡牌均会获得一个附魔。

* **附魔来源**：从全局赛尔附魔列表中筛选出对该卡牌有效的附魔，再从中随机抽取一个。

* **叠加效果**：无法叠加——每张卡牌只能拥有一个附魔，被升级的卡牌若已带附魔，不会再次获得附魔。

## 小贴士

* **免费附魔收益高**：原版附魔需要通过特定途径（如事件、宝箱或商店）才能获得，而雷蒙教官让每次升级都额外赠送一个附魔，相当于省去了寻找附魔源的开销。

* **注意休息处抉择**：每个休息处只能选择一项操作（恢复 / 锻造 / 遗物额外选项）。雷蒙教官依赖「锻造」触发附魔，选了锻造就放弃本次恢复；若还同时拥有其他为休息处添加选项的遗物，可选项越多越需取舍，无法全部兼顾。

* **已附魔卡牌不再获得**：每张卡牌只能拥有一个附魔，被升级的卡牌若已带附魔，将不会再次获得附魔。

* **注意附魔池限制**：附魔是从该卡牌当前可用的附魔类型中随机抽取的，部分卡牌（如诅咒牌、状态牌）没有可用附魔池，此时不会触发。

* **品质不影响附魔类型**：附魔质量取决于该卡牌自身的附魔池，而非遗物品质。普通卡牌的附魔可能不如史诗卡牌强力，但依然有随机收益。

* **性价比**：商店稀有度合理——每次升级都有概率拿到强力附魔，长期积累效果显著。
