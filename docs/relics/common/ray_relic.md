# 雷伊

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 普通

### 数值参数

| 参数 | 数值 |
|---|---|
| 先制加成 | 1 |

## 描述

你使用带有<span style="color:#3aa675;font-weight:600">电</span>或<span style="color:#3aa675;font-weight:600">雷</span>字的牌时，<span style="color:#d4a017;font-weight:600">[先制](/powers/first_strike_power.md)</span>+<span style="color:#3aa675;font-weight:600">1</span>。

判定标准是卡牌的**中文名称**，只要名称中包含「电」或「雷」字即可触发（含 seer 牌与原版牌）。

- **seer 牌**：电石混地、电脉充能、圣灵雷霆斩、瞬雷天闪、雷盖之交、雷神天明闪、激鸣雷封。
- **原版牌**：球状闪电、充电、引雷针、雷霆、闪电霹雳、电流相生、电击、雷暴。

## 风味文字

<span style="color:#d44;font-weight:600">雷伊。</span>

## 小贴士

- **把"先制"想象成下一张牌的减费券**：先制正层数会让你的下一张牌耗能 -1，打出后清零。所以雷伊触发一次先制，等于给你"下一张牌省 1 费"的即时奖励——打出免费/低费的电雷系牌来攒先制，再用一张高费牌吃这笔折扣，是这套遗物的核心榨取方式。
- **判定只看牌名，不看稀有度/品质**：任何带"电/雷"字的牌都能触发，包括状态牌、诅咒牌、事件牌。凑齐一套成体系的电雷系牌组，几乎每回合都能稳定吃一次先制减费。
- **seer 自己给了不少电雷牌**：雷神天明闪、圣灵雷霆斩、瞬雷天闪这些 core 电雷系输出牌天然就吃这个加成——不需要为了雷伊去硬塞，正常雷系构筑就自带收益。
- **原版闪电流派也全吃**：球状闪电、电击、引雷针、雷霆、雷暴、闪电霹雳这些原版电系牌同样触发。想要跨系统配合时，拿原版充电/引雷体系的牌也能低成本激活雷伊。
- **别只当"减费器"看**：先制层数在打出后会被整体清零，所以单次 +1 的实际价值是一次"下一张牌 -1 费"。用它来润滑那些你本来不敢连着打的高费用连锁，收益最明显。
- **性价比**：普通稀有度合理——主动凑电雷牌就近乎常驻小减费，但单层先制触发后即清，强度取决于牌组里的电雷牌密度，属于"锦上添花"的小件。
