# 生命灵珠

> **归属**：玩家可施加
> **施加来源**：
> - [生命灵珠](/potions/life_gem_potion.md)（药水——使用后获得）

## 基本信息

- **类型**: 中性（None）
- **叠加方式**: 计数（Counter）
- **可见**: 是

### 数值参数

| 参数 | 数值 |
|---|---|
| 生命阈值 | 50% |
| 低于阈值：承伤倍率 | 80%（减伤 20%） |
| 高于阈值：造成倍率 | 140%（增伤 40%） |

## 描述

本场战斗中，生命低于 <span style="color:#5a9e2e;font-weight:600">50%</span> 时获得 <span style="color:#3aa675;font-weight:600">20%</span> 减伤，生命高于 <span style="color:#5a9e2e;font-weight:600">50%</span> 时获得 <span style="color:#3aa675;font-weight:600">40%</span> 增伤。

## 详细机制

- **动态判定**：每次伤害结算时按**结算瞬间**的生命比例判定，不固定、不需要预热。
  - 自身生命 **< 50%**：作为**受伤方**时，承受伤害 ×0.8（减伤 20%）。
  - 自身生命 **> 50%**：作为**伤害来源**时，造成伤害 ×1.4（增伤 40%）。
  - 生命**正好 50%**：两个效果都不触发。
- **走乘算区间**：通过 `ModifyDamageMultiplicative` 生效，与其它增减伤效果**相乘**。
- **仅本场战斗生效**：战斗结束随能力移除。

## 小贴士

- **两个效果互斥**：同一时刻只有一种生效——高血时你只能拿到增伤，低血时只能拿到减伤，不存在"又增伤又减伤"。
- **血量在 50% 附近反复横跳时收益最大**：打输出时保持高血吃 1.4 倍，被集火掉到 50% 以下立刻转成抗伤。
- **血量被压到 50% 以下后输出会掉**：低血状态没有增伤，所以要打爆发前先回血、要抗伤害前不必刻意维持高血。
- **对固定伤害无效**：固定伤害不受增减伤影响，所以低血时的 20% 减伤挡不住固定伤害。
