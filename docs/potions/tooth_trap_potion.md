# 🦷 牙齿陷阱

## 基本信息

- **分类**: 防御 / 输出（以伤换伤）
- **稀有度**: 普通
- **使用时机**: 战斗内
- **目标**: 自身（效果反伤全体敌人）

### 数值参数

| 参数 | 数值 |
|---|---|
| 触发条件 | 本回合自身**实际失去生命**（未格挡部分 > 0） |
| 反伤量 | 每次受击 = 相同数值的<span style="color:#3aa675;font-weight:600">固定伤害</span> |
| 作用范围 | 所有可命中敌人（全体） |
| 持续窗口 | 使用后整个当前回合（我方 + 敌方回合），我方下个回合开始时移除 |

## 描述

本回合受到伤害时，给予所有敌人等量[固定伤害](/mechanics/fixed-damage.md)。

## 详细机制

- **一次性临时能力**：为自身施加一层 `SeerToothTrapPower`（Buff / Single 单层），由能力接管本回合的反伤逻辑。
- **窗口覆盖整轮**：能力在我方下回合开始时 `Decrement` 移除，因此生效区间是"打出起的我方回合 + 敌方回合"，**敌方回合受到的攻击同样计入**。
- **只看实扣生命**：仅当 `result.UnblockedDamage > 0`（实际穿过格挡/无实体后掉的血）才触发；被格挡完全吸收、无实体躲掉的伤害一律不算。
- **反实用的是固定伤害，全体施加**：对每个可命中敌人施加等量 `SeerFixedDamagePower` 能力。反伤**穿透敌人格挡**，多个敌人各吃一份完整反伤，是标准的 AOE 反伤。
- **反伤害在下回合结算**：`SeerFixedDamagePower` 由能力在敌人回合开始自行结算，不是即时直伤。

## 小贴士

- **和直觉相悖——你有格挡反而反伤少**：反伤量 = 实际扣血。带大额格挡时伤害被格挡削掉、触发值变小甚至归零；想让这瓶药打满，反而要"少开格挡、放心挨打"，把自身当血包（配合面板减伤 / 自回复更好）。
- **打群怪的收益爆炸**：每中一下伤害都对**全体敌人**各反一份等量固定伤害。三只怪的群战里，一次被砍 20 血 ＝ 对三只各反 20（总 60），以伤换多倍，是这瓶药最宝贵的场景。
- **吃完伤害再看敌人意图再开**：窗口覆盖我方回合 + 敌方回合，最佳打法是在**已经能预判敌方要打你**的回合开局就按——比如敌方已亮高伤意图，这一来一回直接把你吃下的伤害连本带利打回去。
- **空转风险要防**：若该回合敌人不打你、或全被格挡/无实体躲闪，整瓶等于白开。用前先确认"这轮必定实打掉血"。
- **固定伤害穿透的意义**：反出去的伤害无视敌人格挡，用来对付高格挡 / 高甲前排怪尤其好用，相当于把"你掉的甲下肉"转成"它们挡不住的肉"。
- **性价比**：普通稀有度，既护身又输出，是防守型卡组（血量厚、缺爆发）非常划算的补充伤害源。
