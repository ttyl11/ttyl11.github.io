# 🌸 万花球

## 基本信息

- **分类**: 地图 / 休息
- **稀有度**: 普通
- **使用时机**: 战斗外（休息处）
- **目标**: 自身

## 描述

在**休息处**打出，你的下一个选择重复一次。

## 详细机制

- **使用条件**：只能在**休息处**且战斗外时使用。
- **重复下一个选择**：使用后，下一次在休息处的选择（回血或锻造升级）会执行**两次**。
- **回血示例**：选择休息回血时，重复一次意味着共执行两次回血。
- **锻造示例**：选择锻造时，重复一次意味着再额外升级一张牌。

## 小贴士

- **双倍休息收益**：把一次休息变两次价值，回血或升级都能吃两次。
- **择机用**：在即将需要大回复或恰有想升级的牌时使用最赚。
- **性价比**：普通稀有度，配合休息处即可稳定扩大收益。
