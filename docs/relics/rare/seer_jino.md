# 杰诺

## 基本信息

- **分类**: 非塔罗遗物

- **稀有度**: 稀有

## 描述

战斗开始时，随机降低 <span style="color:#3aa675;font-weight:600">5</span> 张你已升级的牌，并升级其它所有可升级的牌（**仅本场战斗临时生效**，战斗结束后还原）。

- **临时生效**：只作用于本场战斗的牌，不会改变永久牌组——降级和升级在战斗结束时全部还原。
- **只降 5 张**：从你已升级的牌里随机挑至多 <span style="color:#3aa675;font-weight:600">5</span> 张打回原形；若升级牌不足 <span style="color:#3aa675;font-weight:600">5</span> 张则全部降级。
- **升级其余**：除被降的这 <span style="color:#3aa675;font-weight:600">5</span> 张外，所有可升级的牌全部升级。

## 小贴士

- **净赚的"临时洗牌"**：每场战斗最多只降 5 张升级牌，却能把其余全部可升级牌升满。只要你升级牌多于 5 张，这一降一升就是白赚的净提升——套着永久牌组去打，每场都是"全牌 +"的战力。

- **被降的那 5 张是随机牺牲品，别慌**：降级随机点名，可能恰好点到你最依赖的 Key 牌，但只是本场临时，战后还原。被点名就少打它那一张，其它照常。

- **是"单场爆发器"，不是"成长器"**：临时提升不改变永久牌组构成，所以它优化的是你**每场的即时战力**，而不是越滚越强的长期成长。升级收益大的技能/能力牌组最爽——这类牌升级后功能往往翻倍，被升满的爆发最明显。

- **升级牌越多越稳赚**：你的升级牌数量越大于 5，被牺牲的数量占比越低、白赚升级的卡越多。若牌组升级牌 ≤5 张，甚至可能完全不降、全体升级，纯赚不亏。

- **性价比**：稀有遗物，用"每场降至多 5 张"的微小代价，换"其余全部升级"的临时爆发，配合高升级收益的牌组极强。
