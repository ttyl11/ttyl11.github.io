# 闪避

> **归属**：玩家与怪物均可持有——懒挂载的判定载体（负命中出现时自动补挂）
> **施加来源**：系统自动——懒挂载（与[暴击](/powers/critical_strike_power.md)引擎同模式）：任一单位被减命中时，自动为其"对位全体"补挂 0 层判定载体，挂上后常驻（不随负命中消失而移除）；内容施加——怪物招式（终末大天使、混沌·千夜死神、狂沙之主·萨特、蒂亚斯、愈灵·克丽娅、战斧等）、[终末](/powers/end_archangel_power.md)、永久闪避刻印（#32）

## 基本信息

- **类型**: 中性（不是 Buff 也不是 Debuff，不被驱散/净化）
- **叠加方式**: 叠加（计数型，不自动递减）
- **可见**: 是（常驻显示，0% 起）
- **允许负值**: 是
- **来源**: mod 能力

### 数值参数

| 参数 | 数值 |
|---|---|
| 基础闪避率 | 0 |
| 每层负命中提供的闪避加成 | 5% |

## 描述

有（有效闪避率）%概率闪避受到的攻击。**角标取最高**（自身层数 + 对方侧最高的[负命中](/powers/accuracy_power.md)加成，每层 +<span style="color:#3aa675;font-weight:600">5%</span>）；描述在其后**逐个点名敌人**，写明"对某某某的闪避几率"——1 个敌人单句点名并拆开构成（自身 X% + 负命中加成 Y%），多个敌人逐行列出（闪避率相同的合并一行），对手都没有负命中时不显示这段。

## 详细机制

- **闪避率构成**：`自身层数 - 攻击者命中 × 5%`（攻击者命中为负时相当于加成，每负一层 +<span style="color:#3aa675;font-weight:600">5%</span>）——被减命中的敌人攻击你时更容易被闪掉。
- **正命中会降低闪避率**：攻击者每有 1 层正命中，你的闪避率 -5%（隐藏机制，卡面不写）；这也是[命中](/powers/accuracy_power.md)正层能稳定命中的原因之一。
- **自身层数 vs 负命中加成**：**自身层数**是真实层数（卡牌/怪物施加、层数消耗都只动它，不随命中变化）；**负命中加成**是实时计算的（|对方命中| × 5%），永不写入层数。
- **逐敌点名**：描述按对手逐个写明"对某某某的闪避几率"（= 自身层数 + **该对手**的负命中加成，这才是对它攻击时真正生效的概率）——**1 个敌人**单句点名并拆开构成（自身 X% + 负命中加成 Y%），**多个敌人**逐行列表、闪避率相同的合并成一行；对手都没有负命中（无区分度）时整段隐藏。
- **角标 = 有效闪避率（取最高、实时）**：角标显示 = 自身层数 + **对方侧最高**的负命中加成，随双方命中变化即时刷新；对方没有负命中时它就是自身层数。多敌人命中不同时，角标是其中最高的那一份，具体对谁是多少看描述里的逐敌列表。
- **图标随载体常驻、数值实时变**：载体一旦挂上，闪避图标就常驻显示，数字 = 有效闪避率并随双方命中变化即时刷新（负命中消失后回落为 0%）。例：你给自己挂了 <span style="color:#3aa675;font-weight:600">-2</span> 命中 → 所有敌人的闪避角标都会变为 <span style="color:#3aa675;font-weight:600">10%</span>（你打它们时、每次攻击有 10% 概率被闪掉）。
- **判定粒度**：每次攻击命令对每个受击目标各判一次——多段攻击整段全闪或全不闪（不会"3 段闪 1 段"）。
- **闪避效果**：被闪避的攻击**伤害归零**，且不消耗[格挡](/mechanics/block.md)；也不触发"受到伤害时"类的效果。
- **适用范围**：只对**敌方阵营的攻击伤害**生效——自伤、队友伤害、[固定伤害](/powers/fixed_damage_power.md)、DoT 不参与闪避。
- **载体机制（懒挂载）**：不做全场预挂——任一单位出现负命中时，其"对位全体"会自动获得 0 层闪避载体并常驻（背景载体；实际闪避率由层数与负命中共同决定）。
- **多人同步**：判定多端同步，联机两端结果一致；逐敌描述是本地展示、不参与判定，两端显示内容一致。

## 小贴士

- **减命中 = 削弱对方输出**：给敌人叠[负命中](/powers/accuracy_power.md)（[失明药水](/potions/blind_potion.md)、[大雨滂沱](/cards/character/heavy_rain.md)、[九月的枷锁](/cards/character/september_shackles.md)等）后，它的攻击会被你以 5%×层数的概率直接闪掉——你自己的闪避图标会亮起并实时显示这份概率。
- **别只看期望**：闪避是"整段全闪或全不闪"——多段重击要么全躲要么全吃，防御决策按最坏情况留[格挡](/mechanics/block.md)。
