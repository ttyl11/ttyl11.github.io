# 免固（MianGu）

**免固**是 Seer Mod 的自定义卡牌关键词，持有者免疫[固定伤害](/mechanics/fixed-damage.md)。

## 基本信息

| 项目 | 说明 |
| --- | --- |
| 类型 | Mod 卡牌关键词（免疫型） |
| 效果 | 免疫固定伤害 |
| 适用 | 卡面缩写术语 |

## 规则说明

- **免疫固定伤害**：本场战斗中不会受到[固定伤害](/mechanics/fixed-damage.md)能力结算的伤害
- 固定伤害由 [能力](/mechanics/fixed-damage.md) 系统在下回合开始时结算；免固阻止该结算对自己生效
- 对比：[免控](/mechanics/mian_kong.md)免疫异常状态、[免固]免疫固定伤害，两者独立存在，可叠加
