# 消强（XiaoQiang）

**消强**是 Seer Mod 的自定义卡牌关键词，打出后消除对手的[全属性](/mechanics/all_attributes.md)提升。

## 基本信息

| 项目 | 说明 |
| --- | --- |
| 类型 | Mod 卡牌关键词（清除型） |
| 效果 | 消除对手全属性提升 |
| 适用 | 卡面缩写术语 |

## 规则说明

- **消除目标**：对手（敌方）的[力量/命中/防御/速度](/mechanics/all_attributes.md)正值提升全部被清除
- 不作用于自身；自身负属性不受影响
- 对比：[吸强](/mechanics/xi_qiang.md)将对手提升吸过来转为己用、[反强](/mechanics/fan_qiang.md)把对手正向提升反转成负值——消强是直接抹除
