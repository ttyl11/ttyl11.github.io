# 💚 长效体力药剂

## 基本信息

- **分类**: 恢复 / 防御
- **稀有度**: 普通
- **使用时机**: 战斗内
- **目标**: 自身

### 数值参数

| 参数 | 数值 |
|---|---|
| 立即回血 | 3 |
| 持续回合 | 3 |
| 每回合回血 | 5 |
| 免疫固定伤害 | 3 回合 |

## 描述

立即恢复<span style="color:#3aa675;font-weight:600">3</span>点生命值。接下来<span style="color:#3aa675;font-weight:600">3</span>回合，每回合开始时恢复<span style="color:#3aa675;font-weight:600">5</span>点生命值，且免疫[固定伤害](/mechanics/fixed-damage.md)。

## 详细机制

- **即时部分**：喝下立刻回 3 血。
- **持续部分**：给自己一层持续型回血能力，**每回合开始**再回 5 血，共持续 3 回合。
- **固定伤害免疫**：同时获得 3 回合的[免疫固定伤害](/powers/immune_fixed_damage_power.md)状态，期间敌人施加的固定伤害对你无效。
- **追加当回合**：回合中途施加时跳过当回合衰减，保证 3 回合完整覆盖。

## 小贴士

- **综合血量再算一笔账**：3 血 + 3×5 血 = 本场最多回 18 血，外加 3 回合固定伤害免疫。普通稀有度能拿到这个量级的"奶 + 防御"组合，性价比相当高。
- **固定伤害免疫的价值常被忽略**：mod 里大量敌人靠[固定伤害](/mechanics/fixed-damage.md)输出（不吃命中/减伤），这 3 回合相当于专门针对这类敌人的"盾牌"，比纯回血药水多了保命维度。
- **回合开始回血**：回血在"回合开始"结算，不像[蓝火](blue_fire_potion.md)那样在回合末——所以它能更早地帮你把血线拉回安全区，配合残血反打体系很顺手。
- **适合拉锯战**：持续 3 回合的节奏型回复在前期小怪、中期精英战都很实用。普通稀有度，建议中期拿到就进发，不必刻意留。
- **对最高爆发有限**：单回合只能兜底 5 血 + 免一次固伤，面对瞬间大额纯攻击伤害仍需[雷诺急救包](reno_first_aid_potion.md)这类即时大奶。
