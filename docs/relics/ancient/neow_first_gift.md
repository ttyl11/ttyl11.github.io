# 启程行囊

<img src="/images/relics/neow_first_gift.png" alt="启程行囊" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 先古

## 描述

拾起时，获得1件随机其他角色的初始遗物（优先未持有）。

- **遗物池**：遍历所有角色（原版与其它 mod 角色）的初始遗物，**排除当前角色自己的初始遗物**，并排除[群星的礼赠](/relics/starter/elemental_core.md)与[星辰之录](/relics/event/star_tracker_relic.md)；同 ID 的遗物只保留一份。
- **优先未持有**：先过滤掉你已经拥有的；只有候选全部拥有时才允许重复发放。
- **无选择权**：随机抽 1 件直接入手，不能挑选。

## 小贴士

- **白嫖一个"别的角色的开局被动"**：原版每个角色的初始遗物都是围绕该角色设计的核心引擎，这遗物等于把这套引擎装到你身上——一局只能有一个角色，行囊让你多带一件别人的起手遗物。
- **池子覆盖原版与其它 mod 角色**：候选来自全部角色（排除自己），所以既能抽到原版角色的经典初始遗物，也能抽到其它 mod 角色的起手件；同 ID 去重，不会出现两件一样的候选。
- **优先补你没有的**：已拥有的会被排除，第二件行囊大概率给新货；但候选全部拥有时会允许重复，重复件的价值取决于该遗物能否叠加。
- **开局一次性收益**：只在拾起瞬间发一次，没有后续成长；对比[宿命纺锤](/relics/ancient/neow_fate_twin.md)（普通/罕见/稀有各 1 张，共 3 张）与[双生印绶](/relics/ancient/neow_dual_blessing.md)（5 选 2 罕见卡），行囊给的是遗物位而不是卡组，与卡组构筑完全解耦。
- **随机结果多端一致**：抽选走同步随机源，多人模式下两端拿到的是同一件遗物。
