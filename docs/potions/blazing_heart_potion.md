# 🔥 炽焰之心

## 基本信息

- **分类**: 增益（高方差）
- **稀有度**: 罕见
- **使用时机**: 战斗内
- **目标**: 自身

### 数值参数

| 参数 | 数值 |
|---|---|
| 火种层数 | 50 |

## 描述

获得 <span style="color:#3aa675;font-weight:600">50</span> 层[火种](/powers/spark_power.md)。

## 详细机制

- **作用于自身**：无需选择目标，为自身施加[火种](/powers/spark_power.md)能力 50 层。
- **火种的真实机制**：每个**自身回合开始时**，每一层火种独立进行 10% 判定；判定成功的层数转化为[火苗](/powers/flame_power.md)，并获得等量的永久增伤与永久减伤；判定失败的层数全部消散。**它不是"随回合累积"，也不是稳定增伤。**
- **50 层是 50 次独立判定**：期望约转化 5 层（+5 增伤 / +5 减伤），实际结果会在 0~10 层上下浮动，并不会"全部转化"或"必然归零"。
- **只判定一次**：未转化的层数当回合就消失，不会留到下一回合再赌；持有【焚世涅槃】时才会保留。
- **悬浮提示**：附带火种能力提示，可确认当前层数。

## 小贴士

- **它不是"全有或全无"**：每一层单独掷 10%，50 层最可能转化 5 层左右，期望约 +5 增伤 / +5 减伤。既不会稳定给满 50，也很少一层都不出——本质是一瓶"高方差的中等增益"。
- **方差才是重点**：运气好能转化十几层、一次拿到 +15 以上的攻守；运气差只有 1~2 层。把它当"期望 +5、上限很高"的增益，而不是彩票。
- **成功后的火苗增/减伤按转化层数结算**：转化多少层就给多少层，不会因为没转化完就全部作废——未转化的部分只是消失，已转化的照样生效。
- **何时用**：长战斗里早用早判定，但只有一次判定机会；短战斗里也别指望它救命。适合"顺手补一点输出与防御"的场合。
- **与"稳定增伤"区分**：它不是火种越叠越强，而是"一次性转化 + 未转化清空"，所以层数高低只影响这一次判定的期望，不影响后续回合。
