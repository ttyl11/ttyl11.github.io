# 卡牌池扩展

Seer Mod 对原版的卡牌池系统进行了扩展，主要包括尘封之书支持 Mod 的先古牌、远古之牙的超脱升级扩展，以及先古卡池的注册机制。

::: tip Mod 扩展了什么
- 尘封之书（原版遗物）的先古牌选择扩展为多级回退查找，支持 Mod 先古牌
- 远古之牙（原版遗物）的超脱升级改写为谱尼/索伦森专用映射：初始牌 → 昪旻/星星之火/神灵救世光 或 混沌灭世决
- 先古卡通过继承注册特性自动注册到 SeerCardPool
:::

---

## 尘封之书扩展

### 原版尘封之书

尘封之书是原版遗物，效果是从角色的卡池中选一张先古稀有度的卡牌。原版只查找角色自己的卡池，如果角色没有先古牌，尘封之书会无法生效。

### Mod 的多级回退查找

Mod 通过补丁扩展了尘封之书的先古牌查找逻辑，采用四级回退：

| 级别 | 查找来源 | 说明 |
| --- | --- | --- |
| 1 | 角色自己的卡池 | 排除远古之牙的超脱卡，找到则放行原方法 |
| 2 | SeerCardPool（圣灵谱尼名下） | 从 Mod 的先古牌池中随机选一张 |
| 3 | 无色卡池 | 从无色卡的先古牌中随机选一张 |
| 4 | 兜底 | 使用固定的先古卡避免 AncientCard 为 null |

### 补充保障

- **获得时补查**：获得尘封之书时若先古牌为 null，自动补查
- **获得后保护**：获得后若先古牌仍为 null，阻止后续逻辑避免崩溃

::: tip 为什么要多级回退
原版角色可能没有先古牌（尤其是 Mod 新增角色），多级回退确保尘封之书在任何情况下都能选到一张先古牌。SeerCardPool（圣灵谱尼名下）是 Mod 先古牌的主要来源。
:::

## 远古之牙扩展

### 原版远古之牙

远古之牙是原版遗物，效果是让特定初始牌通过超脱升级变成另一张卡牌，原版有一组固定映射。

### Mod 对两个角色的改写

补丁替换了「选哪张初始牌」与「变成哪张先古牌」两步，只对谱尼、索伦森生效；其他角色仍走原版映射。

| 角色 | 作为转化源的初始牌 | 超脱后的目标 |
| --- | --- | --- |
| 谱尼 | 牌组中第一张仍存在的初始牌（虚无 / 元素 / 能量 / 生命 / 轮回 / 永恒 / 圣洁） | 从昪旻 / 星星之火 / 神灵救世光中随机 1 张 |
| 索伦森 | 牌组中第一张仍存在的初始牌（寂灭 / 消亡 / 灭世挽歌 / 堕世 / 邪灵降世）；全部转化掉时退到牌组中任意一张非混沌灭世决的牌 | 固定为混沌灭世决 |

- 转化目标会继承源牌的升级状态与附魔。
- 谱尼的随机目标使用 `Rng.Niche`，多端一致。
- 并不存在「轮回 → 先古」这样一条固定映射；轮回只是谱尼可选作转化源的初始牌之一。

## 先古卡池注册机制

### SeerCardPool

- **作用**：承载 Mod 所有先古牌的卡池
- **归属**：圣灵谱尼名下
- **注册方式**：通过 RitsuLib 的共享卡池注册系统注册

### SeerAncientCardPool

- **作用**：空卡池占位，仅用于兼容注册
- **内容**：不生成任何卡牌（返回空数组）
- **原因**：先古牌已统一归到 SeerCardPool，此卡池保留仅为兼容性

### SeerAncientCardBase

- **作用**：先古牌基类
- **注册特性**：通过继承自动注册到 SeerCardPool
- **效果**：所有继承此基类的子类自动注册到 SeerCardPool
- **资源**：默认竖向先古布局，使用专属卡面资源

### 横向先古牌

- **基类**：横向先古牌基类
- **用途**：7 张横向先古衍生牌（光荣之梦、圣灵悲魂曲、神圣复苏、神灵之触、神圣启示歌、圣光吟诵、璨灵圣光），也是真神牌堆的候选弹药
- **实现**：通过设置视觉样式为标准横向布局

## 先古牌与游戏流程

先古牌是 Mod 的高稀有度卡牌，获取途径包括：

1. **尘封之书**：通过多级回退查找获得（主要途径）
2. **Neow 选项**：部分 Neow 选项提供先古牌
3. **远古之牙**：谱尼的初始牌超脱为昪旻/星星之火/神灵救世光之一，索伦森的初始牌超脱为混沌灭世决
4. **真神牌堆**：7 张候选牌全部是先古稀有度的衍生牌

## 战略意义

### 先古牌的稀有性

先古牌是 Mod 最稀有的卡牌类型：
- 正常游戏流程中不易获得
- 需要通过特定遗物（尘封之书、远古之牙）或事件获取
- 每张先古牌都有强力效果

### 尘封之书的普适性

多级回退确保所有角色都能从尘封之书获得先古牌：
- 角色有先古牌 → 使用角色先古牌
- 角色无先古牌 → 从 SeerCardPool 随机选 Mod 先古牌
- 无色卡池有先古牌 → 从无色卡池选
- 兜底保障 → 至少有一张先古牌

### 谱尼/索伦森的超脱路径

- **谱尼**：牌组里留一张初始牌，用远古之牙把它超脱成昪旻 / 星星之火 / 神灵救世光中的随机一张。
- **索伦森**：牌组里留一张初始牌，用远古之牙把它超脱成混沌灭世决（真神牌）。
- 两种都是先古牌的间接获取途径；源牌被其它效果转化掉时会自动改用下一张仍存在的初始牌。
