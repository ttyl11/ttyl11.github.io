# 凝视

> **归属**：怪物专属（玩家无法施加）
> **施加来源**：怪物施加给玩家——[墨鲁萨](/monsters/elite/medusa_minion_monster.md)

## 基本信息

- **类型**: 减益（Debuff）
- **叠加方式**: 单例（不可叠加）
- **可见**: 是

## 描述

①你的朝向会影响部分招式与能力的效果。<br/>②使用指向性卡牌或药水时，你会转向目标。

## 详细机制

- **初始朝向**：右。
- **转向条件**：打出**有目标**的牌、或使用**有目标**的药水时，若目标站在与你相反的一侧，则转向目标。
- **只认左右标记**：目标必须带有「左侧/右侧」标记才会触发转向。
- **贴图同步**：转向时角色本体与所有随从一起翻转。
- **自动校正**：击杀敌人后，若在场敌人全部带同一侧标记，会自动转向那一侧。
