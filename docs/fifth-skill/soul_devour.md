## 小贴士

- **0 费永久成长的三效引擎**：0 费打出，对敌人附加 <span style="color:#3aa675;font-weight:600">5</span> 点[固定伤害](/powers/fixed_damage_power.md)，自己获得 <span style="color:#3aa675;font-weight:600">5</span> 点[格挡](/mechanics/block.md)，外加 <span style="color:#3aa675;font-weight:600">5</span> 点[堕落](/powers/fallen_power.md)，并且**每打出一次这三项全永久各 +1**。0 费意味着每回合都能白嫖一次推进成长，是一张"打到后面会失控"的滚雪球核心牌。
- **固定伤害 + 格挡 + 堕落的三向成长**：成长同时作用于进攻端（固定伤害）、防御端（格挡）和[堕落](/powers/fallen_power.md)——越往后打越是攻防一体。前期是 5 伤 5 挡 5 堕落起的玩具，几十次后可能变成几十点固伤 + 几十点格挡的怪物——一回合 0 费白嫖这么多收益，价值远超任何固定数值牌。
- **堕落增量也在成长——这是它的暗面**：堕落数值本身每打一次 +1，意味着**每次打出的堕落贡献也在递增**：第 1 次 +5、第 2 次 +6、第 3 次 +7……滚雪球越滚，推进[魔君接管](/powers/demon_takeover_power.md)的失控阈值也越快。堕落是负面机制，每满<span style="color:#3aa675;font-weight:600">100</span>层强制接管乱打手牌——长局把这张牌养肥的同时，等于给自己装了一颗越来越快的失控引信，好在触发附带抽<span style="color:#3aa675;font-weight:600">3</span>张与混沌化身，"坏而不致命"。
- **每张独立成长，同步到牌组原卡**：每打出一次，本次的战斗副本和牌组里的原始那张各 +1（与[史莱姆](/cards/colorless/slime.md)同款的 DeckVersion 模式），下一场战斗带着最新数值进场。注意**同名卡各自独立计数**——两张堕语噬亡魂是两条成长线，打出哪张的副本就只推进哪张，多带不会互相加速。
- **固定伤害是延迟且无视格挡的**：附加的固定伤害以减益形式挂在敌人身上，**到敌人自己回合开始时才扣血**（之后移除），并且吃不到[格挡](/mechanics/block.md)减免。对叠甲型 Boss 极其有效——它叠多少甲都挡不住这部分。注意两类反制：敌人若有[免疫固定伤害](/powers/immune_fixed_damage_power.md)/[回合免疫固伤](/powers/turn_immune_fixed_damage_power.md)/[长效体力](/powers/long_lasting_hp_power.md)/[圣谕形态](/powers/divine_form_power.md)（施加瞬间直接归零，最彻底）会直接免疫；更危险的是[坚毅](/powers/resolve_power.md)——被免疫的固伤会**原封不动转移给你方全体**，对有坚毅的 Boss 刷固伤等于自杀。
- **升级给固有是质变**：升级后获得[固有](/mechanics/innate.md)，每场战斗开局必在手牌。这意味着**每场战斗第一回合就能 0 费推进一次成长**，整局下来累积的额外成长次数非常可观。没升级时它得靠抽到才能用，成长节奏慢一截。**升级优先级极高**，拿到就该优先升。
- **长局 Boss 战的真神**：这张牌的强度与战斗/整局长度正相关——短战斗来不及养，长 Boss 战和长跑局里它能堆出恐怖数值。配合"每回合多出牌"的能力（如额外出牌、0 费体系）能一回合打出多次，成长飞快。
- **性价比**：0 费永久成长本身已经超模，升级固有后开局即用更是质变。普通稀有度完全配得上，是长跑局和 Boss 战的核心投资牌，越早拿到越早滚起来。
