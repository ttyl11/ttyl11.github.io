# 弹控（DanKong）

**弹控**是 Seer Mod 的自定义卡牌关键词，持有者免疫[异常状态](/mechanics/abnormal-status.md)并反弹给来源。

## 基本信息

| 项目 | 说明 |
| --- | --- |
| 类型 | Mod 卡牌关键词（免疫+反弹型） |
| 效果 | 免疫并反弹异常状态 |
| 适用 | 卡面缩写术语，配合具体回合数出现 |

## 规则说明

- **免疫**：持有者不会获得异常状态（只判定可见的异常状态）——**自己给自己挂异常也会被挡下**
- **反弹**：本该施加给持有者的异常状态会转为施加给**持有者的所有敌人**，不只是原施加者——多敌人战斗中会同时命中全场敌人；自己或没有施加者的异常只免疫、不反弹
- **持续**：层数 = 覆盖的敌方回合数，在敌方回合结束时衰减 1 层
- 对比：[免控](/mechanics/mian_kong.md)是纯免疫；弹控在免疫基础上带回反制，适合用来惩罚喜欢上状态的敌人
