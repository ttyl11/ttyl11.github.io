# 反强（FanQiang）

**反强**是 Seer Mod 的自定义卡牌关键词，打出后反转对手的[全属性](/mechanics/all_attributes.md)提升。

## 基本信息

| 项目 | 说明 |
| --- | --- |
| 类型 | Mod 卡牌关键词（转换型） |
| 效果 | 反转对手全属性提升 |
| 适用 | 卡面缩写术语 |

## 规则说明

- **反转对象**：对手的[力量/命中/防御/速度](/mechanics/all_attributes.md)正值（提升）
- 对手的正属性反转后变为等量负值，从"强化"一步翻成"削弱"
- 对比：[消强](/mechanics/xiao_qiang.md)归零不加负、[吸强](/mechanics/xi_qiang.md)转移而不反转——反强是"把对手增益变减益"
