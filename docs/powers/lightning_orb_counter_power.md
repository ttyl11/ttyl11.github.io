# 闪电充能球

> **归属**：玩家可施加
> **施加来源**：玩家获得——[雷雨天](/powers/rainstorm_power.md)（能力联动，造成伤害时充能）

<img src="/images/powers/lightning_orb_counter_power.png" alt="闪电充能球" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 增益（Buff）
- **叠加方式**: 叠加（层数 = 当前球数）
- **可见**: 否（后台静默运行，不显示图标）

## 描述

在自己的回合结束时，每颗球对随机敌人造成3点伤害。最多2颗球。

## 详细机制

- **充能**：每次造成伤害 +1 球（最多 2 颗）；已满 2 颗时再充能，会先激发最旧的一颗（8 点伤害）再 +1。
- **被动**：自己的回合结束时，每颗球各对一个随机敌人造成 3 点伤害。
- **激发**：雷祭按本场累计充能次数生成等量闪电球，每颗 8 点伤害；生成后累计数翻倍（4→8→16…）。
- **伤害性质**：不吃力量等属性加成，但可以被格挡；球造成的伤害不会再触发充能，避免循环。
