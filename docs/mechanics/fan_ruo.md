# 反弱（FanRuo）

**反弱**是 Seer Mod 的自定义卡牌关键词，打出后反转自身的[全属性](/mechanics/all_attributes.md)下降。

## 基本信息

| 项目 | 说明 |
| --- | --- |
| 类型 | Mod 卡牌关键词（转换型） |
| 效果 | 反转自身全属性下降 |
| 适用 | 卡面缩写术语 |

## 规则说明

- **反转对象**：自身的[力量/命中/防御/速度](/mechanics/all_attributes.md)负值（下降）
- 负属性反转后变为等量正值，从"被削弱"一步翻成"增强"
- 对比：[解弱](/mechanics/jie_ruo.md)是解除下降归零；反弱是把下降转为提升，收益更高
