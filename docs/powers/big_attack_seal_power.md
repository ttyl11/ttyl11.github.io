# 天叶止戈

> **归属**：怪物专属（玩家无法施加）
> **施加来源**：怪物自带——[不羁·弗里德](/monsters/boss/bujifulide_monster.md)（技能 5「天叶领域」）
> **类型**：中性（None）
> **叠加方式**：按层数叠加
> **可见**：是

### 数值参数

| 参数 | 数值 |
|---|---|
| AttackThreshold | 20 |
| TurnsRemaining | 3 |

## 描述

持续[blue]3[/blue]回合：敌人牌面伤害数值高于[blue]20[/blue]点的攻击牌无法打出。
回合结束时减少[blue]1[/blue]层。
