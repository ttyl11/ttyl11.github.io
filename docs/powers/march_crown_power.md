# 皇冠

> **归属**：玩家可施加
> **施加来源**：玩家获得——[三月的皇冠](/cards/character/march_crown.md)（卡牌）

<img src="/images/powers/march_crown_power.png" alt="皇冠" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 增益（Buff）
- **叠加方式**: 单例（不可叠加）
- **可见**: 是

## 描述

自身所有攻击牌获得[gold]饮血[/gold]。

## 详细机制

- **全牌堆生效**：战斗开始时、能力施加时、以及每个玩家回合开始时，把[饮血](/mechanics/keywords.md)关键词加到**所有牌堆**中的攻击牌上——手牌、抽牌堆、弃牌堆、消耗堆、出牌堆都算。
- **后进也补齐**：战斗中途新生成/加入的攻击牌，会在下一个玩家回合开始时被补上饮血。
- **不重复叠加**：已经带饮血的牌不会重复添加，关键词本身就是饮血的效果。
- **不消耗、不减少**：能力整场常驻，层数不会掉，也不会自行消失。
- **只给攻击牌**：技能牌、能力牌、状态牌/诅咒牌都不会获得饮血。

## 小贴士

- **多段攻击收益最高**：饮血按每次伤害结算回复，攻击段数越多回得越多，配多段攻击牌等于自带续航。
- **只对攻击牌生效**：纯技能/能力构筑拿它几乎没有收益。
- **越早拿越好**：能力在每次玩家回合开始都会补关键词，长期战里等于给整个牌组永久加了一条续航。
