# 妖族元皇·兰蒂斯

## 基本信息

* **分类**: 非塔罗遗物

* **稀有度**: 史诗

### 数值参数

| 参数     | 数值  |
| ------ | --- |
| 斩杀生命阈值 | 10% |

## 描述

①自身攻击牌在自身正先制下使用，造成伤害翻倍（本回合首次攻击牌）。②自身任意牌打出时，若自身命中为负层则反转为等量正层；若为 0 或正层则保持不变。③每个对手回合开始时，若其生命大于 <span style="color:#3aa675;font-weight:600">10</span>%，则自身先制+<span style="color:#3aa675;font-weight:600">1</span>；若其生命小于 <span style="color:#3aa675;font-weight:600">10</span>%，斩杀之。（对每个敌人分别计算）

## 详细机制

* **伤害乘区翻倍（①）**：伤害计算进入乘区时检测——来源必须是**自身**、伤害必须来自**攻击牌**、且自身身上必须有**正层先制**。三者同时满足则将伤害乘以 <span style="color:#3aa675;font-weight:600">2.0</span>，与其他伤害乘区（易伤、破韧等）累乘。注意：先制会在你打出第一张牌时消耗掉（先制本身是"打出牌时移除自身"的 buff），因此 ① 的实际窗口是在获得先制后打出的**第一张攻击牌**——之后先制已消耗完毕，直到敌方回合开始 ③ 再次给予。

* **命中反转（②）**：任意牌打出时，检查自身身上的[命中](/powers/accuracy_power.md)——若为**负层**（命中下降，攻击有概率 Miss），则移除并施加等量**正层**（恢复命中）；若为 0 或**正层**（命中提升），则不做任何操作，保持原样。只作用于自身，不影响任何目标。

* **先制与斩杀二选一（③）**：每个对手回合开始时，对**每个存活敌人**分别计算——HP > 10% 时自身获得 1 层先制；HP < 10% 时**直接击杀**该敌人（绕过常规 HP 归零流程，仍会正常触发死亡事件如掉落、遗物触发等）。等于 10% 时两个分支均不触发。每回合每个敌人只结算一次。

## 小贴士

* **先制窗口转瞬即逝**：①的翻倍只在先制尚未消耗的当张牌生效——先制是"打出牌时移除"的 buff，所以你获得先制的那一轮，只能让**第一张攻击牌**享受翻倍。后续牌、以及纯固伤/非攻击来源，都不会触发 ①。这要求你在规划出牌顺序时把最强的攻击牌放在先制窗口内打出。

* **斩杀是即死，不是"处决 Debuff"**：③的斩杀效果是直接消灭该敌人，不是施加[处决](/powers/execute_power.md)（那是回合开始时触发固定伤害的 debuff）。击杀后仍会正常触发死亡事件（掉落、遗物触发、召唤等）。适合用来规避某些死亡陷阱。

* **命中反转是保护性的**：②只会在命中为负层（有 Miss 风险）时触发，把负层翻成正层帮你找回命中率。如果你本身命中已经是正的，打出任何牌都不会改变它——不会让你从"高命中"变成"有 Miss 风险"。这是纯正向收益，不存在误伤自己的情况。

* **多敌人房间的收益放大**：③的每敌独立计算意味着敌人越多，每回合获得的先制总量越高——三怪房每回合最多 3 层先制，Boss 房只有 1 层。

* **与先制流遗物的协同**：自身获得的先制每回合都在累积（只要敌人 HP > 10%），配合"打出牌时消耗先制"的机制，实际上每回合都能保证至少一张攻击牌享受 2x 伤害——前提是你能控制节奏，让先制不被其他效果提前消耗。
