# 休息处选项

玩家在火堆休息处可以选择各种选项来恢复体力或获得增益。部分遗物会在此处提供特殊选项。

## 常规选项

- **休息**：恢复一定量生命值。

- **锻造**：升级手牌或弃牌堆中的一张卡牌（选择一张牌，费用-1，效果增强）。

- **删除卡牌**：从牌组中永久移除一张卡牌。

- **复制卡牌**：复制手牌或弃牌堆中的一张带[克隆](/enchantments/clone.md)附魔的卡牌。

- **其他**：根据当前进程和已持有遗物动态出现。

## 特殊选项

### 跑步

- **触发条件**：持有 [巧克利](/relics/rare/chocoli.md) 遗物，且已累积至少 1 次跑步机会（每 3 场战斗获得 1 次）。

- **效果**：尽可能多地消耗累积次数，每消耗 1 次同时获得以下加成：

  - 战斗开始时敏捷 +1

  - 战斗开始时速度 +2

  - 战斗开始时手牌上限 +1

  - 复制一份已有的巧克利遗物（多个遗物可叠加）

- **注意**：跑步是一次性结算所有累积次数，每次消耗独立计算加成。

### 赛尔号，启动！

- **触发条件**：持有 [罗杰船长](/relics/shop/captain_roger.md) 遗物，且赛尔号未启动。

- **效果**：赛尔号进入启动状态，本场战斗可打出一次。打出后当场锁定，下场需重新启动。

- **联动**：赛尔号打出后，战斗结束获得 2 件随机普通遗物（升级后获得 3 件）。

### 核心跃迁

- **触发条件**：持有 [工程师苏克](/relics/shop/engineer_su_ke.md) 遗物。

- **效果**：从已持有的可升级遗物中，选一件将其稀有度沿下列链条提升一阶：

  > 普通 → 罕见 → 稀有 → 史诗 → 传说

- **规则**：

  - 传说遗物不可再升级，不会进入可选池。

  - 升级时从同稀有度池随机抽取替代品。

  - 初始遗物、商店遗物、事件遗物、先古类遗物均可参与升级池。
