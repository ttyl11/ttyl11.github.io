## 小贴士

- **自伤换长线成长**：打出损失 <span style="color:#3aa675;font-weight:600">7</span> 点生命（不可格挡、不受力量/易伤影响），换取 <span style="color:#3aa675;font-weight:600">4</span> 个敌方回合的异常免疫反弹 + 战斗结束随机升级。前期自伤 7 点不轻，但长线收益（永久升级牌组）会持续滚雪球——配合回血手段后这笔交易非常划算。
- **免疫范围是异常状态、不含原版减益**：免疫并反弹的是 mod 的 <span style="color:#3aa675;font-weight:600">27</span> 种[异常状态](/mechanics/abnormal-status.md)（灼伤、中毒、冰封、失明、麻痹、石化等），**不免疫**原版虚弱/易伤/脆弱——面对挂原版减益的敌人这层保护是空的，别高估它的覆盖面。
- **反弹给全体敌人**：免疫期间吃到的异常原样弹给**所有**敌人（不是只弹施加者）。多敌人遭遇里反弹收益翻倍——敌人轮流挂异常时等同于给全队自残。
- **覆盖窗口 4 个敌方回合**：反弹层数在**对方回合结束**递减，<span style="color:#3aa675;font-weight:600">4</span> 层覆盖 <span style="color:#3aa675;font-weight:600">4</span> 个敌方回合，比多数免疫手段更长，应对持续异常攻势更从容。
- **战斗结束随机升级**：战斗结束后，从**牌组**中完全随机抽一张，若可升级才升级；抽到已升级/不可升级的牌则本次作废。多次打出本牌会叠层，战斗结束按层数逐次尝试。持久战中越打牌组越强，但随机性意味着可能落空或升到不关键的牌。
- **溯引白嫖仪式**：[溯引](/mechanics/suyin.md)在抽到此牌时立即触发，获得 <span style="color:#3aa675;font-weight:600">1</span> 层[仪式](/powers/ritual_power.md)——即便随后弃掉或消耗此牌，仪式也已到手。仪式每层会让己方回合结束时获得等量[力量](/powers/strength_power.md)，属于锦上添花的持续强化。
- **升级固化启动**：升级后[固有](/mechanics/innate.md)——开局就在[手牌](/mechanics/hand.md)中，保证第一回合就能打出免疫反弹与启动成长，减少关键回合裸奔的风险。
- **堕落滚雪球，但堕落本身是负面**：[堕落](/powers/fallen_power.md) = 当前[堕落](/powers/fallen_power.md)层数 × <span style="color:#3aa675;font-weight:600">50%</span>（向下取整）+ <span style="color:#3aa675;font-weight:600">20</span>——堕落越多涨得越快，但堕落可不是奖励：每跨过 <span style="color:#3aa675;font-weight:600">100</span> 的倍数（100、200……）就会触发[混沌化身](/mechanics/chaos-incarnation.md)并让[魔君接管](/powers/demon_takeover_power.md)强制乱打手牌，等于把失控进度越推越快。打这张牌等于主动接受"负面但不算致命"的代价——有[混沌起源](/relics/starter/chaos_origin.md)回上限兜底时可承受，没有时要留心别让堕落叠过头。
- **性价比**：<span style="color:#3aa675;font-weight:600">1</span> 费、PP<span style="color:#3aa675;font-weight:600">3</span> 换长期免疫反弹 + 永久升级引擎，稀有度合理。自伤 <span style="color:#3aa675;font-weight:600">7</span> 点是主要代价，配回复/护甲才稳；纯速攻短战斗收益相对降低。
