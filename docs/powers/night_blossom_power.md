## 描述

本场战斗中，敌人拥有正[gold]先制[/gold]时，其打出的牌无效。

## 详细机制

- **判定看「先制」**：打出牌时检查出牌者身上是否有正数[先制](/powers/first_strike_power.md)——只要先制 > 0，这张牌就无效。
- **「无效」不是「不能打」**：牌照样支付耗能/PP、照样进入弃牌堆，但**所有效果都不结算**（打出的次数被改成 0，`OnPlay` 不执行）。
- **所有牌型都吃**：攻击牌、技能牌、能力牌都会被无效；能力牌还会额外补一次飞入动画，避免卡在屏幕中央。
- **整场战斗持续**：能力不随回合减少，只要挂着就一支持续生效。
- **先制归零就能打**：把先制削到 0 或负数，出牌即恢复正常。

## 小贴士

- **先制流当场报废**：整场战斗都别攒先制——先制越高，牌越打不出去；把先制压到 0 才能正常展开。
- **代价照付**：无效牌仍然耗能、耗 PP、进弃牌堆，等于白扔一张牌，宁可不出也别硬打。
- **先清先制再输出**：若身上有先制，先用能削先制/清增益的效果把先制压到 0，再正常展开。
