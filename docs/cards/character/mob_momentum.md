## 小贴士

- **"生物"包含自己——3 个敌人 = 4 个生物**：场上生物数 = 所有敌方生物 + 所有己方生物（包括你自己）。单人对战时 3 个敌人就是 <span style="color:#3aa675;font-weight:600">4</span> 个生物（<span style="color:#3aa675;font-weight:600">1</span> 自己 + <span style="color:#3aa675;font-weight:600">3</span> 敌人），抽 <span style="color:#3aa675;font-weight:600">4</span> 张 + <span style="color:#3aa675;font-weight:600">4</span> 能量，但速度 <span style="color:#3aa675;font-weight:600">-4</span>。双人模式己方算 <span style="color:#3aa675;font-weight:600">2</span> 个生物，同样计入。
- **速度惩罚是永久的，不会自动衰减**：施加的负[速度](/powers/speed_power.md)没有回合衰减机制——打完这张牌后，速度 <span style="color:#3aa675;font-weight:600">-4</span> 就一直挂着，直到战斗结束或被主动清除。自己的抽牌不受影响，但**每个敌人回合开始**，每只敌人都会获得“自身最大生命 ×5%×4”的格挡，越拖越硬。
- **代价是把敌人养硬**：4 生物场面（自己 + 3 敌人）= 速度 -4 → 每只敌人每回合获得 <span style="color:#3aa675;font-weight:600">20%</span> 最大生命格挡。双人模式下两名玩家的负速度会**相加**，敌人格挡更厚；先减员再打能显著压低这份惩罚。
- **残局打出惩罚更小**：生物数按打出瞬间的场面实时计算——敌人死亡后立即移出计数。残局只剩 <span style="color:#3aa675;font-weight:600">1</span> 敌 + 自己时打出，速度只 <span style="color:#3aa675;font-weight:600">-2</span> → 该敌人每回合获得 <span style="color:#3aa675;font-weight:600">10%</span> 最大生命格挡，却照常拿 <span style="color:#3aa675;font-weight:600">2</span> 抽 <span style="color:#3aa675;font-weight:600">2</span> 能量收尾。先减员再打这张牌是标准操作顺序。
- **负速度是减益，能被清除**：负速度在游戏中是减益类型，可被清除减益的效果直接清掉。清掉后敌人不再获得这份格挡，等于白嫖了一轮爆发——抽牌和能量到手，速度惩罚被抹除。所以配合减益清除能力可以把这张牌变成无损爆发。
- **重复打出惩罚累加**：速度是计数型能力，多次打出负层数直接叠加——4 生物场面连打 <span style="color:#3aa675;font-weight:600">2</span> 次就是速度 <span style="color:#3aa675;font-weight:600">-8</span>，每只敌人每回合获得 <span style="color:#3aa675;font-weight:600">40%</span> 最大生命格挡。第二次打出前先想清楚战斗还能拖几回合。
- **透支未来的交易**：本回合大抽大赚，但后续每回合敌人都会回一大口格挡。核心矛盾在于——爆发回合能结束战斗就赚，拖久了敌人越来越硬。适合在 boss 战或精英战的关键回合打出，配合速战速决或减益清除使用。
- **升级 0 费让爆发更灵活**：升级后耗能从 <span style="color:#3aa675;font-weight:600">1</span> 降至 <span style="color:#3aa675;font-weight:600">0</span>，打出不占能量——本回合能量全部用于后续出牌，爆发回合的操作空间更大。
- **堕落 24%：爆发局的第三次透支**：打出时获得当前[堕落](/powers/fallen_power.md)×<span style="color:#3aa675;font-weight:600">24%</span>——堕落是负面机制，每满<span style="color:#3aa675;font-weight:600">100</span>层被[魔君接管](/powers/demon_takeover_power.md)强制乱打；好在按比例计算、爆发局叠得不算多，属可管理的暗账，与速度惩罚同属"用长远代价换当下爆发"的牌面主题。
- **性价比**：<span style="color:#3aa675;font-weight:600">1</span> 费（升级 <span style="color:#3aa675;font-weight:600">0</span> 费）换 N 张牌 + N 能量，爆发价公道，永久速度代价是隐性长期成本需配合速战速决或减益清除。

## 相关能力

- [速度](/powers/speed_power.md)：自身负层会让每只敌人回合开始获得最大生命 5%×层数的格挡，不会减少自己的抽牌
- [堕落](/powers/fallen_power.md)：按当前堕落层数 ×24% 累积
