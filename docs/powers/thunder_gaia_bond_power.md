# 雷霆盖亚之契

> **归属**：玩家可施加
> **施加来源**：玩家获得——[雷盖之交](/cards/token/thunder_gaia_bond.md)（卡牌）

<img src="/images/powers/thunder_gaia_bond_power.png" alt="雷霆盖亚之契" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 增益（Buff）
- **叠加方式**: 单例（不可叠加）
- **可见**: 是

## 描述

打出攻击卡时，随机将一张技能卡加入手牌；打出技能卡时，随机将一张攻击卡加入手牌。

## 详细机制

- **攻击→技能**：自己打出攻击牌后，从**赛尔牌池**随机抽 1 张技能牌加入手牌。
- **技能→攻击**：自己打出技能牌后，从赛尔牌池随机抽 1 张攻击牌加入手牌。
- **只认赛尔牌**：候选来自 mod 的赛尔卡池，不是全卡池。
- **只看自己的牌**：队友/敌人出牌不触发。
- **能力牌不触发**：只有攻击牌与技能牌会互相生成。
- **整场常驻**：单例不消耗，战斗结束才消失。
