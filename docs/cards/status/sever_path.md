# 断程

<img src="/images/cards/sever_path.png" alt="断程" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 状态牌
- **最大PP**: 1
- **能量消耗**: 0
- **类型**: 状态
- **稀有度**: 状态
- **目标**: 无
- **关键词**: 无
- **可升级**: 是（最多 99 级，每级耗能 +1）

## 描述

只要此牌位于<span style="color:#d4a017;font-weight:600">手牌</span>，你无法打出<span style="color:#d4a017;font-weight:600">技能牌</span>。每当你打出<span style="color:#d4a017;font-weight:600">能力牌</span>时，此牌升级。

## 详细机制

- **手牌封锁**：它在手牌时，你的技能牌全部无法打出；离开手牌后封锁解除。
- **升级机制**：它在手时，你每打出一张能力牌，它升级 1 次；升级效果是**耗能 +1**，最高 99 级。
- **主要来源**：[机械王·马尔修斯](/monsters/boss/maerxiusi_monster.md)的源生动力，会销毁你的 0 费牌并按张数把断程塞入抽牌堆。
- **本身可打出**：0 费、消耗 1 点 PP（PP 1/1）；打出后离开手牌、解除封锁，但它只是进弃牌堆，之后还可能被重新抽到。
- **只管手动出牌**：被效果自动打出的技能牌不受它封锁。

## 小贴士

- **技能流被它一卡封死**：在手就禁技能牌，防御/过牌/解异常类技能全部瘫痪；尽快打出或弃掉。
- **打能力牌会把它养成高费牌**：每打一张能力牌它 +1 费（最高 99 级），越养越难打出；要么尽早 0 费打掉，要么这段时间别连打能力牌。
- **和锁匣同时来最难受**：一个封攻击、一个封技能，只剩能力牌可打；手牌会被状态牌彻底锁死，提前准备弃牌/消耗手段。
- **断程自己也是 0 费牌**：下一次源生动力会把它一起销毁（进销毁牌堆）。
