# 必暴（BiBao）

**必暴**是 Seer Mod 的自定义卡牌关键词，下一次攻击必定暴击。

## 基本信息

| 项目 | 说明 |
| --- | --- |
| 类型 | Mod 卡牌关键词（暴击型） |
| 效果 | 下一次攻击必定暴击 |
| 适用 | 卡面缩写术语 |

## 规则说明

- **必定暴击**：持有此关键词的角色下一次攻击伤害按暴击结算（暴击机制见[暴击](/mechanics/critical-strike.md)）
- 常配合"下 N 次攻击"的层数/次数描述一起出现（如[黎羽幻生](/cards/character/feather_phantom.md)的"下两次攻击[必暴]"）
- 与[暴击](/powers/critical_strike_power.md)能力、暴击增益乘区相互叠加
