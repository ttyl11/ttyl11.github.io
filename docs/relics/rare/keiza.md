# 克雷扎

## 基本信息

* **分类**: 非塔罗遗物

* **稀有度**: 稀有

### 数值参数

| 参数     | 说明                               |
| ------ | -------------------------------- |
| 变形目标限制 | 抽牌堆中可被变形的非基础牌                    |
| 生成卡牌   | [弹簧](/cards/character/spring.md) |

## 描述

每回合开始时，选择你抽牌堆中的一张牌，将其变为[弹簧](/cards/character/spring.md)。

## 风味文字

<span style="color:#d44;font-weight:600">克雷扎。</span>

## 小贴士

* **需要玩家手动选择**：触发时会弹出选择界面，从抽牌堆中选一张符合条件的牌进行变形。

* **仅影响可变形牌**：抽牌堆中只有[可变形](/mechanics/transform.md)的牌才能被选中（非基础牌、未被变形过的牌）。若抽牌堆中没有符合条件的牌，则不触发。

* **弹簧的价值**：变形得到的弹簧是一张 PP 牌，打出后提供格挡并施加[弹簧能力](/powers/spring_bonus_power.md)，使后续每回合多抽多能量，持续回合数随打出张数累加。

* **稀有度平衡**：稀有遗物，每回合稳定提供一张弹簧，配合奇巧 Combo 和多张弹簧叠加机制可大幅扩展资源爆发。
