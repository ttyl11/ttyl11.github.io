# 铸盾

> **归属**：怪物专属（玩家无法施加）
> **施加来源**：怪物自带——圣盾·瓦尔德

## 基本信息

- **类型**：中性（None）
- **叠加方式**：不叠加
- **可见**：否（后台静默计数）

## 描述

记录本场战斗累计获得的[gold]格挡[/gold]量。

## 详细机制

- **累计口径**：持有者每次**实际获得**格挡时累加（按修正后的实际数值，不是卡面数值）。
- **隐藏能力**：不显示图标，仅作为计数载体。
- **用途**：供技能「破晓光耀击」读取，按其累计值的 7% 计算伤害。
