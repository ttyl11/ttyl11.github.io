# 返璞归真

> **归属**：怪物专属（玩家无法施加）
> **施加来源**：怪物自带——[盖亚](/monsters/boss/gaia_monster.md)

## 基本信息

- **类型**: 无类型（不参与增益/减益分类，不可被驱散/净化）
- **叠加方式**: 单例（不可叠加）
- **可见**: 是

## 描述

①自身登场时，从三种规则中随机创建<span style="color:#3aa675;font-weight:600">1</span>种。<br/>②自身造成<span style="color:#d4a017;font-weight:600">暴击</span>时，回复等同于该次伤害的生命值。

## 详细机制

- **开局随机一条横幅规则**（三选一，多端随机一致）：
  - **血之规则**：盖亚受到的伤害 ×2，但从第 3 回合起，它的攻击直接秒杀对手。
  - **天之规则**：非暴击伤害降到 40%，暴击伤害提高到 3 倍。
  - **邪之规则**：受到的伤害减少「70 − 5×回合数」%（越拖减伤越低）。
- **暴击回血**：盖亚造成暴击攻击伤害时，按**实际掉血**回复等量生命；多段攻击每一段暴击都会回一次。
- **只认攻击伤害**：固定伤害、DoT 不触发回血。
- **规则是独立能力**：横幅只是开局提示，实际效果由对应的规则能力承担。
