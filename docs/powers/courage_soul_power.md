# 勇气之魂

<div style="text-align:center;color:#888;font-size:0.9em;margin-bottom:16px">不可见能力 · 无图标</div>

## 描述

自身下个回合结束时，再额外开启一回合。

## 来源

- [勇气号](/relics/rare/courage_ship.md)：每次洗牌时获得 1 层勇气之魂。

## 机制说明

- **额外回合**：当勇气之魂生效时，你在当前回合结束后不会直接进入敌方回合，而是再获得一个完整的玩家回合（相同的能量、抽牌、行动机会）。
- **可叠加**：多层勇气之魂会依次触发，每层对应一个额外回合。
- **结算时机**：在"自身回合结束"时检查，触发后立即进入额外回合，然后再正常进入敌方回合。
- **与连锁效果配合**：额外回合可以打出更多牌，适合配合需要多回合输出的构筑（如 [连营](/mechanics/lian_ying.md)、[消耗](/mechanics/exhaust.md) 等）。
