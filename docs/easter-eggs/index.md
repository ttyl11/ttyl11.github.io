# 彩蛋与趣味细节

## 群星的礼赠：角色彩蛋遗物

初始遗物[群星的礼赠](/relics/starter/elemental_core.md)的"遗物宝库"（局外右键 30 选 1）会按你正在使用的**原版角色**，额外放入一组角色彩蛋遗物（源码 `GetTreasuryEasterEggs`）：

| 原版角色 | 彩蛋遗物 |
|---|---|
| 铁甲战士 | [典韦](/relics/epic/dian_wei.md)、[邪冥龙帝](/relics/uncommon/evil_nether_dragon_emperor.md)、[超算鲁比克](/relics/rare/rubik_supercomputer.md)、[正义](/relics/common/tarot_justice.md) |
| 静默猎手 | [流萤·雪](/relics/uncommon/firefly_snow.md)、[超算鲁比克](/relics/rare/rubik_supercomputer.md)、[恋人](/relics/common/tarot_lovers.md)、[隐者](/relics/common/tarot_hermit.md) |
| 摄政王 | [神剑·天音](/relics/uncommon/divine_sword_tianyin.md)、[超算鲁比克](/relics/rare/rubik_supercomputer.md)、[星灵圣王](/relics/common/star_holy_king.md) |
| 故障机器人 | [东海龙王](/relics/common/east_sea_dragon_king.md)、[圣王·萨格罗斯](/relics/rare/holy_king_sargeros.md)、[超算鲁比克](/relics/rare/rubik_supercomputer.md)、[高塔](/relics/common/tarot_tower.md) |
| 死灵之缚 | [鬼剑罗刹](/relics/common/ghost_sword_rakshasa.md)、[超算鲁比克](/relics/rare/rubik_supercomputer.md)、[死神](/relics/common/tarot_death.md) |

超算鲁比克出现在所有角色的彩蛋位上；塔罗牌彩蛋为各职业各配了一张。

## 剧情彩蛋

- **[紫袍学者](/events/purple_robed_scholar.md)的《日月前事》**：选项没有任何收益——你刚开口她就吓得转身逃走，纯联动剧情梗。
- **[缺失的愚者](/events/missing_fool_tarot.md)**：触碰魔盒后你会发现"缺失的愚者"就是你自己。
- **[M78 星云的外交时刻](/events/nebula_diplomacy.md)**：虚张声势一句狠话，就能把光之国的赛罗吓得交出物资。

## 梗值数据

- **怪物血量梗**：史莱姆 114514、试炼史莱姆 114514、魔狮迪露 1000000——均为源码设定的初始血量（详见[怪物图鉴](/monsters/index.md)）。
- **卡名的梗**：诅咒牌[拖50](/cards/curse/drag_burden.md)、[氪金](/cards/curse/pay_to_win.md)、[云玩家](/cards/curse/cloud_gamer.md)、[保底](/cards/curse/guaranteed.md)、[老鼠药](/cards/curse/rat_poison.md)；无色牌[好男孩](/cards/colorless/good_boy.md)/[好女孩](/cards/colorless/good_girl.md)、[低等精灵](/cards/colorless/low_elf.md)、[疯狂编码](/cards/colorless/crazy_code.md)；衍生牌["大奖？"](/cards/token/grand_prize.md)/["大奖！"](/cards/token/surprise_grand_prize.md)。
- **[保底](/cards/curse/guaranteed.md)的抽卡彩蛋**：战斗结束若它在手，1% 概率白送一张随机稀有卡——99% 落空、1% 出货，就是"抽卡保底"的梗。
- **五音"卩"**：[卩](/enchantments/five_tone_seal.md)是彩蛋级成长附魔——以此牌击败对手后永久 +10% 攻击伤害、-5% 受伤（可叠加），每次触发最大生命 -20。
