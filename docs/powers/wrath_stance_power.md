# 愤怒姿态

> **归属**：怪物专属（玩家无法施加）
> **施加来源**：怪物自带——[泰格尔](/monsters/boss/tiger_monster.md)（技能「冲天霸气」切换姿态）

## 基本信息

- **类型**: 中性（None，不参与增益/减益分类）
- **叠加方式**: 单例（不可叠加）
- **可见**: 是

## 描述

自身造成与受到的伤害翻倍。

## 详细机制

- **双向翻倍**：泰格尔造成的攻击伤害 ×2，泰格尔受到的攻击伤害也 ×2。
- **只作用于攻击伤害**：固定伤害、异常状态持续伤害、充能球等非攻击伤害不翻倍。
- **乘法阶段结算**：与力量、易伤、元素克制等乘区相乘，不是简单的加算。

## 小贴士

- **双刃剑姿态**：泰格尔攻击力翻倍，但受到的攻击伤害同样翻倍——是输出期也是破绽期。
- **非攻击伤害不受影响**：固定伤害、中毒/烧伤等持续伤害不受翻倍影响，可以安全输出。
