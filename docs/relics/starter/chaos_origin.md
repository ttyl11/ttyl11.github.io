# 混沌起源

<img src="/images/relics/chaos_origin.png" alt="混沌起源" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 初始

### 数值参数

| 参数 | 数值 |
|---|---|
| 堕落:最大生命转化 | 50:1 |

## 描述

在每场战斗开始时，获得[混沌](/powers/chaos_power.md)属性。
每回合开始时，每拥有[堕落](/powers/fallen_power.md)<span style="color:#3aa675;font-weight:600">50</span>，获得<span style="color:#3aa675;font-weight:600">1</span>点最大生命。

## 详细机制

- **战斗开始时获得混沌属性**：每场战斗开局自动获得[混沌](/powers/chaos_power.md)属性（克制 飞行/冰/神秘/次元/邪/自然/神圣系，被 电/机械/格斗/轮回/虚空系克制），全队生效，不需要靠卡牌补水。
- **每回合堕落→最大生命**：我方回合开始时，取当前[堕落](/powers/fallen_power.md)层数 ÷ <span style="color:#3aa675;font-weight:600">50</span>（向下取整）获得等量最大生命（堕落 50 层=+1、100 层=+2、……）。每次获得还会同时回复等量当前生命（增加最大生命默认会补上差额）。
- **堕落不清零，收益滚雪球**：[堕落](/powers/fallen_power.md)是索伦森的持久计数体系（每场战斗独立、不清零），所以一场战斗中消耗越大，这个遗物每回合喂的最大生命越多——是堕落体系的持续续航引擎。
- **先古升级**：被原版遗物「欧洛巴斯之触」升级后，变为先古版遗物[混沌魔君索伦森](/relics/legendary/chaos_demon_lord.md)。

## 小贴士

- **战斗开始即有混沌属性的稳定输出**：每场战斗自动挂[混沌](/powers/chaos_power.md)属性（克制飞行/冰/神秘/次元/邪/自然/神圣，被电/机械/格斗/轮回/虚空克制），等于免费拿到打大半敌人的属性优势，配合索伦森的各种混沌系卡牌效果稳定触发。
- **堕落越高，回血越猛**：堕落 50 层起步每回合 +1 最大生命，200 层就是每回合 +4 最大生命。但**堕落本身是负面**——层数越高，魔君接管触发越频繁，混沌化身扣掉的上限也多。这个遗物把堕落层数变成回上限的缓冲，等于给失控的机制兜底，是索伦森"被打又回、下限还在"的关键。
- **和魔君接管错峰**：魔君接管在堕落满 100 时强制乱打牌 + 扣上限，接管结束后堕落继续累积；这个遗物再把层数转回生命续航——一边失控扣血、一边自动回血，两者是同一条堕落曲线的一收一放，别只盯着回血忘了还有失控那一面。
- **性价比**：初始遗物白送属性 + 成长续航，配合堕落体系性价比极高；不玩堕落体系的构筑下它只提供混沌属性，收益缩水——所以本遗物与堕落卡组的绑定度很高。
