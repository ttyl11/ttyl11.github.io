## 基本信息

* **分类**: 非塔罗遗物

* **稀有度**: 商店

### 数值参数

| 参数   | 数值                   |
| ---- | -------------------- |
| 战斗间隔 | {CombatCount} 场      |
| 奖励   | 通用刻印激活水晶 ×1（+1 手牌上限） |

## 描述

每{CombatCount}场战斗后，打造一颗[通用刻印激活水晶](/relics/event/universal_engraving_gem_relic.md)。

## 风味文字

<span style="color:#d44;font-weight:600">星吉拉。</span>

## 小贴士

\*- **通用刻印激活水晶效果**：永久增加 1 点[手牌上限](/mechanics/hand.md)，可在任意刻印槽位使用，重复获取可叠加。

* **固定节奏触发**：每隔固定场数战斗自动触发，不受战斗结果影响（胜利或失败均可累积进度）。

* **商店稀有度定位**：稳定的手牌上限提升对后期手牌管理极有帮助，适合需要大量手牌支撑的Combo牌组。

* **与其他刻印遗物的搭配**：可与其它刻印类遗物叠加，逐步积累手牌上限优势。
