# 元素克制

Seer Mod 引入了赛尔号原版的元素克制系统。**26 种元素**构成完整的克制表，影响攻击伤害的最终结算。

::: tip 这是赛尔号的灵魂
如果你玩过赛尔号，这套元素克制关系你应该很熟悉——草克水、水克火、火克草……Seer Mod 完整还原了这套体系，让每场战斗都有"选对属性"的策略层。
:::

## 克制倍率

元素克制只影响**攻击伤害**的乘法结算，三种倍率：

| 关系 | 倍率 | 说明 |
| --- | --- | --- |
| 克制对方 | **×1.5** | 攻击伤害提升 50% |
| 被对方克制 | **×0.75** | 攻击伤害降低 25% |
| 中性 | **×1.0** | 无克制关系时不修正 |

::: warning 只影响攻击伤害
元素克制**只作用于攻击伤害**（卡牌/怪物招式造成的伤害）。以下伤害类型**不受元素克制影响**：

- 异常状态的持续伤害（中毒、烧伤、冻伤等回合结算伤害）
- 固定伤害
- 充能球伤害
- 荆棘、反伤等被动伤害
- 生命流失效果
:::

## 多属性合并（官方公式）

一只精灵可以拥有多个属性。多属性**不是各自直接相乘**，而是按赛尔号官方 n 属性公式合并。

**单属性打单属性**：直接查表。

**多属性打单属性 / 单属性打多属性**：把「多属性」那一侧拆成多个单属性，各查表得系数 x₁…xₙ，然后：

> **系数 = (x₁+…+xₙ) ÷ n × (1 + 克制系数重复个数) ÷ (1 + 无效系数个数)**

- 「克制系数重复个数」= **克制系数的个数 − 1**（不足 2 个克制则为 0）。
- Mod 把赛尔号原版的「无效(0)」并入了「微弱(0.75)」，属性表里没有 0 —— 所以「÷(1+无效个数)」这一项在 Mod 里**恒为 ÷1**。

**多属性打多属性**：**只拆防守方**（不能拆攻方）→ 分别算出「多打单」的系数 → 再取平均。

几个常用结果（Mod 系数）：

| 攻 → 守 | 算式 | 结果 |
| --- | --- | --- |
| 单属性克制 → 单属性 | 1.5 | **×1.5** |
| 双属性都克制 → 单属性 | (1.5+1.5)÷2×(1+1) | **×3** |
| 三属性都克制 → 单属性 | (1.5×3)÷3×(1+2) | **×4.5** |
| 四属性都克制 → 单属性 | (1.5×4)÷4×(1+3) | **×6** |
| 一克制一微弱 → 单属性 | (1.5+0.75)÷2×1 | **×1.125** |
| 双属性都克制 → 双属性 | 各算多打单再平均 | **×3** |

> 规律：**n 个属性全克制 = 1.5 × n**（赛尔号原版是 2 × n）。

结算只由「主属性」（元素类型序号最小者）执行一次，避免多属性重复叠乘；主属性选取在两台机器上一致。

## 属性分配机制

战斗开始时，没有元素属性的生物会被分配元素：

- **玩家**：若当前没有元素，从 26 种元素中随机获得 1 种
- **普通敌人**：同上，随机 1 种
- **固定属性怪物**：部分怪物在元素表中有预设属性（可以是多属性），不会参与随机
- 元素属性以"元素能力"形式存在，是**中性属性**（不是 Buff 也不是 Debuff），不会被消除 Buff/Debuff 类效果清除
- 玩家与敌方的随机都使用跑局同步随机流，多端结果一致

## 克制表查询

每个元素对应一个"元素能力"，该能力内置了对其它 25 种元素的克制倍率表。例如：

- **远古** 克制：草、飞行、神秘、龙、虚空（×1.5）
- **远古** 被克：机械、冰、王、轮回（×0.75）
- **虫** 克制：草、地面、战斗、混沌、虫（×1.5）
- **虫** 被克：水、火、冰、光（×0.75）

完整的 26×26 克制表可在游戏内通过元素能力的悬浮提示查看，或参考赛尔号原版克制关系。

## 战略意义

- **选对属性打**：克制时伤害 ×1.5，是重要的输出提升手段
- **避开被克目标**：被克时伤害 ×0.75，相当于浪费了 1/4 伤害
- **龙系是双刃剑**：龙系攻击方克冰/龙/圣灵/邪灵（×1.5），但被草/水/火/电/远古/虫克（×0.75，与其它元素同档）——六个弱点里草/水/火/电都很常见，龙化前先看敌方属性构成
- **元素是随机的**：每场战斗的元素分配不同，需要根据当局属性调整策略

## 局外宝库与怪物能力配置

群星的礼赠的右键宝库和对应的怪物能力配置详见 [遗物右键点击](./relic-right-click)。宝库稀有度只影响每场战斗的自身增伤/减伤或敌人减伤（按幕查表）；怪物额外能力（强体/侵蚀/城守/吸血/复活等 62 种）的概率随探索房间数累积，与宝库选择无关。
