# 刻印图鉴（284 项）

刻印是 Seer Mod 的**局内**成长体系：每条刻印都带有一个**试炼**条件，达成后立即**赐予**对应奖励，并消耗 1 次可用次数。刻印按角数分为五类。

## 系统规则

- **栏位**：同时最多装备 3 条刻印。只能在**战斗外**更换，战斗中无法装卸。
- **背包**：容量 999，按拥有的刻印总数计算；同一条刻印可以重复拥有，每个个体各自独立计算试炼进度与剩余次数。
- **试炼**：只有**已装备且未耗尽**的刻印才会推进试炼。达成条件后立即结算赐予，试炼进度清零、次数 -1；次数耗尽后显示「已耗尽」，不再推进也不再触发。
- **记录保留**：拥有、装备栏位、试炼进度与剩余次数在本局内保留（卸下期间进度不清零），跑局结束后清空，不跨局继承。

## 角数

- **二角**：单场战斗或单回合内达成。
- **三角**：战斗外累计达成。
- **四角**：战斗外单次达成。
- **五角**：全局累计达成（跨战斗不清零）。
- **特殊**：在特定时点判定（如死亡、进入房间、生命变化、牌组或资源变化等）。

> 下表的「试炼」「赐予」文案与游戏内悬浮提示一致；「次数」为该刻印整局可触发的总次数。
