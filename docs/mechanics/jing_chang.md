# 净场（JingChang）

**净场**是 Seer Mod 的自定义卡牌关键词，打出后清除双方所有[增益](/mechanics/bound.md)和[减益](/mechanics/abnormal-status.md)。

## 基本信息

| 项目 | 说明 |
| --- | --- |
| 类型 | Mod 卡牌关键词（清除型） |
| 效果 | 清除双方所有增益和减益 |
| 适用 | 卡面缩写术语 |

## 规则说明

- **清除范围**：双方（自身与所有对手）身上的全部增益（力量/命中/防御/速度等 Positive）与减益（异常状态、负属性等 Debuff）
- 一次性拉平战场：对方的高增幅、己方的重减益同时消失
- 注意：净场清增益也清减益，用在己方优势期会自损，谨慎使用
