# 🍖 香酥豚排

## 基本信息

- **分类**: 恢复
- **稀有度**: 普通
- **使用时机**: 战斗内
- **目标**: 自身

### 数值参数

| 参数 | 数值 |
|---|---|
| 回复量 | 当前生命 × <span style="color:#3aa675;font-weight:600">50%</span>（不超过最大生命） |
| 目标 | 自身 |

## 描述

回复当前<span style="color:#3aa675;font-weight:600">已有生命值</span>的<span style="color:#3aa675;font-weight:600">50%</span>。

## 详细机制

- **按当前而非最大**：回复量 = 使用瞬间的**当前生命** × 50%，与最大生命无关；超过最大生命的溢出部分会被封顶（`CreatureCmd.Heal` 内部 `Math.Min(amount, MaxHp - CurrentHp)`）。
- **滚雪球式抬血**：血量越高单瓶加得越多，因此连续空喝呈等比放大逐步逼近上限。
- **封顶浪费**：仅当当前血 ≤ 最大生命的 2/3 时才不会被封顶截断，超过 2/3 后仍按最大回复量截断。
- **战斗内使用**：属于战斗使用类，需在战斗中打出。

以最大生命 100 为例的实际数值：

| 使用当前血 | 回复量 | 使用后 |
|---|---|---|
| 20 | +10 | 30 |
| 40 | +20 | 60 |
| 60 | +30 | 90 |
| 66.6 | +33.3 | ≈100（满） |
| 80 | +40（封顶 +20） | 100（满） |
| 95 | +47.5（封顶 +5） | 100（满） |

## 小贴士

- **最反直觉的一点**：它和其他"回复最大生命百分比"的药水相反——**血越满这瓶越厚，残血反而加得最少**。残血 20% 时一瓶只补 10%，救不了命；而在 2/3 血时一瓶能补将近 33% 最大生命（约等于三瓶 10% 血瓶）。别把它当残血救命药，它更适合"稳住高血线"。
- **最优切入点约在 2/3 血**：从表格可见，一旦超过 66% 血就触碰上限开始浪费；想榨干单瓶价值，在约 2/3 血时一次补满收益最高。
- **连续使用呈 1.5 倍放大**：若在低血连续两瓶，等价于 `0.5 → 0.75 → ≈满`，等比回升，适合把团战中途掉下来的血迅速抬回去。
- **定位是"稳血线 + 续战"**：适合配合高额格挡/减伤在战斗中期持续把血线维持在安全区，而非紧急大回血，主治疗请交给固定数值大招。
- **性价比**：普通稀有度就能拿到"按现有生命一半"的稳定回复，随属性血条越厚越赚，是长线成长型回血。
