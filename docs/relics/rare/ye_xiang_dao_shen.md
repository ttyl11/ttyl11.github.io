# 夜香刀神

<img src="/images/relics/ye_xiang_dao_shen.png" alt="夜香刀神" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物

- **稀有度**: 稀有

## 描述

你打出技能牌时，向手牌中加入一张<span style="color:#3aa675;font-weight:600">小刀+</span>。

- **触发条件**：仅自身打出的[<span style="color:#d4a017;font-weight:600">技能牌</span>](/mechanics/hand.md)触发，每张技能牌加入 1 张小刀+。

- **小刀+**：小刀的升级版，伤害更高，是一张 0 费攻击牌。

## 风味文字

<span style="color:#d44;font-weight:600">夜香缭绕，刀光微凉。</span>

## 小贴士

- **技能牌是"产刀机"**：每打出一张技能牌就 +1 张小刀+ 入手牌，配合多段技能、连发的低费技能牌，一回合就能攒出一手小刀。小刀+是 0 费攻击牌，等于把"打技能"的节奏直接转成"白嫖输出"。

- **核心是"技能复用"而非"技能数量"**：真正赚的是那些能让你**多次打出技能牌**的手段——回响、复制、自动打出技能等，把一张技能牌变成好几张小刀+，量变产生质变。

- **喂给小刀流派的弹药**：小刀+天然契合"以刀计数"的输出路线。只要你的 Build 里存在按手牌/牌堆小刀数量结算伤害、或强化小刀本身的机制，这件遗物就是源源不断的弹药库——它本身不提供终结能力，但把技能频率越滚越厚。

- **别忽略小刀+的耗能**：小刀+本身 0 费，但一张张"加到手上"会占满手牌上限，手牌溢出会烧掉你原本想留的牌。铺场前还是要算好手牌空间，别把小刀当纯白嫖。

- **性价比**：稀有遗物，用"每张技能牌 → 1 张小刀+"把技能频率转化为稳定输出，配合技能流和小刀体系收益成倍放大，是很值的一件"增量"遗物。
