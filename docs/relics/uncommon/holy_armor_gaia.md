# 圣甲盖亚

<img src="/images/relics/holy_armor_gaia.png" alt="圣甲盖亚" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 罕见

## 描述

每次受到未被格挡的伤害后，反弹等量的<span style="color:#d4a017;font-weight:600">不可格挡伤害</span>给攻击者，自身<span style="color:#d44;font-weight:600">[堕落](/powers/fallen_power.md)</span>等量。

- **反弹伤害**：受到伤害后，当目标为拥有者且未格挡伤害大于 0 时，对伤害来源（存活且非自身）造成等量反弹伤害。
- **反弹伤害不可格挡**：反弹的是等量的**不可格挡伤害**（代码 `ValueProp.Unblockable | ValueProp.Unpowered`）——敌人的格挡无法拦截反弹，且不受力量影响。
- **反弹后获等量堕落**：每次反弹伤害结算后，自身获得与反弹量相等的[堕落](/powers/fallen_power.md)。堕落是**负面层数**——反弹越多堕落越快，被多段攻击、高额伤害打中时一次反弹就能积累可观层数；层数逼近 100 就会被[魔君接管](/powers/demon_takeover_power.md)失控，堆堕落时心里要有数。

## 小贴士

- **反弹量 = 实际掉血量**：反弹的是你**未被格挡**的部分——掉多少血就弹回去多少。格挡越多反弹越少，完全格挡不触发，叠甲流和它的相性天然紧张：要么偏格挡保命、要么偏裸奔换输出。
- **多段攻击每段都弹**：多段攻击的每一段只要未被格挡就独立触发一次反弹。敌人一次 5 段攻击全裸吃，等于把整段伤害原样奉还。
- **反弹可以打断多段攻击**：反弹发生在每一段命中结算之后——若反弹伤害当场击杀攻击者，多段攻击的后续段数直接作废。对残血的多段攻击敌人，第一段就能让它闭嘴。
- **不弹自伤、不弹无来源伤害**：自伤（伤害来源是自己）不触发；烧伤这类无来源的持续伤害也不触发。反弹对象必须是"活着且不是你自己"的伤害来源。
- **反弹伤害不可被格挡拦截**：反弹是**不可格挡**的伤害（代码 `ValueProp.Unblockable`）——敌人的格挡完全拦不住反弹，掉多少血就全额弹回去多少，是敌人的硬性损失。
- **反弹不会无限循环**：反弹本身带防递归保护，且反弹属于非攻击伤害——敌人若有同类反伤遗物也不会互相弹到天荒地老。
- **堕落与反弹同步累积**：每次反弹同时给自身叠加等量堕落——面对高伤、多段攻击敌人时，一次回合就能攒下两位数堕落。**但堕落是负面**：层数逼近 100 会触发[魔君接管](/powers/demon_takeover_power.md)（当回合失控自动打牌），反弹流叠堕落要留意别在关键回合把它推破百。
