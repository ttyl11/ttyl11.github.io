## 被动能力

**雷雨天**：由 3 个不可消除能力（雷雨天、暴击、锁定II）加闪电充能球计数器共同实现。

- **雷雨天**：自身攻击必定暴击；每次造成伤害（含自伤）后，闪电充能球 +1。充能球造成的伤害不会再生成新球。
- **暴击**：暴击伤害 ×<span style="color:#3aa675;font-weight:600">1.5</span>。
- **锁定II**：自身暴击率固定为 <span style="color:#3aa675;font-weight:600">100%</span>。
- **闪电充能球**：开局 0 层，最多 <span style="color:#3aa675;font-weight:600">2</span> 个槽位；每次造成伤害 +1 球，满槽再生成先激发最旧的球（<span style="color:#3aa675;font-weight:600">8</span> 点伤害）；使用雷祭时生成本场累计生成数量的球，每球 <span style="color:#3aa675;font-weight:600">8</span> 点伤害，生成后累计数量翻倍。
- **球的被动**：自身回合结束时，每个球对随机敌人造成 <span style="color:#3aa675;font-weight:600">3</span> 点伤害（非攻击伤害，不触发暴击，也不会生成新球）。

## 策略提示

1. **血量更高会改变爆发阈值**：本体雷伊是 140~143 血的速杀目标，这里固定为 236~246，约为本体血量的 1.7 倍，原本一回合能收掉的血线现在收不掉。按「接近 1.7 管本体血」重新规划爆发。

2. **招式不变，威胁密度不变**：它仍然是 4 招等概率随机，不会因为血量更高多出新机制。难点是战斗轮次变长，随机到高伤招式的次数变多。

3. **子地图没有死亡惩罚**：子地图内玩家生命归零不会真正死亡，会恢复并退出子地图；但打空这场的收益只是活动进度，不值得为它交掉关键药水/遗物。

4. **活动奖励才是目标**：幽暗之证的核心产出是通关活动后的史诗/传说遗物，这场只是路障。能稳过即可，不必追求无伤。
