# 盖亚

<img src="/images/relics/seer_gaiya.png" alt="盖亚" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物

- **稀有度**: 普通

## 描述

对<span style="color:#d4a017;font-weight:600">[意图](/mechanics/intent.md)有攻击</span>的敌人造成伤害时，该伤害提升<span style="color:#3aa675;font-weight:600">20%</span>。

- **按意图加成**：当你想攻击的目标，它头顶当前[意图](/mechanics/intent.md)里包含**攻击**意图时，你对该目标造成的伤害提升 <span style="color:#3aa675;font-weight:600">20%</span>。
- **判断的是"要打你的目标"**：只有目标当前"打算攻击"才吃到加成；目标本回合是防御、加益、放状态等非攻击意图时，对该目标的伤害**不提升**。
- **乘区增伤**：这是伤害**乘区**的放大（+20%），与你自身力量、增伤减伤等在各自独立的乘区，可叠加相乘。

## 机制说明

- **攻击意图判定**（[意图](/mechanics/intent.md)）：读目标怪物的"下一行动"意图列表，只要其中包含**攻击类意图**（`AttackIntent`）即视为"意图有攻击"。若目标当前被控制/眩晕、意图尚未设定，或当前是纯防御/增益意图，则不触发。
- **结算同步**：该判定不消耗随机种子、不依赖回合数，伤害预览与实际结算读的是同一个（目标当前）意图，因此显示与造成一致，多人下也稳定。
- **作用范围**：只作用于"你"造成的伤害（dealer 是持有者本人）；队友或其它来源造成的伤害不受影响。

## 小贴士

- **他打你，你打得更疼**：盖亚的收益完全由敌人意图驱动——会主动攻击你的敌人，就是你的首要输出对象。面对**多攻击怪**（好几只都亮着攻击意图）的波次，这件普通遗物等于全场 +20% 输出，性价比很高。

- **白给的低风险增伤**：作为普通稀有度却大多时候有效，因为绝大多数回合绝大多数敌人都在攻击。唯一"空档"是对方这回合在叠甲/上增益/放状态——这时尽量补一些不依赖盖亚的伤害来源即可。

- **和"先制/抢先"天然契合**：因为你输出加成只针对"当前正打算攻击"的敌人，越快行动（先制）越能在对方换到非攻击意图前，把爆发打在有加成的那回合。

- **叠加与成长**：它和攻击附带的增伤（力量、易伤、各种增伤%）相乘，配合同套叠加能滚出明显的高爆发；配合能频繁让敌人锁定攻击的阵容或嘲讽类控场收益更稳。

- **性价比**：普通。用"敌人正打算攻击"这一恒常条件换一个稳定乘区增伤，几乎常驻生效，是普通稀有度里相当扎实的一件。
