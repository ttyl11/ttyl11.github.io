# 遗歌彻夜

> **归属**：怪物专属（[冥契·格斯塔丝](/monsters/boss/mingqi_gesitasi_monster.md)）
> **类型**：中性（None，不可被消除）
> **叠加方式**：计数（图标数字 = 本场死亡数，不参与层数结算）
> **可见**：是

## 描述

①每次有生物死亡时，层数+1。<br/>②友军死亡时，其承受的致死溢出伤害的<span style="color:#3aa675;font-weight:600">100%</span>转移给敌人。每次转移后，该比例+<span style="color:#3aa675;font-weight:600">100%</span>。

## 详细机制

- **死亡计数**：任何生物死亡都会让图标数字 +1；被免死、复活拦截的死亡同样计入，且敌我双方都算。该数字是整场战斗的累计值，不会随回合或能力消失清零。
- **计数的用途**：技能 4「染夜天妖」读取该数字，作为束缚层数、随机异常种数/层数、四维下降量。
- **转移对象**：除玩家角色外，任何生物（含双方召唤物）死亡时，若本次致死伤害有溢出，就触发转移；玩家角色死亡或持有者自身死亡不转移。
- **溢出伤害**：本次伤害超出死者剩余生命的部分，转移量按比例向下取整。
- **转移目标**：若击杀者是存活的玩家，只转移给该玩家；否则转移给持有者的所有存活敌人，且每个目标各承受全额，不分摊。
- **转移伤害**：不可格挡、无视伤害加成与减伤的生命流失。
- **比例递增**：初始 100%；每次至少对 1 个目标完成转移后 +100%。没有溢出、没有存活目标或转移量为 0 时不递增。
- **能力保留**：持有者死亡后此能力不会随之移除，死亡计数仍会继续累加（但不再转移伤害）。
