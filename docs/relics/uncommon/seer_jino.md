# 杰诺

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 罕见

## 描述

①第 1 回合开始时，随机降低 <span style="color:#3aa675;font-weight:600">5</span> 张你已升级的牌，并升级其它所有可升级的牌（**仅本场战斗临时生效**，战斗结束后还原）。<br/>②每升级 <span style="color:#3aa675;font-weight:600">1</span> 张牌，<span style="color:#d44;font-weight:600">[堕落](/powers/fallen_power.md)</span><span style="color:#3aa675;font-weight:600">2</span>。

- **临时生效**：只作用于本场战斗的牌，不会改变永久牌组——降级和升级在战斗结束时全部还原。
- **只降 5 张**：从你已升级的牌里随机挑至多 <span style="color:#3aa675;font-weight:600">5</span> 张打回原形；若升级牌不足 <span style="color:#3aa675;font-weight:600">5</span> 张则全部降级。
- **升级其余**：除被降的这 <span style="color:#3aa675;font-weight:600">5</span> 张外，所有可升级的牌全部升级。
- **每升级堕落**：本场被升级的牌每 1 张 = 堕落 <span style="color:#3aa675;font-weight:600">2</span> 层，触发一次（第 1 回合开始时整体结算，按升级总张数计算）。

## 小贴士

- **净赚的"临时洗牌"**：每场战斗最多只降 5 张升级牌，却能把其余全部可升级牌升满。只要你升级牌多于 5 张，这一降一升就是白赚的净提升——套着永久牌组去打，每场都是"全牌 +"的战力。

- **被降的那 5 张是随机牺牲品，别慌**：降级随机点名，可能恰好点到你最依赖的 Key 牌，但只是本场临时，战后还原。被点名就少打它那一张，其它照常。

- **②堕落是这套"临时爆发"的价码**：升级张数越多，堕落越多——大牌组升满 20+ 张就得背 40+ 层。堕落是**负面层数**，满 <span style="color:#3aa675;font-weight:600">100</span> 会被[魔君接管](/powers/demon_takeover_power.md)当回合失控自动打牌（附带抽 1 与混沌化身补偿）。堕落流（如索伦森）可以把这份负面当免费进度；常规构筑则要留意，别让"每场白升一堆牌"变成"每场白捡几十层负面"。

- **是"单场爆发器"，不是"成长器"**：临时提升不改变永久牌组构成，所以它优化的是你**每场的即时战力**，而不是越滚越强的长期成长。升级收益大的技能/能力牌组最爽——这类牌升级后功能往往翻倍，被升满的爆发最明显。

- **升级牌越多越稳赚**：你的升级牌数量越大于 5，被牺牲的数量占比越低、白赚升级的卡越多。若牌组升级牌 ≤5 张，这 ≤5 张会被全部降级，其余可升级牌照常升级；只有 0 张升级牌时才无牌可降。

- **性价比**：罕见遗物，用"每场降至多 5 张 + 一点堕落"的代价，换"其余全部升级"的临时爆发，配合高升级收益的牌组极强。
