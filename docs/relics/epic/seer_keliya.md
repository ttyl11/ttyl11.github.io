# 愈灵·克丽娅

<img src="/images/relics/seer_keliya.png" alt="愈灵·克丽娅" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 史诗

### 数值参数

| 参数 | 数值 |
|---|---|
| 初始复活概率 | 100% |
| 复活后概率变化 | 减半（100%→50%→25%→12.5%…） |
| 概率下限 | 1% |
| 复活后生命 | 满血（最大生命值） |

## 描述

自身[死亡](/powers/demise_power.md)时，以<span style="color:#3aa675;font-weight:600">100%</span>概率满血复活一次（初始概率，成功复活后减半）。成功复活后，下次死亡复活概率减半。<br/>
当前复活概率：<span style="color:#3aa675;font-weight:600">100%</span>（随成功复活次数减半）

## 风味文字

<span style="color:#d44;font-weight:600">愈灵·克丽娅。</span>

## 详细机制

- **全局累计复活次数**：`ReviveCount` 是持久化计数，**跨战斗累计**——上一场用掉的复活会降低今后所有战斗的复活概率。首次死亡 100% 必活，成功复活一次后变 50%，再成功变 25%… 依次减半，**下限 1%**（不再归零）。
- **概率动态显示**：遗物面板上的当前复活概率会随 `ReviveCount` 实时刷新——你当前还剩多少概率复活，看到的就是多少，含下方"当前复活概率"一行。
- **战斗开始时挂上复活拦截**：`BeforeCombatStart` 为自身施加隐藏的 `SeerKeliyaRevivePower`（单层、不可见）。之后每次死亡都经它判定。
- **判定方式**：死亡时掷骰 `Rng.Niche.NextInt(0,100)`，结果落在 `[0, 概率)` 内即复活（概率=100 时必中）。随机源用同步 RNG，多人对战表现一致。
- **成功→满血复活并减记**：判定通过则在死亡结算前拦截（`ShouldDieLate` 返回假），随后 `AfterPreventingDeath` 把生命回满，`ReviveCount+1` 并刷新概率。
- **失败→放行死亡**：判定未通过时正常死亡，不会因为遗物反复拦截最后一只生物而卡死。
- **每场战斗只依赖当前概率，不限制局内次数**：只要概率还在，一场里可以多次复活（每次成功都让下次概率减半）。

## 小贴士

- **第一条命近乎白送**：首次 100% 必活等于拿到它当回合就多出一条命——高压 Boss 前务必把这条"必活"留给最危险的一次死亡，而不是在杂鱼战提前浪费掉（一旦消耗，后续复活概率直接砍半）。
- **复活优先级高但非无脑强**：每次成功复活后概率减半，这条命会越用越不可靠——它奖励的是"出其不意多活一次"，而不是"无限苟命"。真正靠它赢的场面通常是：关键节点用掉那条 100% 必活，或赌一手 50%。后期概率低于 25% 后基本只能当"万一"看待。
- **与各类免死/复活的配合顺序**：克丽娅在自己的死亡结算处拦截，先于其他"防止死亡"的 Power 生效与否取决于登记时机；多条命资源叠乘时，一般都建议把克丽娅的必活留到最后关头的真实死亡，先消费更常见的复活/免死来源。
- **抢血线的启发**：因为复活会把生命回满，残血时反而更愿意放手输出/卖血换资源——反正死了能满状态站回来。但别指望它当常驻免伤，概率衰减后风险陡增。
- **性价比**：史诗稀有度合理——整体是"一次稳定复活 + 若干次递减复活"的高上限保命件，长局价值大于短局，但同样存在概率越滚越低的手感衰减。
