# 🌀 混乱药水

## 基本信息

- **分类**: 异常状态
- **稀有度**: 普通
- **使用时机**: 战斗内
- **目标**: 全体敌人

### 数值参数

| 参数 | 数值 |
|---|---|
| 异常状态种类数 | 3 |
| 持续回合数 | 3 |

## 描述

对所有敌人施加<span style="color:#3aa675;font-weight:600">3</span>种随机[异常状态](/mechanics/abnormal-status.md)，各持续<span style="color:#3aa675;font-weight:600">3</span>回合。

## 详细机制

- **随机选取**：从 25 种[异常状态](/mechanics/abnormal-status.md)中随机选 3 种，多人模式两端结果一致。
- **目标范围**：对所有敌人逐一施加这 3 种异常状态。
- **持续回合**：每种异常状态持续 3 回合。
- **每种异常对所有敌人生效**：选出的 3 种异常对每个敌人都施加，即每个敌人同时中 3 种异常 3 回合。
## 小贴士

- **随机性强**：3 种异常完全随机，可能抽到强力异常（如[石化](/powers/petrify_power.md)）也可能抽到一般的，收益不稳定。
- **群体多异常压制**：每个敌人同时中 3 种异常，配合[焚天](burn_sky_potion.md)可形成异常状态爆发。
- **多人模式两端一致**：所有玩家的随机结果相同，意味着不会出现某玩家拿到好异常而另一玩家拿到差异常的尴尬。
- **预期管理**：不要指望每次都能抽到理想组合，把它当作一种"可能性"工具而非稳定手段；抽出石化是惊喜，抽不出是常态。
- **3 回合不算短**：每种异常持续 3 回合，即使抽到一般的异常（如中毒、减速）也能提供一定的战术价值。
