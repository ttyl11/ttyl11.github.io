# 余罪魔女

<img src="/images/relics/seer_crime_witch.png" alt="余罪魔女" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物

- **稀有度**: 传说

## 描述

战斗结束的[<span style="color:#d4a017;font-weight:600">卡牌奖励</span>](/mechanics/game-flow.md)张数固定为<span style="color:#3aa675;font-weight:600">7</span>。每场战斗后，额外获得一次[<span style="color:#d4a017;font-weight:600">稀有卡牌奖励</span>](/mechanics/custom-rarity.md)。卡牌奖励界面额外出现「余罪」选项：放弃本次卡牌选择，随机获得七罪之一的效果（无负面、可无限次）。每并入<span style="color:#3aa675;font-weight:600">1</span>个七罪，每次随机触发<span style="color:#3aa675;font-weight:600">1</span>个效果（即触发数量 = 已并入七罪数）。每回合开始时，获得<span style="color:#3aa675;font-weight:600">7</span>层<span style="color:#d44;font-weight:600">[堕落](/powers/fallen_power.md)</span>。

## 风味文字

<span style="color:#d44;font-weight:600">七罪归一，唯余罪独存。</span>

## 获得方式：七罪合成

余罪魔女不能直接通过卡池掉落（稀有度为自定义"传说"），只能由七罪遗物合成而来：

- **拥有任意 2 个七罪**时，**自动合成**：移除这些七罪遗物，获得余罪魔女。

- **已持有余罪魔女**时，再获得任意七罪，该七罪会**自动并入**余罪魔女（移除该七罪，已并入数 +1）。

- 遗物角标显示的"已并入数"，就是「余罪」每次随机触发的效果个数：并入 <span style="color:#3aa675;font-weight:600">1</span> 个抽 <span style="color:#3aa675;font-weight:600">1</span>、并入 <span style="color:#3aa675;font-weight:600">3</span> 个抽 <span style="color:#3aa675;font-weight:600">3</span>、最多抽 <span style="color:#3aa675;font-weight:600">7</span> 个（七罪不重复，各至多触发一次）。

## 机制说明

- **卡牌奖励固定 7 张**：所有卡牌奖励（战斗奖励、额外稀有奖励、事件奖励）张数统一固定为 7，不再随默认数量走。

- **每场战斗后追加稀有奖励**：战斗结束后，在原本奖励之外**再追加一波稀有卡牌奖励**（同样固定 7 张，同样带「余罪」按钮）。

- **「余罪」按钮**：在任何卡牌奖励界面出现。点击即放弃本次选牌，并**随机获得七罪之一的效果**——效果来自下方七罪的"无负面版"，可无限次使用。

- **随机效果 = 已并入数**：每次点击会从七罪里**不重复**地随机抽取「并入数」个效果并全部触发。并入越多，一次点出越多效果。

- **每回合堕落 7**：自身回合开始时获得 7 层[堕落](/powers/fallen_power.md)（每场战斗独立计数）。堕落满 100 层倍数会触发混沌化身（抽 1 张 + 魔君接管自动打牌），长战斗中会自动滚出连锁收益。

- **新局清零计数**：「余罪」抽到各罪多少次会显示在悬浮框里，用于回溯这次随机到了什么；进入新的一局自动清零。

|---|---|---|
| ① | 傲慢 | 本次奖励的一批复选牌，本局不再出现于任何卡池 |
| ② | 嫉妒 | 触发一次其它角色稀有牌池的五选一奖励 |
| ③ | 愤怒 | 向牌组中加入 1 张附魔「迅捷1」的愤怒 |
| ④ | 暴食 | 获得 4 点最大生命 |
| ⑤ | 贪婪 | 获得 3 点泰坦之灵 |
| ⑥ | 色欲 | 累计魅惑 +1（每场战斗中自身第一个回合开始时对所有敌人施放，每层 5%） |

## 小贴士

- **传说级资源制造机**：并入越多，每次「余罪」触发越多效果——一口气可能加血 + 得泰坦之灵 + 拿稀有牌 + 叠魅惑，是极稀有的"多点收益"遗物。并入 2 个就抽 2、并入 7 个直接一次拉满。

- **稀有奖励翻倍**：固定 7 张 + 每场额外一波稀有奖励，前期平滑、后期能持续补强稀有牌——等于战斗奖励的门槛被大幅抬升。

- **并入策略很重要**：想要更多随机效果，就优先凑 7 个七罪让它们全部并入余罪魔女；只并入 1~2 个时，每次只触发 1~2 个效果，收益虽是纯正向但单次不爆炸。

- **"余罪"是无限免洗牌的方向盘**：因为可无限次用、且无负面，卡牌奖励来牌不顺时点一下就能把它"洗"成若干资源，属于"永不亏"的保底出口。

- **效果也是七罪的纯净版**：余罪抽到的傲慢不再背诅咒、愤怒不加累赘牌等等——每一条都是去负面的正面效果，随便抽都不亏。

- **抢先手建优势**：每场开战先靠固定 7 张和额外稀有奖励把卡池喂肥，再用余罪滚资源，中后期卡组厚度和资源密度都远超无魔女的对局。

- **注意与傲慢排除的差异**：余罪会排除当批复选牌，若你正想在奖励里锁定某张牌，先拿到手再点，避免误排。

- **每回合 7 层堕落是白送的联动资源**：即便不玩索伦森角色，拿到余罪魔女后每回合白得 7 层[堕落](/powers/fallen_power.md)——长战斗自动往 100 层里程碑滚，满 100 层触发一次混沌化身（抽 1 张牌 + 魔君接管自动打牌）；配合[混沌起源](/relics/starter/chaos_origin.md)（每 50 堕落 +1 最大生命）、[万魔天尊](/relics/rare/wan_mo_tian_zun.md)（每场战斗开始堕落 X）等堕落体系收益还能持续变现。

- **多人协作**：在多人中，固定 7 张 + 多波稀有奖励会让自身成长明显更快，可作为团队的主力输出/资源位。

## 扩展·机制说明（补充）

- 角标"已并入数"即每次随机触发的效果数（`max(1, 已并入)`，上限 7，七罪不重复、各至多触发一次）。

- 熔入的七罪会被移除并计数，再获得七罪也并入；已并入数持续累加。

- 七罪效果一览在该遗物的悬浮框中也会实时列出（含本次「余罪」随机到各罪的触发次数），方便你回溯每次随机到了什么；新开一局自动清零。
