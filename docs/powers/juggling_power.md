# 杂耍

<img src="/images/powers/juggling_power.png" alt="杂耍" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **归属**：玩家能力（原版）
- **类型**：增益
- **叠加**：计数型（层数 = 复制张数）
- **施加来源**：原版卡牌「杂耍」；[恶魔男爵](/relics/uncommon/demon_baron.md)（战斗开始时获得 1 层）

## 描述

每回合打出第 <span style="color:#3aa675;font-weight:600">3</span> 张**攻击牌**时，将等同于层数的该牌复制加入手牌。

## 详细机制

- 只统计**攻击牌**，技能牌、能力牌、状态牌不计入。
- 触发点是本回合**恰好第 3 张**攻击牌；第 6、9 张不会再次触发。想多次触发需要重新获得这个能力或提高层数（层数只增加复制张数，不增加触发次数）。
- 复制的是刚打出的那张牌的克隆，加入手牌，可以再次打出。
- 获得能力时会先统计本回合**已经打出**的攻击牌数量，所以中途获得不会白送一次触发。
- 计数在拥有者回合结束时清零。
