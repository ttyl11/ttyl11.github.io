# 隐匿炸弹

<img src="/images/cards/hidden_bomb.png" alt="隐匿炸弹" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 诅咒牌
- **能量消耗**: 1
- **类型**: 诅咒
- **稀有度**: 诅咒
- **目标**: 自身
- **关键词**: [薇](/mechanics/vigil.md)
- **可升级**: 否

## 描述

失去 3 点最大生命值，10 点生命值。

## 详细机制

- **薇**：非「薇」的相邻牌被打出时，此牌自动打出。也就是说它会在你打相邻牌时被动触发，逼你承受代价。
- **双重代价**：失去 <span style="color:#3aa675;font-weight:600">3</span> 点**最大生命值**（永久）与 <span style="color:#3aa675;font-weight:600">10</span> 点生命值（不可格挡的非攻击伤害）。
- **主动打出**：也可以花 1 费主动打出，触发同样的代价后离场（进弃牌堆，不是消耗），避免继续被薇连锁；但它之后还可能被洗回来。
- **主要来源**：[王牌术师](/monsters/elite/ace_magician_monster.md)的「帽子戏法」在战斗中向你的抽牌堆、手牌、弃牌堆、消耗堆各塞入 5 张（每人共 20 张）。这些是战斗内生成的临时牌，战斗结束后不会留在牌组里。

## 小贴士

- **它是持续扣上限的诅咒**：每次触发都永久少 3 点最大生命，拖得越久血越短；早处理早止损。
- **薇会强制触发**：把它放在手牌边缘（不与常用牌相邻）可以减少被动触发；但手牌位置不可控时，主动 1 费打掉更省心。
- **残血时可能直接暴毙**：10 点不可格挡伤害在低血量时很致命，触发前先确认血线。
- **别把它当纯废牌**：它的代价是双重的，但打出后能离开手牌、暂时摆脱薇；比起留在手里反复被薇触发，主动处理通常更划算。真正的解脱是打完这场战斗——临时炸弹不会带出战斗。
