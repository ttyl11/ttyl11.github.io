# 牙齿陷阱

> **归属**：玩家可施加
> **施加来源**：[牙齿陷阱](/potions/tooth_trap_potion.md)（药水——使用后获得）

## 基本信息

- **类型**: 增益（Buff）
- **叠加方式**: 单例（Single，层数固定为 1，不叠加）
- **可见**: 是
- **来源**: mod 能力

## 描述

本回合内，当自身受到伤害时，给予所有敌人等量[固定伤害](/mechanics/fixed-damage.md)。下个回合开始时移除。

## 详细机制

- **生效窗口**：打出后覆盖**整个当前回合**——我方回合 + 敌方回合，直到**我方下个回合开始时**移除。敌方回合受到的攻击同样计入。
- **触发条件**：仅当持有者**实际失去生命**时触发——即伤害穿过格挡、无实体后实扣的血。被格挡完全吸收、被无实体躲掉的伤害一律不算。
- **反伤形式**：对每个**可命中敌人**施加等量[固定伤害](/mechanics/fixed-damage.md)，**不是即时直伤**——由该能力在敌人回合开始自行结算。
- **全体结算**：多个敌人各吃一份**完整等量**的反伤，是标准的 AOE 反伤。
- **不叠加**：单例能力，层数固定 1，重复使用只刷新持续窗口。

## 小贴士

- **反伤量 = 实际掉血量**：有格挡反而反得少——想打满就"少开格挡、放心挨打"，把自身当血包（配合减伤 / 自回复更佳）。
- **打群怪收益爆炸**：每中一下伤害都对全体敌人各反一份等量固定伤害，三只怪时一次被砍 20 血 = 对三只各反 20（合计 60）。
- **固定伤害穿透格挡**：反出去的是固定伤害，无视敌人格挡，对付高甲前排怪尤其好用。
- **空转风险**：若该回合敌人不打你、或全被格挡 / 无实体躲掉，整瓶白开——用前先确认这轮必定实打掉血。
- **与[牙齿陷阱](/potions/tooth_trap_potion.md)药水页一致**：药水描述只写了"本回合受到伤害时"，实际窗口覆盖到我方下个回合开始，敌方回合也算在内。
