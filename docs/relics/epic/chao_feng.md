# 嘲风

<img src="/images/relics/chao_feng.png" alt="嘲风" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 史诗

### 数值参数

| 参数 | 数值 |
|---|---|
| 每次获得风龙结 | 手牌上限个 |
| 风龙结上限 | 100 |
| 风龙结增伤 | 每 1 个 +1% |
| 解除阈值 | 风龙结 > 50 |
| 龙属性永久减伤 | 50%（每场仅一次） |

## 描述

①受到[异常状态](/powers/debuff_immune_power.md)时，获得<span style="color:#3aa675;font-weight:600">手牌上限</span>个[风龙结](/powers/wind_dragon_knot_power.md)。②[风龙结](/powers/wind_dragon_knot_power.md)大于 <span style="color:#3aa675;font-weight:600">50</span> 时，解除自身所有[异常状态](/powers/debuff_immune_power.md)。

## 详细机制

- **"异常状态"是那 24 种**：触发条件是[异常状态列表](/powers/debuff_immune_power.md)中的状态（睡眠/定身/烧伤/冰冻/中毒/流血/冻伤/恐惧/麻痹/沉默/虚弱/狂暴/束缚/沸腾/石化/感染/超频/灰烬/致盲/诅咒/臣服/寄生/恍惚/易燃）**真正施加到自身**——被[异常免疫](/powers/debuff_immune_power.md)之类拦下的异常不算"受到"，不触发。
- **一次异常 = 手牌上限个风龙结**：手牌上限是**当前值**（受[如梦令](/cards/character/ru_meng_ling.md)-2、[吕蒙](/relics/ancient/lu_meng.md)+3 等修正影响）。默认 10 手牌上限 → 每被挂一次异常 +10 风龙结；手牌上限被压缩时会叠得慢。
- **风龙结是独立可见能力**：每有 1 个，自身造成伤害+1%（增伤，与其它增伤**相乘**），上限 100。到达 100 时结算，两分支消耗不同——不为龙：**消耗全部**、恢复所有 PP、切换为[龙](/powers/dragon_power.md)；已为龙（**每场仅一次**）：获得[永久减伤](/powers/permanent_damage_reduction_power.md)50%，**不消耗**、风龙结稳定在 100。
- **>50 立即清异常**：获得风龙结后若总数超过 50，**当场**解除自身所有异常状态（清的是"当前身上"的异常，包括刚触发加风龙结的那一个）。被清掉的异常如果还挂在回合持续上，回合开始重挂时会再次触发加风龙结——等于每回合刷一次"异常入账"。
- **能力与遗物的分工**：风龙结的增伤、到 100 变龙/永久减伤是**能力本身**的效果（[风龙结](/powers/wind_dragon_knot_power.md)能力页）；嘲风遗物只负责两件事——"受异常→加结"和">50→清异常"。两者解耦，能力可被其它内容复用。

## 小贴士

- **异常流敌人的噩梦**：遇到爱挂异常的敌人（烧伤、中毒、诅咒系），每回合白嫖 10+ 个风龙结，增伤滚雪球，还自动清异常——这是对异常特化阵容的天然克制。
- **50 阈值是"免疫级"分水岭**：风龙结过 50 后，异常状态在挂上的同一瞬间就被解除，实战中几乎等于"不再被异常困扰"（回合刷新时依旧会触发一次加结，但没有异常会留身上）。
- **200 个 = 全效果**：100 个时如果还不是龙，走的是"回 PP + 变龙"分支（清零）；变龙后再叠满 100 才拿到唯一一次的永久减伤 50%，且此后风龙结**稳定在 100**——增伤 +100% 与减伤 50% 同时常驻。想拿全效果总共要叠 200 个，一般要到中后期。
- **增伤在龙分支后常驻 100%**：非龙阶段叠满 100 会清零重来，想长期挂高增伤得"踩刹车"（别叠满）；一旦走完"变龙 → 再叠 100"流程，风龙结固定 100 层，增伤永久 +100%（伤害翻倍）不再波动，永久减伤 50% 是唯一一次防御兑现、到不了 100%。
- **与变龙体系联动**：变龙后吃[龙属性](/powers/dragon_power.md)的元素克制与[龙牌联动](/relics/common/jin_rui_fu_long.md)，配合唯一一次的永久减伤 50%，嘲风是"越被打越能打"的成长型攻防一体遗物。
