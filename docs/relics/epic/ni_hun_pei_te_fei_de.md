## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 史诗

### 数值参数

| 参数 | 数值 |
|---|---|
| ①战斗开始防御 | +2 |
| ②固定伤害 | 自身格挡 30% + 能力提升段数 + 堕落 10% |
| ②石化概率 | 50% |
| ②未石化 | 自身全属性 +1 |
| ③触发 | 自身四维能力提升被消除时（仅正提升，负值移除不触发） |
| ③效果 | 全体敌人石化1 + 解除自身异常 + 下回合开始获20格挡 |

## 描述

①战斗开始时，自身[gold]防御[/gold]+[blue]2[/blue]。②自身打出[gold]攻击牌[/gold]时，额外造成（自身[gold]格挡[/gold]的[blue]30%[/blue]+[gold]能力提升段数[/gold]+[red]堕落[/red][blue]10%[/blue]）[gold]固定伤害[/gold]；[blue]50%[/blue]概率令目标[red]石化[/red][blue]1[/blue]层，未石化则自身[gold]全属性[/gold]+[blue]1[/blue]。③自身能力提升被消除时，所有敌人[red]石化[/red][blue]1[/blue]层，解除自身异常，下回合开始获得[blue]20[/blue]格挡。

## 详细机制

- **①的防御+2 与"能力提升段数"联动**：每场战斗开始时自身防御 +2（属性提升），该 +2 也会计入②计算段数。防御层会被"清除属性提升"类效果消掉，从而触发③。
- **②只响应攻击牌**：打出攻击牌时结算（非攻击牌不触发）。固定伤害 = **自身当前格挡 × 30%**（向下取整）+ **能力提升段数**（自身四维正提升层数之和：力量 + 防御 + 命中 + 速度，只算正数）+ **堕落的 10%**（向下取整）。固定伤害走[固定伤害](/powers/fixed_damage_power.md)能力结算（受免疫固定伤害减益等机制影响）。
- **②石化判定**：每次打出攻击牌**整体判定一次**（不是每目标一次）：50% 命中 → 本次攻击的目标石化 1 层；未命中 → 自身**全属性 +1**（力量/防御/命中/速度各 +1）。
- **③是"被动反制"**：利用 `PowerRemoved` 事件，自身任一**正面**四维 power 被移除时触发一次：**全体敌人**石化 1 层 + **解除自身所有异常** + **下回合开始时获得 20 格挡**。伤害来源不限于敌人——自己触发"清除属性提升"类效果、被消强时都会连锁触发（注意节奏）。
- **③只认"正提升被消除"**：代码在 `PowerRemoved` 中过滤 `power.Amount <= 0` 直接跳过——只有被消除的是**正值**四维才触发。因此"解弱（清除自身负值属性）"不会触发③，别指望靠负值被清除来白嫖石化+格挡。

## 小贴士

- **堆格挡就是堆输出**：②的固定伤害与自身当前格挡正相关，配合高格挡牌/防御型遗物，一张攻击牌能同时砸固定伤害 + 大概率石化。
- **能力段数滚雪球**：力量/防御/命中/速度的正层全算进固定伤害，四维越高，攻击牌附带伤害越猛——先铺属性再打攻击牌收益最高。
- **堕落也进伤害公式**：② 额外附加 [堕落](/powers/fallen_power.md)的 10%——堕落 300 层时 +30 固伤、1000 层时 +100，配索伦森的堕落体系越打越重。
- **被消除=免费爆发**：敌人/技能消你属性提升时，等于白送一次"全体石化+清异常+20格挡"的连锁，合理送掉一层低价值提升能换一轮控制。
- **注意"解弱"不会自触发**：自身带四维负值（下降）期间被"解除属性下降"效果清掉时**不会**触发③（负值移除被过滤），只有**正值**提升被消时才触发。所以负面属性该清就清，不必为了触发③特意留负值。
