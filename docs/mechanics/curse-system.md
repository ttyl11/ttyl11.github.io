# 诅咒卡系统

Seer Mod 引入了 **18 张自定义诅咒卡**，构成一个独立的诅咒子系统。与原版诅咒牌不同，Mod 的诅咒卡大多**不需要打出**——它们只要留在手牌中就会持续产生负面效果，迫使玩家尽快处理或承受代价。

::: tip 与原版诅咒牌的区别
原版诅咒牌（如沮丧、寄生）通常只是占用手牌位、不可打出。Mod 的诅咒卡则**主动惩罚**持有者：有的每回合造成伤害，有的封锁 PP 卡牌，有的甚至强制结束回合。它们是双刃剑——部分诅咒卡打出后反而能产生正面效果。
:::

---

## 基本特性

所有 Mod 诅咒卡共享以下基础属性：

| 属性 | 值 | 说明 |
|---|---|---|
| 不可升级 | 是 | 升级等级上限为 0 |
| 卡牌类型 | 诅咒 | 与原版诅咒牌类型相同 |
| 稀有度 | 诅咒 | 专属稀有度 |
| 目标 | 无目标 | 大多数不可主动打出 |
| 卡牌池 | 诅咒卡池 | 独立卡池，不混入常规卡池；随机诅咒池实含 17 张，隐匿炸弹由王牌术师的「帽子戏法」单独生成，不在随机池中 |

## 七罪系列

七张以"七宗罪"为主题的诅咒卡，每张都有独特的手牌惩罚机制：

| 诅咒 | 效果 |
|---|---|
| **嫉妒** | 永恒、不可打出、蚀返。回合结束时若在手牌中，战斗结束随机加入一张打击或防御牌（每场最多一次） |
| **暴食** | 永恒、X 费、消耗。打出时获得 X 点最大生命；迁鸣：牌堆变化时获得当前能量点最大生命并清空能量 |
| **贪婪** | 永恒、保留，2 费。回合结束时若在手牌中，受到当前金币 <span style="color:#3aa675;font-weight:600">5%</span> 的伤害 |
| **色欲** | 永恒、薇，4 费。打出时对自己施加 <span style="color:#3aa675;font-weight:600">4</span> 种随机异常状态，各 <span style="color:#3aa675;font-weight:600">4</span> 回合 |
| **傲慢** | 永恒、蚀返，1 费。溯引：抽到时随机消耗半数手牌并清空 PP |
| **懒惰** | 永恒、保留，2 费。在手牌中时你无法打出攻击牌 |
| **暴怒** | 永恒，0 费。抽到时自动打出，对所有生物造成 <span style="color:#3aa675;font-weight:600">9</span> 点伤害 |

::: warning 七罪策略
七罪卡的惩罚集中在「手牌驻留」与「打出代价」两端：懒惰、贪婪留在手里持续压制；暴食可以主动打出换最大生命；暴怒抽到就自动打出、伤及全场。处理时先判断这张牌是「留着更痛」还是「打出去更痛」。
:::

## 其他诅咒卡

除七罪外，Mod 还有 11 张主题各异的诅咒卡：

| 诅咒 | 效果 |
|---|---|
| **借鉴** | 溯引：抽到时向手牌加入 3 张其他角色的牌（费用 +1）。残鸣：被消耗时销毁三个牌堆中的所有非 PP 牌 |
| **冲锋** | 虚无、迟涌、不可打出。溯引：抽到时受到「144 ÷ 本场已造成伤害」的伤害 |
| **云玩家** | 固有、保留、消耗，3 费。4 场战斗后从牌组移除；在手牌中时所有 PP 卡牌无法打出 |
| **拖50** | 迟涌、不可打出。回合结束时若在手牌中，受到当前回合数 × 3 的伤害 |
| **保底** | 碎心、进化，0 费。1% 获得随机遗物，否则获得 1 金币；每场战斗自动升级一次，每级 +1%（最高 99 级） |
| **氪金** | 回响、不可打出。迁鸣：每次挪牌扣除 6 金币 |
| **涨价** | 不可打出。此牌在牌组时，抽奖所需泰坦之灵 +1 |
| **老鼠药** | 固有、保留、消耗，3 费。在手牌中时，使用药水失去 5 点最大生命 |
| **渺小** | 不可打出，可升级（最高 99 级）。每打出一张牌受到 3 点固定伤害（每级 +1） |
| **开龟** | 虚无。在手牌中时，你每回合累计造成 30 点未被格挡的伤害后，强制结束你的回合（每回合重新计数） |
| **隐匿炸弹** | 薇。失去 3 点最大生命值，再失去 10 点生命值 |

---

::: details 触发模式详解
诅咒卡的效果触发遵循几种典型模式：

**1. 手牌驻留惩罚** —— 诅咒卡在手牌中时持续生效。如懒惰（无法打出攻击牌）、云玩家（封锁有 PP 的卡牌）、老鼠药（用药扣最大生命）、开龟（单回合造成 30 伤害后强制结束回合）等。这类诅咒卡需要通过打出、消耗或弃牌来解除惩罚。

**2. 回合结束触发** —— 部分诅咒卡在回合结束时检查是否在手牌中，若在则触发。如嫉妒（标记战斗结束加打击/防御）、贪婪（按金币 5% 受伤）、拖50（按回合数 ×3 受伤）等。

**3. 抽到时触发** —— 部分诅咒卡在抽到瞬间触发。如傲慢（随机消耗半数手牌并清空 PP）、冲锋（按已造成伤害反噬）、暴怒（自动打出并伤害全场）等。

**4. 打出后双刃** —— 部分诅咒卡可以主动打出，但打出后有代价。如暴食（获得最大生命，但消耗全部能量）、色欲（4 费，对自己施加 4 种异常）、保底（碎心换 1% 遗物概率）等。
:::

::: details 处理诅咒卡的方式
- **打出**：部分诅咒卡可打出，但通常有代价
- **消耗**：通过消耗机制将诅咒卡移入消耗堆
- **弃牌**：通过弃牌机制移除
- **转化**：部分卡牌或遗物可将诅咒卡转化为其他牌
- **等待移除**：如云玩家会在 4 场战斗后自动从牌组移除

::: tip 与其他系统的联动
诅咒卡与 Mod 的多个系统有联动：[湮灭](./annihilation)机制中的邪诲/圣诰可配对造成伤害；部分遗物会在获得诅咒时触发效果；[空元之诗](./void-poem)的渍效果可给敌人施加诅咒。
:::
:::
