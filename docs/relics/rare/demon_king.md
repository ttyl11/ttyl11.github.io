# 厉魇魔王·咤克斯

<img src="/images/relics/demon_king.png" alt="厉魇魔王·咤克斯" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 稀有

### 数值参数

| 参数 | 数值 |
|---|---|
| 初始增伤 | 5% |
| 初始减伤 | 5% |
| 初始秒杀概率 | 0.5% |
| 堕落百分比 | 19（%） |

## 描述

①战斗开始时，获得增伤<span style="color:#3aa675;font-weight:600">5</span>%和减伤<span style="color:#3aa675;font-weight:600">5</span>%。<br/>②攻击未击杀敌人时，有<span style="color:#3aa675;font-weight:600">0.5</span>%概率直接秒杀。<br/>③每场战斗胜利后，增伤、减伤各提升2%，秒杀概率提升0.2%。<br/>④打出名称含<span style="color:#d4a017;font-weight:600">违</span>的牌时，获得当前<span style="color:#d44;font-weight:600">堕落</span>层数<span style="color:#3aa675;font-weight:600">19%</span>的<span style="color:#d44;font-weight:600">堕落</span>。

- **增伤只加攻击牌伤害**：永久增伤是乘法百分比修正，仅提升你造成的攻击牌伤害，非攻击伤害不受影响。增伤虽然是增益（Buff），但不会被任何"消除增益 / 驱散"类效果移除，战斗内稳定生效。
- **减伤只减受到的攻击伤害**：永久减伤同为乘法百分比修正，仅减少你受到的攻击牌伤害。减伤同样是增益（Buff），同样不会被任何"消除 buff/debuff"类效果清除，一旦战斗开始就稳定生效整场。
- **成长公式**：增伤 = 5% + 胜利场次 × 2%，减伤 = 5% + 胜利场次 × 2%，秒杀概率 = 0.5% + 胜利场次 × 0.2%。三者随本局冒险的胜利场次线性成长，数值随存档保存（读档不丢），新开一局从初始值重新算。
- **秒杀触发条件**：你造成的每一段攻击伤害未击杀目标时，独立判定一次秒杀概率。概率随胜利场次增长。
- **堕落19%**：打出带「违」字的牌时，自身获得"当前堕落层数×19%"（向下取整）的[堕落](/powers/fallen_power.md)，与[黑啵啵](/relics/uncommon/hei_bo_bo.md)同口径。

## 小贴士

- **胜利场次是核心滚雪球变量**：本局冒险每赢一场战斗，增伤/减伤各 +2%，秒杀概率 +0.2%，数值写入存档、读档不丢。打 10 场后增伤/减伤达 25%，打 20 场达 45%——越往后面板越恐怖，是典型的"越打越强"型运营遗物（注意：成长只在本局内累积，新开一局重新计算）。
- **增伤减伤只对攻击伤害生效**：增伤按百分比放大你的攻击牌伤害，减伤按百分比削减你受到的攻击牌伤害，非攻击伤害（能力伤害、异常掉血、[固定伤害](/powers/fixed_damage_power.md)）完全不受影响。这件遗物对攻击牌构筑收益最大，对靠能力/异常打伤害的牌组收益打折。
- **增伤减伤都不会被清除**：两者都是增益（Buff），但已从 mod 内一切消除增益、驱散类效果中排除，敌方无法把它们洗掉；复制、计数等其它增益交互照常。
- **秒杀是锦上添花不是核心**：初始 0.5% 概率极低，每场只 +0.2%，打 20 场才 4.5%。真正有价值的是长战斗中偶尔秒杀残血精英/Boss，属于意外惊喜而非战术依赖。
- **多段攻击的秒杀判定密度更高**：每一段伤害未击杀目标都独立判定一次——5 段攻击 = 5 次判定机会，多段连击牌的实际秒杀期望是单段牌的数倍。
- **攻防一体的全能面板**：增伤加输出 + 减伤加坦度 + 秒杀加惊喜，三效合一覆盖攻防节奏全维度。稀有度合理，是长局运营的核心遗物。
