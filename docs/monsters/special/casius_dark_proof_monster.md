## 被动能力

**山神之力（开局自带，仅触发一次）**：自身生命值首次降到最大生命的 50% 及以下时，获得 <span style="color:#3aa675;font-weight:600">40%</span> 减伤与壁垒（格挡回合开始不清空），并向你的抽牌堆加入 <span style="color:#3aa675;font-weight:600">7</span> 张随机状态牌。

- 减伤只作用于攻击伤害（攻击伤害 ×0.6）。
- 能力不可消除。

## 行动逻辑

分三个阶段，由血量阈值与量子绝灭波的使用次数驱动。触发山神之力的当回合，还没执行的那一招会被立刻换成量子绝灭波；下一回合再强制打一次量子绝灭波；之后四招随机循环。

```mermaid
flowchart TD
    A([每回合选招]) --> B{"当前处于哪个阶段？"}
    B -->|"阶段 1：山神之力未触发"| C{"3 招等权随机"}
    C --> C1["连山绝壑"]
    C --> C2["融入黑暗"]
    C --> C3["乾坤反转"]
    C1 --> A
    C2 --> A
    C3 --> A
    B -->|"阶段 2a：触发当回合（仅一次）"| D["立即改打<br/>量子绝灭波（第 1 发）"]
    D --> A
    B -->|"阶段 2b：触发后的下一回合"| E["量子绝灭波（第 2 发）"]
    E --> A
    B -->|"阶段 3：两发已打完"| F{"4 招等权随机（循环）"}
    F --> F1["连山绝壑"]
    F --> F2["融入黑暗"]
    F --> F3["量子绝灭波"]
    F --> F4["乾坤反转"]
    F1 --> A
    F2 --> A
    F3 --> A
    F4 --> A
```

- **阶段 1**（生命 > 50%）：连山绝壑 / 融入黑暗 / 乾坤反转 三选一，量子绝灭波权重为 0。
- **触发山神之力后**：两次量子绝灭波连打（触发当回合 + 下一回合）；壁垒让第一发的格挡留到第二发，第二发累计格挡翻倍后可达 <span style="color:#3aa675;font-weight:600">60</span> 点伤害。
- **阶段 3**：四招等权随机循环。

## 策略提示

1. **山神之力的触发点被拉长**：本体在 50% 血量触发 40% 减伤 + 壁垒 + 塞 7 张状态牌。这条变体血量为 256~266，你需要先打掉 128~133 点才会看到这条线，爆发窗口与减伤窗口都更靠后。

2. **更高的血量让「山神之力」更难绕**：减伤 + 壁垒 + 状态牌三件套会显著拖慢后半程，提前准备固定伤害、状态牌清理和壁垒对策。

3. **前半程是纯输出窗口**：触发山神之力前它没有额外减伤，尽量把爆发打在这段时间，避免进减伤阶段后硬磨。

4. **子地图无真正死亡**：失败只会退出子地图，不会丢局；但仍会浪费活动进度，能稳过优先。
