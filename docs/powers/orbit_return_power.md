# 轨道回归

> **归属**：玩家可施加
> **施加来源**：玩家获得——[宙轨重回](/cards/character/orbit_return.md)（卡牌）

<img src="/images/powers/orbit_return_power.png" alt="轨道回归" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 增益（Buff）
- **叠加方式**: 按层数叠加
- **可见**: 是

## 描述

每[blue]2[/blue]回合触发一次，获得[blue]1[/blue]×层数的[gold]轨道[/gold]能力。

## 详细机制

- **触发节奏**：自己回合开始时计数 +1，每满 <span style="color:#3aa675;font-weight:600">2</span> 个自己的回合触发一次（第 2、4、6… 个回合），触发后计数清零。
- **获得层数 = 层数 × 层数**：按当前实现，每次触发获得的「轨道」为轨道回归层数的平方——2 层轨道回归 → 每次 +4 层轨道，3 层 → 每次 +9 层轨道。
- **轨道本身的效果**：每累计消耗 <span style="color:#3aa675;font-weight:600">4</span> 点能量，回复等同轨道层数的能量；消耗越多触发越频繁。
- **层数只影响每次给的轨道数**：提高轨道回归层数会让每次触发给的轨道更多，但不改变触发节奏。
- **整场常驻**：能力不自行减少，持续到战斗结束或被清除。

## 小贴士

- **高费卡组最吃**：轨道靠「消耗能量」触发，能量消耗越快，回能越频繁——适合高费连打。
- **叠层收益为平方增长**：每次获得的轨道 = 层数 × 层数（2 层 → 4 层，3 层 → 9 层）；叠得越高，单次回能越可观。
- **别指望立刻生效**：第 2 个自己的回合才第一次触发，前期需要先撑过一回合。
