# 意图

意图表示怪物在敌方回合即将执行的动作。Seer Mod 在原版意图类型基础上，新增了多种特殊意图类型，并扩展了意图失效机制。

::: tip Mod 扩展了什么

- 新增意图类型：行动失效、封印（攻击无效/封属）、同生共死、解析

- 新增动态多段攻击意图（连击次数随条件变化）

- 新增意图失效机制（攻击无效/封属、凝滞施加封属、龙威类型匹配）
  :::

***

## 原版意图类型

原版已有、Mod 沿用的意图类型：

- **攻击**：造成伤害

- **多段攻击**：造成多次伤害

- **防御**：获得格挡

- **增益**：获得能力

- **减益**：对玩家施加 Debuff

- **击晕**：使玩家下回合无法行动

- **未知**：意图显示为问号

***

## Mod 新增意图类型

### 行动失效

- **效果**：此行动已失效，不会产生任何效果

- **来源**：纯意图行动被[攻击无效](#攻击无效)或[封属](#封属)整体失效时，原意图被替换为"行动失效"

- **显示**：意图图标显示为失效状态，原伤害数值仍可见

::: tip 行动失效 vs 击晕
行动失效是让怪物自己的意图失效；击晕是让玩家无法行动。两者方向相反。
:::

### 攻击无效

- **效果**：本回合该敌人**攻击意图**的效果全部失效（攻击伤害无效）

- **来源**：卡牌（[跪地求饶](/cards/character/kneel_beg)、[天霜杀伐](/cards/character/heaven_frost_slaughter)）、遗物（[阿尔蒂克](/relics/epic/arteck)、[刘备](/relics/rare/benevolent_heaven_lord_liu_bei)、[万恶魔主](/relics/rare/evil_beast_emperor)、[塔罗系列](/relics/)）、能力（[致命印记](/relics/legendary/order_killing_god_luo)、[支援](/powers/support_power)）等

- **显示**：作为额外意图图标显示在敌人意图栏末尾，与"解析"同机制

- **特性**：只影响攻击意图，非攻击意图照常执行；纯攻击行动会整体失效（显示为行动失效）

### 封属

- **效果**：本回合该敌人**非攻击意图**的效果全部失效（增益/减益/防御/治疗/召唤/状态牌等）

- **来源**：卡牌（[跪地求饶](/cards/character/kneel_beg)、[无限·虚数湮灭](/cards/character/infinite_void_annihilation)）、遗物（[苍龙](/relics/uncommon/azure_dragon)、[阿尔蒂克](/relics/epic/arteck)、[钢傀](/relics/epic/steel_puppet)、[刘备](/relics/rare/benevolent_heaven_lord_liu_bei)、[万恶魔主](/relics/rare/evil_beast_emperor)、[塔罗系列](/relics/)）、能力（[凝滞](/mechanics/abnormal-status)、[致命印记](/relics/legendary/order_killing_god_luo)、[支援](/powers/support_power)）等

- **显示**：作为额外意图图标显示在敌人意图栏末尾，与"解析"同机制

- **特性**：只影响非攻击意图，攻击意图照常执行；纯非攻击行动会整体失效（显示为行动失效）

### 同生共死

- **效果**：将你的当前生命值变为与自身相同

- **来源**：特定怪物招式

- **战略**：高血量怪物用这招会把你血量拉满（好事），低血量怪物用这招会把你血量拉低（坏事）

### 解析

- **效果**：对所有敌人造成生命流失伤害

- **来源**：特定怪物招式

- **特性**：生命流失不吃格挡、不吃力量/虚弱/易伤

### 动态多段攻击

Mod 有大量"连击次数随条件变化"的招式：

| 招式    | 连击条件                     |
| ----- | ------------------------ |
| 瞬影裂刃  | 等于当前回合数                  |
| 双重暗影  | 场上每有 1 个击晕意图，连击 -1       |
| 极月无双破 | 你每拥有 1 种全属性提升，连击 +1      |
| 迅捷撞击  | 每有 1 层速度，连击 +1           |
| 魔龙冲天  | 每使用过一次此技能，连击 +1          |
| 绷带痛击  | 等于剩余绷带层数                 |
| 五彩音域  | 伤害 = 2 的 x 次幂（x = 手牌杂音数） |
| 瞬雷天闪  | 造成伤害后自身力量 +1（每段）         |
| 凤舞    | 多段攻击                     |
| 飞叶风暴  | 多段攻击                     |

## 意图失效机制

### 凝滞施加封属

怪物持有[凝滞](/mechanics/abnormal-status)异常状态时，**回合开始对其施加封属**——非攻击意图（增益/减益/防御/治疗/召唤/状态牌等）效果全部失效，但攻击意图照常执行。这意味着凝滞可以让怪物的辅助招式失效，但不能阻止攻击。

### 龙威类型匹配

哈莫雷特的龙威能力会让玩家打出的牌按类型匹配触发：

- 玩家打出的牌与上一张**类型不同**时，重放一次

- 玩家打出的牌与上一张**类型相同**时，此牌无效

详见 [龙威](./dragon-majesty)。

### 石化操控

墨杜萨的石化操控招式会让玩家**下个回合结束时清除所有格挡并转化为等量固定伤害**——这是一种延迟性的意图修改，让玩家的格挡变成负担。

***

## 意图显示规则

- **意图锁定**：玩家回合开始时（清块、抽牌、回能量之前）怪物招式就完全锁定，出牌过程中不会变

- **多段攻击显示**：显示为"伤害 × 次数"格式

- **附加效果显示**：部分意图会显示附加效果（如"附加固定伤害"、"获得异常"等）
