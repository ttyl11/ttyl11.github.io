# 断程

> **归属**：玩家施加给敌方
> **类型**：减益（Debuff）
> **施加来源**：玩家获得——[断程](/cards/status/sever_path.md)（卡牌，拿在手中时施加）
> **叠加方式**：计数（层数无实际效果）
> **可见**：否（隐藏能力）

## 描述

[gold]手牌[/gold]中有「断程」时，你无法打出[gold]技能牌[/gold]。

## 详细机制

- **触发条件**：持有者的手牌里存在「断程」这张牌时才生效；断程离手（打出/弃掉/消耗）后立刻解除。
- **只封技能牌**：攻击牌、能力牌照常打出。
- **断程本身可打**：这张牌自己不受封锁，可以用来主动解除。
- **自动打出豁免**：AutoPlay 路径不受限制。
- **只封持有者**：队友与敌人不受影响。
