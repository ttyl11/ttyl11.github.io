# 关键词图鉴（34 项）

原版 7 个 + Mod 新增 27 个。点击条目查看详情。

| 图片 | 名称                    | 效果                                              |
| -- | --------------------- | ----------------------------------------------- |
| —  | [消耗](exhaust)         | 原版。在战斗结束前移除。                                    |
| —  | [虚无](ethereal)        | 原版。回合结束时留在手牌则消耗。                                |
| —  | [保留](retain)          | 原版。保留的牌不会在回合结束时被弃掉。                             |
| —  | [固有](innate)          | 原版。每场战斗开始时这张牌会出现在手牌。                            |
| —  | [不能被打出](unplayable)   | 原版。无法通过正常方式打出。                                  |
| —  | [永恒](eternal)         | 原版。无法从牌组中移除或变化。                                 |
| —  | [奇巧](sly)             | 原版。回合结束前从手牌被丢弃时，免费打出。                           |
| —  | [碎心](shattered_heart) | Mod。打出时，失去 2 点最大生命值。                            |
| —  | [悼](mourning)         | Mod。打出时，下个回合由瓦库代替你行动。                           |
| —  | [寂灭](nirvana)         | Mod。打出时，本场战斗结束后从你的牌组中移除此牌。                      |
| —  | [化墟](ruination)       | Mod。打出时，向你的弃牌堆中加入一张随机状态牌。                       |
| —  | [陨](fallen)           | Mod。打出后，此牌转化为"圣逝"。                              |
| —  | [芜生](void_birth)      | Mod。打出后，此牌转化为"芜"。累积 5 层触发即死。                    |
| —  | [缢形](hanged_form)     | Mod。打出时，本场战斗中你无法再获得任何增益。                        |
| —  | [异变](aberration)      | Mod。打出时，对自己施加随机 1 种异常状态，持续 2 回合。                |
| —  | [毁灭](destruction)     | Mod。打出时，将你的消耗堆中的所有牌移动到销毁牌堆。                     |
| —  | [邪恶](evil)            | Mod。打出时，本场战斗结束后向牌组添加一张此牌的复制品。                   |
| —  | [炼狱](purgatory)       | Mod。伤害翻倍，打出时对己方施加随机异常状态 5 回合。                   |
| —  | [回响](echo)            | Mod。每回合开始时，若此牌在[抽牌堆](draw_pile)，向[弃牌堆](discard_pile)生成一张复制品。 |
| —  | [饮血](vampiric)        | Mod。此牌造成的伤害回复 20% 生命值。                          |
| —  | [薇](vigil)            | Mod。非"薇"的相邻牌被打出时，此牌自动打出。                        |
| —  | [戏法](trick)           | Mod。打出时，若弃牌堆有牌，随机从弃牌堆抽一张牌到手中。                   |
| —  | [真神](true_god)        | Mod。此牌只能被自动打出，存放在独立的真神牌堆中。                      |
| —  | [湮灭](annihilation)    | Mod。对所有敌人，邪诲与圣诰每配对一组造成 8 点伤害。                   |
| —  | [薇尔诗](vier-poem)      | Mod。根据手牌位置提供不同免疫效果（全属性下降/异常状态/固定伤害）。            |
| —  | [预见](scry)            | Mod。打出时查看牌堆顶 N 张牌，可选择丢弃其中任意数量。                  |
| —  | [空元之诗](void-poem)     | Mod。打出时若自身有空妄诗章，随机触发渍/镀/柱/烙/均五种效果之一。            |
| —  | [连营](lian_ying)       | Mod。打出时，自动一次性从任意位置打出并销毁所有其他的连营牌。                |
| —  | [蚀返](shifan)          | Mod。此牌被[消耗](exhaust)时，向[抽牌堆](draw_pile)生成一张复制品。 |
| —  | [残鸣](canming)         | Mod。此牌被[消耗](exhaust)时，触发此牌的效果。                  |
| —  | [迁鸣](qianming)        | Mod。牌堆变化时，触发此牌的效果。                              |
| —  | [迟涌](chiyong)         | Mod。洗入牌堆时，自动放入[抽牌堆底](draw_pile)。                |
| —  | [凝驻](ningzhu)         | Mod。此牌无法从[弃牌堆](discard_pile)洗入[抽牌堆](draw_pile)（会停留在[弃牌堆](discard_pile)）。 |
| —  | [溯引](suyin)           | Mod。抽到此牌时，触发此牌的效果。                              |
