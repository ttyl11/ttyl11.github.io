# 星陨

> **归属**：怪物专属（玩家无法施加）
> **施加来源**：怪物自带常驻被动——伽玛星魂

<img src="/images/powers/gamma_star_soul_power.png" alt="星陨" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**：中性（None）
- **叠加方式**：不叠加
- **可见**：是

## 描述

①免疫并反弹暴击伤害。
②每次被[gold]暴击[/gold]命中后，立即结束该敌人的回合。

## 详细机制

- **只认暴击攻击**：只有「攻击伤害 + 本次为暴击」才触发；非暴击、非攻击伤害照常结算。
- **免疫**：该次暴击伤害的乘区置 0，相当于完整免伤。
- **反弹**：把免疫前的伤害数值，以不可格挡、不吃加成的伤害反弹给攻击者。
- **结束回合**：对每个敌对玩家强制结束回合（`canBackOut: false`），多人时所有玩家的回合都会结束。
- 每次攻击前会清空待反弹缓存，避免上一刀残留。
