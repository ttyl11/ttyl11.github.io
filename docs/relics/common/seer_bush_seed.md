# 布布种子

<img src="/images/relics/seer_bush_seed.png" alt="布布种子" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物

- **稀有度**: 普通

## 描述

拾起时，选择 <span style="color:#3aa675;font-weight:600">1</span> 张牌，为其附魔[播种](/enchantments/sown)。

[播种](/enchantments/sown)（原版附魔）：你在每场战斗中第一次打出这张牌时，获得 <span style="color:#3aa675;font-weight:600">1</span> 点能量。

- **一次性永久选择**：拾起时选一张牌永久附魔，之后不会再让你选。

## 风味文字

<span style="color:#d44;font-weight:600">随风而至，落地生根。</span>

## 小贴士

- **一张"每场免费过路费"的牌**：[播种](/enchantments/sown)让选中的牌每场战斗第一次打出就送你 <span style="color:#3aa675;font-weight:600">1</span> 点能量。虽然单次不多，但附在必打牌上就是**每场稳定的额外手续费减免**——等于这牌从"你要花钱打"变成"打它还发工资"。

- **选谁？给"每场一定先打"的牌**：最适合给每场必打一遍的高费强力牌、启动牌或循环核心牌。1 点能量看似小，但配高费启动牌等于净省 1 费，配合先制/连招顺畅不少。

- **只有一次机会，别浪费在杂牌上**：附魔是不可转移的永久效果，选完就绑死。给收益最大、出场率最高的那张，别拿去附魔会消耗/收不回来的杂牌。

- **性价比**：普通遗物用一张牌的附魔槽换"每场首打免费 1 费"，长期稳定白嫖，朴素但好用。
