# 👑 战神联盟秘药

## 基本信息

- **分类**: 卡牌生成 / 爆发
- **稀有度**: 稀有
- **使用时机**: 战斗内
- **目标**: 自身

## 描述

将一张王·联盟审判加入你的手牌，本回合费用为0。

## 详细机制

- **生成卡牌**：往手牌加入一张「王·联盟审判」。
- **本回合 0 费**：该卡标记为"本回合免费"，可立即打出而不消耗能量。
- **一次性爆发**：仅影响当前回合，用完整瓶即结束。

## 小贴士

- **开局即大招**：直接获得一张强力卡且免费，等于战斗开局先手甩一个高费级技能，瞬间拉开血线差距。
- **与[大暗黑天秘药](great_dark_sky_potion.md)是同门双生子**：一个给魔系、一个给联盟系指定卡，选哪个取决于你卡组更依赖哪套体系。
- **替代高费操作的机会成本**：免费不等于无代价——它占用一个药水栏。只有在你"喝下去这回合就能打出明显优势"时才真的赚。
- **别让它烂手里**：免费卡限当前回合，有多余 PP/能量配合它的机制就当场用掉，拖到下回合就只剩"一张普通卡"了。
