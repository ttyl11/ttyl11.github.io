# 滑溜

<img src="/images/powers/slippery_power.png" alt="滑溜" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **归属**：任意角色均可持有（原版能力）
- **类型**：增益
- **叠加**：计数型（按受击次数递减）
- **可见**：是
- **施加来源**：原版怪物 / 事件能力

## 描述

持有期间，自身每次受到的伤害生命损失降为 <span style="color:#3aa675;font-weight:600">1</span>，按次数递减，归零后移除。

## 详细机制

- 每次受到伤害时，**未被格挡的生命损失**最多只算 1 点；格挡仍然按原伤害正常消耗。
- 只有真正打掉至少 1 点生命的那次受击才会消耗 1 层；被格挡完全吸收的伤害不消耗层数。
- 多段攻击逐段判定：每段只要掉血就各消耗 1 层。
- 层数归零后能力消失，后续伤害恢复正常。
- 多人模式下层数会按玩家人数放大。
