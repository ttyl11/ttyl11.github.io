# 增益流失睡眠

## 基本信息

- **归属**：玩家能力
- **类型**：增益
- **叠加**：计数型（层数 = 持续回合）
- **施加来源**：当前版本没有卡牌、遗物或怪物接入该能力，仅源码中存在定义
- **可见**: 是

## 描述

<span style="color:#3aa675;font-weight:600">层数</span>回合内，自身任一<span style="color:#d4a017;font-weight:600">增益</span>消失，则使对手获得<span style="color:#3aa675;font-weight:600">2</span>层<span style="color:#d4a017;font-weight:600">睡眠</span>。

## 详细机制

- **持续回合**：获得时的层数就是持续回合数，每次自身回合开始时 −1。
- **触发条件**：拥有者身上任意一个可见的增益能力被移除时触发，不要求是异常状态或负面效果。
- **不监听自身**：这个能力自己被移除时不会触发。
- **触发效果**：对拥有者的所有敌人各施加 2 层睡眠。
- **一次一层**：每移除一个增益结算一次，同一回合移除多个增益会多次触发。
