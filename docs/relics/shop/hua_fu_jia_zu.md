# 华夫家族

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 商店

## 描述

每次击败<span style="color:#d4a017;font-weight:600">精英</span>后，获得<span style="color:#d4a017;font-weight:600">李家华夫饼</span>。

- **触发条件**：仅在精英战斗胜利后触发，普通战斗/Boss 触发时判定不会生效。
- **奖励**：每场精英胜利获得 1 件原版遗物「李家华夫饼」。

## 风味文字

<span style="color:#d44;font-weight:600">华夫家族。</span>

## 小贴士

- **精英奖励放大器**：每个精英都给华夫饼，配合华夫饼自身效果，精英众多的高难路线收益最大。
- **判定精确**：只在 `RoomType == Elite` 时给，不让普通战斗刷华夫饼。
