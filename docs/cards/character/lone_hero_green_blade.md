## 小贴士

- **平方伤害，但龙胆封顶 7 层**：伤害 = 打出并施加 <span style="color:#3aa675;font-weight:600">2</span> 层后的龙胆总层数平方。龙胆最多 <span style="color:#3aa675;font-weight:600">7</span> 层，所以单次伤害上限 <span style="color:#3aa675;font-weight:600">7</span>² = <span style="color:#3aa675;font-weight:600">49</span>。没有其它来源时：第一次 <span style="color:#3aa675;font-weight:600">2</span> 层→<span style="color:#3aa675;font-weight:600">4</span> 伤，第二次 <span style="color:#3aa675;font-weight:600">4</span> 层→<span style="color:#3aa675;font-weight:600">16</span> 伤，第三次 <span style="color:#3aa675;font-weight:600">6</span> 层→<span style="color:#3aa675;font-weight:600">36</span> 伤，第四次被封顶在 <span style="color:#3aa675;font-weight:600">7</span> 层→<span style="color:#3aa675;font-weight:600">49</span> 伤，之后每次都是 <span style="color:#3aa675;font-weight:600">49</span>。
- **龙胆不衰减，整场战斗累积**：[龙胆](/powers/dragon_whisker_power.md)没有回合结束减层，层数一直保留到战斗结束，但上限 <span style="color:#3aa675;font-weight:600">7</span> 层。所以这张牌越早打越赚，第 <span style="color:#3aa675;font-weight:600">3</span> 次打出就有 <span style="color:#3aa675;font-weight:600">36</span> 伤，第 <span style="color:#3aa675;font-weight:600">4</span> 次达到封顶的 <span style="color:#3aa675;font-weight:600">49</span> 伤。
- **龙胆双功能争抢层数是核心矛盾**：龙胆既是平方伤害的基数，又是异常免疫的消耗品——每抵消一次异常状态消耗 <span style="color:#3aa675;font-weight:600">1</span> 层。即使层数已经掉到 <span style="color:#3aa675;font-weight:600">0</span>，下一次异常仍会被完全挡掉，只是没有层数可扣。想保高伤害就别被上异常；对面上异常时，你的雪球会被打断。
- **固定伤害联动是额外收益**：自己每打出一张牌，就对随机敌人施加等于当前龙胆层数的[固定伤害](/powers/fixed_damage_power.md)。龙胆 <span style="color:#3aa675;font-weight:600">7</span> 层时每张牌附带 <span style="color:#3aa675;font-weight:600">7</span> 点固定伤害——配合过牌流派能触发多次，是这张牌隐藏的输出来源。
- **1 费是最低门槛雪球卡**：<span style="color:#3aa675;font-weight:600">1</span> 费就能进入雪球循环，是 mod 里最便宜的平方增长卡。对比原版[恶魔形态](https://slay-the-spire.fandom.com)3 费每回合 +2 力量（线性增长），这张牌的平方增长在长战斗中远超线性，代价是需要多次打出累积。
- **升级饮血补足生存**：升级添加[饮血](/mechanics/vampiric.md)关键词，攻击伤害的 <span style="color:#3aa675;font-weight:600">20%</span> 回复自身生命（按总伤害、含被格挡部分）。伤害越高回血越多，封顶 <span style="color:#3aa675;font-weight:600">49</span> 伤时回复 <span style="color:#3aa675;font-weight:600">9</span> 点，让这张牌从纯输出变成输出+续航。
- **短战斗收益有限**：平方伤害需要多次打出累积，短战斗（1-2 回合）只打出一次 <span style="color:#3aa675;font-weight:600">4</span> 伤等于浪费。这张牌只适合长战斗（Boss 战、多波精英战），短战斗别留这张牌。
- **性价比**：<span style="color:#3aa675;font-weight:600">1</span> 费给 <span style="color:#3aa675;font-weight:600">2</span> 层龙胆 + 平方伤害 + 异常免疫 + 固定伤害联动。单次 <span style="color:#3aa675;font-weight:600">4</span> 伤偏低，但第 <span style="color:#3aa675;font-weight:600">3</span> 次 <span style="color:#3aa675;font-weight:600">36</span> 伤、第 <span style="color:#3aa675;font-weight:600">4</span> 次封顶 <span style="color:#3aa675;font-weight:600">49</span> 伤，长战斗收益扎实；短战斗只打一次则很亏。
- **带[溯引](/mechanics/suyin.md)**：抽到此牌时获得 <span style="color:#3aa675;font-weight:600">1</span> 层[龙胆](/powers/dragon_whisker_power.md)，每次抽到都叠 <span style="color:#3aa675;font-weight:600">1</span> 层（多张同名反复抽可累积，但同样受 <span style="color:#3aa675;font-weight:600">7</span> 层上限）。还没打出就能先长龙胆层数，等于打第一拳前雪球已经先滚了一圈，进一步抬高平方伤害基数。

## 相关能力

- [固定伤害](/powers/fixed_damage_power.md)：减益能力，目标下回合开始时受到等于层数的固定伤害
