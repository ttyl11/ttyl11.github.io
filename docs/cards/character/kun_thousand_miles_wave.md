## 小贴士

- **鲲鹏互生是跨回合循环链**：这张牌未击杀就衍生[鹏·万里遨游](/cards/character/peng_thousand_miles_soar.md)放抽牌堆顶，鹏·万里遨游未击杀又衍生鲲·千里击涛回抽牌堆顶——两张牌互为衍生对象，只要一直没击杀就能不断链。但这不是单回合无限：每一轮你都要重新抽到、并支付 <span style="color:#3aa675;font-weight:600">3</span> 费与 <span style="color:#3aa675;font-weight:600">1</span> 点 PP 才能继续。
- **衍生牌带本能，但不会继承升级**：衍生的牌附带[本能](/enchantments/instinct.md)附魔（攻击伤害 ×<span style="color:#3aa675;font-weight:600">2</span>，乘法修正，正常叠[力量](/powers/strength_power.md)、[易伤](/powers/vulnerable_power.md)）。衍生牌是**全新的未升级牌**：即使这张鲲已升到 <span style="color:#3aa675;font-weight:600">50</span> 伤，衍生的鹏仍是基础 <span style="color:#3aa675;font-weight:600">33</span> 伤 ×<span style="color:#3aa675;font-weight:600">2</span> = <span style="color:#3aa675;font-weight:600">66</span>。只有你自己另外把鹏升级并保留本能时，才会出现 <span style="color:#3aa675;font-weight:600">100</span> 伤的翻倍牌。
- **击杀才回手 + 先制 3 层**：击杀敌人时这张牌回手，并获得 <span style="color:#3aa675;font-weight:600">3</span> 层[先制](/powers/first_strike_power.md)（每层让下张牌减 <span style="color:#3aa675;font-weight:600">1</span> 费）。<span style="color:#3aa675;font-weight:600">3</span> 层先制正好抵消 <span style="color:#3aa675;font-weight:600">3</span> 费——回手后能量层面等于 0 费再打一次。但 PP 不会因回手重置：<span style="color:#3aa675;font-weight:600">3</span>/<span style="color:#3aa675;font-weight:600">3</span> 的 PP 默认最多支持手动打出 <span style="color:#3aa675;font-weight:600">3</span> 次，先制只免能量、不免 PP。
- **溢出伤害也算击杀**：用 <span style="color:#3aa675;font-weight:600">33</span> 伤打 <span style="color:#3aa675;font-weight:600">1</span> 血敌人照样触发回手+先制，不需要精准控血。所以残血敌人就是回手触发器。
- **悼会接管下回合**：带[悼](/mechanics/mourning.md)关键词，打出后下回合由瓦库按手牌顺序自动打出可打出的牌——每张牌先扣能量与 PP，资源不够就停，最多 <span style="color:#3aa675;font-weight:600">18</span> 张。瓦库会自动把衍生的鹏/鲲打出去继续循环，不需要你手动操作。但要规划好悼触发时的手牌内容，别让瓦库乱打。
- **核心矛盾：想击杀回手 vs 未击杀衍生翻倍**：击杀回手拿先制（即时收割，回手牌保持当前状态，附魔与升级都保留）；未击杀则衍生翻倍牌（延迟强化，但放抽牌堆顶要等下回合再抽）。两条路都赚——击杀是即时收益，未击杀是延迟强化。实战中通常第一发没杀掉反而不可怕，因为下回合抽到的是 <span style="color:#3aa675;font-weight:600">66</span> 伤的翻倍牌。
- **升级 +17 伤只强化本牌**：升级 <span style="color:#3aa675;font-weight:600">33</span>→<span style="color:#3aa675;font-weight:600">50</span>，提升本牌自己的击杀线。它**不会**把衍生鹏的 <span style="color:#3aa675;font-weight:600">66</span> 变成 <span style="color:#3aa675;font-weight:600">100</span>——衍生鹏始终是全新的未升级牌，带本能后仍是 <span style="color:#3aa675;font-weight:600">66</span>。想拿到 <span style="color:#3aa675;font-weight:600">100</span> 伤的翻倍牌，得单独给鹏升级。
- **性价比**：<span style="color:#3aa675;font-weight:600">3</span> 费 <span style="color:#3aa675;font-weight:600">33</span>（升级 <span style="color:#3aa675;font-weight:600">50</span>）伤，约合每费 11-17 伤，接近常规价，加上击杀回手 + 鲲鹏循环 + 翻倍衍生，收割收益明显偏强，但需要击杀或循环条件触发。
