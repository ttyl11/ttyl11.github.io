# 凝驻（NingZhu）

**凝驻**是赛尔（Seer）职业独有的稀有关键词，控制带有此关键词的牌在单场战斗内的循环行为。

## 规则说明

| 项目       | 说明                                                   |
| ---------- | ------------------------------------------------------ |
| 适用范围   | 仅赛尔角色牌                                                |
| 触发时机   | 普通洗牌时（每次弃牌堆洗回抽牌堆的操作）                          |
| 效果       | 带有凝驻的牌不参与本次洗牌，留在[弃牌堆](/mechanics/discard_pile.md)中不进入抽牌堆 |
| 战斗重置   | 每场新战斗开始时，凝驻牌正常进入抽牌堆，与常规牌无异                        |

**典型流程：**

1. **战斗开始**：凝驻牌随初始牌库正常洗入[抽牌堆](/mechanics/draw_pile.md)，可被正常抽取和使用。
2. **首次使用**：牌打出后伤害结算，进入弃牌堆。
3. **同场战斗后续洗牌**：下次弃牌堆洗回抽牌堆时，凝驻牌被排除在外，留在弃牌堆中。此后本场战斗内无论经过多少次洗牌，该牌都不会回到抽牌堆。
4. **下一场战斗开始**：该牌重新作为普通牌加入抽牌堆，可以再次被抽取和使用——**每场战斗独立计算，互不影响**。

关键细节：

- 战斗开始时的首次洗牌（初始洗库阶段）→ 直接跳过，凝驻牌正常进入抽牌堆
- 战斗中的普通洗牌 → 将带凝驻的牌从洗牌列表中移除，使其留在弃牌堆
- 不存在任何跨战斗的计数器或持久化状态；每场战斗结束后所有数据清空，下场战斗从零开始

## 实战影响

- 一张凝驻牌在单场战斗中最多只能使用 **一次**（第一次使用后留在弃牌堆，后续的洗牌都不会把它带回来）。
- 但可以通过遗物、能力等手段将牌从弃牌堆移回手牌或抽牌堆，从而在一场战斗中多次使用同一张凝驻牌。
- 凝驻牌本质上是"每场战斗限用一次"的控制手段，而非"永久消失"或"跨战斗冷却"。

## 与类似机制的区别

| 机制                  | 区别                                                                  |
| --------------------- | --------------------------------------------------------------------- |
| **消耗（Exhaust）**     | 消耗后牌移出本局所有区域，彻底离开本次旅程；凝驻仅限制当前战斗的循环，下场战斗自动恢复 |
| **毁灭（Destruction）** | 毁灭牌在使用时立即销毁；凝驻牌正常使用并在战斗结束后才暂停参与循环         |
| **保留（Retain）**      | 保留允许牌使用后留在手上；凝驻控制的是弃牌堆→抽牌堆的循环行为             |
| **陨（Fallen）**        | 陨触发牌堆变更时的形态转换；凝驻纯粹控制洗牌行为，不涉及形态变化            |
