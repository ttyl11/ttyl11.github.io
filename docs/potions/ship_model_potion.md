# 🚀 赛尔号模型

## 基本信息

- **分类**: 成长（删牌 / 卡组压缩）
- **稀有度**: 稀有
- **使用时机**: 自动触发（战斗胜利后）
- **目标**: 自身

### 数值参数

| 参数 | 数值 |
|---|---|
| 触发 | 战斗胜利后自动 |
| 删牌 | 每次选择 1 张删除（可取消） |
| 计数 | 累计 <span style="color:#3aa675;font-weight:600">5</span> 次后消失 |

## 描述

战斗胜利后，可选择一张牌**删除**。累计删除 5 张后此药水消失。

## 详细机制

- **自动触发、不可主动用**：使用按钮禁用，由药水在**战斗胜利后**弹出删牌选择界面。
- **自选一张删除**：从整副牌中选 1 张移出牌组，删牌选择界面**可取消**。
- **实际删除才计次（关键）**：只有真正删除一张牌计数才 +1（计数常驻持有）；若选择取消，不删、不计次、药水也不消耗。因此**永远不会浪费次数**。
- **消失条件**：累计实际删除满 5 次后本药水自动消失。

## 小贴士

- **与"赛尔绘"是鲜明对照**：赛尔绘"胜利即计次、作废也扣寿命"，赛尔号模型"真正删牌才计次、取消不算"——这瓶药是**你自己完全可控**的删牌权，心情不好时可无限观望，直到确实想删那一刻。
- **5 次自由删牌＝极强压缩**：相当于白送半套"瓶装删卡"，可以清诅咒、删状态垃圾、去掉成型后冗余的卡，分别治牌组的"肥、废、混"三大病。
- **前后期分梯次用**：早期先剔最废的诅咒/初始垃圾，留几次给牌组成型后出现的冗余/污染源，比一口气删完更划算。
- **自动弹窗不打断节奏**：胜利后自动弹出，想删就删、想关就关，绝不强制，是"收益零风险"的典型。
- **性价比**：稀有稀有度，净收益的删牌权，长期优化卡组厚度的价值极高。
