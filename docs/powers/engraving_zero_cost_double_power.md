# 省元

> **归属**：玩家可施加
> **施加来源**：刻印「先知之印」赐予（此后每场战斗开始时获得）

## 基本信息

- **类型**：中性（None）
- **叠加方式**：不叠加
- **可见**：是

## 描述

本场战斗中，你打出的[blue]0[/blue]费牌造成的伤害翻倍。

## 详细机制

- **0 费判定**：按结算时的实际耗能（含全部费用修正）= 0；X 费牌按打出的 X 值判定，X=0 也算 0 费。
- **生效范围**：只对造成者为自身、且伤害来源为该卡牌时生效，倍率 ×2。
- **不限制伤害类型**：该卡牌造成的伤害都翻倍。
