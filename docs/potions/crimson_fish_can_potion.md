# 🥫 绯红鱼罐头

## 基本信息

- **分类**: 元素变身 / 清理
- **稀有度**: 普通
- **使用时机**: 战斗内
- **目标**: 自身

## 描述

永久变[火系](/powers/fire_power.md)，选择抽牌堆中任意张牌直接消耗，并清空其 PP。

## 详细机制

- **永久变火系**：把自身属性永久设定为火系（跨战斗持续）。
- **选牌消耗**：从抽牌堆中选出任意张牌，直接[消耗](/mechanics/exhaust.md)（不打出），并为选中的 PP 卡清零 PP。
- **精准瘦身**：可一次处理多张，用于清理抽牌堆里不想再抽到的牌。

## 小贴士

- **"清抽牌堆"的定向纠结**：火系永久 + 自己挑抽牌,把不要的牌(状态牌/废卡)直接消耗掉,让后续抽牌质量大幅提升。这是把抽牌堆"净身"再进火系,战术意义比伤害更重。
- **永久火系的取舍**：火系在全克制里偏输出倾向,适合火伤/连击体系。但变系是永久的——选它意味着后面每一场都按火系结算,确认你的卡组吃火系加成再喝。
- **别只抠清牌价值**：清牌+清 PP 是附赠,真正的大头是"永久火系";若只为清牌,单独清牌手段可能更便宜。把它当"变身药水送一次抽牌堆整理"来评估。
- **与陷阱点**：清 PP 的牌会被一起消耗掉,等于主动放弃那几张某段时间的资源——搬走废牌是赚,搬走好牌（如高价值大招）反而亏,选牌时想清楚。
