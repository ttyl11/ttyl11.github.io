# 🧱 积木塔

## 基本信息

- **分类**: 资源（泰坦之灵）
- **稀有度**: 普通
- **使用时机**: 战斗内（被动累积 + 主动打出）
- **目标**: 自身

### 数值参数

| 参数 | 数值 |
|---|---|
| 累积速度 | 每个**我方回合开始** +<span style="color:#3aa675;font-weight:600">1</span> 块积木 |
| 清零 | 每场战斗开始时归零（单场累积） |
| 打出结算 | 获得泰坦之灵 = 当前积木数 |
| 目标 | 自身 |

## 描述

单场战斗中，每累计 <span style="color:#3aa675;font-weight:600">1</span> 个回合多 <span style="color:#3aa675;font-weight:600">1</span> 块积木，当前共 `{Bricks}` 块。打出时，获得等量[泰坦之灵](/mechanics/currency.md)。

## 详细机制

- **被动累积**：持有且在战斗内时，每个**我方回合开始**自动 +1 块积木（`AfterSideTurnStart`），无需任何操作。
- **首回合即有 1 块**：战斗开场我方回合开始立即 +1，因此首回合就已经有 1 块，不需要先"白等一回合"。
- **单场清零**：每场战斗开始时 `Bricks` 强制归零（`BeforeCombatStart`），避免药水留在腰带上跨战斗继续累加。
- **主动打出换资源**：点击使用后按当前积木数一次性转换为等量[泰坦之灵](/mechanics/currency.md)，同时消耗本药水。
- **泰坦之灵是持久局内货币**：写入局内货币系统，退出重进不丢失，是泰坦之灵房间等处的通用资源。

## 小贴士

- **本质是"你的回合数银行"**：它把"你在本场打了多少个我方回合"换算成泰坦之灵。越会拖、回合越多的战斗，打出时收益越高——精英 / Boss 慢节奏局是刷积木的最佳舞台。
- **纯白嫖累积**：挂着就涨、战斗结束前随时可转，不占用手法。真正要做的只是"在需要钱或战斗快结束时把它打掉"这一下。
- **拖回合与承伤的取舍**：想多攒就要多拖，而拖回合通常意味着多吃伤害。防御 / 控制 / 自恢复强的卡组有资本安全拖满全场，进攻型快攻卡组则更适合临近斩杀时顺带打出。
- **封顶就在一场**：因为每场清零，别抱着'留到下把更好'的念想——它只算本场回合数，该出手就出手。
- **性价比**：普通稀有度稳定的泰坦之灵来源，数量虽小却零成本，适合在需要局内货币时随手变现。
