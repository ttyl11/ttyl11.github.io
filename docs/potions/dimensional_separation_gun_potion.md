# 🌌 位面分离枪

## 基本信息

- **分类**: 地图
- **稀有度**: 罕见
- **使用时机**: 战斗外 / 被动
- **目标**: 自身

## 描述

拾起后的**下个房间**起，可进行 <span style="color:#3aa675;font-weight:600">1</span> 次[非相邻移动](/mechanics/game-flow.md)后消耗。

## 详细机制

- **纯被动药水**：不能主动饮用（使用按钮禁用），持有期间自动提供能力，避免白喝浪费。
- **拾起当房不可用**：拾起的当前房间内不允许使用跳跃。
- **下个房间起开放**：进入拾起后的下一个房间后，才开放"地图自由跳跃"能力。
- **一次非相邻跳跃**：开放后，真正从当前节点跳到**非相邻**节点（跨过路径直接到达）即消耗这一瓶药水，能力随之消失。
- **相邻移动不消耗**：正常沿路径移动到相邻节点不触发消耗，药水保留继续生效。
- **对应移动视作跳跃**：非相邻移动等价于原版"自由旅行"（`ShouldAllowFreeTravel`），只是原版该能力被本药水接管并限制为一次。

## 小贴士

- **战略绕路**：一条跳过多余节点直取关键房（商店/事件/精英），节省体力与资源。
- **把握好消耗时机**：只有真正跳非相邻才消耗，若不急着绕远，可挂在栏里留作应急。
- **性价比**：罕见稀有度，提供整局一次的自由跳跃，关键时刻价值很高。
