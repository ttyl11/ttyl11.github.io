# 🌑 黑色暮光

## 基本信息

- **分类**: 异常状态
- **稀有度**: 普通
- **使用时机**: 战斗内
- **目标**: 全体敌人

### 数值参数

| 参数 | 数值 |
|---|---|
| 持续回合 | 2 |

## 描述

所有敌人获得 <span style="color:#3aa675;font-weight:600">2</span> 回合的[束缚](/powers/constrict_power.md)、[害怕](/powers/fear_power.md)和[诅咒](/powers/curse_power.md)。

## 详细机制

- **目标范围**：遍历当前所有可攻击敌人，逐一施加，无需选择目标。
- **三重异常同步铺场**：每个敌人同时获得束缚、害怕、诅咒 3 种异常状态，各持续 2 回合。
- **束缚**：封锁被施加者**获取先制**的能力，且回合末 -1 层。注意它只拦"获得"，不消除已存在的先制。
- **害怕**：被施加者造成的**攻击伤害 -30%**（×0.7），回合末 -1 层。
- **诅咒**：对怪物同时带来攻击伤害 -10% + 回合末受 <span style="color:#3aa675;font-weight:600">3</span>–<span style="color:#3aa675;font-weight:600">50</span> 随机不可格挡伤害（50%→3、40%→5、9%→8、1%→50，每层期望约 4.7 伤害），回合末 -1 层。
- **SS 型异常**：三者均为异常状态，可被异常免疫·反弹等能力免疫或反弹。

## 小贴士

- **一条把"攻击怪"压到哑火的套装**：害怕 -30%、诅咒 -10% 攻击相乘后约 -37% 攻击；再叠束缚封死其先制，等于专门针对高攻/先手怪的一瓶"封攻打"。2 回合内敌人的输出被压掉接近四成。
- **别小看诅咒的随机伤**：虽然单层期望只有约 4.7 伤害/回合，但对全体 2 回合就是纯白嫖的血线消耗，且 1% 爆 50 面对多怪时偶尔能直接送走脆皮。当作"附赠的彩票"即可，别指望稳定斩。
- **对"先制型"敌人有奇效**：遇到靠先制抢回合、叠先制打爆发的敌人，束缚能直接掐断其先制来源；配合害怕减攻等于双重压制。但对不吃先制的怪，束缚这半边几乎无用。
- **2 回合窗口怎么看**：害怕/诅咒/束缚都是回合计时递减型，2 回合是它们的全部寿命。适合在敌人即将爆发的前 1 回合打出，让减攻覆盖到最疼的那一拳。
- **局限**：三异常都不造成即时伤害（诅咒伤随机且不可控），对已进入斩杀线、急于收尾的战斗收益一般——这种时候不如换一瓶能直接打输出的药。
