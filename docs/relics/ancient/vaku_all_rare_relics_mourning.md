# 僭越者神枢

<img src="/images/relics/vaku_all_rare_relics_mourning.png" alt="僭越者神枢" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 先古

## 描述

拾起时，获得所有Seer<span style="color:#d4a017;font-weight:600">传说遗物</span>。战斗中，瓦库将全程接管你的回合，自动打出卡牌。

- **传说遗物发放**：拾起时一次性获得所有赛尔[传说遗物](/mechanics/custom-rarity.md)，已拥有的跳过，不占常规掉落槽位。
- **瓦库接管**：每个你的回合开始时，瓦库循环打出手中第一张可打出的牌，最多打 <span style="color:#3aa675;font-weight:600">18</span> 张，直到手牌无可打出、能量/PP 不足、战斗结束或你主动按下结束回合；之后剩余手牌仍由你自己打出。
- **自动打出要付资源**：每张牌打出前都会先支付费用，**真实消耗能量与 PP**——不是免费倾泻。资源耗尽后即使手里还有可打牌也会停下。

<span style="color:#d44;font-weight:600">瓦库全权接管。</span>

## 小贴士

- **全传说遗物加身**：一次性获得所有赛尔[传说遗物](/mechanics/custom-rarity.md)，是整个 mod 里最夸张的即时收益。传说遗物本就该改变命运，全部集齐基本等于提前通关。
- **瓦库替你打牌**：每回合瓦库会先按顺序打出手中可打出的牌（最多 18 张），你无法选择出牌顺序、目标与留牌。敌方牌打第一个敌人，友方牌随机选队友，自身牌打自己。
- **出牌权被抢先**：瓦库只认"第一张可打出"，不懂连招也不懂留 PP。依赖出牌顺序、目标选择或关键牌留手的组合技牌组会被它拆散。
- **可主动叫停**：按下结束回合能让瓦库提前收手，想保留某些牌时这是唯一的干预手段。
- **最佳适配**：简单直接的伤害/格挡牌组最契合——但瓦库会真实花掉能量与 PP，还可能把资源倾泻在低价值的第一张牌上；它不理解“留费给关键牌”。带[悼](/mechanics/mourning.md)关键词的牌本就由瓦库接管，与这件遗物天然联动。
- **性价比**：全传说遗物的收益远超任何代价，自动打牌的失控感更多是体验问题而非强度问题。拿到后基本可以躺赢，但若想精打细算每张牌它会让你抓狂。
