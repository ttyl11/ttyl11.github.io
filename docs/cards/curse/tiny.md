# 渺小

## 基本信息

- **分类**: 诅咒牌
- **类型**: 诅咒
- **稀有度**: 诅咒
- **关键词**: [不可打出](/mechanics/unplayable.md)
- **可升级**: 是（最高 99 级）

### 数值参数

| 参数 | 数值 | 升级后 |
|---|---|---|
| 每张每次打出受到的固定伤害 | 3 | 每级 +1 |

## 描述

此牌在[手牌](/mechanics/hand.md)中时，每打出一张牌受到 <span style="color:#3aa675;font-weight:600">3</span> 点[固定伤害](/mechanics/fixed-damage.md)。

## 升级后

此牌在<span style="color:#d4a017;font-weight:600">手牌</span>中时，每打出一张牌受到<span style="color:#3aa675;font-weight:600">4</span>点<span style="color:#d4a017;font-weight:600">固定伤害</span>。

## 小贴士

- **它是"出牌节奏税"**：只要渺小在手，你每打出一张牌，手牌里**每张**渺小就各算一次伤害、合计施加。**你打得越多、越快，罚得越狠**——快攻、连击、铺场流是天敌，慢速控制流几乎无感。
- **是"固定伤害"，不能格挡、也不立即结算**：它以下[固定伤害](/mechanics/fixed-damage.md)形式施加——不吃格挡 / 力量 / 虚弱 / 易伤，而且**要等你下回合开始才真正扣血**（血条上会出现粉橙色预扣段）。能被[免疫固定伤害](/powers/immune_fixed_damage_power.md)类效果拦下或反弹。
- **对策只有两条**：①**当回合少出牌**——只打关键牌，把节奏压下来；②**提前用消耗 / 变牌把渺小移出手牌**（它一离开手牌，后续出牌就不再计费；但已经挂上的固伤照扣，所以清牌要趁早）。
- **多张叠加**：手握 2 张渺小，惩罚直接翻倍——抽到多张时要优先处理。
- **重放只收一次税**：同一张牌一次打出后被连续重放（如某些"额外重放"效果），只在最后一次结算一次，重放不会让渺小多扣。
- **警惕升级**：它是 mod 里能升到高等级的诅咒之一（另一张是[保底](/cards/curse/guaranteed.md)，同样最高 99 级），每级 +1。任何"升级手牌"的效果砸到它都会让惩罚永久膨胀——**别给渺小升级**。
- **性价比**：无费不可打出。它按出牌张数收费，**优先级取决于你的构筑节奏**：快攻流必须优先清，慢速流可以放到最后。
