# 封属

> **归属**：玩家施加给敌方
> **施加来源**：玩家获得——封印/控制类卡牌与药水（如[星能药水](/potions/star_energy_potion.md)）
> **叠加方式**：按层数叠加
> **可见**：否（效果由意图图标显示）

## 描述

非攻击意图无效。
回合结束时移除此能力。

## 详细机制

- **只废非攻击部分**：目标本回合的增益、防御、治疗、召唤、上状态等非攻击效果全部失效；攻击伤害照常。
- **纯非攻击行动整体跳过**：若该敌人本回合只有非攻击意图，则整个行动不执行。
- **seer 怪物走执行器**：mod 怪物由专门执行器逐个子行动跳过非攻击，不会误伤攻击子行动附带的增益。
- **敌方回合结束移除**：只影响目标这一个回合，之后自动消失。
- **隐藏图标**：能力本身不显示，玩家看到的是敌人意图上的封属标记。
