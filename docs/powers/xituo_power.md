# 焚天

> **归属**：怪物专属（玩家无法施加）
> **施加来源**：怪物自带——[希拓](/monsters/elite/xituo_monster.md)（常驻被动）

## 基本信息

- **类型**: 中性（None，怪物开局被动）
- **叠加方式**: 单例（不可叠加）
- **可见**: 是

## 描述

①处于[red]烧伤[/red]的敌人，其攻击伤害降低，降低值等于其[red]烧伤[/red]层数。
②自身回合开始时吸取生命，回复量等于所有敌人[red]烧伤[/red]层数之和。

## 详细机制

- **烧伤压制**：任意处于烧伤的敌方单位造成**攻击伤害**时，伤害先减去其烧伤层数（加法修正，最低归 0）；非攻击伤害不受影响。
- **回合吸血**：希拓自己的回合开始时，回复量 = 所有存活敌人烧伤层数之和；没有烧伤则不回复。
- **隐藏禁疗**：处于烧伤的敌方单位在希拓存活时**无法恢复生命**——治疗量直接被拦截（该条未写进能力悬浮描述，但实际生效）。
- **层数越多越痛**：烧伤既是持续伤害，又同时削弱该单位的攻击、给希拓回血，还能禁疗，是希拓体系的核心。

## 小贴士

- **先清烧伤再回血**：带着烧伤时治疗无效，想靠回血续航必须先去除自身烧伤。
- **高烧伤=高惩罚**：烧伤层数越高，攻击削得越狠、希拓回得越多，别在希拓面前无脑叠烧伤。
