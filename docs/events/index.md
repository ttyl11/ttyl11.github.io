# 事件图鉴

Seer Mod 为尖塔新增了 34 个专属事件，涵盖剧情抉择、功能服务、职业导师与特殊商店四大类。事件是跑局中获取卡牌、遗物、[赛尔豆与泰坦之灵](/mechanics/currency.md)、[永久属性](/mechanics/permanent-bonus.md)的重要渠道。

本页按**事件允许出现的层数**排列（以源码判定为准）。第一层为密林 / 暗港，第二层为巢穴，第三层为荣耀，第四层为星海尽头，第五层为终焉之门。

> 第四、五层的事件池 = **原版四幕全部事件 + 除特殊事件与有条件事件外的全部赛尔事件**，详见[第四幕与第五幕](/mechanics/act-four-five.md)。所以层数栏里带 4、5 的赛尔事件，在这两幕都会出现；特殊商店与志旭之战不进随机池，「！？商店？！」因金币条件只在前三层出现。
