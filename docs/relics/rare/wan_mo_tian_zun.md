# 万魔天尊

<img src="/images/relics/seer_wan_mo_tian_zun.png" alt="万魔天尊" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物
- **稀有度**: 稀有

### 数值参数

| 参数 | 数值 |
|---|---|
| 差值 X | 右键时最大生命 - 当前生命 |
| 每次召唤量 | X（奥斯提 HP） |
| 每次堕落 | X |
| 进化阈值 | 累计召唤 300 |
| 手动次数 | 仅 1 次 |

## 描述

①战斗中右键：将[gold]最大生命[/gold]设为[gold]当前生命[/gold]，差值为[blue]X[/blue]（仅一次）。②此后本局每场战斗开始，召唤[blue]X[/blue]并[red]堕落[/red][blue]X[/blue]。③累计召唤[blue]300[/blue]后，变为[gold]无上魔尊[/gold]。

## 详细机制

- **右键触发一次，改动不可逆**：只在战斗内可右键。右键后**最大生命直接降为当前生命**（剩余生命上限被"砍"掉一截），并记录差值 X = 原最大生命 - 当前生命。若满血时右键，X=0，遗物基本不生效——**要在残血时右键才划算**。
- **X 是全游戏固定值**：X 只记录右键那一刻的差值，之后不再变化；每场战斗开始召唤的奥斯提和获得的堕落都是同一个 X。
- **召唤的是奥斯提（Osty）**：每场战斗开始时用 `OstyCmd.Summon` 召唤一只 HP=X 的奥斯提（与我方同阵营的宠物单位）。若上一只奥斯提还活着，召唤会改为给其 +X 最大生命。
- **堕落 X 与魔君体系联动**：每场战斗开始获得 X 层[堕落](/powers/fallen_power.md)，堕落每满 100 会触发混沌化身/魔君接管（[堕落](/powers/fallen_power.md)能力页）。堕落层数会随着战斗越叠越深，注意别把自己"堕落"到被崩溃。
- **进化看的是玩家累计召唤总量**：激活后，**任何来源的召唤**（本遗物每场战斗开始召唤的 X、宿主岩受伤召唤、咕噜咕王充能球召唤、蓓丽安特/混元天尊等其它召唤遗物、召唤类卡牌）都会累加进"累计召唤"计数，累计 ≥ 300 时遗物自动替换为[无上魔尊](/relics/epic/wu_shang_mo_tsun.md)（X 越大、其它召唤来源越多，进化越快）。**遗物图标角标会实时显示当前累计召唤量**，方便随时查看到 300 的进度。
- **X 与"变身后"的收益是同一笔资源**：右键相当于"用当前生命上限换召唤物+堕落进度"，进化成无上魔尊后，此前获得的召唤物/堕落不会被回收——进化只替换遗物本身。

## 小贴士

- **残血时再右键**：X = 最大生命 - 当前生命，血越残 X 越大。想速刷进化就在残血瞬间右键（如休息点后、战斗开始时），把一管血的上限换成几十点召唤进度。
- **高 X 一两次战斗就进化**：若残血 X≥150，第一场战斗召唤 150，累计 150；第二场战斗再召唤 150（累计 300）即触发进化，两场就变无上魔尊。
- **堕落是双刃**：每场 +X 堕落，低层数无害，但层数逼近 100 的倍数会被[魔君接管](/powers/demon_takeover_power.md)拖进失控节奏——要多带可消耗堕落的卡来对冲。
- **右键时机最好在"不再需要满血上限"之后**：最大生命降为当前生命是不可逆的（本局不会再涨回），会在剩下所有战斗里少一截血上限。取舍是"当前战力强化" vs"长期血线"。
- **性价比**：这一环是进化链的"启动器"，实际价值在你把它喂成无上魔尊后才完全兑现——稀有度合理，单看右键降上限略有代价，建议想走魔尊体系的玩家拿到后尽早找机会使用。
