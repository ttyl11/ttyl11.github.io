# 免控（MianKong）

**免控**是 Seer Mod 的自定义卡牌关键词，持有者免疫[异常状态](/mechanics/abnormal-status.md)。

## 基本信息

| 项目 | 说明 |
| --- | --- |
| 类型 | Mod 卡牌关键词（免疫型） |
| 效果 | 免疫异常状态 |
| 适用 | 卡面缩写术语，配合具体回合数出现 |

## 规则说明

- **免疫异常状态**：持有此关键词的角色不会获得异常状态（烧伤/中毒/石化/睡眠等 26 种异常状态均免疫）
- 描写面常见写法为"免控 X"（X 为回合数），效果对应本场战斗免疫异常状态 X 回合（或按描述中的具体层数计）
- 与「免疫异常」的区别：免控是关键词防盾，免疫的是整个异常状态体系，不针对单一来源
