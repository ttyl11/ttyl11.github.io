# 归源（XuPP）

**归源**是 Seer Mod 的自定义卡牌关键词，触发后所有卡牌 PP 回满。

## 基本信息

| 项目 | 说明 |
| --- | --- |
| 类型 | Mod 卡牌关键词（资源回复型） |
| 效果 | 所有卡牌 PP 回满 |
| 适用 | 卡面缩写术语 |

## 规则说明

- **PP 回满**：全场所有带 [PP](/mechanics/pp-system.md) 的卡牌 PP 补满（手牌/抽牌堆/弃牌堆中的 PP 卡一并回满）
- 一次性资源拉满，适合连续打出高 PP 消耗牌的关键回合
- 与 [PP药水](/potions/pp_potion.md)效果一致，但作为关键词挂在卡上触发时机更灵活
