# 鬼焰神君·陆逊

## 基本信息

* **分类**: 先古遗物（通用池）

* **费用**: 0

* **稀有度**: 先古（史诗品质）

## 效果

① 拾起时：选择三张牌获得[连营](/mechanics/lian_ying.md)。

② 每次精英战斗结束后：随机1张牌获得[连营](/mechanics/lian_ying.md)。

③ 持有本遗物时：[连营](/mechanics/lian_ying.md)牌打出后不进入[销毁牌堆](/mechanics/exhaust.md)，而是进入[弃牌堆](/mechanics/discard_pile.md)。

## 小贴士

* **① 拾起时选三张**：获得遗物的瞬间弹出选牌界面，从当前牌组选三张牌赋予[连营](/mechanics/lian_ying.md)关键词。建议优先选择高费牌——连营触发后所有连营牌会免费自动打出，高费牌一次打出多张收益远超低费牌。也可搭配自带抽牌/过牌能力的牌，扩大连营触发的连锁反应。

* **② 精英战后随机补充**：每场精英战斗结束后，系统从尚未获得连营的牌中随机选一张赋予连营。这是"随机"而非自选——如果想精准控制哪些牌获得连营，应在①阶段选好。

* **③ 连营进弃牌堆而非销毁堆**：无本遗物时，连营牌被打出后进入销毁牌堆（后续回合无法再次使用）；持有本遗物后，连营牌改为进入弃牌堆，可再次被抽到并触发连营，形成持续循环。

* **①与③的联动**：①阶段选好的三张连营牌是最稳定的核心——它们参与连营且进入弃牌堆而非销毁堆，可以在后续回合中反复被抽到。配合②的持续补充，可以逐步将整副牌都转化为连营牌，实现"越打越多、打完还能洗回来"的滚雪球效果。

* **连营的触发机制**：打出任意一张[连营](/mechanics/lian_ying.md)牌时，关键词效果自动从**手牌、抽牌堆、弃牌堆**中收集所有其他连营牌，并一次性自动打出。若已持有本遗物，这些自动打出的牌会进入[弃牌堆](/mechanics/discard_pile.md)而非[销毁牌堆](/mechanics/exhaust.md)，可被再次抽到循环触发；若无本遗物，则连营触发牌本身连同所有其他连营牌一起移入销毁牌堆（整回合用光）。一回合内一张连营牌即可清空整个牌组的所有连营牌。

* **牌数不足时的降级行为**：若牌组中可用于选择的牌不足三张（拾起时），则只会给所有可用牌添加连营；精英战后若没有未获得连营的牌可选，则不会触发②。若触发连营时已持有遗物但牌组中不存在其他连营牌，则不执行任何操作（无浪费）。
