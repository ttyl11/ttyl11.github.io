# 🗺️ 一副涂鸦

## 基本信息

- **分类**: 地图
- **稀有度**: 稀有
- **使用时机**: 战斗外（先古之民节点）
- **目标**: 自身

## 描述

重置当前章节的整张[主地图](/mechanics/ancients.md)，重新洗牌所有路径与遭遇。

仅可在[先古之民](/mechanics/ancients.md)地图节点处、**战斗外**使用。

## 详细机制

- **使用条件**：只能在先古之民地图节点处、且非战斗状态下点击使用，其他节点/战斗中不可用。
- **重置整章地图**：用独立 RNG 重新生成当前章节的完整地图，路径与遭遇（含 Boss）全部重掷，每次得到不同布局。
- **使用后自动刷新**：使用后自动重掷地图并重新打开地图界面，立刻看到新布局。
- **洗牌不掉进度**：仅重排路线与遭遇，已获得的牌组/遗物/资源不受影响，之前的移动记录按需清理。

## 小贴士

- **避开糟糕路线**：当前章节路线太差（连续精英/死亡路线）时，用它可以洗出一张更优地图。
- **先古节点才有**：需要在先古之民节点使用，规划行程时留意是否顺路经过此类节点。
- **稀有且条件苛刻**：稀有稀有度 + 节点限制，属于"洗白重来"的战术型道具，关键时刻价值极高。
