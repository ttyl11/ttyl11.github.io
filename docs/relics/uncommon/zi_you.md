# 紫幽

<img src="/images/relics/seer_zi_you.png" alt="紫幽" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **分类**: 非塔罗遗物

- **稀有度**: 罕见

### 数值参数

| 参数     | 数值        |
| ------ | --------- |
| 初始提升   | 全属性 +5    |
| 每回合衰减  | 全属性 -1    |
| 归零回合   | 第 5 回合    |

## 描述

[战斗开始](/mechanics/game-flow)时，自身[全属性](/mechanics/all_attributes) + <span style="color:#3aa675;font-weight:600">5</span>。每[回合开始](/mechanics/game-flow)时，自身[全属性](/mechanics/all_attributes) - <span style="color:#3aa675;font-weight:600">1</span>。

- **全属性**：力量、防御、命中、速度四项一起变化。
- **衰减不可逆**：每回合四项各 -1，第 5 回合起由增益转为负层（按各属性负效果结算）。

## 小贴士

- **巅峰就在进战那一刻，第一回合已经开始跌**：战斗开始瞬间全属性 +5 是峰值，随后每个回合开始 -1——首回合实际只吃到 +4。但前几回合一上来就力量撑攻击、防御减受伤、速度多抽牌，压制力依然极强，是罕见遗物里少见的"开局就硬好几个身位"的类型。

- **核心矛盾：它逼你在热度没过之前结束战斗**：每回合四项都 -1，拖到第 5 回合 +5 归零后开始反向削弱。它明摆着是"速战速决"型遗物，跟拖字诀卡组相性很差——打得越久，这件遗物就从帮手变成累赘。

- **负层数按各属性负效果结算，不是简单白板**：归零之后力量减攻击、防御反过来增加受到的攻击伤害、命中每负层有概率未命中、速度少抽牌——拖到后期会四项同时拖你后腿，所以别把它当永久增益养。

- **四项 +5 里真正立刻生效没那么满**：命中正层自身没有直接增益（只用来抵消负命中），速度是每 2 层 +1 抽牌（约 +2 抽），真正即时的硬提升是力量加攻击和防御减受伤。但即便只看这两项，前几回合也够猛。

- **性价比**：罕见，第一回合白送全属性 +5，前几回合接近"增伤 + 减伤 + 抽牌"全包；只要不拖到第 5 回合后就是纯赚，适合爆发快、回合短的卡组。
