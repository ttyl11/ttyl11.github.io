# 黄色龙鳞

> **归属**：玩家可施加
> **施加来源**：玩家获得——[武心婵](/relics/legendary/wu_xin_chan.md)（遗物，战斗开始时赋予）

<img src="/images/powers/yellow_dragon_scale_power.png" alt="黄色龙鳞" style="max-width:300px;border-radius:8px;box-shadow:0 2px 8px rgba(0,0,0,0.15)" />

## 基本信息

- **类型**: 增益（Buff）
- **叠加方式**: 单例（触发即消失）
- **可见**: 是

## 描述

①免疫[red]异常状态[/red]。
②触发免疫时移除对手基础属性提升，然后自身消失。

## 数值

| 参数 | 数值 |
|---|---|
| 免疫类型 | 异常状态 |
| 触发后效果 | 移除对手基础属性提升 |
| 基础属性范围 | 力量、命中、防御、速度 |
| 持续 | 存在期间持续免疫，触发后消失 |

## 详细机制

- **异常免疫**：任何异常状态施加到持有者身上时被完全拦截——不获得层数，也不触发"受异常"类联动。
- **反击削属性**：触发免疫后，对所有对手**正向**的力量/命中/防御/速度层数清零；负值不受影响。
- **一次性**：反击结算后立即移除自身，只挡一次异常。
- **与红/黄/蓝三色鳞片的关系**：三色龙鳞由武心婵遗物在战斗开始时各给 1 层，且每 2 回合会随机移除其中一枚；三枚全部消失后才补上[白色龙鳞](/powers/white_dragon_scale_power.md)。

## 小贴士

- **挡关键异常**：留着它挡睡眠/石化/沉默这类致命异常，比被普通小异常骗掉更划算。
- **触发即扒属性**：对手身上堆的力量/命中/防御/速度会被一次清空，对依赖属性增益的敌人很致命。
